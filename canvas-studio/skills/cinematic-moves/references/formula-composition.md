# 万能公式填空组合

自定义运镜的组合公式：从词库中各选 1-2 个，填入公式即可生成新运镜。

---

## 万能公式

```
运镜描述 = 镜头运动 + 摄影机角度 + 人物动作 + 环境变化 + 光影氛围 + 画面质感
```

**四大原则**：
1. 人物情绪越强，镜头越近（愤怒/流泪/震惊 → 特写 + 推镜）
2. 场面越大，镜头越拉远（战场/宫殿/云海/城市 → 全景 + 升降 + 俯冲）
3. 动作越快，镜头越要有方向（冲刺/挥剑/闪避 → 镜头跟着人物动作走）
4. 转场不乱用（同场景直接切；换场景用穿越/甩镜/叠化）

## 组合示例

### 示例1：人物出场（平静）
- 运镜：推镜（缓慢）
- 角度：平视
- 动作：静立
- 环境：山巅云海
- 光影：体积光
- 质感：电影级

**组合结果**：镜头缓慢向前推进，平视推进，人物静立于山巅云海，体积光洒落，电影质感

### 示例2：打斗高潮（激烈）
- 运镜：环绕（360度）
- 角度：仰拍
- 动作：挥剑
- 环境：废墟战场
- 光影：逆光剪影
- 质感：电影级

**组合结果**：摄影机360度环绕双方战斗，仰拍强化力量感，挥剑动作连续衔接，废墟战场逆光剪影，电影质感

### 示例3：心理戏（细腻）
- 运镜：推镜（缓慢）
- 角度：特写
- 动作：流泪
- 环境：窗边
- 光影：侧光勾边
- 质感：电影级

**组合结果**：镜头缓慢推近至人物眼睛，突出瞳孔反光与泪水滑落，窗边侧光勾边，电影质感

## 视觉同源不撞款技巧

**核心原则**：画风、光影、质感锁死不动，只轮换镜头运动、角度、节奏、环境这四样。

**操作方法**：
1. 确定画风（如国风/赛博/写实）
2. 确定光影基调（如暖色/冷色/逆光）
3. 确定质感（如电影级/动画/写实）
4. 轮换以下四维之一：
   - 镜头运动（推镜→环绕→航拍）
   - 角度（平视→仰拍→俯拍）
   - 节奏（慢→快→冻结）
   - 环境（云海→雨夜→宫殿）

**效果**：视觉统一、镜头全新，既统一又不撞款。
