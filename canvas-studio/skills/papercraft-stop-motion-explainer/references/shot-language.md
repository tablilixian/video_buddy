# 分册：分镜 · 节奏 · 镜头 · 转场（papercraft-stop-motion-explainer）

> 何时读：写分镜表、定编辑节奏、选运镜、选转场时。
> 分镜表落地与节拍纪律以 `canvas-studio-creation` 为准；本册只给本风格的分镜列与镜头语言。

## 1. 分镜表

- 文字保持紧凑，不要在表格单元格里写长段落。
- 只为选定时长提供必要的镜头数。
- 15s：通常 4 镜；30s：通常 5-6 镜；60s：通常 7-9 镜。
- 每镜只解释一个知识节拍。

必需列：

- 时间
- 知识节拍
- 视觉动作
- 纸张运动
- 机位 / 转场
- 声音线索

分镜前先给一段简短的内容概览：一句视频前提、目标时长与画幅、视觉主结构、知识路径（钩子 → 解释 → 例子或文化连接 → 记忆句）。

## 2. 编辑节奏

按时长与讲解清晰度定节奏：

- 15s：4-6 镜，快但可读，每镜 2-4 秒。
- 30s：6-8 镜，每镜 3-5 秒。
- 60s：8-12 镜，每镜 4-7 秒。
- 标签卡出现时短暂停顿。
- 观众还没看懂纸机构之前不要切。
- 用有节奏的纸张运动，而不是激进的数字剪辑。

## 3. 镜头规则

用"像拍一个微缩纸舞台"的运镜。

推荐：

- 缓慢推进进入纸世界。
- 带多平面视差的横移。
- 主持人讲解的固定中景。
- 纸纹理与关键道具的微距特写。
- 剖面图的轻微俯视角度。
- 进入内部结构时的穿层。

避免：

- 高速飞镜头。
- 除非布景专门为此搭建，否则不要 360 度环绕。
- 数字故障运动。
- 液态变形。
- 超写实 CG 运镜行为。

## 4. 转场

使用服从纸物理的转场。

推荐：翻页 / 立体书展开 / 拉片滑动 / 纸质标签擦除 / 纸云掠过 / 圆形纸遮罩 / 剪纸门开启 / 剖面分层 / 纸屑迸发 / 胶带或贴纸揭示。

避免电子扫描线、霓虹故障、玻璃碎裂、金属擦除与科幻粒子转场——除非用户明确要求反差效果。
