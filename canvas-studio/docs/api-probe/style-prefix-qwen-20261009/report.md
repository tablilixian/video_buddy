# 风格前缀出图差异探针（V1）

- 固定用户提示词：`一位少女站在长安城楼上，远处是连绵的山脊与晨雾`
- 重复次数：1
- 端点：POST http://117.50.108.73:8082/api/v1/generate/txt2image（1280×736）
- 成功 3 / 失败 0

> **机器只负责产出可比对的图，不判定优劣。** 风格差异是否肉眼可辨、
> 哪条前缀真的生效，交给人工看图判断。

## 用例与产物

| # | 风格 | 前缀字数 | 耗时 | 产物 |
| --- | --- | --- | --- | --- |
