# 分册：素材与生产简报（minimalist-product-ad-generator）

> 何时读：清点素材、判定素材是否可用、产出产品事实摘要、组装生产简报、决定多变体策略时。
> 流程推进与审批以 `canvas-studio-creation` 为准；本册只给该风格的素材要求与简报字段。

## 1. 开拍前必须拿到的生产事实（一次问全）

风格要求一次问齐这几项，缺项按下面的默认值补齐并在结果里回显已采纳的值：

1. **产品图与相关素材**：产品照片、包装图、渲染图、细节图、已有视频素材、视觉参考。
   - 当前消息或画布已有素材时直接声明"已检测到素材"，不要重复索要，只确认是否沿用。
   - 有多份候选且角色不明时，问哪一份是主图。
2. **产品变体状态**：单一变体还是多变体/多色/多型号；多变体时确认主变体。用户不指定时可按产品图推荐一个，但分镜里仍要写出具体颜色或型号名。
3. **目标时长**：5s / 10s / 15s，默认推荐 10s。
4. **画幅比例**：16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 跟随参考图。选定后锚点照、视频、终版交付全程严格保持该比例。
5. **苹果风模板**：白科技 / 暗轮廓光 / 品牌色场 / 明亮生活场景。
6. **画面内文案**：用户提供，或由 agent 生成苹果风英文文案。
7. **视频模型**：本项目没有可选视频模型，固定 MiniMax-H3（H3 常常给出更干净的苹果式产品特写、留白与高级产品片运镜）。**不把模型作为提问项**；若 H3 失败，重试或放宽要求，不换模型。

## 2. 素材检查与产品事实摘要

无产品素材时先请用户上传。已有素材则分析并输出简短产品事实摘要：

- 产品品类。
- 主体位置与画面占比。
- 画质：锐度、光线、构图、可见细节。
- 产品主色与可能的主变体。
- 可展示结构：开合、旋转、抬起、吸附、折叠、弹出、发光、屏幕、纹理等。
- 可用于分镜的真实外观特征：材质、边缘、按键、接口、包装、透明件、屏幕、独特剪影。

画质不可用时停下并给出具体的补拍建议，不要硬着头皮往下做。

产品事实摘要输出项：所用材质 / 产品品类 / 主色候选与主变体建议 / 画质通过与否 / 可展示结构或特性。

## 3. 生产简报字段

把上面确认的结果转成可执行简报，不要重复追问已确认项。必含字段：

- 所用产品素材。
- 主变体 / 产品主色。
- 画幅比例。
- 目标时长。
- 选定的苹果风模板。
- 单一变体 / 多变体策略。
- 画面内文案模式：用户提供，或 agent 生成苹果风英文文案。

## 4. 多变体产品规则

- 用户选风格，**不要**自动把其他变体全删掉。
- 每个多变体项目必须先定一个主变体。
- 其他变体不要在开场就全部出现，只在过程节拍、转场或终版全系列里出现。
- 用户不定主变体时，可选视觉最稳的一个当主角，其余用于节奏与层次。
- 避免电商矩阵、九宫格、堆叠、散落铺排、全部颜色平铺、满屏产品墙。

## 5. 简报驱动什么

简报驱动叙事骨架、文案、锚点照与节拍分镜表——这四项都从简报取值，不要各自另起一套设定。
