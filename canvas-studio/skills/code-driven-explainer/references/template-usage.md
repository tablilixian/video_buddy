# 模板通道（用模板出片，而不是从零编排）

> 这是**入口文档**：什么时候用模板、怎么选、怎么填、失败怎么办。
> 槽位字段的完整语义在模板自己的 `slots.json` 里（`scaffold_manifest({ templateId, dryRun: true })` 可直接看）。

## 0. 一条不变的链路

```
list_templates（挑模板）
      ↓
scaffold_manifest({ templateId, slots, writeTo: "build/manifest.json" })
      ↓            ← 回执里的「配乐位」：模板只声明要什么曲子，不自带音频
（要 BGM 时）生成一条 ≥ 模板时长的纯器乐 → scaffold_manifest({ …, bgmUrl }) 重编（覆盖同一文件）
      ↓
render_composition({ manifestPath })        ← 唯一出片口
```

**没有** `render_composition({ templateId })` —— 模板产出的 manifest 是**普通文件**，
你可以继续加轨、改配色、换文案。模板是起点，不是终点。

工具预算：**≤3 次**（不含配乐）；模板带配乐位时 **+2 次**（生成 + 重编）。
这 +2 次比「渲完发现没声音 → `node -e` 手改 JSON」便宜，也不会丢掉模板建议的音量与淡出。
不配乐也能出片，但回复里必须说明「本条未配乐」。
需要看槽位全文时把第 2 步换成 `dryRun: true`（仍是 3 次）。

## 1. 什么时候该用模板

用模板的前提是**效果已经被验过**：版式、时序、构件、音效都固化在模板里，你只换内容。
所以判断标准不是「像不像」，而是**这份内容装不装得下**：

| 情况 | 做法 |
|---|---|
| 体裁匹配 + 条目数 ≤ 模板卡片位 + 内容填充率 ≥ 35% | **用模板** |
| 用户列举的条目数 > 模板卡片位 | 不用（第 4 条起会被静默丢弃）；提示合并，或自由编排 |
| 用户只给一句话 | 不用（其余槽位只能编造）；先补素材，或自由编排 |
| 需要配图 / 图表 / 长字幕 | 不用（模板不提供这些轨） |
| 用户点名要某个模板 | 用（用户的话就是明确选择） |

**恰好 1 个模板通过五条判据**才可以自主选；**0 个**走自由编排；**≥2 个**把候选
（名称 + 一句话差异）列给用户选 —— 不要自己拍，模型的偏好不可复现。

## 2. 五条判据（`list_templates({ requirements })` 会机器判）

传 `requirements` 就会逐条给 ✅/❌，不用自己推理：

| 判据 | 字段 | 判据不通过时 |
|---|---|---|
| 容量 | `contentChars` | 内容字数 > 必填槽容量 |
| 素材 | `assetCount` | 模板要 N 份素材、你 0 份 |
| 时长 | `durationSeconds` | 目标时长不在模板适用区间（固定片长 ±35%） |
| 条目数 | `itemCount` | 你说 4 条、模板 3 个卡片位 |
| 信息充足度 | `contentChars` | 内容字数 / 必填槽容量 < 35%（会逼出编造） |

阈值可用 `minInfoRatio` 覆盖（缺省 0.35）。

## 3. 填槽位的三条纪律

1. **按 `semantic` 写，不按 `label` 猜**：`semantic` 说明这一格该写什么、用什么语气。
2. **字数按码点算，换行也算一行**：`maxChars` 是总量，`maxCharsPerLine` 是单行。
   超了会**编译前**被拒收，文案直接告诉你「删掉 N 字」或「第 K 行压到 M 字内」。
3. **不要为了凑满而注水**：填充率低说明内容不足（判据 5），注水出来的片子比自由编排更差。

```jsonc
// 正确：字符串按整块给，句子之间用逗号，不要换行（模板只要一行）
{ "lead": "不是离太阳远近，而是地轴斜了 23.4°" }
```

## 4. 失败怎么处理（都要**显式告知用户**）

| 现象 | 你的动作 |
|---|---|
| 槽位超限被拒 | 按文案改短再试一次；改不动就换模板或自由编排，并把「为什么装不下」说给用户 |
| 没有可用模板 | 走自由编排（`scaffold_manifest({ title, durationSeconds })`），回复里写「没有匹配模板，已按自由编排生成」+ 原因 |
| 多个模板都适配 | 列给用户选，**不要**自己挑 |
| 契约版本不符 | 该模板不可用（`contractVersion` 与渲染器不符），换模板 |

> 静默降级最坏：用户会以为是模板效果差，或以为自己说的内容被忽略了。

## 5. 模板之外还能改什么

模板产物就是一份普通 manifest：

- **想加一条自己的轨**：直接往 `tracks` 里追加（`id` 唯一、`startFrame` + `durationInFrames` 自洽）；
- **想换配色**：改 `tracks[].color` / `accentColor` / `meta.backgroundColor`；
- **想改时长**：改末尾轨并把 `meta.durationInFrames` 同步成最大结束帧（否则被尾部完整性校验拒收）；
- **想加装饰**：参照 `motion-patterns.md §5`（四角括线 / 进度条 / 星点的等效写法）。

**唯一不要做的**：删模板的卡片（轨道数变了，版面就不再是验过的那个效果）。
