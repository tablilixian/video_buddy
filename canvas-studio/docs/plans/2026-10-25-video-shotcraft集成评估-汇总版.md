## 二、能不能集成？——结论与理由

**结论：整包不引入；作为"教科书"选择性吸收四样东西。**

### 不整包引入的五个理由

| # | 理由 | 说明 |
|---|---|---|
| 1 | **片型错配** | 它的采集链是"无头浏览器抓真实网页 + 元素级抠图 + layout 坐标表"，服务产品宣传片；我们的素材来自画布资产/用户上传/AI 生成，采集链对我们无用 |
| 2 | **产物形态不通** | 它的 `demos/*.tsx` 是直接写 React/Remotion 组件；我们的产物是 **manifest DSL**（`tracks[]` + 白名单组件），这是刻意架构（确定性 + 可校验 + 无任意代码执行），不能为复用模板放弃 |
| 3 | **体量与依赖** | 124 卡 + 216 demo + 149 音效 + chrome-headless-shell/Python；我们安装包已 ~345MB（onnxruntime 占大头），整包引入体量翻倍 |
| 4 | **许可链** | Remotion 对 3 人以上公司需付费授权（条款随版本变动）；音频逐条授权且存在不可溯源项 |
| 5 | **证据强度** | 第三方评估（FSRS 61/100）为静态审查未复现；剪映导出路径作者自承未真机验证——把它当"参考实现"而非"可靠资产" |

### 值得吸收的四个理由

| # | 价值点 | 对应我们的实证痛点 |
|---|---|---|
| 1 | **知识形态：散文 → 卡片**（卡名/适用/参数/最小可粘片段/观感要点） | 会话实证：模型为确认引擎语义读了 24 次源码；"选卡填参"直接替代"翻译散文 + 读源码"（G6 的解法） |
| 2 | **起点缺失的解法**：已验收模板 + 卡片序列 = 组装起点 | 我们每次从空 manifest 试错，首轮结构合法率低 |
| 3 | **声音维度**：149 SFX 按 16 类组织，转场/强调/文字音效我们全缺 | "像不像专业片"的差距里最便宜可补的一块 |
| 4 | **卡点方法论**：beat 分析 → 按拍切镜 → 渲后回测切点误差 | 我们完全空白；先做"建议器"即可借方法论，不动渲染层 |

边界要说清：它对**运行时层**（渲染超时、claim-stall、每帧成本）**零帮助**——那条线由 CV-363~365 与 2026-10-25 会话6诊断的 P0 项负责，不要把两条线混账。

## 三、集成建议（收拢版）

路线沿用吸收方案的 **S0–S4**（详见 [吸收方案](2026-10-25-shotcraft吸收方案.md)），此处只列骨架与门槛：

```
S0 观察(2h)      clone 到 /tmp，15 张对照表；复刻率 ≥60% 才继续，否则转能力补齐线
S1 卡片化(0.5d)  定 5 段卡schema，先写 12 张；每张片段必须过 validateManifest；守卫测试
S2 主题预设(1d)  meta.themeId 校验前展开；先 2 个预设；写死"显式字段优先于主题默认"并测
S3 音效(0.5d)    挑 10–20 个，逐条核 ATTRIBUTION（本次新增：绕开 ~6 个不可溯源项），体积增量 <2MB
S4 卡点(可选)    先做离线建议器（cutFrames[] 建议），验证有收益再谈 manifest 字段
```

决策点 D14–D18 的建议不变（卡片=文档+守卫；主题=meta.themeId；音效=用它的库挑；卡点=S1–S3 后再说；TSX=默认不移植，极高门槛例外）。

### 新增取舍注意：卡片选型必须过"渲染预算"这道筛

2026-10-25 会话6实测（session.v4.jsonl 6：9 次渲染调用、7 次死于 claim-stall、探针 msPerFrame=7855ms、带图探针约 19s/帧；诊断结论目前仅在会话讨论中，**尚未落盘成文**）：我们 CSR 渲染**每帧 7.9–19 秒**。shotcraft 的卡是按 Node 侧 Remotion 正常渲染速度设计的，若照单吸收"多层叠加/高斯模糊/每帧重栅格化"类高刷动效卡，吸收完会发现渲不动。因此：

- S1 的 12 张卡**优先选低每帧成本的组合**（位移/透明度/遮罩类，避开逐帧全量重绘类）；
- 每张卡在"观感要点"里加一行**渲染成本标注**（预计是否显著增加每帧耗时）；
- 每帧成本这堵墙不拆（会话6诊断的 P0），卡片库收益会被渲染超时吃掉。

## 四、风险与边界清单

1. **talkcraft（姊妹 skill）license=NOASSERTION**：只借方法论文本，不搬任何资产/代码。
2. **Remotion 许可**：随公司规模与版本变动，引入前过一遍当前条款。
3. **音频逐条授权**：S3 落地前逐条登记 ATTRIBUTION，不可溯源的一律不用。
4. **数量口径**：对外/对内引用统一为 **124 卡 / 150 镜头 / 216 demo / 149 SFX**，旧数字（157/209/106/152）作废。
5. **不吸收**：动效工作台、剪映导出、puppeteer 采集链、整包 vendor。
