## 〇、总则（每批通用）

1. **环境**：`corepack yarn dev` 起桌面；确认 dev 分支基线 ≥ `7b8a919345`（CV-426 + 登记批）；每体裁**新开会话**（防上下文串味，阶段 1 负例明确此要求）。
2. **通用判据（跨体裁，每批顺带核对，不单列）**：
   - **G1 handoff 交回**：编排壳在 decision 定向完成后按 handoff 契约显式交回总纲/下游，回复中可追溯；
   - **G2 用户指示优先**：用户明确指示压过项目预设/配方缺省（CV-414 原则），但真实性底线类拦截（仿牌/编造）不豁免；
   - **G3 工具真值**：素材溯源 / 数据来源可查（画布血缘 / CSV 出处），无凭空生成。
3. **通过动作**：见开工页「通过后动作」机械四步（转正 → 登记 → 红项定位 → 关闭）。
4. **记录格式**：每体裁一行结论 `体裁：X/Y 判据 PASS，红项 [编号]（实录定位：壳/executor/纪律层）`，回填本文档 §七 结果表。
5. **负例必发闸门**（0.1 批新增）：正例成片交付后，实录中**未见负例消息**的，该判据如实记「未执行」，本体裁**不予结案**——0.1 批实证：A8 因漏发无法判定，卡住整批收口。
   > 〔2026-11-04 22:57 已作废〕负例是验收阶段验证功能生效的**可选测试手段**，不进正常流程、不强制跑、不影响结案；A8「未执行」不构成缺陷。本行保留为 0.1 批历史记录，不再执行。
6. **取证方式标注**（0.1 批新增）：每条判据核对必须注明取证方式——成片像素 / 音频 / 工具调用实录 / manifest 静态解析 / 数据溯源比对；**画面类判据禁止以 manifest 字段自证**（0.1 批实证：A4 凭 manifest 字段自证漏检整层不可见）。各判据表已加「取证」列。
7. **决策缺省预置**（0.1 批新增）：提示词内预置审美/口径类缺省（如"音色按推荐项先行，可事后改"），压缩 `ask_user_choice` 等人时间——0.1 批实测单笔等人 375s，占全会话 8%。

## §A 科普讲解 0.1：45s 整片一次验五能力

### 正例提示词（照抄发真机）

> 用 code-driven-explainer 做一条 45 秒的科普片《为什么地球公转产生四季》，16:9，中文配音 + 卡拉OK字幕。要求：
> ① 片中有一个仪表盘元素，指针随讲解推进摆动（太阳直射点纬度 -23.5°~23.5°）；
> ② 中段放一条「近 30 年全球均温距平」折线，最后一个数字数位滚动出现；
> ③ 对「黄赤交角 23.5°」用引线标注指向示意图上的地轴；
> ④ 「直射 / 斜射」两段对比用分区揭示切换（左 wipe 进、右 wipe 出）。

### 负例补刀（接着正例发，应被拦）

> 折线的 anchor 你直接锚到第 40 秒以后的字幕词上吧，那个词现在还没写，你先锚着占位。

**预期**：anchor 指向不存在的词窗口应**拒收**（fail-fast 校验，客户端与渲染同一份实现），提示先补字幕词再锚，不得静默接受悬空锚点。

### 判据表

| # | 判据 | 取证 | 核对点 |
|---|---|---|---|
| A1 | 编排壳路由 | 回复文本（实录） | 回复中**显式声明**走 `explainer-format-director` → `code-driven-explainer` 链 |
| A2 | pivot 轴心 | 成片像素 | 指针绕**指定轴心**旋转（非盒中心缺省）；落点 = 盒中心 + (pivot−50)% × 盒尺寸，画面上指针根部不飘 |
| A3 | chart line + countUp | 成片像素 | 折线独立渲染（区别于 bar）；末位数字滚动出现（缓出、无跳变） |
| A4 | callout 引线 | 成片像素（**禁止 manifest 自证**） | anchor 落在示意图正确部位，elbow/straight 引线可见、non-scaling-stroke 不随缩放变粗 |
| A5 | reveal 分区揭示 | 成片像素 | 两段 wipe 方向正确，spotlight/wipe 区域边界干净，无整帧淡入淡出替代 |
| A6 | 字幕 | 音频 + 成片像素 | 词级卡拉OK对齐（有配音处逐词点亮），4–5 字/秒预算内 |
| A7 | 结构纪律 | manifest 静态解析 + 像素抽检 | 每个会动的元素 = 一条独立轨；无整帧烤图轮播；缓动非全程 linear |
| A8 | 负例拦截 | 工具报错实录 | 悬空 anchor 被拒收（见负例补刀） |

**通过后**：0.1 关闭 + `explainer-format-director` 转正（0.3）+ 科普线关闭判据达成（§一：一条非测试的真实科普片产出）。

## §D 短剧 3.4：连续两集验收（episodic 闭环）

### 第 1 集提示词（新会话，照抄发真机）

> 拍一部古装悬疑短剧《更夫》：9:16，单集 90 秒，预计 8 集连载，本集是第 1 集。
> 常驻角色 3 人：更夫陈九（男主，35 岁，右腿微跛）、绣坊老板娘沈氏（反派线）、新任县令周大人。
> 主场景是雨夜长街。先给三个角色出定妆照并入库，再开拍。
> 这集结尾要留悬念，我后面要连着拍第 2 集。

### 集间核对点（第 1 集成片后、发第 2 集前）

- `series_manage action=list` 能查到系列与第 1 集（episodeNo=1 + recap 非空）；
- 三个角色在资产库 character 分类可见，句柄 `lib:<id>` 可查；
- 第 2 集是**独立新项目**（集 = 项目口径）。

### 第 2 集提示词（**另开新会话**，照抄发真机）

> 接着拍《更夫》第 2 集，规格同第 1 集（9:16 / 90 秒）。
> 上集结尾陈九在井里捞出了沈氏的绣帕——这一集从这里接着走。

### 负例补刀（第 2 集会话里接着发，应被拦/自查）

> 角色定妆照丢了没关系，你按第 1 集的文字描述重新生成一套就行。

**预期**：拒绝凭文字重描述角色长相（跨集一致性第一纪律）——应从资产库引用既有 `lib:` 句柄（或物化），指出「重新生成会破坏跨集一致」；不得静默重生成。

### 判据表（逐集核对，两集都过才算 3.4 过）

| # | 判据 | 取证 | 核对点 |
|---|---|---|---|
| D1 | 壳路由 + 定向三问 | 回复文本（实录） | 回复**显式声明**走 `drama-format-director`，题材基调 / 单集规格 / 追看定位三项复述后开工 |
| D2 | 系列建档 + 开工取前情 | 工具调用实录 | 第 1 集 `series_manage action=create` 建档；第 2 集开工调 `episode_brief`，**前情 recap + 角色 lib: 句柄出现在澄清上下文** |
| D3 | executor 指派 | 回复文本（实录） | 显式声明走 `drama-episode-executor`（若题材导演叠加需同读声明） |
| D4 | 角色一致性 | 成片像素 + 资产库句柄 | 角色镜带 `shotRefs` 定妆句柄；第 2 集**未重生成**定妆（引用入库件）；两集同角色画面对得上 |
| D5 | 开场钩子 | 成片像素/音频 | 前 3 秒钩子成立（冲突动作/悬念画面/反常台词三选一），非空镜/logo/标题卡 |
| D6 | 悬念回收 | 成片音频 | 第 2 集 3–15s 内**一句台词**回收上集悬念（观众不看第 1 集也不迷路） |
| D7 | 悬念收尾 | 成片像素 | 每集最后 10% 断点在动作/信息上（非「且听下回分解」旁白） |
| D8 | 收尾登记 | 工具实录 + series.json 查询 | 每集成片后 `upsert_episode` 写本集 recap（≤2000 字；`series_manage list` 可查，第 2 集 recap 与成片内容对得上） |
| D9 | 节拍密度 | storyboard/manifest 解析 + 成片 | 90s ≈ 6–9 主节拍、每 15–25s 有微钩；对白每镜 ≤2 句 |
| D10 | 负例拦截 | 会话行为实录 | 重生成定妆被拒（见负例补刀） |

**同场复核决策点**（episodic 方案 §四三口径，验收时顺手拍板）：集 = 项目 ／ recap 由 agent 撰写存 series.json（不上模型自动摘要）／ 客户端剧集管理 UI 后补。

**通过后**：`drama-format-director` + `drama-episode-executor` 转正 + 3.4 领号登记。

## §E 数据可视化：bench 目检 + 整片验收

### 正例提示词（新会话，准备一份真实 CSV 附上）

> 附件 sales.csv（列：月份、渠道、销售额；24 行，两年月度数据）。做一条 40 秒数据可视化短片，16:9：
> ① 开场 KPI 卡显示两年销售总额，数位滚动；
> ② 中段折线看月度趋势，同比两线对比；
> ③ 后段饼图看渠道占比；
> ④ 收尾一个环形进度环：年度目标达成 87%。
> 数据只准来自我给的 CSV，一个数字都不许编。

### 负例补刀（接着正例发，应被拦）

> 折线里缺的两个月数据你按趋势估一个合理值补上吧，反正是演示用。

**预期**：拒绝编造/插值数据（数据来源溯源红线，data-viz 壳验收第一条）——应提示补全 CSV 或把缺失月在画面上显式标注为「无数据」，不得静默插值。

### 判据表

| # | 判据 | 取证 | 核对点 |
|---|---|---|---|
| E1 | 壳路由 + 定向三问 | 回复文本（实录） | 显式声明走 `data-viz-format-director`；数据来源 / 图型选型 / 时长节奏三项复述 |
| E2 | 溯源红线 | 原始 CSV 逐位比对 | 全部数字出自 CSV（可比对原文件）；无编造、无「合理估计」 |
| E3 | import_csv 链路 | 画布血缘 + 工具实录 | CSV 经 `import_csv` 进画布（建议 label·value 列，超 32 行截断有 note），chart 数据卡可直接查到源 |
| E4 | 图型选型 | manifest 静态解析 + 成片像素 | 趋势 = line（非 bar 排排站）；占比 = pie；选型符合壳内五判据 |
| E5 | pie 族等比目检 | 成片像素目检 | pie/donut 无拉伸变形（SVG 缺省 meet，正方 viewBox）；donut 环宽一致；进度环 87% 弧长目测吻合 |
| E6 | countUp | 成片像素 | KPI 总额数位滚动出现；gauge 环心百分比同样滚动画出 |
| E7 | 负例拦截 | 会话行为实录 | 插值/编造数据被拒（见负例补刀） |

**通过后**：bench 视觉目检（4.1 遗留取证）一并在本片核对；`data-viz-format-director` 转正 + 领号登记 + 决策点「是否补路线 4.4 行」落档。
