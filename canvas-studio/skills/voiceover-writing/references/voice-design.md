# 声音设计分册：语言 / 方言清单与示例库

> `tts_voiceover` 的 `instruct_prompt` 写法细则。后端模型 VoxCPM2（`tts_cpm.json`），
> 一切声音特征用自然语言描述——模型能理解的措辞远不止本清单，清单是**实测可用的保底集合**。

---

## 一、支持的语言（30 种）

阿拉伯语、缅甸语、中文、丹麦语、荷兰语、英语、芬兰语、法语、德语、希腊语、
希伯来语、印地语、印度尼西亚语、意大利语、日语、高棉语、韩语、老挝语、马来语、
挪威语、波兰语、葡萄牙语、俄语、西班牙语、斯瓦希里语、瑞典语、他加禄语、泰语、
土耳其语、越南语

> 用语言的自然名称写（「日语」「Japanese」皆可）；不写语言维度时模型可能自选，
> 中文稿**显式写「普通话」或「中文」最稳**。

---

## 二、中文方言（9 种）

四川话、粤语、吴语、东北话、河南话、陕西话、山东话、天津话、闽南话

> 方言与语言维度同位：写「四川话」就不再写「中文」（方言已含语言归属）。
> 方言下仍可叠加语气 / 情感 / 语速维度。

---

## 三、常用维度词速查

| 维度 | 可用词（保底集合） |
|---|---|
| 性别 | 男声 / 女声 / 男性 / 女性 |
| 年龄 | 童声 / 少年 / 青年 / 30岁 / 中年 / 60岁 / 老年 |
| 语气 | 笑着说 / 悄声说 / 一本正经地说 / 命令式 / 喃喃自语 / 播音腔 |
| 情感 | 温柔 / 坚定 / 平静 / 低沉 / 兴奋 / 悲伤 / 愤怒 / 恐惧 / 慈祥 / 冷漠 |
| 语速 | 慢速 / 中速 / 稍快 / 语速很快（**无数值**，不要写「1.2倍速」） |
| 音色修饰 | 沙哑 / 清亮 / 浑厚 / 气声 / 鼻音重 |

## 五、常见坑（都源于「逐字念出」这一个事实）

1. **舞台指令会被念出来**：`（压低声音）`、`[停顿2秒]` 这类标记一律不要出现在
   text 里——要么删掉，要么把效果写进 instruct_prompt。
2. **填充词要 purposive**：口语稿里的「嗯、啊、然后」会被如实念出来；除非刻意
   营造口语感，先删干净。
3. **数字歧义**：`3.5亿` → 写「三点五亿」；`1998年` 一般正确，拿不准就写
   「一九九八年」。
4. **多语言混排**：一句中文里夹英文单词通常没问题（VoxCPM2 支持 30 语种），
   但整段语种最好一致；混排时在 instruct_prompt 里点明（如「中文为主，品牌名
   读英文」不做保证，实测为准）。
5. **emoji / 特殊符号**：不读或读错，text 里不要出现。
