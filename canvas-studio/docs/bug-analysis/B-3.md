# B-3 ｜ 任意视频可加入资产库（期望视频不可加入）

> 优先级 P2 ｜ 风险 T1 ｜ 依赖：无
> 无截图（资料库纯文字条目）。

## 现象
视频节点右键有「加入资产库」且能成功入库；产品期望视频不可加入。

## 代码级原因
- 入口无过滤：`client/canvas/CanvasContextMenu.tsx:106-107` `{item('加入资产库', ...)}` 对所有节点无条件展示（对照同文件 :124-125「拆分视频」有 kind 门槛）。
- 服务端无过滤：`routes.ts:955-1003`（POST /library）与 `:1005-1023`（anchors）都经 `asset-library.ts:550-572` `collectNodeMediaSources`——只校验 url 归属与文件在盘，不看 `node.kind`；`copyMediaSources`（:504-538）只跳过 text/null，video 放行。

## 修复方案
1. 服务端单点：`collectNodeMediaSources` 找到 node 后加 `if (node.kind === 'video') throwError('CS-USER-ERR', { message: '视频不支持加入资产库' })`——create/addAnchor 两条路由全覆盖。
2. 客户端隐藏入口：`CanvasContextMenu.tsx:107` 改 `{node.kind !== 'video' && item('加入资产库', ...)}`（入口不出现，而非点击报错）。
3. 口径注明：库内手动上传视频（`addMedia`，routes.ts:1073）若保留属产品例外，不动。

## 改动风险
低。已入库的存量视频媒体不受影响（只堵新增）；未来放开只需移除两处。

## 验收
无头：asset-library 单测（视频节点入库抛 CS-USER-ERR）+ 菜单源码断言。桌面：视频右键无「加入资产库」。
