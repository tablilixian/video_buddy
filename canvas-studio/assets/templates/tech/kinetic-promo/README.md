## 为什么卡片墙只在第 1 段

`cardWall` 的 12 张卡各自带 `perspective()` ⇒ 每张一次 WebGL 预合成
（能力基准 #13 实测 60 层 = 243ms/帧）。把它限制在 0–336 帧，3D 层只覆盖
**23% 的片长**；第 2 段起全是 2D 轨，整片成本因此远低于「全程 3D」。
这是 D-40 的性能预算在模板层的落地，不要把它改成全片常驻。

## 槽位

26 个槽，**全部必填且全部带缺省文案** ⇒ 不给 slots 也能编译出样片；改哪格覆盖哪格。
全部必填是 1（CV-463）立下的起步纪律（避免可选槽静默留空），本模板靠 `default`
而不是 `required:false` 来实现「零输入可出片」。

## 素材与占位（S2 起）

`requiredAssets: []` —— 使用者**零自备素材**即可出片。原片里的真人 PIP / 圆形头像
收敛为**程序生成的剪影占位**（`frames/presenter-placeholder.svg`，随包只读路由
`/canvas-studio/remotion/templates/…` 托管）：`s4-portrait`（竖幅人像端口）与
`s8-roundpip`（圆形 PIP，`clip:'circle'`）两条 `image` 轨默认引用它。确需真人出镜时
把这两条轨的 `src` 换成使用者自己的素材即可（不预留空 `src`，编译期会拒收）。
