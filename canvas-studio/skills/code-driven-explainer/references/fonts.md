# 字体声明口径

目标：让**中文字幕卡**在任何机器上都不静默 fallback（观感事故）。字体解析与注入是**宿主 / 客户端渲染器**的职责，skill 只负责**声明**。

## 你只需要做两件事

1. **中文成片声明缺省字体**：

   ```jsonc
   "global": { "fontFamily": "Noto Sans SC" }   // 随包中文字体（缺省即此；显式声明更稳）
   ```

   不声明时组件走宿主缺省字体；中文卡建议显式声明，避免落到非中文字体触发 fallback。

2. **需要随包字体之外的字族 / 字重时，用 `global.fonts[]` 声明**：

   ```jsonc
   "global": {
     "fontFamily": "Noto Serif SC",
     "fonts": [
       { "family": "Noto Serif SC", "weight": 700 },
       { "family": "Noto Serif SC", "weight": 400 }
     ]
   }
   ```

   - `family`：与 CSS `font-family` / `global.fontFamily` 对应的族名。
   - `weight`：字重，默认 400。
   - `src`：可选，字体文件**同源 URL**（同 `tracks[].src` 约束：`/canvas-studio/assets/...` 或本项目资产目录内的绝对路径，宿主会物化）；缺省由宿主字体解析表解析。

## 宿主侧的解析顺序（你只需知道，不必手动实现）

1. **命中随包字体子集**（**Noto Sans SC**，OFL 许可）→ 直接用，**离线必能出片**；
2. 未命中 → 从自托管源下载并缓存（命中缓存不重复下载，二次渲染离线可用）；
3. 下载失败 / 无网 → 随包字体 fallback + warning 进结果 `warnings`，**不阻断渲染**。

渲染前客户端会在字体就绪后才出帧（防空白帧 / 半截字），你无需为此做任何事。

## 纪律

- **不要声明外链字体**：`src` 只接受同源 URL 或本项目资产目录内的绝对路径；带 `scheme://` 的一律被拒（防外链泄露）。
- 一部片子**尽量只用一两种字族**；混排过多字族会明显拖慢渲染、也难统一观感。
- 字体与 `@font-face` 的 `src` 不同源会导致**静默 404 → 回退系统字体**（最难查的一类）；因此能用缺省就别自造 `src`。
