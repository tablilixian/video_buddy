## 7. Step 3 规格（D/E/F 组）—— 做完 Step 2 再做

### 7.1 放置求解器（E 组，与 `nodeActionAnchor` **同族**）

在 `src/canvas-view.ts` 新增（复用 `clampTo` / `NODE_ACTION_MARGIN=8` / `NODE_ACTION_GAP=8`，坐标换算式与 `nodeActionAnchor` 一致：`left = box.x * scale + view.x`）：

```ts
export interface EditorPlacement {
  mode: 'float' | 'sheet'
  side: 'right' | 'left' | 'below' | 'above'
  rect: { x: number; y: number; width: number; height: number }   // 屏幕坐标
  pan: { dx: number; dy: number }                                 // 需施加到 view 的**最小**平移
  visible: boolean                                                // 节点完全在视口外 ⇒ 调用方不渲染
}
export function editorPlacement(
  node: CanvasBox, view: StudioCanvasView, viewport: CanvasViewport,
  panel: CanvasViewport, narrow: boolean, bottomInset?: number,
): EditorPlacement
```
规则（编号即方案 §3 E 组）：① 候选序 `right → left → below → above`，取第一个满足「面板 ⊆ 安全区」**且**「面板 ∩ 节点 = ∅」的侧（左右放置恒不遮挡）；② 夹取进安全区（8px 边距 + `bottomInset` 让位）；③ 四侧都放不下 ⇒ 按"节点在视口左半→放右、右半→放左"算**最小平移**把该侧腾出来，**只迭代一次**，且**不得把节点推出视口**；④ `|dx|,|dy| < 4px` 归零；⑤ `narrow === true` ⇒ `mode='sheet'`（底部抽屉、高约 46%），必要时只用**垂直**平移把节点抬到抽屉之上；⑥ `visible === false` ⇒ 不渲染。
**箭头级约束**：平移只作用在 **view**（画布）上、**不改 `scale`**；用户手势（滚轮/拖动）期间**立即放弃**自动平移；关闭编辑器**不回弹**，但浮层头部给「恢复视野」（打开时的 view 快照）。

### 7.2 长文本（D 组）

判据做成纯函数（**由内容算，不由用户手选**）：≤ 8 行 **且** ≤ 240 字 ⇒ `short`；命中 IR 段名（行形如 `^[a-z_]+:$`）或含 `<Picture N>` ⇒ `ir`；否则 `long`。
- `short`：自增高 textarea，上限 260px；
- `long`：就地档**不展开全文**，显示「长提示词 · N 行 / M 字」+ 前 3 行预览 + 「展开编辑」；展开高度 = `min(56vh, 520px, 视口高 − 2×边距)`，**先夹高度 → 再测量 → 再定位**；超出内部滚动 + 上下渐隐；
- `ir`：段名行常显、段体可折叠（只展开要改的那段）；整篇重写引导到既有聚焦档（1040×640）；
- 参考区 > 6 张 ⇒ **单行横滚 + 共 N 张**（面板高度不随张数增长）。

### 9.3 `src/client/styles.ts` 的红线（有守卫测试）

- 不许新增"空转令牌"（新增 `--cs-*` 必须被引用）。

### 9.5 测试脚手架踩过的坑（照抄规避）

- Node 全局 agent 默认 keep-alive ⇒ `server.close()` **永不返回**：必须 `agent: false`（每个请求）+ `server.closeIdleConnections()` + `server.closeAllConnections()` 再 `close()`；
- 假 `ctx.webServer.register` **必须返回 disposer**（`registerStudioRoutes` 收集的是它的返回值，不是路由对象）；
- 假 `registry` 必须给 `sweepUnclaimedDraftDirs()`（注册时会 fire-and-forget 调一次）；
- `node fetch` 不自动发 `origin` / `sec-fetch-site`，`Host` 头要用原生 `http.request`；同源测例要显式给 `origin: http://127.0.0.1:<port>`。
