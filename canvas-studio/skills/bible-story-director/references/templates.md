# 稿子模板（S9 必读）

> 两块内容：**第一段交付的可读拆解稿模板**（在对话里给用户看的），和**第二段分笔写入的 JSON 骨架**。末尾附一个 60s / 8 镜的完整参考实例（大卫与歌利亚）。

## 1. 可读拆解稿模板（对话里输出）

八小节，照抄这个顺序，**每节一张表，不要写成长散文**。用户要能一眼扫完并指着某一格说「改这里」。

```markdown
## ① 故事与出处
| 项 | 内容 |
| 故事 | 大卫与歌利亚 |
| 出处 | 撒母耳记上 17:1–58 |
| 一句话摘要 | … |
| 时代标签 | 士师与王国（约前 1050–930） |

## ② 考据设定
| 维度 | 内容 |
| 时代 / 人群 / 服饰 / 建筑 / 器物 / 光线 | …（每条注明依据） |

## ③ 主题与弧线
| 项 | 内容 |
| 切口策略 | A 单场景切口 |
| 主题（一句话） | … |
| 情感走向 | 压迫 → 迟疑 → 决定 → 静默 |
| 结局处理 | 如实呈现，不补说教句 |

## ④ 人物表
| ID | 姓名 | 出现场次 | 气质 | 面容 | 服装 | 配色 | lockedPrompt 要点 |
| C1 | 大卫 | S1–S3 | … | … | … | … | … |

## ⑤ 节拍链与时长分配
| 拍 | 内容 | 时长 | ≈占比 |
| … | … | 8s | 13% |

## ⑥ 旁白逐句
| ID | 旁白 | 时长 | 挂镜 |
| V1 | … | 8s | S1-Sh1 |

## ⑦ 分镜表
| 镜号 | 场 | 景别 | 运镜 | 时长 | 衔接 | 画面描述 | 声音 | 旁白 |
| S1-Sh1 | S1 叫阵 | 大远景 | 固定 | 8s | — | … | 谷风、远处旗声 | V1 |

## ⑧ 声音与约束
| 项 | 内容 |
| BGM | 62 BPM / -18 LUFS / 有对白时压低 6dB |
| SFX | 谷风、皮革甩响、石落 |
| §08 硬约束 | 五条默认 + 本片增补 |
```

**用中文写 `画面描述`**。这一段是给人审的规划文字，不是 H3 prompt——不要出现英文参数堆砌、`<d>` 标签、`subject_definitions:`。

## 2. 四笔写入骨架

确认稿子后按顺序调用 `write_storyboard`。分节合并语义：传了哪节替换哪节，没传的保留。

**第一笔**（进度 3/9）

```json
{
  "meta": { "genre": "圣经叙事", "targetDuration": 60, "aspect": "16:9", "audience": "成人写实" },
  "00_creative": { "brief": "…200–400 字…" },
  "02_visual": { "tokens": [ { "k": "主体", "v": "…" }, { "k": "环境", "v": "…" },
                             { "k": "材质", "v": "…" }, { "k": "色彩", "v": "…" }, { "k": "光线", "v": "…" } ] }
}
```

**第二笔**（进度 4/9）

```json
{
  "04_storyboard": { "scenes": [
    { "id": "S1", "title": "叫阵", "shots": [
      { "id": "S1-Sh1", "duration": 8, "frames": 192, "camera": "大远景，固定",
        "visual": "…", "audio": "…", "narrationRef": "V1", "backup": false }
```

```json

  "05_characters": [

      "palette": { "base": "…", "accent": "…" },

  "06_sound": { "bgm": { "bpm": 62, "lufs": -18, "sidechain": "对白与旁白出现时压低 6dB" },
                "sfx": ["旷野谷风", "皮革投石索甩响", "石子破空"] }

```

**第四笔**（进度 9/9）

```json
{
  "01_facts": { "facts": [ { "claim": "…", "source": "撒母耳记上 17:1–58", "status": "verified" } ] },
  "07_assets": [],
  "08_constraints": ["…五条默认模板 + 本片增补…"]
}
```

四笔写完后**停手**，请用户在画布顶条「拍摄定稿」覆盖层审阅并点「确认落地」。

## 3. 完整参考实例：大卫与歌利亚（60s / 8 shot）

### 三节的正文示例

**`§00_creative.brief`**

> 本片取材于《撒母耳记上》17:1–58，采用单场景切口，只拍以拉谷两军对峙的这四十天里的决定性一天，不交代大卫此前的受膏与搏杀狮熊。主题是「外表的尺寸不是力量的尺寸」——画面刻意让歌利亚长期占据更大的画幅比例，直到投石索松开那一刻才把重心交还给少年。情感走向：压迫（仰视巨人）→ 迟疑（试穿盔甲）→ 决定（跑向战场）→ 静默（倒下后的空谷）。60 秒，16:9，成人写实。

**`§01_facts`**（示例两条，实际给 5–8 条）

| claim | source |
| 故事出自大卫击杀非利士巨人歌利亚的记载 | 撒母耳记上 17:1–58 |
| 两军在以拉谷隔谷列阵，非利士人一方有巨人歌利亚 | 撒母耳记上 17:1–11 |
| 大卫当时是牧羊少年，尚未入伍，有三个兄长随军 | 撒母耳记上 17:13–15 |
| 大卫拒绝扫罗的盔甲，只带杖、投石索与五块溪石 | 撒母耳记上 17:38–40 |
| 该时期为以色列联合王国初立、冶铁尚未普及 | 近东考古常识：铁器在该区域于前 10 世纪逐步取代青铜 |

**`§08_constraints`**

```json
["时代锁定：公元前 11 世纪近东，禁止中世纪欧洲元素（板甲、尖顶盔、城堡、哥特教堂）",
 "人群特征：闪米特/中东相貌，橄榄至棕褐肤色，深色卷发，禁止金发白肤默认脸",
 "服饰器物：粗麻内袍、无染羊毛斗篷、皮革凉鞋、青铜/早期铁制武器，全片不混用其他时代器物",
 "情节忠实：不增删人物、不改结局（大卫以投石索击中额心）、不把神迹改写成巧合",
 "跨镜一致性：大卫相貌与服饰、歌利亚的全套护具、以拉谷的空间方位与日照方向全片恒定"]
```
