# REQ-038 R11 · 段级编辑闭环 实施计划

> 2026-11-16 11:21 起。目标不是「分镜渲得更快」，是**改一段不动全片**。
> 判据：改一段的代价 = 1 段渲染 + 1 次确认，且不触碰其他段产物与其他分镜卡。
> 依据：`REQ-038-R11-代码review-20261116.md` §6（真机实测）/ §7（四问答疑）/ §8（优先级）。

## 0. 为什么契约先行

O-1（可寻址）和 O-2（可隔离）看起来是两件事，实际缺同一个东西：**段表**。

- 段渲染现在靠 `boundariesFromSpec` → `planStages` 的等分起点（200 / 400）；
- 而内容轨被 `applyStageTransitions` 左移 10 帧（190 / 390）。

两者错位 10 帧，于是每段末尾都含下一段的入场画面 ⇒ 改 s2 必脏 s1（实测 `1 复用 / 2 重渲`）。
段表把「段的真实内容窗」变成 manifest 里的一等数据，段渲染、段挂载、段级 patch 读同一份，
**C1 与 C3 一次性解决**，不用靠轨 id 前缀（`s2-` / `u0-s2-`）猜归属。

## 1. 契约定义

```jsonc
// manifest.meta.segments（可选；缺省 = 旧 manifest，走现有回退，逐帧不变）
"segments": [
  { "id": "s1", "startFrame": 0,   "frames": 190 },
  { "id": "s2", "startFrame": 190, "frames": 200 },
  { "id": "s3", "startFrame": 390, "frames": 210 }
]
```

| 项 | 规定 |
|---|---|
| 谁写 | `planFromSpec`（唯一），在 `applyStageTransitions` **之后**聚合 `screenTracks` 每桶的最早 `startFrame` |
| 谁读 | `resolveShotBoundaries`（段窗）、段挂载、段级 patch、验收脚本 |
| 语义 | `startFrame` = 该段首轨的**实际**起点（含转场预卷）；`frames` = 到下一段起点（末段到片尾）；**首尾相接、无重叠、Σ = durationInFrames** |
| 空屏 | 该段无轨 ⇒ 起点取 `timeline[i].startFrame`，段仍保留（保持段序与 sections 一一对应） |
| 兼容 | 字段可选，不影响 `MANIFEST_CONTRACT_VERSION`；旧 manifest 无此字段 ⇒ 回退 `spec` 边界 ⇒ 现有测试与产物不变 |
| 登记 | `KNOWN_META_KEYS` 必须加 `segments`，否则每份 manifest 刷「契约外字段」警告 |
| **指纹** | `manifestGlobalsFingerprint` **必须排除 `segments`**：它是派生数据，不是渲染输入；不排除 ⇒ 任何段表改动让全段 dirty，缓存直接失效 |

## 3. 测试策略

**每个批次必须有「反向变异」用例**（改回旧行为必须变红），否则等于没锁。

| 批 | 正向用例 | 反向变异（必须红） |
|---|---|---|
| B0 | 段表 Σ frames == durationInFrames；首尾相接；起点严格升序 | 把 `segments` 塞回指纹 ⇒ 「撤销段表后 hash 不变」用例红 |
| B1 | 改 s2 ⇒ 只有 s2 hash 变；改 bg ⇒ 全变；改 s3 ⇒ 只有 s3 变 | 把 `resolveShotBoundaries` 优先级改回 spec 边界 ⇒ 「改 s2 只脏 s2」红 |
| B2 | 段 mp4 无 audio；`nb_frames == frames`；段时长 == frames/fps | 把 `muted` 改回 `audioCodec:null` ⇒ 音轨断言红 |
| B3 | patch 只改目标字段，diff 长度 1；备份卡拒绝并给出原因 | 去掉 `backup` 过滤 ⇒ 「画布 6 张卡」红 |

## 5. 风险与红线

| 风险 | 处置 |
|---|---|
| 段表进 meta 导致全段 hash 失效 | 指纹显式排除（B0 的硬性验收项） |
| 段窗变化让全部缓存一次性失效 | 接受：一次性重渲，换回后续「改一段只重渲这段」 |
| 段窗与 `sliceByShots` 半开区间语义不一致 | 单元测试锁 `[start,end)`，末段 `end = durationInFrames` 不进区间 |
| 旧 manifest 无段表 | 回退 `spec` 边界，行为逐帧不变（回归纪律） |
| 分镜卡加字段破坏 `adopt` 往返 | `segmentRef` 只新增、不参与 `04_storyboard` 解析；adopt 忽略未知字段 |
| 段级 patch 误改其他 section | patch 只接受 `sectionId` + 白名单字段，写回前 diff 回显 |

## 6. 不做

- 段级 UI 编辑器（C1/C2 契约未稳）
- ref2va 镜头视频混入 spec 通道（「一段」语义会含混）
- 把 `build/shot-cache` 当交付（hash 名 + 静音轨 + 过期回收）
- 给 spec 加 DSL（先证明用户真会按段改）
