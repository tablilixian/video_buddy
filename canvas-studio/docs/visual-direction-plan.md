## 0. 一句话结论

> **它不是缺一层皮肤，是缺三根骨头：一致的设计系统、真实的空间层级、兑现的时间维度。**
>
> 方向：把 UI 从「工具面板」重新定位成「**制作现场**」——让人一眼看出这里正在制作一部片子，而不是一堆控件的容器。
>
> 顺序：**秩序（一致）→ 空间（深度）→ 叙事（时间与镜头）**，不可颠倒。

## 1. 诊断：为什么现在不「高级」

> 以下每条都是**可验证的代码事实**，不是审美意见。证据取 `src/client/styles.ts`（4616 行）、`src/brand.ts`、`src/client/canvas/*`。

### 1.1 设计系统只落地了四分之一（令牌空转）

品牌方案 §3 定义了一整套 `--cs-*` 令牌。实际引用次数：

| 令牌组 | 设计用途 | styles.ts 实际引用 | 判定 |
| --- | --- | --- | --- |
| `--cs-accent*` | 品牌主色 / 选中 / 强调 | **49 次** | ✅ 真落地 |
| `--cs-radius-*` | 圆角 4 档 | 16 次 | ⚠️ 部分（大量裸值 `8px` / `10px` 仍手写） |
| `--cs-shadow-*` | 阴影 3 档 | 5 次 | ⚠️ 部分 |
| `--cs-canvas-bg*` | **画布专属底色** | **2 次** | ❌ 名存实亡 |
| `--cs-space-*` | 间距 4px 基数 7 档 | **0 次** | ❌ **空转** |
| `--cs-duration-*` | 动效时长 3 档 | **0 次** | ❌ **空转** |
| `--cs-glow-accent` | 选中节点光环 | **0 次** | ❌ **空转** |

**直接后果**：间距、字阶、时长全靠各处手感写死。证据：`styles.ts` 里 `font-size` 有 **11 种离散取值**（10/11/12/13/14/15/16/18/20/22/56px），`transition` 有 14 处但时长各不相同。

> 高级感首先来自**一致性**，而不是单点华丽。一致性缺位时，往上堆装饰只会更像拼装品——这是本方案把「收口」排在第一位的唯一理由。

### 1.2 空间层级失灵：全界面几乎同一个底色

| 容器 | 实际背景 |
| --- | --- |
| `.csCanvas`（画布容器） | `var(--dsw-alias-bg-base)` |
| `.csNode`（节点卡片） | `var(--dsw-alias-bg-base)` |
| `.csToolbar`（工具栏） | `var(--dsw-alias-bg-base)` |
| `.csDetailPanel`（详情浮层） | `var(--dsw-alias-bg-base)` |
| `.csProjects` / `.csChat`（左右栏） | 不设底色 → 继承同色 |

**全部同色**，整个界面靠 1px `border-l2` 描边切分。两个连带事实：

1. 品牌方案 §2.3 明写的「**画布区底色比宿主 bg 深一档 + 网格点阵，把创作台与工具壳视觉区隔**」——**从未落地**（`--cs-canvas-bg` 只被引用 2 次）。
2. 画布网格是 **1px 直角网格**（`linear-gradient` 双向 + `border-l2` mix 45%），不是点阵；`--cs-canvas-grid-major`（主网格）定义了却基本不用，**没有主次双层**。

> 专业工具靠**明度分层 + 景深**建立空间（DaVinci 的内容区比壳暗一档，Figma 的面板比画布亮一档）。我们现在让用户靠描边去猜哪块是画布。

### 1.3 隐喻断链：品牌讲了「导演」，界面说的是「控件」

品牌层已落地：场记板 logo、4 套 accent preset、金色审批（`--cs-gold`）、teal 播放（`--cs-teal`）。

但**骨架**没有兑现隐喻：顶部工作流条（`.csWorkflowBar`）是「一行灰字 + 两个按钮」；节点是通用卡片；图层是通用列表。产品最独特的价值——**agent 当导演、你当监制**——在界面结构上读不出来。

> 辨识度风险：把 logo 换掉，它就是一个普通的白板工具。

### 1.4 时间维度缺失：视频产品的灵魂没被做出来

`src/client/canvas/CanvasTimeline.tsx`（242 行）实际是**一条横向 chip 列表**：`csTimelineItem` = 缩略图 + 时长文字 + 勾选区。

| 真时间轴应当有 | 现状 |
| --- | --- |
| 时间标尺（秒 / 半秒刻度） | ❌ 无 |
| 播放头（可拖、联动选中） | ❌ 无 |
| 片段按**真实时长比例**排布 | ❌ 等宽 chip |
| 多轨（视频 / BGM / 参考） | ❌ 单条流 |
| 真波形 | ❌ **伪数据**（`csNodeAudioWave` 用写死的高度数组 `waveBars`） |

> 用户感受不到「我在剪片子」，只感到「我在拖卡片」。这是**差异化最强、也最欠缺**的一块。

### 1.5 反馈层贫瘠：4600 行样式表里只有 3 个动画

| 指标 | 实测 |
| --- | --- |
| `transition` 声明 | 14 处（集中在 frame / modal） |
| `@keyframes` | 3 个：`csProgressSlide`（进度条）、`csToastIn`、`csLogoPulse` |
| `backdrop-filter` | 1 处 |
| `filter: blur / drop-shadow` | 0 处 |

生成中 = 节点盖一层灰 + 不定进度条；完成后无任何"时刻感"。

> 高级工具的动效不是**多**，而是**每一次都说明一件事**。现在的状态是「静，但不精密」。

## 2. 设计定调

### 2.1 一句话方向

> **从「工具面板」到「制作现场」**：界面不是控件的容器，而是一部正在拍摄的片子的现场。

### 2.2 三层递进（执行顺序不可颠倒）

```
秩序（Order）        空间（Space）        叙事（Narrative）
令牌唯一来源    →    明度三档 + 景深  →   时间轴 + 镜头语汇 + 动效语义
"不再各处手感写"      "一眼看出哪里是画布"   "一眼看出在拍什么、拍到哪了"
```

没有秩序的空间只是花；没有空间的时间轴只是图。

### 2.3 三条设计原则

| # | 原则 | 含义（可检验） |
| --- | --- | --- |
| P1 | **暗得专注，不是黑得压抑** | 任何一屏里，**内容（图/视频）永远是最亮的东西**，UI 一律退到它后面 |
| P2 | **明度差表达层级，动效表达状态** | 每个明度档、每个动画都必须能回答"它想说明什么"；答不出来就删 |
| P3 | **在宿主里，不抢宿主** | 令牌叠加，不改 `--dsw-alias-*`，不动右侧对话区（宿主所有） |

## 3. 方案分批

### DD-01 设计系统收口（地基 · 必须第一个做）

**做什么**
1. 扩令牌：在 `src/brand.ts` 的 `NON_COLOR_TOKENS` 增补
   - **字阶**：`--cs-font-xs/sm/md/lg/xl/display` = 11/12/13/14/18/24px（把现有 11 种离散值收敛到 6 级）
   - **层级**：`--cs-z-canvas/node/panel/modal`（现在 z-index 散落 5/30/…）
   - **景深**：`--cs-dim-opacity`（0.7）、`--cs-surface-*` 三档明度
2. 迁移纪律：**禁裸值**（新写的样式不得出现裸 `font-size` / 裸时长 / 裸 z-index）；存量按「**触碰即迁移**」——只在改动某个组件时顺手迁该组件，不做全表重写。
3. **自动化守卫**（本批真正的价值）：新增 `tests/design-tokens.test.mjs`
   - 断言 `styles.ts` 中裸 `font-size: <数字>px` 数量 **不增加**（存量白名单）
   - 断言 `--cs-space-*` / `--cs-duration-*` / `--cs-canvas-bg*` **被引用次数 ≥ N**（防"定义了没人用"重演）
   - 断言 **`brand.ts` 里每个令牌名必须在 `styles.ts` 出现过**——这条守卫如果早存在，今天 §1.1 那 3 个「0 引用」当场就会被拦下

**验收**：视觉零变化（纯地基），但守卫测试全绿且能演示"故意加一个未使用令牌 → 测试红"。

---

### DD-02 空间层级重做（感知提升最大的一步）

**做什么**
1. **明度三档**（把 §1.2 的同色问题连根拔掉）
   | 层 | 底色 | 用途 |
   | --- | --- | --- |
   | 壳 | 宿主 `bg-base` | 左右栏、工具栏 |
   | 画布 | `--cs-canvas-bg`（#0F1117）| 画布容器 —— **终于用上早就定义好的令牌** |
   | 节点 / 浮层 | `--cs-canvas-bg-l1`（#1A1D29）→ `--cs-surface-l2` | 节点卡、详情面板、菜单 |
2. **网格改点阵 + 主次双层**：40px 点阵（`--cs-canvas-grid`）+ 200px 交点加重（`--cs-canvas-grid-major`），随缩放联动 —— 这是专业工具的标志性细节
3. **景深（focus dim）**：选中某节点时，**非相关**节点降到 `--cs-dim-opacity`。注意与 CV-089 的区别：CV-089 撤掉的是「**拖动就 dim**」（语义接反），本条是「**有选中才 dim**」，且幅度轻、可在设置里关
4. **面板玻璃化**：工具栏 / 详情浮层 / 右键菜单改 `backdrop-filter: blur(12px)` + 半透明底（现在全表仅 1 处）。**面积红线**：只用于浮动小面板，不用于左右大栏（避免合成开销）

**验收**：同一屏截三张图（改造前 / 后 / 明色主题），**不标注也能一眼分出画布区与工具壳**。

---

### DD-03 节点卡片重做（"作品感"的核心）

**做什么**
1. **媒体框随真实宽高比**（`canvas-aspect.ts` 已有能力），不再一律矩形同尺寸
2. **片门感**：媒体区上下加极窄暗带（模拟胶片片门），选中时媒体区外发光（用上 `--cs-glow-accent`）
3. **镜头条头部**：`#03` 镜号 + 景别徽标 + 版本 chip（`v2`），数字统一 `tabular-nums` 对齐
4. **参考图角标升级**：从「一个圆点」改成「角色牌」小色块 + role 短名（角色/场景/风格），与 Look 资产卡体系呼应
5. **生成中转为"显影"**：灰罩 + 不定进度条 → **扫描光带 + 阶段文案**（分镜推演 / 定妆中 / 渲染中），一次写清"它代表正在显影"

**验收**：**单个节点的截图**就具备产品识别度（可做 A/B 盲测：给非项目成员看两张节点图，问哪个更像专业视频工具）。

---

### DD-04 时间轴升维（差异化最强 · 独立排期）

**分两小步做，不要一次吃下**

- **DD-04a（不碰数据，先做观感）**
  - 时间标尺（秒 / 半秒刻度，`tabular-nums`）+ **播放头**（可拖，联动画布选中节点）
  - 片段按**真实 duration 比例**排布（真值时长链路 CV-138 已通）
  - 剪辑点标记 + 与画布节点**双向高亮**
  - **保留现有全部能力**（勾选参与合成、拖拽排序 → 等价映射到时间轴拖动）
- **DD-04b（需要数据侧配合）**
  - 多轨：视频轨 / BGM 轨 / 参考轨
  - 音频轨画**真波形**：用已有 `ffmpeg-run.ts` 通道抽音量包络（**不假造** —— 现在节点里的波形是写死数组）

**验收**：时间轴截图给非项目成员看，对方能说出"这是剪辑软件"。

---

### DD-05 生成过程叙事化（把「等待」变成「看得见的制作」）

**做什么**
1. **顶部工作流条 → 制作阶段轨道**：剧本 → 分镜 → 定妆 → 关键帧 → 镜头 → 成片，当前阶段行进中、已完成打勾。数据源：现有 workflow state（CV-084 已设计过 steps 契约，可复用）
2. **审批条 → 场记板形态**：打板动作 + 金色（`--cs-gold` 已有）—— 品牌隐喻**第一次真正进入骨架**，而不是停在 logo 上
3. **完成的"时刻感"**：节点生成完成时 240ms 显影淡入 + 极轻 scale（**不要弹跳**，工具感要克制）
4. **动效语义契约**（写进 DD-01）：全产品只允许三种动效语义
   | 语义 | 用于 | 曲线 |
   | --- | --- | --- |
   | **显影** | 生成完成、内容出现 | `--cs-ease` 240ms |
   | **行进** | 进行中、loading | 线性循环 |
   | **让位** | 面板/浮层开合 | `--cs-ease` 200ms |

**验收**：录 30 秒屏幕，**不看文字也能看出"AI 正在按流程往下推进"**。

---

### DD-06 首屏与三态（第一印象）

1. **欢迎屏**：现在是居中卡片 → 改为「**未开拍的现场**」意象：点阵画布 + 一束 accent 光晕（低透明度）+ tagline
2. **空画布**：从"空空如也"改为「**预演**」—— 画一条极淡的示例流水线（分镜 → 定妆 → 镜头 → 成片）作为幽灵引导，用户一眼看懂工具干什么
3. **错误态**：三级处置（`error-kind.ts` 已有逻辑）补视觉分级（可重试 / 去设置 / 查服务）

**验收**：首启截图可直接当作产品介绍图使用。

```
                  └──► DD-04 时间轴（独立排期，04a 可提前插入）
```

| DD-06 | DD-02 | 需要新空间语言定稿后再画首屏 |

## 5. 硬约束（不可谈判）

| # | 约束 | 说明 |
| --- | --- | --- |
| 1 | **零外部依赖** | 不引 CDN / webfont / 图表库 / 动画库；动效全部 CSS 实现 |
| 2 | **不改宿主令牌** | `--dsw-alias-*` 只读；插件样式全部走 `--cs-*` + `data-plugin='canvas-studio'` 作用域 |
| 3 | **不动右侧对话区** | 对话槽属宿主，只可重排不可改内容 |
| 4 | **零数据迁移** | 纯表现层改造，不碰 `canvas.json` 契约与用户存量数据 |
| 5 | **性能红线** | 动画只用 `transform` / `opacity`；`backdrop-filter` 仅限浮动小面板；`will-change` 仅手势期间挂 |
| 6 | **每批走验证链** | typecheck（Host+Client）→ build → `test:smoke` → 桌面人工验收；**只认 `# fail 0`** |
| 7 | **降级尊重** | 所有动效包 `prefers-reduced-motion`；明色主题同样成立（不能只为暗色优化） |

## 6. 风险与取舍

| 风险 | 说明 | 处置 |
| --- | --- | --- |
| 暗基调压内容 | 画布再暗一档，暗部素材可能糊 | 只压"壳与画布"，**节点内容区不压**；改造后拿暗部素材实测截图 |
| 玻璃拟态性能 | 大面积 blur 会掉帧 | 面积红线（约束 5）+ 只在浮层 |
| 景深引发误操作感 | 用户可能以为节点"变灰=不可用" | 幅度轻（0.7）+ 提供开关 + 只在有选中时触发 |
| DD-04 体量最大 | 真时间轴是独立工程 | 拆 04a/04b，先保观感与功能不倒退 |
| 与 CV 条目抢排期 | 视觉批次可能挤压缺陷修复 | DD 批次与 CV 缺陷按"一次一批"交替，不做并行大改 |
