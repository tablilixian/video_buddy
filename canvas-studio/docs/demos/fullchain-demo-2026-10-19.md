# 主链路真机验收片 ·《修表的人》— 演示脚本与跑法（2026-10-19）

> **定位**：走 `canvas-studio-creation` 的**完整 11 步**（澄清 → 拍摄定稿 → 确认落地 → 资产卡 → 定妆/场景 → 逐镜视频 → 合成 → 质检），**不跳步**；第 10 步用 `render_composition` 出片，让三期（REQ-034 · W1~W6）能力在同一支片子上被真机验证。
> **与另一份的关系**：`remotion-phase3-demo-2026-10-19.md` 是**旁路案例**（知识型图文短片，第 9 步整步跳过），只能验引擎、验不到框架。本轮主测是本文。

---

## 一、为什么是《修表的人》

选型标准是「链路走得全 + 一致性风险可控 + 视频生成成本可接受」：

| 约束 | 本例怎么满足 |
| --- | --- |
| 要能测资产卡与一致性 | **单主角**（老修表匠），一个 `character_sheet` 就能锚住全片 |
| 要能测 Ref2VA | **单场景**（表店），角色定妆 + 场景概念 + 道具手部特写 = **3 张参考**，正好够 Ref2VA 的 ≥3 张下限 |
| 要能测多镜合成与转场 | **3 镜 + 片头片尾卡**，微距 → 中景 → 全景，景别递进，转场有得看 |
| 视频生成成本 | 3 镜 × 5s，不是 10 镜长片；后端单任务串行，预计 15–30 分钟 |
| 三期能力有落点 | 字幕卡 ×3、片头片尾 ×2、统一调色、转场 ×4、BGM 铺底 + 闪避 |

**故事**：一家打烊前的修表店，老人把一枚停了的旧表修好，起身关灯。

## 二、内容（分镜表）

1920×1080 / 16:9 / 30fps / 总长 ≈ 20s（片头卡 2.5s + 3×5s + 片尾卡 2.5s）

| 镜 | 时长 | 景别 / 运镜 | 画面 | 台词（字幕） |
| --- | --- | --- | --- | --- |
| **片头卡** | 2.5s | 纯排版 | 深色底 + 细横线 | 主标「修表的人」/ 副标「时间坏了，不一定要换」 |
| **S1** | 5s | 微距特写，极缓推近 | 老人的手在灯下拆一枚旧机械表，镊子、齿轮散在绒布上 | 「时间坏了，不一定要换新的。」 |
| **S2** | 5s | 中景，固定机位，轻微呼吸感 | 老人抬头看向窗外，玻璃上有雨痕，店里暖光 | 「停下来的东西，也能修。」 |
| **S3** | 5s | 全景，机器缓退 | 老人把表放回柜台，伸手关掉台灯，店暗下来 | 「明天，它还会走。」 |
| **片尾卡** | 2.5s | 纯排版 | 近黑底 | 小字「—— 致所有还在走的东西」 |

**音乐**：低音提琴 + 秒针滴答，约 20s，铺底不抢台词；首尾淡入淡出；字幕在屏时自动压低。

```

   字幕「时间坏了，不一定要换新的。」
S2 5s 中景固定机位：老人抬头看向窗外，玻璃上有雨痕，店里暖光
   字幕「停下来的东西，也能修。」
S3 5s 全景缓退：老人把表放回柜台，伸手关掉台灯，店暗下来
   字幕「明天，它还会走。」
片尾卡 2.5s：小字「—— 致所有还在走的东西」

【流程要求】
1. 先做需求澄清（形态/Look/画幅时长），我逐项选
2. 拍摄定稿写好后停下，等我在覆盖层点「确认落地」
3. 落地后先建角色资产卡（老修表匠，60 多岁，花白短发，深灰色羊毛背心，
   袖口磨白，右手食指有老茧），锁定提示词给我确认
4. 出定妆照 + 表店场景概念图
5. 逐镜出视频（每镜一条，不要把一个分镜拆成多条）
6. 成片要带字幕卡、片头片尾、转场和全片统一调色 —— 用 Remotion 时间轴合成，
   不要用纯片段拼接

【观感要求】
- 全片统一影调：偏暖、轻暗角、细颗粒，别三镜三套色
- 字幕不要硬出现硬消失，进出都要有动画
- 镜与镜之间用带缓动的叠化，不要硬切
- 片头主标要有落位感（轻微回弹），不要匀速推上去
- 字幕在屏时 BGM 自动压低，字幕走了再回来
- 底部可以有一条很细的音频律动，贴着底边

【出片顺序】
1. 先草稿质量档出一版对节奏
2. 定稿后标准档再出一版
3. 把渲染报告（耗时/单帧耗时/质量档/命中了几条编排体检）和抽帧图片一起给我
4. 最后出质检报告
```

## 四、逐步确认模式下会停的三次（提前知道，别以为卡住了）

| 时机 | 谁动手 | 你要做什么 |
| --- | --- | --- |
| 第 1 步澄清 | 你点选项 | 产物形态 → Look → 画幅/时长，**一次只问一个**；想省事就切「放手跑」，它会自列假设 |
| **第 3 步「确认落地」** | **只能你点覆盖层按钮** | agent 不能代点。它一到这一步就该停手；如果它没停、还在继续生成，那是越权，别批准 |
| 第 6a 步关键帧门 | 你点确认 | **默认不出关键帧 ⇒ 不会停**。只有你要求「这镜构图要钉死」才出、才停一次 |

> 若整轮只想跑一次不被打断：切「放手跑」模式，它会一路到成片（关键帧门直接放行、也不再弹点选）。

## 五、逐步验收点（对着 11 步看，哪步没发生就是漏了）

| 步 | 该发生什么 | 在哪里看 |
| --- | --- | --- |
| 1 | 澄清是**点选**弹窗，一次一个要素 | 对话流 |
| 2b | 产出拍摄定稿：§00 主题 / §03 剧本 / §04 分镜 / §05 台词 | 故事板页 |
| 3 | 你点「确认落地」后，画布上**自动长出**镜头节点与资产节点 | 画布 |
| 4 | 角色资产卡生成，`lockedPrompt` 先给你过目再锁定 | 画布资产卡 |
| 5 | 定妆照 + 场景概念图各出 1 张 | 画布 |
| 7 | 每张镜头图都有上传回执，不是本地路径直塞 | 节点详情 |
| 8 | 文案节点里有对白与整体音景描述 | 节点详情 |
| 9 | 每镜**恰好一条**视频；用的是多参考 Ref2VA（参考 ≥3 张） | 画布视频节点 |
| 10 | 成片带字幕卡/片头片尾/转场/统一调色 | 成片节点 |
| 11 | 一份《质检报告》随交付输出 | 对话流 |

**合规红灯**（看到任何一条就说明跑了 shortcut）：

- 画布上没长出镜头节点，却已经有视频了
- 一个分镜拆成了多条视频（违反「一镜一条」）
- 参考图只有 1–2 张却走了 Ref2VA
- 成片是纯拼接（无字幕/无转场/无调色）
- `lockedPrompt` 被改写（一致性硬约束被绕过）

## 六、三期能力在第 10 步的落点（这才是本轮真正要看的）

成片合成必须走 Remotion 时间轴，manifest 里应当能看到：

| 三期能力 | 该出现的位置 | 肉眼/数据怎么验 |
| --- | --- | --- |
| `startAfter` 顺序衔接 | 5 段（片头+3镜+片尾）依次接上 | 日志有「顺序衔接已解析」；衔接处无 1 帧黑缝或重叠 |
| `exit` 退场 | 每条字幕、每张卡 | 字幕/卡片都是淡出或下沉，**没有突然消失** |
| 缓动升级 | 片头主标、字幕入场 | 主标有回弹（先过冲再落定）；字幕入场利落不匀 |
| `meta.look` 统一调色 | 全片 | 与「删掉 look 再渲一版」对比，影调差别应明显 |
| 转场参数化 | 镜与镜之间 4 处 | 叠化时长够、有缓动，不是「啪」一下 |
| BGM 闪避 | 每条字幕在屏期间 | 字幕出现时音乐明显变轻，字幕走了回来 |
| `audioViz` 线条律动 | 底部细条 | 有平滑律动，不是方块乱跳 |
| 质量档 | 两次出片 | `draft` 明显更快（目标 ≥2.5×），报告里 `quality` 对得上 |
| 渲染报告 + 抽帧 | 每次出片结果 | 有 `msPerFrame` / `totalMs` / lint 条数 / ≥4 张抽帧 |

**编排体检（lint）判据**：≤3 条可接受；出现 **ML-02**（片尾前结束却没退场）必须修；出现 **ML-09**（元素出画）必看抽帧确认。

## 七、成本与耗时

| 项 | 量 | 说明 |
| --- | --- | --- |
| 图像 | 约 4–6 张 | 定妆 + 场景 + 必要参考 |
| 视频 | 3 条 × 5s | 后端单任务串行，每条约 3–8 分钟 ⇒ **15–30 分钟** |
| 音乐 | 1 条 ≈20s | 若失败则跳过音频轨，其余照测 |
| 人工停顿 | 1–2 次 | 确认落地（必）；关键帧门（可选） |

## 八、可选加测（想多压一点就加，不想就不加）

1. **关键帧门**：明确要求「S1 的构图要钉死，出姿态关键帧」→ 会出关键帧并停一次等你确认。这条能验 6a 与「提交即停手」。
2. **返工**：挑一镜点「需要修改」→ 看它走 `replaces` 指旧节点，而不是覆盖；一致性卡不得改写。
3. **参考视频**：给一段参考视频让它「拆分视频」，验跨模态参考上限与拆分链路。

## 九、跑挂了先降哪一级

| 现象 | 降级 |
| --- | --- |
| 视频生成排队/超时 | 砍到 2 镜（S1+S3），片段缩短到 4s |
| 角色一致性崩（三镜像三个人） | 先把 S1 改成纯手部特写（不露脸），一致性压力减半 |
| 资产卡 `lockedPrompt` 被反复改写 | 停下来记录，这是硬约束被绕过，属真缺陷，先别继续跑 |
| 第 10 步又退回纯拼接 | 明确回一句「要字幕卡和转场，用 Remotion 时间轴合成」，不要自己补做 |
