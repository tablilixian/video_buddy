设计要点（来源）

图标即状态：徽标只保留「图形 + 时间」两个语义单元。图形（呼吸点/勾/叹号/暂停）跨语言可读，时间是数字 —— 两者都不需要翻译，文案挪进 tooltip。
等待置顶：Claude Code 把 Needs input 排在 Working 之前、永远最上 —— 列表的第一职责是「哪里需要我」，不是「哪里在跑」。
动画 = 执行中：所有 harness 对 running 都用动态元素（呼吸环/转圈），静态图标无法和已完成区分。
hover 弹框：参考你截图的会话详情卡 —— 标题 + 状态 + 环境/目录/分支/更新时间。行内保持极简，详情按需浮现，移开即走。
刚刚完成是瞬态：完成 + 短时间窗内高亮，配合系统通知，超时回落 —— 避免用户错过「刚出炉的结果」。
双层状态：参考 Cursor —— 项目状态由最近一次会话 run 推导（CREATING/RUNNING/WAITING/FINISHED/ERROR…），项目本身不发明状态。
