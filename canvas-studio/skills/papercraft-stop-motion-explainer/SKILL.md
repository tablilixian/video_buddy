# Papercraft Stop-Motion Explainer

手工纸艺定格讲解片的**风格知识库**：视觉纵深、纸艺质感、定格运动语言、镜头与转场、声音与自检清单。

## 立场声明

**本 skill 只提供风格知识与该风格的特殊约束；流程、审批门禁与工具契约一律以 `canvas-studio-creation` 为准。**

## 何时用 / 何时不用

**用**：用户要用手工纸质感讲科学、教育或通识内容——剪纸、纸板剪影、微缩立体场景、定格木偶、立体书舞台、纸质道具与真实投影。

**不用**：常规 2D 卡通、线稿涂鸦、真人实拍、没有纸艺质感的讲解。

## 风格知识

### 视觉纵深（本风格的第一优先级）

每一份视觉方案、预览提示词、视频提示词与审阅都要同时保住"分层纵深"与" unmistakably 纸艺定格"两件事：

- 场景要有清晰的前景 / 中景 / 背景 / 远景四个平面。
- 用纸叶片、云、画框、幕布、道具或剪影做前景遮挡来造深度。
- 主体知识对象或焦点动作放在可读的中景平面。
- 用背景视差、小幅环境运动与分层拉开距离，**不要**平面静止背板。
- 有助于读懂纵深时可用圆形、对角线、隧道、立体书或剖面构图。

### 纸艺质感（对象必须看起来是纸做的）

- 层压纸板、裁切边、纸纤维、折痕、接缝、插舌、铆钉、关节、拉片、滑轨、转盘与可见厚度。
- 背景元素在可能时也做成纸机构：纸云沿轨道滑行、纸月亮/圆盘沿轨道移动、分层布景做视差、纸叶飘落、纸灯摇晃、纸板门开启。
- **禁止**：顺滑 CG 运动、塑料 3D 表面、扁平矢量背板、过于静止的背景、破坏微缩定格感的大幅角色运动。

### 定格运动语言

- 逐帧手工操控感：小步位移、细小停顿、轻微回弹、铰接手势、滑动的纸机构、翻页、拉片显形、纸片落定。

### 风格 DNA（必须全程一致）

手工纸艺定格质感 / 微缩纸立体场景或暗箱舞台 / 层压纸板剪影且厚度可见 / 哑光触感纸纹理、纤维、折痕、接缝、撕裂或裁切边 / 纸偶角色由分离叠片构成 / 层间真实投影 / 前后中远景多平面 / 微距微缩摄影、轻微景深、2.5D 视差 / 用纸做的教学标签、箭头、卡片与简单符号 / 背景层带纸机构运动而不是静态彩绘布景。

**为什么这样定**：纸这种媒介把抽象科学变成可触摸的物件，并让分层讲解变得容易理解。场景必须像真的被搭出来、逐帧动起来，而不是"仅仅画了纸纹理的插画"。

### 镜头与转场（像拍微缩纸舞台）

推荐运镜：缓慢推进进入纸世界 / 带多平面视差的横移 / 主持人讲解的固定中景 / 纸纹理与关键道具的微距特写 / 剖面图的轻微俯视 / 进入内部结构时的穿层。

避免：高速飞镜头 / 除非布景专门为此搭建否则不要 360 度环绕 / 数字故障运动 / 液态变形 / 超写实 CG 运镜。

推荐转场（必须服从纸的物理）：翻页 / 立体书展开 / 拉片滑动 / 纸质标签擦除 / 纸云掠过 / 圆形纸遮罩 / 剪纸门开启 / 剖面分层 / 纸屑迸发 / 胶带或贴纸揭示。

避免电子扫描线、霓虹故障、玻璃碎裂、金属擦除与科幻粒子转场——除非用户明确要反差效果。

### 声音方向

触感手工音色板：翻纸 / 剪刀咔嚓 / 纸板滑动 / 纸张窸窣 / 木头轻响 / 轻 pop / 撕胶带 / 木偶关节敲击 / 开盒 / 纸屑散落。SFX 按分镜时间轴映射，作为触感重音，不要变成夸张卡通音。

配乐要贴合题材的文化与情绪，而不只是泛泛的纸艺风格：中秋讲解倾向克制的中国传统音色（古筝、琵琶、竹笛或箫、轻打击、软弦乐，给旁白留够静默）；无强文化属性的科学/课堂题材用轻马林巴、钢片琴、拨弦、轻打击与温暖的教育气质。旁白下压低音乐并做 ducking；避免厚重电影贝斯、激进 EDM、未来感音色与过度戏剧化配乐。

### 分层景深表（多层舞台的硬要求）

- 列：层号 / 平面角色 / 纸元素 / 材质与边缘处理 / 运动或视差行为 / 阴影关系 / 知识功能。
- 多数镜头用 4-7 层；阅读密集的标签放在稳定层；前景元素允许部分遮挡舞台以获得微缩真实感；核心概念留在注意力最强的中景；用层间关系解释层级、顺序、结构、因果或尺度。
