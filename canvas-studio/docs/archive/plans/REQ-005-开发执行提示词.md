## 3. 已核验的关键事实与陷阱（这些不要再验证一遍）

1. **会话就绪不是 await 的**：`openProject`（client/index.ts:1183-1235）里 workspace 绑定/画布重载都 await，但 `startSession` 是 fire-and-forget，且 1207 行刚 `sessionSvc.clear()` → 新建项目后 `sessions.current` 极可能为 undefined。**发送首条消息前必须就绪等待**（复用 `waitSessionBound`，`index.ts:1351-1360`；注意它超时抛效果测试专用的 `CS-EFFECT-001`，要 catch 转降级，或写等价本地轮询）。
2. **send 失败二分**：scope/get 取不到 = 未就绪 → 重试至 3s 超时；`conversation.send()` promise reject = 业务失败 → 立即降级（toast + `insertReferenceToken` 注入输入框，`StudioFrame.tsx:867-896`）。**禁止照抄 `wakeAgent` 的 `.catch(() => {})`**（index.ts:783，会吞掉一切、降级永不触发）。
3. **回首页是两层缺口**：品牌区 LogoMark 目前不是按钮（入口要新建）；裸用 `select(null)` 会被 `syncActiveProject`（index.ts:598-607，订阅点 :1027/:1035）踢回。`homePinned` 短路只加在 `syncActiveProject` 即可（`syncHasConversation`/`alignStartupSession` 不绕过）；解除建议做在 `select` action 内（projectId !== null 即清）。
4. **CSS 不止一条**：lobby 态现有规则 `styles.ts:89-157` 会把 `.csChat`（含 conversation + ChatStrip）搬进中栏居中 → 需在 `data-mode="lobby"` 下隐藏整个 `.csChat`，不能只藏 `.csConversation`。
5. **测试命令**：根 `corepack yarn test/check` **不含 canvas-studio**。正确链路见 §4。测试 import `../lib/*.js`，源码写坏测试照样绿——typecheck/build 才是闸门。
6. **touch 路由**：`POST /canvas-studio/projects/:id/touch` 必须带 `mutationAllowed` 守卫（routes.ts:152，同 :395/:428/:461 口径）。`openProject` 只由用户动作触发（:1244/:1333/:1393/:1463），启动不会自动 open。
