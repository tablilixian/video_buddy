## 第 1 项 · CV-464：历程视图默认主视图 + 进度状态条

以正常用户操作，逐条核对：

1. **打开一个已有项目** → 期望：直接进「历程瀑布流」视图，不是自由画布。
2. **切到自由画布，关掉应用再重开** → 期望：还记得上次是自由画布（视图切换被记住）。
3. **看画布顶部的进度条** → 期望：有全局进度 `已完成/总数`、一条活动行、几个阶段小色块（chips）。
4. **点其中一个阶段色块** → 期望：跳到对应的那一节。
5. **三个开关逐个拨动**：显示文本类 / 显示辅助卡 / 跟随新产出 → 期望：每个都能立刻看到对应变化。
6. **生成一个新节点**（保持"跟随新产出"开）→ 期望：新节点自动出现在视野里，不用手动找。
7. **把窗口缩到很窄**（约 800px 以下）→ 期望：卡片缩小但内容不溢出、不重叠。

## 第 2 项 · CV-465：版本堆栈折叠 + 角标浮层 + 回滚

1. **同一个镜位反复重新生成 3 次** → 期望：画布上只看到当前最新版，旧版不铺满画布。
2. **看最新版的卡头部** → 期望：有一个类似 `v3 · 2 历史` 的小角标（版本号 + 历史数量）。
3. **点这个角标** → 期望：弹出一个居中的小面板，列出刚才那 3 个版本，每行有缩略图、标题+版本号、落盘时间、状态（已被取代/已作废）。
4. **在面板里选一个旧版，点「回滚为此版」** → 期望：旧版变成当前生效版，原当前版自动作废；切到自由画布再看，两边显示一致。
5. **打开「显示废弃素材」开关** → 期望：所有旧版平铺回显（回到折叠前的行为）。

## 第 3 项 · CV-466：卡面快捷操作

1. **在历程视图里单选一张图片/视频/音频卡，鼠标悬停在卡上** → 期望：卡片右上角浮出两个小按钮：`✎`（改提示词）和 `↻`（重新生成）。
2. **点 `✎`** → 期望：打开的提示词输入框，和右键菜单里的「修改提示词」是同一个（不是新面板）。
3. **点 `↻`** → 期望：走正常的重新生成流程，参数不变。
4. **多选几张卡** → 期望：这两个按钮**不出现**。
5. **找一张正在生成中的卡、一张失效的卡** → 期望：这两个按钮**不出现**。
6. **鼠标快速划过卡片边缘** → 期望：不误触发拖拽或框选。

## 第 4 项 · CV-467：项目列表状态徽标 + hover 弹框

1. **看左侧项目列表** → 期望：每个项目行有一个徽标，只有图标 + 时间，**没有文字**。
2. **制造这几种状态并逐一核对徽标**：
   - 项目需要你回答问题时 → 琥珀色、置顶、左边框高亮
   - 项目正在运行时 → 蓝色
   - 项目刚出结果时（5 分钟内）→ 绿色
   - 项目正常完成时 → 淡绿
   - 项目失败时 → 红色
   - 项目空闲/暂停时 → 灰色
3. **鼠标悬停或用 Tab 键聚焦到项目行** → 期望：浮出一个详情弹框，含 5 行（阶段 / 模式 / 目录 / 更新于 / 规格）+ 一块状态专属内容。
4. **重点看状态专属内容**：运行中 → 一条走动的进度条（**不该显示假的百分比数字**）；失败 → 显示问题原文；刚出结果 → 有"成片已就绪"提示。
5. **看列表分组的小标题旁** → 期望：有色点 + 数字计数，状态变化时会闪一下。
6. **视觉对照基准**：用浏览器打开 `canvas-studio/docs/demos/2026-11-16-项目状态徽标与hover弹框-demo.html`，对比实际界面与基准差异。
