## 悬疑 / 惊悚张力（最高频使用）

| 机制 | 核心规则 |
|------|---------|
| `offscreen-cue-progressive-tightening-unrevealed-source` | 只拍反应者，画外线索逐次逼近；每次线索后景别更近、动作更小，**始终不揭示来源**，用停顿或黑场收尾。门外有动静类场景的首选。 |
| `delayed-turn-silhouette-contamination-lens-breach` | 走廊/门框中人物先背对镜头保持日常基线，缓慢转身建立面孔，异常（发丝/烟影）从肩部连续扩张，全片只允许一次贴近镜头的突破。 |
| `prove-background-anomaly-through-recording` | 异常先出现在背景而人物继续日常；用记录设备（手机/监控）把异常隔离成证据，人物**延迟一拍**才反应。 |
| `escalate-evidence-into-reality` | 稳定现实中同一证据载体（照片/屏幕/纸条）连续更新，最后异常内容**延迟跨入现实**。 |
| `message-distance-collapse` | 远端警告先模糊后精确，第二条信息把威胁位置压缩到主角当前空间；结尾只留转身前的反应，不揭示威胁。 |
| `social-arrival-delayed-baggage-anomaly-return` | 新来者先完成可信的普通抵达，等社交基线成立后再用连续局部插镜揭示行李异常；结尾回到**仍未察觉**的群体，信息差即张力。 |
| `ritual-expectation-blackout-return` | 温暖仪式（吹蜡烛）立即切全黑场；同一人物在冷亮环境回归，表情由期待转失落，因果反差一步完成。 |
| `reveal-evidence-through-failed-concealment` | 遮挡每失败一次就暴露更深证据，以人物停止遮挡、回到原位收口。 |
| `optical-search-evidence-contraction` | 受限光学视野（门缝/猫眼/镜头）承担完整搜索：远处锁定 → 逐级收紧到细节，每次靠近回答一个更具体的问题。 |
| `passive-anchor-to-extraordinary-exit` | 长停留固定主角位置，威胁进入后逐次压缩活动余地，全片只允许一次超常出口改变冲突状态。 |
| `frontal-retreat-collapsing-corridor` | 主角面向威胁、背向出口持续后退，镜头匹配速度倒退；危险逐段占据走廊，余量不断缩小，以边界闭合结束。 |
| `sensory-seal-location-swap-resumption` | 主动封闭感官（闭眼/捂耳/静止）作为触发，只在主体完全静止时发生一次全画幅换境，用同一身份和恢复动作证明空间已变。 |
| `trusted-carrier-delayed-interior-release` | 密封载体（包裹/柜子/门）经可信流程进入空间，静置一段时间后从内部开启，隐藏内容在环境尺度留下可见后果。 |
| `still-group-anomaly-displacement-direct-threat` | 安静群像 → 局部表情异常 → 强制位移留出空场证据 → 已异变者从深处逼近占满镜头，四级升级。 |
| `pursuit-route-collapse-remote-survivor-reframe` | 逃生载体离站后遭不可逆破坏，切到远处安全高位让同一人物重现直视来向——空间分离重新解释前段追逐。 |
| `future-message-environmental-verification` | 私密装置先给出"来自未来/未知"的警告，主角转向可核查的外部窗口，用城市异常版本证明时间/空间错位。 |
| `threat-substitution-rescue-to-renewed-pursuit` | 更大威胁介入终止旧敌；每次解围都同时打开下一层危险，结尾保留更大威胁的活动迹象。 |
| `suspended-accident-active-sampling` | 事故冻结在最大混乱状态，唯一能行动的主体取走证据物件并离场——异常由"独占行动权"证明。 |
| `direct-imperfect-memory-farewell` | 观察者视角发现日常 → 外部信号改变人物目标 → 以**有动机的拍摄失误**收尾（回忆/监控叙事）。 |

## 情绪表演 / 微表情（特写镜头质量控制）

| 机制 | 核心规则 |
|------|---------|
| `continuous-emotion-escalation-conceal-residue` | 锁定人像/背景/距离，用可累计的眼神、嘴部、呼吸、泪痕把中性状态推向峰值；峰值后允许短暂遮挡但必须重新露出，**保留情绪残余**，不瞬间恢复。 |
| `build-microexpression-greeting-arc` | 近锁定人像五段微表情：侧身 → 直视 → 垂眼停顿 → 闭眼笑峰值 → 开放放松；不换场景不加大动作。 |
| `facial-action-unit-calibration` | 只让眼睑/眉/下颌/视线/唇形等局部动作单元**分段**变化，中间用微小复位防止表情混成。 |
| `selfie-affect-crest-interruption-neutral-hold` | 笑到峰值 → 画外提示打断 → 笑意消退、重新调节呼吸 → 同构图内保持中性/轻微担忧。手机前表演通用。 |

## 双人关系 / 对白节奏

| 机制 | 核心规则 |
|------|---------|
| `ensemble-dyad-position-realignment` | 群像建立关系 → 收紧到两人 → 用发言轮次、目光、微动作更新关系 → 一人越过原轴线另一人跟随，以站位变化收束。 |
| `stage-two-turn-pause-reaction` | 双人同框：建立眼线 → 第一轮说话 → **清楚停顿** → 第二轮说话 → 第一人无声反应收尾。对白节奏的基准模板。 |
| `practical-adjustment-nonverbal-readiness-confirmation` | 全程无对白：一次连续功能明确的双手动作（整理衣领/包扎）+ 退开 + 双方克制微反应 + 同框证明准备完成。 |
| `showy-effort-quiet-skill-social-status-reversal` | 炫技者建立预期，安静者一次干净完成更难动作；围观者视线转向完成地位反转，双方都以克制反应收尾。 |
| `apparent-vulnerability-readiness-reversal-resumption` | 看似无助 → 两三个克制的准备微动作重新编码为有能力的一方 → 单一清楚能力链解决 → 回到原目标路线。 |
| `misdirected-violation-comic-retaliation-exit` | 喜剧向：违规者偷窃后自行失衡，被偷者取回并用重复受控动作完成温和惩罚，笑点来自社会关系不靠摔倒。 |

## 叙事结构 / 日常流

| 机制 | 核心规则 |
|------|---------|
| `bounded-day-loop-recurring-anchor` | 重复人物特征和随身物串联一天：准备 → 出发 → 通勤 → 工作 → 与开场呼应的休息；高密度切换保持因果顺序。 |
| `extraordinary-visitor-mundane-day-return` | 一眼可识别的非常规访客制造钩子后**不解释来历**，让同一身份锚点完成一系列普通任务，结尾回到开场的静止状态——荒诞被日常秩序正常化。"门外人"类题材核心结构。 |
| `ordinary-task-to-breathing-reset-exit` | 普通触觉任务 → 过渡到静坐 → 一次慢呼吸+微笑 → 重新起身沿既定方向离场，证明静默不是终点。节奏呼吸口。 |
| `repeat-reset-escalating-mishap-anthology` | 同一关系反复执行：普通准备 → 主动动作 → 可见后果 → 见证者反应 → 场景复位；每轮更换物理问题并提高强度（喜剧连击）。 |
| `stage-deadpan-chain-failure` | 正式场合连锁失控不断升级，主体始终镇定——反差本身构成笑点。 |

## 使用方式

1. **先选机制**：按剧情节拍在上表匹配（如"门外有动静"→ `offscreen-cue-*`）。
2. **再套 Context-IR**：机制的"结构锚点"映射为 `[Shot N]` 时间线节拍，按
   `SKILL.md` 五步流程 + `format-base.md` / `format-ref2va.md` 编译。
3. **守硬约束**：机制原文里的遮断卡/文字卡等 Seedance 视觉元素，改用 H3 的
   画面内文字（英文双引号）或 `cross-dissolve`（仅用户明确要求时）表达。
4. 一条 10s 纪 IR 一般只承载**一个机制**；多机制叠加会让单镜头过载。
