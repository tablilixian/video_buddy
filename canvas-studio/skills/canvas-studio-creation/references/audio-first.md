# 声音规划（audio-first）—— S4 分册 · 2026-10-28

> 总纲第 2d 步的完整细则。背景：S2b 收口后，多镜成片走「视频母版 + 音轨从零装配」——
> 原生环境声按各镜真实时长落位、BGM 铺底（0.35）、旁白满音量、`voiceOverNodeIds`
> 多句排布、短 BGM 自动补静音并明确告知。**纪律换参数**：这套模型让「BGM 时长铁律」
> 从「agent 必须守约」变成「守约有奖、违约兜底」，但按真值规划仍然是最优解。

## 一、开工前先定死三件事（第 2d 步清单）

| 事项 | 取值 | 落点 |
|---|---|---|
| **人声/纯器乐** | 对白片/口播 → 人声路径；氛围片 → 纯器乐 | `music_generation` 的 lyrics 留空（自动 `[Instrumental]`） |
| **有没有旁白** | 有字幕/台词 → 必配（逐步确认模式问用户，放手跑按形态默认：对白片必配、纯图文卡不配） | 结论写进 storyboard 的 `narration` / `sound` |
| **BGM 目标时长** | = 预计成片总时长（余量梯度见 toolchain.md「BGM 时长铁律」） | `music_generation` 的 `duration` |

## 二、两条路线

### 路线 A：音乐先行（推荐，MV / 卡点片 / 情绪驱动片）

1. 需求澄清后**立即** `music_generation`（duration = 预计总时长 × 梯度系数）；
2. 产物节点落画布 → **记下节点 id**（bgmNodeId）；
3. 分镜时**按乐段结构写节奏**（前奏 N 秒起画面、副歌对应高潮镜——音乐长度已知，切镜有依据）；
4. 合成时 `compose_video(bgmNodeId=…)`。

**失败判据**：分镜总时长与 BGM 时长差 > 容差 → 以**成片真值**为准（见路线 B 第 3 步的对齐纪律），不要重生成 BGM 除非结构性错误（风格不对 / 长度差 > 30%）。

### 路线 B：视频先行 + 事后对齐（默认降级路线）

1. 正常走完 1–9 步（视频全出）；
2. `list_shots` / compose 缺省选片估计总时长；**成片真值以 H3 帧量化后为准**（请求 5s → 5.167s，多镜累计放大——`compose_video` 结果里的时长漂移提示会说）；
3. 按**真值 + 余量**生成 BGM → `compose_video(bgmNodeId=…)`。
4. BGM 已经生成但偏短 → **不必重生成**：S2b 起装配自动补静音并在结果里明确告知「已自动补 N.Ns 静音」；若尾段静音不可接受（音乐在高潮处戛然而止），再按真值重生成。

**失败判据**：结果 warnings 含「已自动补静音」且用户在意 → 重生成；含「未探测混入音源时长」 → 用 `cut_audio` / 重新 `music_generation` 修，不要无视。

## 三、多句旁白写法（compose 路径）

**两句及以上旁白 → `compose_video` 的 `voiceOverNodeIds: string[]`**（与 `bgmNodeId` 并存）：

- 数组**顺序 = 播放顺序**：第一句从 0s 起，后续句零间隙紧跟前一句结束处；
- 每句满音量、不加淡入淡出、允许短于成片（旁白说完就静是正常形态）；
- 结果文本逐句回显起止 —— **合成后必读回显核对**，与分镜对不上就用 `cut_audio` 裁句长或改写台词。

**每句起始秒怎么算**（需要错落分布时）：`startSec = 该镜头起始秒 + 入点留白(0.2–0.5s)`。
镜头起始秒 = 该镜前面所有片段真实时长之和（`list_shots` 的 duration 真值累加；成片结果
文本的「音轨装配」摘要也会回显每段落位，可对账）。**禁止**自己在 shell 里算 ffmpeg 参数——
装配是 Host 的事。

需要逐句精确到帧（MV 跟唱、卡点字幕）→ 走 `render_composition` 的
`audio.voiceOver: [{src, startFrame}]`（src 抄同源 URL，startFrame 30fps 帧号）。

## 四、单句旁白与角色

- 单句旁白：直接 `compose_video(bgmNodeId=<tts_voiceover 节点 id>)` —— 按 `resolveAudioMixRole`
  自动识别为旁白轨（满音量、无淡变、允许短于成片），音轨构成报「旁白」不报「纯 BGM」。
- 用户想调音量/淡变/duck → 时间轴「混音」面板（写回音频节点，装配时生效）；agent 侧
  不要替用户拍这些审美参数。

## 五、验收自查（合成后必做）

1. 结果文本「音轨装配（N 段）」摘要：每段起止与分镜预期一致？
2. `warnings` 有无「无原生音轨」「已自动补静音」「未探到时长」——每条都要么处置、要么向用户说明；
3. 音轨构成（native+bgm / bgm+voiceOver / none…）与设计一致 —— `none` 而你以为是 `native+bgm` 说明 clipIds 选错或 BGM 节点失效。
