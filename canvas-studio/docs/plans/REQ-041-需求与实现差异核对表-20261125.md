## 2. 三个偏离摊开说

**判据（#1）**：写需求时按「理想分镜卡」推的字段，真机数据不是那个值。实现选了「复用 `isShotCard`」而不是新写一个字段判据 —— 否则画布上会同时存在两套「什么是分镜卡」的事实，将来必漂移。

**卡片形状（#3）**：`DeliveryCard.segments` 是顶层字段；需求文档的 `pointers.segments` 是早期笔误。清单兼容两种，不挑数据。

**下载（#2）**：§9.5 的「只留三项」按「**生成类专属项**收窄」执行，通用节点操作没砍。分镜卡是 text 节点，`canDownloadNode` 不给 text 出「下载资产」——要让它出现，得单独接一个「下载本屏视频」入口（URL 从已取的 `segmentMediaByRef` 拿，不写画布）。这是新增接线，不是原四步的一部分，**没做，也没假装做了**。
