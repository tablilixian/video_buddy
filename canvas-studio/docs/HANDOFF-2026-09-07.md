## 六、教训备忘（避免重蹈）

- **工作区确认先行**：开工前先 `pwd` / 确认对话工作区，本轮 C1 曾误在 WL 仓库实现后被迫移植。
- Bash 命令一律加 `cd <绝对路径> &&` 前缀（cwd 会被重置到仓库根）。
- macOS BSD grep 交替语法用 `grep -E`，不支持 `\|`。
- 修改画布节点用节点标题/URL 字段，**不要用 `mv` 改磁盘文件名**（会导致节点 404）。
