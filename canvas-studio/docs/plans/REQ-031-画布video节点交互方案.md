# REQ-031 画布 video 节点交互方案（开工方案 v1.0）

> 状态：**拍板已收口（两批 14 项）· 方案待用户审核，审核前不开工**。拍板记录见 [tracking.md](../tracking.md) REQ-031 条目「拍板」两段；基座事实见 [REQ-029 方案](./REQ-029-画布image节点交互方案.md)（CV-281 五步已落地待验收）。开工时按 STATUS §0 规则领主线号（顺位 CV-282）。
> 本方案的**反遗漏核心是 §四功能点对照总表**：演示 HTML 逐元素盘点的 F1~F29 + H1~H7 全量编号，每点映射到 Step 与守卫/偏差，验收按表逐项过。

## 一、目标与范围

**目标**：在 CV-281 输入框卡基座上实现 video 形态——对 `canvas-videonode-inputbox.html`（167KB，3280 行）+ 三图做 **1:1 精准还原（布局/颜色/交互）**，功能点按 §四总表全覆盖。

**非目标（本方案不做）**：
- REQ-022 两阶段 Storyboard（节奏的分镜语义归属地，本方案只做前缀注入）；
- 商业化计费（积分=前端估算明细，标「预估」）；
- REQ-029 的桌面验收返工（若涉及共享组件则修复插队，见 §十）；
- Higgsfield CDN 演示视频外链（拍板②：置灰，不复用第三方素材）。

## 二、事实源与还原纪律（1:1）

1. **像素级事实源**：`docs/assets/library-2026-10-07/canvas-videonode-inputbox.html`（3280 行，交互含 JS 状态机）+ `video-node.png`（主态）/ `video-node2.png`（运镜面板）/ `video-node3.png`(节奏面板)。实现前逐组件对照，不凭记忆。
2. **裁决顺序**：拍板口径 > 演示 > 现状交互延续。拍板只裁「选项集合/语义/数据源」，不动「布局/颜色/交互形态」。
3. **演示 HTML 是存档件不改**；每处偏差登记 §十偏差表（沿用 CV-280/CV-281 手法）。
4. **本方案最大的架构性偏差（拍板②已定，先亮明）**：演示的提示词是 **contenteditable token 系统**——运镜以可拖拽 chip 内嵌文本流（`.mv-tok`，双向同步、悬停浮出官方演示视频）。我们沿用 CV-281 的 **textarea + PromptEditor**（复用三档编辑器/@-引用/草稿），运镜按拍板② = **纯文本短语插入**（退格可删），不建 token/拖拽系统。由此派生：运镜「多选有序」= 以提示词内出现顺序为准；「以 token 顺序回写状态」（`syncMotions`）不适用，改为从提示词文本解析已选运镜。

## 三、演示设计规格速览（提取自 HTML，实现对照基线）

- **色板**：与 image 演示同一套 tokens（`--bg:#0a0b0e`、卡片渐变 `#161a1f→#12151a`、chips `#1e222a/262c35/2b323d`、描边 `#252a33/1c2027`、弹层 `#1a1e25/2d343f`、正文 `#e9ecf1`、accent `#ffb066`）；video 特有：**荧光绿浮标**「添加到提示词」（`#c8f542` 系，运镜卡悬停态）、节奏分段指示条（黄绿分段）。
- **JS 状态机关键事实**（实现交互形态的依据）：
  - `MODELS`：minimax-h3（基准 20 · 支持音频 · 最长 15s）/ seedance-20（16 · 10s）/ seedance-25（24 · 15s）；**切模型钳时长**（超 `maxDur` 回落 + toast）；
  - `MOTIONS`：**33 条运镜**（Higgsfield Camera Controls 全量预设，`{id, 中文名, en 官方原名, anim}`）；**运镜多选有序**；
  - `PACES`：**5 档单选**（自动/一镜到底/舒缓/动感/凌厉碎剪），`segs` = 分段指示条段数（0/1/3/8/12），「改动即时生效，无重置/确定按钮」；
  - 积分公式 `costRows()`：模型基准 + 时长加长（`(dur−5)×2`）+ 清晰度 + 参考素材分类计价（图 ×2 / 视频 ×6 / 音频 ×3 / 首帧 2 / 尾帧 3）+ 原生音频 8 → **明细行弹层**（popCredit，290px）；
  - 角标/进度环副文案：`画幅 · 时长s · 清晰度` 与 `模型 · 模式 · 时长s`；
  - 模式 Tab 联动：托盘形态（fl 双槽 / omni 三分类）、占位文案、进度环副文案；
  - 时长在演示里是**滑杆**（`durRange`）——拍板④改预设六档（偏差登记）。

## 六、组件设计：`NodeInputCard` 形态配置化

CV-281 的 `NodeInputCard` 按拍板「同组件两形态」升级为 **`form: 'image' | 'video'`** 配置驱动（形式沿用既有 props 面，不 fork 第二个组件）：

- **托盘配置**（`TrayConfig`）：image = 单分类（图片 ≤4，无分类标签）；video-omni = 三分类（图 9/视频 3/音频 3，各带 [+]，候选按模态过滤）；video-fl = 首帧/尾帧双特殊槽。分类定义含：键名（`filenames` / `videoRefs` / `audioRefs` / `filenameTail`）、上限、模态、标签。
- **chips 配置**：image = 模型/画幅清晰度/风格/摄像机；video = 追加运镜（影片设置面板入口）、清晰度 chip 并入「画幅·时长·清晰度」三段 chip（演示形态）。
- **候选池模态过滤**：画布候选按 `kind`（image/video）、资产库媒体按 `media[].kind`、音频候选含时长实测（试听用 url 播放）。
- **影片设置面板**（新组件 `FilmSetupPanel`，挂运镜 chip）：双 Tab（运镜网格 33 词条 / 节奏轮播 5 档），即时生效无确定钮，关闭 = 点外/Esc/再点 chip（演示注释原文语义）。
- **积分明细**（新 `CreditBreakdown`）：按演示 `costRows()` 公式逐行渲染，合计标「预估」。
