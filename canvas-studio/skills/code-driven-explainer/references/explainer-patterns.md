# 科普结构、卡片形态与节奏

本分册给**内容组织**建议（不是硬约束）。目标：让 30–90 秒的解说短片「一看就懂、一屏一个点」。

## 结构：钩子 → 主体 → 收尾

| 段 | 时长占比 | 做什么 | 常用卡片 |
| --- | --- | --- | --- |
| 钩子 | 10–15% | 用一个反常识问题 / 一组对比数字抓住注意力 | `title` / `dataCard` |
| 主体 | 70–80% | 3±2 个要点，**一个要点一张卡或一段素材** | `subtitle` / `dataCard` / `bullets` |
| 收尾 | 10–15% | 一句话结论 + 行动 / 回味 | `title` / `subtitle` |

**一屏一个点**：不要在同一张卡里塞两个论点；观众注意力只够消化一个。

## 卡片形态怎么选

- `subtitle`：配旁白逐句呈现的核心信息，本路径的主力。
- `dataCard`：出现具体数字 / 对比时用 `data` 键值对（`全球老龄化 16%`），比把数字塞进字幕条清楚得多。
- `bullets`：并列清单（3–5 条），配停顿逐条点出。
- `title`：开场主题或章节转场。

## 素材与卡片的配合

- 有实拍 / 生成视频素材时：**素材铺底、字幕卡叠上**（字幕卡 `startFrame` 落在对应素材区间内）。
- 纯图文解说（无视频素材）：用 `shape` 的 `gradient` 做背景、`image` 铺图、`textCard` 承载信息，`transition` 在段落间过渡。
- `image` 用 `fit: "kenburns"` 给小图加缓推，避免静态感。

## 用动画讲对比与过程

静态卡片只能"陈列"，动画才能"解释"。四种最常见的信息关系，都靠 `animate` 表达
（字段写法见 `references/manifest-contract.md`「帧级动画」）：

| 想讲清的事 | 动起来的方式 |
| --- | --- |
| **顺序 / 步骤** | 元素依次出场：各轨错开 `startFrame`，用同一套入场 `animate` |
| **大小 / 量级对比** | 同一时刻到位、各给不同 `to.scale`（起点可一致），让"差多少"自己说话 |
| **趋势 / 累积** | 本契约没有"宽度动画"：把长条拆成几段**相邻轨接力**（每段 `box.w` 更大），或对 `line` 用小幅 `scale` 近似 |
| **周期 / 关系**（脉动、往复、环绕） | 两条**首尾相接**的 `animate` 做往复；绕中心转用**多条短 `animate` 逐段近似** |

三条纪律：

- **动一次就够**：入场动画 0.5–0.8s（15–24 帧 @30fps）。全程都在动 = 没有重点。
- **别让观众等**：`animate.startFrame` 要落在这张卡真的在屏上的区间内 —— 卡切走了再动没人看得到。
- **只动该动的维度**：只写 `x` / `opacity` 的动画不会碰 `scale`，可以安全地与 `fit: "kenburns"` 叠加。

## 节奏与时长

- 单张卡**别短于 1.5s**（来不及读）也别长于 6s（开始走神）；中文按 ≤18 字配约 2.5–4s。
- 转场（`fade` / `slide`）时长 **0.5–1s** 足够；全片别全都是同一种转场（宿主会判「幻灯片风险」）。
- 宿主会给「图文卡片型成片」的风险提示（命中静态占比 / 运动密度 / 镜头数）：**这是合法形态**，
  别为此去改成逐镜生成视频。削弱静态感的正解是**让画面动起来**——差异化转场、`image` 用
  `fit: "kenburns"` 缓推、**给卡片 / 形状写 `animate`**（入场、缩放、往复）、把并列信息拆成逐张入场。

## 自检清单（交给用户前过一遍）

- [ ] 钩子在**前三秒**内出现？
- [ ] 主体 ≤ 5 个要点，每个要点一张卡 / 一段素材？
- [ ] 每句字幕都配了旁白，且句长与展示时长匹配？
- [ ] 数字类信息用了 `dataCard` 而非字幕条？
- [ ] **至少一处在动**（视频 / `kenburns` / `animate`），且动得有理由（不是为动而动）？
- [ ] 需要讲"对比 / 过程 / 关系"的地方用了 `animate`，而不是只放一张静态图？
- [ ] 收尾有一句明确结论？
