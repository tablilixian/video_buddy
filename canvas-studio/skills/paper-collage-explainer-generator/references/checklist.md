# 分册：质检 · 交付 · 失败处理（paper-collage-explainer-generator）

## 1. 质检标准

对静帧与片段逐条核对：

- 隐喻或故事节拍不上文字也能看懂。
- 静帧有干净有力的色场、默认 16:9 下好看的构图、清晰物件层级、可见的前景/中景/背景纵深。
- 物件组数量保持可读，不是一屏碎片。
- 片段从与已确认静帧或批量色板一致的色场起手。
- 组装逐件可见，不是全局淡入。
- 运动读作定格拼贴：分离纸组 pop 进或滑进，轻回弹、按压平整、停顿、锁定。
- 默认项：触感拼贴音效保留；BGM、口播/语音、字幕在未明确要求时缺席。
- 纸张质感受控：不太平、不过度做旧、未确认时不是棕色/牛皮纸。
- 全批色调一致。
- 终帧与已确认静帧接近。
- 没有不想要的可读字母、假 UI、字幕、水印或 logo。

细节上的轻微漂移可以接受，只要隐喻仍然清晰、终帧构图仍像已确认静帧。**必须重做或后期处理**的情况：明显漂移、加了文字、假 UI、开场配色不搭、不想要的牛皮纸底、纸质感过度发皱/发脏、定格组装丢失、不想要的 BGM、不想要的口播。

## 2. 交付内容

多段故事视频按已确认的分镜顺序拼接，默认保留每段的原拼贴音效。

只有用户明确要求时才加 BGM、口播或字幕。片段已存在之后用户才要求 BGM 或口播时，把它们与拼贴音效混音，**不要**替换掉音效——除非用户要求静音原音效。

每项完成品交付：

- 终版 B-roll 视频路径或成片路径。
- 相关时的已确认静帧路径。
- 一句话说明台词或视觉节拍如何变成视觉隐喻。
- 媒体说明：默认有拼贴音效，并列出用户明确要求的 BGM、口播或字幕增项。
- 该片段以可接受的轻微漂移通过时的 QA 备注。

批量作业时按条目编号归组产物，并让用户的原始台词或故事节拍与对应结果保持关联。

## 3. 失败处理

- 制作方案默认成了无声视频：改回只保留拼贴音效，除非用户明确要求静音。
- 制作方案里没有用户明确要求就含 BGM、口播或字幕：移除它们，并把三项作为可选项呈现。
- 制作方案太直白：回到视觉命题，把它改得更物件驱动。
- 静帧含假文字或假 UI：出视频前重做静帧；不要只在视频提示词里补救。
- 静帧或片段太乱：减少纸层、简化物件数量、恢复负空间。
- 视频缺组装运动：减少物件数量，把逐件到达顺序写得更明确。
- 运动像顺滑数字图层：围绕定格节拍重写提示词——出现 → 轻回弹 → 按压平整 → 停顿 → 锁定。
- 纸太平：加细微撕裂边、纤维纹理、层叠接缝与柔和阴影。
- 纸过度做旧或发脏：去掉牛皮纸、棕/泛黄底、重度褶皱、污渍与做旧处理。
- 开场配色与已确认静帧冲突：从与静帧相同的主背景色起手。
- 终帧与静帧漂移过大：强化"已确认静帧就是完成后的最终构图"这条指令。
- 生成的音频没有拼贴音效但画面本身很强：问用户保留、加更强的 SFX 方向，还是后期补 SFX。
- 生成的音频含不想要的 BGM 或口播：交付前移除或重做。
- 需要精确图层控制：建议改用分层动画或剪辑工作流，不要继续用本风格硬做。
