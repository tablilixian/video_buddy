# 图生图与图像改写提示词规范

适用：`image_generate` **传了参考图**（`filename` 单图 / `filenames` 最多 4 张）的图生图路径，以及 `character_generate` 角色三视图。**纯文生图不要用本规范**，改加载 `z-image-prompt-writing`。

## 核心区别：指令式，不是描述式

图生图端点接受 1–4 张参考图（后端 `image2image`，Krea2 Edit 技术路线，`krea2_edit.json` 工作流，steps 固定 9、cfg 固定 1.0）。提示词描述的是**对输入图做什么**，而不是「成图长什么样」。

- ❌ 描述式（`A red sports car on a mountain road at sunset`）→ 模型无视输入图、凭空重画，角色/构图全丢。
- ✅ 指令式（`把车的颜色改成红色，其余元素完全一致`）→ 保留构图、打光与未提及的部分。

**一句话判断**：要「在原图上改一点」用指令式；要「借参考图的角色/风格重画一个新场景」用「保留子句 + 新场景描述」的混合式（见下）。

## 四段式公式（每次必写全）

```
操作（动词）+ 目标（具体部位/对象）+ 规格（改成什么样）+ 保留子句（什么不许动）
```

| 段 | 写法要点 | 例子 |
|---|---|---|
| 操作 | 替换 / 移除 / 添加 / 调整，一次只做一个 | 替换 |
| 目标 | 具体部位或对象，同类多物用位置消歧 | 前景那只狗 / 左边第二个人 |
| 规格 | 改成什么，含材质与光照方向 | 金毛犬 |
| 保留子句 | **最关键**，没有它模型会过度改动 | 保持打光与背景完全一致 |

完整例：`把前景的狗替换成金毛犬，保持打光与背景完全一致，其余元素全部保持不变。`

**保留子句不是可选项。** 每句提示词末尾都要有，哪怕只是「其他部分尽量不变」。

## 分步链式（复杂改动必用）

一次请求只做一个操作。「改发型 + 换背景 + 加墨镜」写在一起会互相干扰。复杂需求拆成链式多步：上一步产物 → `upload_image` → 作为下一步参考图，**每一步都重申保留约束**。

顺序原则：先大后小（背景/构图 → 主体 → 细节），每步都写保留子句。

## 多参考图分工（filenames 最多 4 张）

传多张时提示词里说明每张图的用途，模型才知道谁提供身份、谁提供场景、谁提供风格。典型席位分配：

- 席位 1–2：角色身份（人物锚点）
- 席位 3：场景与打光氛围
- 席位 4：画风/材质参考

```
参考图 1 提供角色身份与面部特征，参考图 2 提供场景与打光氛围，
合成一张自然合影，两人身份特征各自保持不变，背景沿用参考图 2
```

留空的 `image2`~`image4` 后端会自动从工作流排除，不影响生成；**建议至少提供 `image1`**。

单张参考图走 `filename`（等价 `image1`），多张走 `filenames`。

## 常见场景模板

| 场景 | 提示词骨架 |
|---|---|
| 换装/换发型（保身份） | 保持人物身份与面部特征不变，把上衣改成白色衬衫，发型改成短发，其他部分尽量不变 |
| 光线/氛围调整 | 把光线改成清晨侧逆光，增强轮廓光，保持产品外观、颜色与细节不变 |
| 视角/构图变化 | 保持产品外观、颜色与细节一致，把视角改为 45 度俯视，保持产品完整可见 |
| 材质替换 | 保持结构、形状与尺寸不变，把材质替换为雾面金属，保留刻线与阴影关系，光线方向不变 |
| 背景替换 | 保持主体角度、打光与反射不变，仅替换背景为抛光黑大理石台面 |
| 文字编辑 | 把标题文字「春季促销」改成「夏季大促」，保持字体风格、大小、颜色与位置不变 |

**文字编辑**：新旧文本都必须加引号，并显式锁定字体属性（风格/大小/颜色/位置）。中英文均支持，模型会保持原字体风格。

## 角色三视图（character_generate）

`character_generate` 走 `qwen_4view_char_2step` 工作流，**不接受 prompt 参数**（只吃设计图）。三视图质量完全取决于输入设计图质量 —— 想改三视图只能回头改设计图，不要用提示词尝试纠偏。

## 局部改写：走图生图 + 四段式

单图局部修改不建多参考，`filename` 传原图 + 四段式一次到位。要对照「改前 vs 改后」时，把原图与标注图一起传（`filenames` 两张），提示词里声明「参考图 2 的标注区域」。
