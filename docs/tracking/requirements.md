## 二、按优先级详细记录

### P0（12 条）

#### R-P0-01 ｜ 重大调整：制作过程分两阶段产出（已排期 / 2026-10-07）
- **标题**：把制作过程分为 2 阶段产出。
- **详细描述**：第一阶段产出故事板（Storyboard）——一个 Agent 经过搜索后产出的详细拍摄故事面板，包含对用户创意的理解、视觉效果、拍摄的分镜设计、每个分镜的 shot 安排、人物设定、音乐设计、旁白对话设计等，使用良好排版的 HTML 给用户呈现。用户在此基础上不断调整，产出确认稿后再进入第二阶段画布产出（目前主要功能）。
- **附件**：2026-10-01-20-24-20.zip（含 workbuddy 产出 HTML 样板与导出 md 拍摄定稿，作功能参考）
- **图片**：https://workbuddy-space-static.codebuddy.work/image/7tDW1EUf9uXqKcRm1rPRBT.png 等 4 张
- **项目关联**：这是产品形态级改造，引入「Storyboard 阶段」作为画布阶段的前置。涉及新增 storyboard 产物形态与 Agent 编排（搜索 + 排版 HTML），需与现有 canvas-studio 画布阶段衔接。对应需求表首条「重大调整需求」。

#### R-P0-02 ｜ 全局资产库增加角色音色参考（已排期 / 2026-10-07）
- **标题**：全局资产库页面增加角色音色参考。
- **详细描述**：在 agent 中通过自然语言或者 @ 符引用该资源。prompt 中修改也要能使用。
- **项目关联**：资产库（Host 资产服务 + 真画布 assetDir）扩展「音色」资产类型；需打通 @ 引用与自然语言解析。与 Bug C-5（TTS 多音色）强相关，应合并设计以保证音色一致性。

#### R-P0-03 ｜ 抄 libtv 提示词修改框体验（待评审 / 2026-09-28）
- **标题**：抄 libtv 等的提示词修改框体验，这个 UI 需要抄。优化提示词、图引用的快速修改和重试。
- **项目关联**：画布节点提示词编辑 UI（Client 侧）。涉及 `styles.ts` 视觉令牌与节点详情/重放抽屉。

#### R-P0-04 ｜ agent 任务更新 bug / 升级 dsh（待评审 / 2026-09-28）
- **标题**：agent 任务更新有 bug，模型上下文长度显示有问题。升级 dsh。
- **项目关联**：`dsh-plugin-desktop`（Cordis Host）版本与 agent 任务更新机制；上下文长度显示为 host-boundary 层问题。

#### R-P0-05 ｜ agent 对话流改造（待评审 / 2026-09-28）
- **标题**：agent 对话流需要改造。目前废话显示太多，tools 调用应该更直观，比如中文显示「生成 xxx 图」「生成 xxx 分镜视频」。一些其他 tools 调用都可省略不显示。用户需要看到跟项目最相关的生成信息，且默认用户不懂 agent harness。
- **项目关联**：`tool/result` 事件订阅与对话面渲染（Client）。需将工具调用映射为中文生成动作，并对非关键 tools 调用做折叠/隐藏。

#### R-P0-06 ｜ 支持拖拽文本作为剧本（开发中 / 2026-09-28）
- **标题**：支持拖拽文本作为剧本。
- **项目关联**：Host 拖放捕获（CV-231：`capture` 阶段截断接管；dragover 看 `items.type`、drop 看 `files` MIME）。文本拖入作为剧本输入。

#### R-P0-07 ｜ 支持拖拽音频文件（已排期 / 2026-09-28）
- **标题**：支持拖拽音频文件作为背景参考音或者说话参考音模式。
- **项目关联**：同上拖放通道；音频资产类型（参考素材通道中音频不能唯一，需注意）。

#### R-P0-08 ｜ 支持 qwen_image_2_1 prompt（t2i & i2i）（已排期 / 2026-09-28）
- **标题**：支持 qwen_image_2_1 prompt for t2i & i2i，skill 参考附件。
- **附件**：qwen-image-2-1-prompt.zip
- **项目关联**：图像生成模型路由扩展（Krea2 / qwen-image 并列）；需保证产出正确挂载画布（见 Bug A-13）。

#### R-P0-09 ｜ image edit 换 qwen image 2_1 并评估（已排期 / 2026-09-28）
- **标题**：image edit 已经换成 qwen image2_1，评估体验效果和 krea2 参考修改的差异，是否能用参考 image 来弥补 qwen image 修改死板的问题。
- **项目关联**：图编辑（i2i）管线模型替换与体验对比；影响 `image2image`/`image2fix` 接口选型。

#### R-P0-10 ｜ 新接口 txt2image_withtxt（已排期 / 2026-09-28）
- **标题**：新接口 txt2image_withtxt 使用。在文字多、需要排版的海报制作等时，主动避开 krea2，使用该接口。另外，尽量用 krea2 生成人物和环境，后用 image2image 或 image2fix 接口来添加文字等。目前 image2fix 接口也使用 qwen image 2_1 了，注意评估。
- **项目关联**：模型路由决策（按内容/文字密度选择接口）；与 R-P0-09 接口评估联动。

#### R-P0-11 ｜ 30 秒视频分镜太空、提升 shot 密度（已排期 / 2026-10-07）
- **标题**：生成一个 30 秒的视频，10 秒的分镜，内容很空，一条分镜一个运镜结束了。期望 10 秒分镜文戏 2.5 秒左右安排一个 shot，武戏 1.3 秒左右安排一个 shot。
- **项目关联**：分镜→shot 编排策略（computeShotLanes 镜位框）；与 Bug C-16（未按 6 分镜/11 shot 编排）同源，需统一编排算法与约束。

#### R-P0-12 ｜ 画布节点可手动连线（已排期 / 2026-10-07）
- **标题**：画布节点可手动操作连线，各连线能手工连接和断开。能拖动连线放开后弹出菜单手动创建节点。
- **项目关联**：画布连线交互（`groupBoxOf`/`nodeActionAnchor` 等）；与 Bug A-4（生成应先连线）、C-10（断链）共同定义连线系统能力。

### P1（5 条）

#### R-P1-01 ｜ 画布 480p→720p 丝滑过渡（已排期 / 2026-09-28）
- **标题**：画布上实现从 480p 到 720p 生成的丝滑过渡。
- **详细描述**：让用户能前期在 480 下快速试片，在 720 定下成片。
- **项目关联**：分辨率三档（唯一像素表 `config.ts OUTPUT_SIZE`）；与 Bug C-8（默认 480p 却 720p）共同暴露默认值/实际值不一致问题。

#### R-P1-02 ｜ camera motion / wuxia action lora（已排期 / 2026-09-28）
- **标题**：支持 camera motion 和 wuxia action lora。camera_motion、wushu_action 为开始的 prompt 来触发相关 lora 的效果体现。
- **附件**：prompt-sample.txt、skills.zip
- **项目关联**：提示词触发 lora 的 skill 路由（skills 系统）；与风格技能（如 oriental-mythic-visual-director）同属 skill 注入策略。

#### R-P1-03 ｜ 画布提示词按使用者语言呈现（已排期 / 2026-09-28）
- **标题**：画布上的提示词，按使用者的语言呈现为优先，且为比较自然的描述。后面实际生成时，按用户或系统要求使用 Krea2、qwen-image、或者 H3、Seeddance2.0、2.5 规范翻译，提交后台。
- **项目关联**：提示词呈现与模型路由规范（param-guard / 入参规范）；与 Bug C-12（删中文仍用 qwen）共同指向语言→模型路由决策。

#### R-P1-04 ｜ 安装包太大（已排期 / 2026-09-28）
- **标题**：安装包太大，建议评估 turi 的模式和官方 desktop 版，目前 deepseek desktop 安装包只要 266M。
- **项目关联**：`dsh-plugin-desktop` 打包（Electron）。注意本机打包镜像变量需自备（ELECTRON_MIRROR 等），且 universal 构建受 provenance 文件限制需用户本地跑。

#### R-P1-05 ｜ Agent 实现微信制作方法类视频（已排期 / 2026-10-07）
- **标题**：Agent 能实现指定微信文章里的制作方法，制作该类视频。例如：制作「AI 平权时代，你该做好什么？」约 1 分钟视频。音乐、音效自行解决，配音用 tts。右上角需有 AI 平权 LOGO，结尾需有品牌卡（关注/点赞/收藏/评论）。
- **PRD 链接**：https://mp.weixin.qq.com/s/hC98onKuRtR67RTpe33VIA
- **项目关联**：端到端视频生成 + 品牌卡/LOGO 叠加（ffmpeg 合成）+ TTS 配音；可复用 R-P0-02 角色/品牌资产与 C-5 TTS 一致性方案。

### P2（3 条）

#### R-P2-01 ｜ 修改画布鼠标操作习惯（已排期 / 2026-09-28）
- **标题**：改 ctrl+滚轮=缩放 为 滚轮=缩放（单手习惯）；鼠标按住移动=拖动画布。选中效果不明显，ctrl+选中后无法多个目标一起进入「引用到对话」等操作。
- **项目关联**：画布交互（Client）；多选 + 批量「引用到对话」属画布操作层。

#### R-P2-02 ｜ 点击 Canvas Studio 返回首页 / 项目排序（已排期 / 2026-09-28）
- **标题**：点击左上角「Canvas Studio」区域需返回首页，每次进入 app 需停留在首页。项目需按改动时间排序，最近的在前。
- **项目关联**：`dsh-plugin-desktop` 首页与项目列表；与 Bug E-1/E-2（启动加载画布/空项目目录）同属启动与首页体验。

#### R-P2-03 ｜ 静止画面本地 ffmpeg 制作（已排期 / 2026-10-07）
- **标题**：判断是静止画面（如 1-2 秒静止的海报），可直接用 ffmpeg 制作静态片段，不用上 H3。对文字多的 H3 上由于对图缩放了，大图会有问题，文字参考会坏。更建议静止画面本地 ffmpeg 做，还不花钱。
- **项目关联**：内置 ffmpeg（CV-201）；静态片段本地合成策略，规避 H3 大图文字缩放问题（亦关联 Bug C-11 景点文字模糊）。

## 四、落地优先级建议（结合项目实际）

1. **先收敛缺陷再扩需求**：P0 需求中 R-P0-01（两阶段）属形态级改造，工作量大；建议与高优缺陷（C-5 TTS、E-1 首页、C-8 分辨率）并行，先稳定现有画布阶段再扩展 storyboard 阶段。
2. **模型路由是贯穿线**：R-P0-08/09/10/11 与 R-P1-03 均指向「语言/内容 → 模型（Krea2/qwen-image/H3/Seeddance）路由规范」，应在 `param-guard`/入参规范层统一决策点，避免散落各 skill。
3. **连线系统是地基**：R-P0-12（手动连线）与多起 Bug（A-4、C-10、C-16）共同要求画布连线/引用系统先稳定，再谈编排密度。
4. **资产库是复用好物**：R-P0-02 角色音色 + R-P0-07 音频参考 + R-P1-05 品牌资产，建议建统一「资产引用（@/自然语言）」能力，一次性解决音色一致性（C-5）与品牌卡复用。
5. **ffmpeg 本地化降本**：R-P2-03 + C-11 + C-13（ffprobe）可由内置 ffmpeg（CV-201 出包后）统一承载静态片段与探针，减少 H3 调用成本与文字缩放缺陷。
