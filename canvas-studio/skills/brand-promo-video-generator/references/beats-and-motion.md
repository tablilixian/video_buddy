# 分册：节拍与运动（brand-promo-video-generator）

> 何时读：选叙事骨架、排逐节拍时间线、给整片定运动语言时。

## 1. 叙事骨架选型

用户没选方向时给 2-3 个简洁方向，推荐一个。按产品品类选骨架：

| 品类 | 骨架 |
| --- | --- |
| AI / SaaS | 用户意图 → 思考或规划 → 能力 → 执行 → 有用产出 → 佐证 → logo |
| 实体产品 | 主视觉揭示 → 交互 → 特性微距 → 使用场景 → 结果 → logo |
| 服务 / 公司 | 语境 → 流程 → 证据 → 成果 → 承诺 → logo |
| 图像主导品牌 | 真实影像 → 视觉母题 → 利益点 → 情绪回报 → logo |

故事要贴着产品走：展示真实的功能、交互、场景、产出与佐证，不要把故事藏在抽象特效后面。

## 2. 精确节拍

出片前排帧级感知的时间线。除非输出链路另有要求，规划约定用 30fps。

- 15s 片：目标 5-8 个主节拍。
- 30s 片：目标 8-12 个主节拍。

每个节拍定义：

- 起止时间或帧区间。
- 视觉归属与真实资产 ID。
- 主动作。
- 镜头里展示的产品或品牌佐证。
- 文案与可读停留。
- 色彩状态。
- 进出场转场。
- 运动意图：setup、anticipation、commitment、impact、brake、settle。

15s 的实用节拍模式：品牌钩子 → 用户意图或铺垫 → 产品机理 → 能力或场景 → 产出或佐证 → 产品回报 → 终版 logo 与 CTA。出镜运动自然接上下一个镜头时，用 6-12 帧的重叠。

## 3. 运动语言

- 用有控制的方式堆强度：让产品运动、光标路径、界面流程、光线、滚动内容、物体边缘或匹配的几何来驱动转场。
- 使用 2-5 个与语义挂钩的刻意色彩状态。
- 一拍一个主动作，次要层稍晚出现。
- 设定 2-3 个高能峰值与安静的刹车时刻。
- 保住可读的剪影、文案与 logo 安全空间。
- 避免假 HUD、无意义的玻璃卡、装饰文字墙、未证实数据，以及全片同一种缓动。
- AI 类产品至少给出一条可读链路：prompt → 规划 → 并行能力 → 生成结果 → 佐证。
- 实体或服务类产品展示从用户动作到具体结果的因果。
