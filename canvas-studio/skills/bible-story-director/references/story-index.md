# 圣经故事索引（S1 必读）

> **用途**：把一个故事名 / 人物名 / 口语说法，钉死成一个**出处**（书卷 + 章:节）。
>
> **为什么必须查表**：模型凭记忆报经文章节号会编——小节号尤其不可靠。表里有的**逐字取**，表里没有的**先联网核对再写**，永远不要凭印象写章号。出处错了，`§01` 的事实锚点就全废，后面的考据也跟着偏。

## 用法

1. **匹配优先级**：精确故事名 → 别名/口语说法 → 人物名（一个人物可能对应多段叙事，此时用 `ask_user_choice` 问是哪一段）。
2. **一处出处**：只取故事的核心叙事段落，不要写「创 1–50」这种整卷范围。
3. **写进 `§01`**：出处本身算一条事实，`claim` 写「故事出自《书名》章:节」，`source` 写书卷名 + 章:节，`status: verified`。
4. **表外故事**：不在表里 → 先 `WebSearch`（查询式如「和合本 以利亚 寡妇 撒勒法 列王纪上 17」）核对书卷与章号，核对到才写；**核对不到就明确告诉用户「我没把握这段的出处，需要你确认书卷章号」**，不许猜。
5. **一个人物多段故事**：如「彼得」可指蒙召、行走水面、三次不认主、五旬节讲道——必须问清再动。
