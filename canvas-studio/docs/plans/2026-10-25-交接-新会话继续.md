## 五、铁律与陷阱（新会话最容易踩）

### 环境
- **真渲染必须 `RF_NO_SANDBOX=1 NODE_OPTIONS= ...`**，否则沙箱直接把 Electron 进程 SIGTERM，一行输出都没有（不是超时，是静默死）。
- `bash` 的 `cd` 不持久，每条命令内联。
- 本机**无 ffmpeg**（开发态缺失是设计），别当 bug 报。
- `lib/` 是运行时产物，用户客户端正在加载 ⇒ **禁 `rm -rf lib`**；要重建先 `mv lib /tmp/`。

### 本仓特有的"坑"
- **`git add` 必须显式带 `canvas-studio/skills`**：只 add `docs` 会漏掉 skill 分册，提交后门禁红。
- **本仓 commit 后会被外部自动 push**（reflog `update by push`，非本会话所为）。每次 commit 后必 `git status -sb` 核对 ahead，并向用户说明。
- **STATUS.md 每行 ≤1700 字节**（`status-shape` 守卫），长条目要按分号断成多行 `> ` 前缀。
- **JSON 状态档必须 `writeFileAtomic`**（`@deepseek-ai/dsh-atomic-write`，选项只有 `mode`/`dirMode`，**没有 `encoding`**）；裸 `writeFile` 会被 AR-03① 判红。
- **改工具描述前先 grep 测试断言**：`remotion-shape-box` / `render-tool-contract` / `render-host-executor` 里钉了 7 条"描述里必须有"的短语（`manifestPath` / `尾部完整性校验` / 时长判据原文 / `隐藏渲染窗口` / `关掉整个 App 会中断渲染` / `x/y 是形状中心` / `{x:50,y:50,w:100,h:100}`）。
- **`SKILL.md` 已 11.8KB**（闸 12KB）：加内容前先腾位置。

### 已验证的领域事实（别再重新发现）
- **`kenBurns: true` 是死字段**（类型里有、实现从不读）；正确写法 `fit:'kenburns'`。
- **`animate` 不支持 `scaleX`/`scaleY`**，只有等比 `scale`；写错不报错、不生效。
- **manifest 没有 `group`/父子坐标**（目前只能绝对百分比手算）。
- **`inspect_image` 只有 `profile/bbox-dark/bbox-bright/colors/grid`**，无取点色/区域统计。
- 每步模型有 **≈6s 固定 TTFT**（provider 侧），本仓改不了；能改的是**减步数**。
- 90 帧 draft 真渲成本：**热态 1.4s/张**，半冷 16.7s/张（贵在窗口冷启）。
