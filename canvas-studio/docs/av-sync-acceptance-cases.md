## T1 时长真值落盘（CV-140）

**对 agent 说**：「生成一段 5 秒 16:9 的城市夜景视频」

| 步骤 | 预期 |
|---|---|
| 1. 视频节点落盘 | 节点角标显示**真实时长**（约 `5.17s`，24fps 帧量化，允许 ±0.2s），**不是** `5.00s` 整 |
| 2. 让 agent 跑 `list_shots` | 返回的 `duration` 与角标一致（真值） |
| 3. （对照）节点详情 | 请求值另存 `declaredDuration=5`（详情面板可见则为加分项，不可见不算失败） |

❌ 判失败：角标仍显示 `5.00s` 整 = 真值探测没生效。

## T2 音乐生成转正（CV-125 / CV-146 / CV-140 音频侧）

**对 agent 说**：「生成一段 16 秒的爵士钢琴 BGM，纯器乐」

| 步骤 | 预期 |
|---|---|
| 1. 音频节点落盘 | 节点出现、可点开播放器试听、非静音 |
| 2. 角标 | 显示**真实时长**（约 `16.0s`，允许 ±0.2s），不是 16.00 整数假象 |
| 3. 画布摘要 | 显示「纯器乐 · 无歌词」（不露出 `[Instrumental]` 方括号串） |
| 4. 结果文本 | agent 结果里应带 `bgmNodeId=<节点id>` 的 compose 接入指引 |

❌ 判失败：报「无音乐生成能力」= 降级占坑（CV-125 未生效）；产物丢失（CV-146 复发）。

## T3 多镜 + BGM 合成（CV-141 策略 + CV-138 守卫 + CV-143 可见化）—— 核心用例

**对 agent 说**：「做一条 15 秒三镜的口红广告，横屏 16:9，每镜 5 秒；分镜、关键帧、逐镜出视频；然后 `list_shots` 拿真实时长，生成足够长的 BGM，最后合成」（可一次说清，让 agent 自己走全流程）

| 步骤 | 预期 |
|---|---|
| 1. 三个片段生成 | 每个节点真值 ≈ `5.17s`，三个合计 ≈ `15.5s` |
| 2. agent 生成 BGM | 请求时长 **> 15.5s**（如 16s）—— agent 应主动从 `list_shots` 算出成片真值再定 BGM 长度（这是 CV-140 的编排价值） |
| 3. `compose_video`（带 `bgmNodeId`） | 成片落盘，角标 **`15.50s · 纯 BGM`** |
| 4. 听（关键） | **听不到任何环境声**；BGM 从头播，**头 1s 淡入、末 1s（约 14.5→15.5）淡出**，结尾不硬切 |
| 5. 血缘 | 成片节点连向 3 个源片段 |

❌ 判失败：成片里能听到各镜环境声（=`-an` 策略未生效）；结尾硬切（=淡出锚点还在按 BGM 时长算）。

## T4 单镜 + BGM（CV-141 单镜解禁 + amix normalize=0 配平）

**对 agent 说**：「刚才那条改成一镜到底 10 秒重做：一个片段 + 一段 11 秒 BGM，合成」

| 步骤 | 预期 |
|---|---|
| 1. 单片段合成 | **不再被「至少需要 2 个视频片段」拒绝**（旧硬闸已解） |
| 2. 成片角标 | **`10.00s · 环境声+BGM`** |
| 3. 听（关键） | **环境声在**，BGM 铺在下面；两者都不发闷（`normalize=0` 修掉了「每路各减半」） |

❌ 判失败：环境声消失（=单镜仍按多镜丢音轨）；BGM 和环境声都明显偏小（=normalize 未修）。

## T5 BGM 短于成片 → 报错不落半成品（CV-138 守卫）

**对 agent 说**：「故意用一段 10 秒的 BGM 和刚才的三镜片段合成一次，我看看报错」

| 步骤 | 预期 |
|---|---|
| 1. 合成被拦 | 工具报**中文错误**，文案含精确差额与建议值，形如：`BGM 比成片短 5.5 秒（成片 15.500s，BGM 10.0xxs）。请把 BGM 时长提高到 ≥15.500s（建议 16s）后重新合成。` |
| 2. 画布 | **不出现**残次成片节点（没有「看着像成片、其实被截了」的假产物） |
| 3. 自愈（加分项） | agent 读到报错后自动重生成 ≥16s 的 BGM 再合成 → 走通 |

## T6 多镜无 BGM → 明确警告 + 无声（策略矩阵 ⚠️ 分支）

**对 agent 说**：「三个片段直接合成，不要配 BGM」

| 步骤 | 预期 |
|---|---|
| 1. 合成成功 | 结果/节点带警告：`本次为多分镜合成且未提供 BGM，成片将无声（各镜环境声按策略已丢弃）。` |
| 2. 成片角标 | **`15.50s · 无声`** |
| 3. 听 | 全片无声（预期行为，不是 bug） |

## T7 分镜时长和校验（CV-142，弱断言）

**对 agent 说**：让分镜表每镜声明 5s（合计 15s），走完 T3 后问 agent「合成结果里有没有时长偏差的警告」

| 步骤 | 预期 |
|---|---|
| 1. 偏差在阈值内 | 无警告（正常） |
| 2. 人为制造偏差 | 分镜声明合计与成片真值差 > 阈值时，结果 `warnings` 报出（如「分镜合计 15s（360 帧），成片真值 15.500s」） |

> 此用例为弱断言：无警告且成片正常即通过；能演示出偏差警告为加分项。

## T8 音频参考 audioRefs（CV-129 / CV-155，感知层同步初判）

**对 agent 说**：「用刚才那段 BGM 作为音频参考（audioRefs），配一张参考图，走 ref2va 生成 5 秒视频，让画面动作跟上音乐节奏」

| 步骤 | 预期 |
|---|---|
| 1. 工具调用 | `video_generate`/`video_composite` 带 `audioRefs=[音频节点]`，走参考模式（r2v）；若该组合原本会走首尾帧，结果应带「帧模式与参考模式互斥」的说明 |
| 2. 产物 | 视频落盘可播；**主观判**：动作/剪辑感是否呼应音乐（感知层，不要求精确卡点） |

❌ 判失败：上传音频 500（=CV-155 自愈/上传端点问题）；结果完全无音频。

## T9（UI 验收层）按钮路径：排除片段 + BGM 下拉（CV-006/007 已落地）

**操作**：不经过 agent，直接在时间轴操作（多镜项目 + 画布上有 ≥1 个音频节点）

| 步骤 | 预期 |
|---|---|
| 1 | 时间轴默认**只显媒体**（video/audio/image）；勾「显示全部」后便签/文案等非媒体出现 |
| 2 | video/audio chip 角标显示**真值时长**（如 `5.17s · 14:32`）；工具栏显示「预计成片 ≈ Σ真值」 |
| 3 | 点某 chip 右上 ✓ 勾选区排除它 → chip 降透明、总时长同步减少；导出后成片**不含**该片段 |
| 4 | 工具栏 BGM 下拉选一段音频 → 成片角标 `· 纯 BGM`（多镜）/ `· 环境声+BGM`（单镜），与 T3/T4 的 agent 路径产物一致（同一合成函数，殊途同归） |
| 5 | 选一段**短** BGM → 下拉旁出 amber 软提示；强行导出 → 服务端中文报错原样 toast 呈现、画布无半成品 |
| 6 | 作废片段的勾选区**禁用**（✕），不参与计数 |

> 历史基线（CV-006 落地前）：按钮路径多镜恒无声。现已修复——UI 与 agent 走同一 `/compose` 通路。
