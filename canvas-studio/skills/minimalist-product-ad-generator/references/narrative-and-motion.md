# 分册：叙事骨架与运动语言（minimalist-product-ad-generator）

> 何时读：给整片选叙事骨架、在写文案与出锚点照之前定运动语言与强弱节奏时。

## 1. 选产品叙事骨架

写文案与出锚点照之前，先选一条轻量的产品叙事骨架。不要用宽泛的企业品牌片结构；本风格聚焦实体产品的短苹果片。

用户没选方向时给 2-3 个简洁方向、推荐一个，按推荐推进（"你决定"就直接用推荐的）。

推荐骨架：

1. **新品发布（默认推荐）**
   - 留白开场 → 主变体确立主视图 → 材质/结构细节 → 自然产品动作 → 变体或色彩关系 → 全文案收尾。
   - 适合耳机、手表、数码配件、小家电、香氛设备等。
2. **特性触碰**
   - 产品静止 → 交互触发 → 特性动作 → 细节放大 → 结果/感受 → 收尾帧。
   - 适合有开合、旋转、磁吸、亮屏、折叠、喷雾等清晰动作的产品。
3. **色彩家族**
   - 主变体独现 → 辅助变体轻滑入 → 色彩秩序成形 → 材质与结构保持统一 → 全系列收尾 → 文案落定。
   - 适合多色、多变体、多型号产品。

输出一句话描述选定的叙事骨架，例如：

> This film uses the Color Family spine: the purple main variant establishes the hero view, other colors enter as supporting layers, and the full product set closes with the English copy.

## 2. 产品叙事必须具体

- 不要复用固定耳机模板，也不要写"产品状态变化"这类含糊说法。
- 分镜必须建立在产品品类、形态、材质、结构与可见动作上。
- 产品动作必须可视且具体，例如"盖子打开 30 度、内壁反光出现""表冠旋转、高光沿边缘滑过"。

## 3. 给整片定运动语言

这一步不产出资产，只定义运动强度、转场逻辑与节奏峰值，供后面的分镜使用。

1. **转场由真实产品或视觉元素驱动**
   - 优先：产品边缘、材质高光、开合/旋转/吸附/滑移动作、变体排列的几何变化、色彩进出、匹配机位方向、匹配产品剪影。
   - 禁止用无意义白闪、抽象粒子、随机光效或随机硬切来假装高级运动。
2. **一拍一个主动作**
   - 次要元素稍晚出现，不与主动作同时争注意力。
   - 例：产品先入场，文字后出现；主变体先稳定，辅助变体再滑入；材质高光先扫过，文字动效再开始。
3. **设定强点与安静点**
   - 5s：1 个小峰 + 1 个稳定收尾。
   - 10s：1-2 个峰 + 1-2 个刹车点。
   - 15s：2-3 个峰 + 2 个安静刹车点。
   - 峰值可以是产品动作完成、变体入场、文案后半显现、全产品收尾。
   - 刹车点可以是材质细节停顿、文案可读停留、终帧停留。
4. **留出安全空间**
   - 产品剪影保持清晰，单行文案保持可读，主变体不被遮挡。
   - 只有用户提供了 Logo 才加 Logo；不要编造假 Logo。
5. **避免假科技装饰、镜面白台与空洞开场**
   - 避免假科技界面、无意义玻璃卡、装饰文字墙、未证实数据、随机粒子与堆叠光效、全片同一种缓动、满屏产品墙。
   - 白科技风不是镜面白台，也不是死平白光；不要把产品放在反光地板、玻璃桌或廉价棚拍镜面上。
   - 苹果式留白就是简单白背景；冲击力来自好看的产品角度、真实产品动作、机位节奏与留白构图，不是镜面反射或空等。
   - 开场不能是空洞死时间，要迅速露出好看的产品动作或角度（产品从自身结构中平滑旋出、从开合机构里出现、沿自身剪影滑行、被边缘高光揭示）。具体动作要从当前产品形态推断，不要写死成耳机。

输出一句简短的"运动语言"陈述，例如：

> This film uses product-edge highlights and the purple main variant sliding motion to drive transitions. The main peaks are variant entrance and full-copy landing, with a stable final hold for the product and copy.

## 4. 过程可见

- 每一步之后要说清产出了什么、下一步需要什么决策；不要闷头把整条流水线跑完。
