# 视频效果提升方案——现状与建议对比（决策稿）

> **状态：待拍板**。本文档是决策依据，不是实施记录；每一项改动给出「现状 → 建议 → 理由 → 改动范围 → 风险/代价」五要素，供逐项决策。
> **背景**：多镜头叙事成片的观感与 H3 网上演示效果存在差距。经排查，差距来自三层：链路能力缺口（后端）、流程路由缺口（本插件 skill）、生成策略缺口（无抽卡/镜头节奏）。
> **关联**：CV-039（H3 规范去重）、CV-043（Ref2VA 音频参考远期）、CV-062/CV-063（已落地项）。
> **日期**：2026-09-01

---

## 一、问题定位总览

| 层 | 问题 | 影响 | 归属 |
| --- | --- | --- | --- |
| 链路能力 | 视频无原生音频（`generateAudio` 占坑未接入） | 哑片 + 外挂 BGM，H3 最大差异化优势（音画一体）被砍 | 后端 |
| 链路能力 | 视频模型固定 FL2VA 路线（`model` 占坑），生图模型一般 | 关键帧画质 = 该镜画质上限 | 后端 |
| 流程路由 | Ref2VA 多参考被窄化为"同镜关键帧转场"，角色/场景参考组合模式**不可达** | 跨镜一致性靠反复转译间接传递，每镜都在漂移 | **本插件（本文重点）** |
| prompt 规范 | Ref2VA 六段式规范不在总纲内，流程也不要求加载 `h3-prompt-writing` | 即使触发多参考，prompt 也是按首尾帧格式写的 | **本插件** |
| 生成策略 | 每镜生成一次即过，无候选挑选；30s 默认 4–6 镜切碎表演 | 概率性产物无抽优；H3 单镜动作弧线被腰斩 | 本插件 + 使用方式 |

**核心判断**：网上惊艳的 H3 视频大多是「单镜 15s + T2VA 全自由 + 音画一体 + 抽卡」。多镜头叙事想要「每镜稳定且惊艳」，正确武器是 **Ref2VA 参考组合模式**（角色/场景作为身份参考锁定 + 保留运镜动作自由度），而这正是当前流程唯一没接上的一环。

## 二、逐项对比

### 改动 1：视频生成路由改为「参考组合优先」（核心改动）

| | 内容 |
| --- | --- |
| **现状** | creation-spec 标准工作流第 9 步按**关键帧数量**路由：单关键帧 → `video_generate`（FL2VA）；两段衔接 → `video_composite` 两图（首尾帧）；三张及以上 → `video_composite` 多参考（Ref2VA）——且仅指「同镜多关键帧转场」。即：每镜实际只喂 **1 张首帧**，角色一致性全靠关键帧间接传递 |
| **建议** | 改为按**用途**路由，默认走参考组合：每镜组合喂 `[角色定妆照（1–2 张）, 场景概念图（1 张）, （可选）起始姿态关键帧]`（≤6 张）→ `video_composite` Ref2VA + 六段式 prompt；仅"同镜首尾帧转场"这一种场景才走 2 图 FL2VA |
| **理由** | H3 的 Ref2VA 设计本意就是**参考生成**（reference generation）：`<Subject 1>` 定义角色身份、`<Subject 2>` 定义场景环境——身份被参考锁定，运镜/动作/节奏保持接近 T2VA 的自由度。这同时解决两个诉求：「稳定」（参考锚定，不再经 图→关键帧→视频 两次转译衰减）+「惊艳」（不被单张首帧钉死构图）。后端能力已就绪：`image2videoref2va` 端点存在（`config.ts:29`）、`video_composite` 支持最多 6 张 |
| **改动范围** | 仅 `skills-local/canvas-studio-creation/SKILL.md` 第 9 步 + 提示词章节（纯规范改动，不动工具代码） |
| **风险/代价** | ① ~~Ref2VA 在本后端的实际效果**未实测过**~~ → **2026-09-02 已实测**：最小烟雾测试（R001/T1）通过——端点可用、双参考路由正确、六段式 prompt 6/6 齐全（见 `docs/effect-tests/` 轮次记录表）；② 多参考镜的生成成本可能高于单图；③ 参考组合的图片需要每镜就位（定妆照已有，场景概念图需补生成步骤） |

### 改动 2：补 Ref2VA 六段式 prompt 规范

| | 内容 |
| --- | --- |
| **现状** | 总纲「视频提示词写法」章节只教 FL2VA 的首行对齐指令 + 三字段；Ref2VA 的六段式（`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`）只在 `h3-prompt-writing` skill 的 `references/ref-en.txt` 里，且流程不要求加载它 |
| **建议** | 总纲提示词章节补一段 **Ref2VA 最小骨架**（六段各自的职责 + `<Subject N>` / `<Picture N>` 标签用法 + 一个精简示例），并写明「完整规则与示例读 `h3-prompt-writing` 的 `references/ref-en.txt`」 |
| **理由** | 不定义 `<Subject N>` 的多参考调用等于把参考图当普通首尾帧用——这正是当前"触发了也没效果"的直接原因。骨架放总纲保证每次都有下限，全量规则按需读 references 保证上限（渐进披露，与 CV-063 后的 skill 体系一致） |
| **改动范围** | 仅 SKILL.md 提示词章节 |
| **风险/代价** | 总纲增重约 1–2K 字符（可用「详细规则读 ref-en.txt」控制篇幅）；六段式 prompt 更长，需在示例里给出"足够好但不过度"的示范 |

### 改动 3：关键帧生成同样吃组合参考

| | 内容 |
| --- | --- |
| **现状** | 第 6 步逐镜出图只传**定妆照 1 张**作参考；`image_generate` 实际支持 `filenames` 最多 **3 张**多参考 |
| **建议** | 关键帧生成默认传 `[定妆照, 场景概念图]`（2 张），需要风格统一时第 3 张传首镜成图 |
| **理由** | 关键帧是 Ref2VA 的输入之一（起始姿态锚），也是"未走视频参考组合时"的一致性载体。现在场景一致性在关键帧阶段就已丢失，后端能力却闲着 |
| **改动范围** | 仅 SKILL.md 第 6 步 |
| **风险/代价** | 多参考图生图的后端融合效果未实测；多图参考可能稀释单主体相似度——需要一轮对比验证 |

### 改动 4：镜头节奏默认值调整

| | 内容 |
| --- | --- |
| **现状** | 分镜规划对镜头数无约束，30s 常见 4–6 镜（每镜 5–8s）；镜头间为 ffmpeg 硬切拼接 |
| **建议** | 总纲增加节奏指引：叙事短片 **30s ≤ 3–4 镜、每镜 8–12s**；H3 单镜内可完成完整动作弧线（预备→爆发→收尾），除非转场有叙事意义否则不切镜；转场优先用首尾帧插值（FL2VA）做"镜头内转场"而非硬切 |
| **理由** | 镜头切多必碎：① 每多一镜多一次一致性衰减；② 5s 不够 H3 完成表演弧线；③ 硬切拼接零转场是"像 PPT"的直接原因。"少而长的镜"是单镜质量与叙事完整性的最优平衡点 |
| **改动范围** | 仅 SKILL.md（分镜规划与镜头词汇章节各加一行指引） |
| **风险/代价** | 单镜时长越长（逼近 15s 上限），生成失败率与重试成本上升；对"快节奏卡点视频"类需求不适用——需写成"默认值"而非硬规则 |

### 改动 5：抽卡机制（候选并列挑选）

| | 内容 |
| --- | --- |
| **现状** | 关键帧与视频每镜**生成一次即过**，不满意只能整镜重试（单节点右键重试） |
| **建议** | 总纲规定：关键帧与逐镜视频默认同 prompt 生成 **2 个候选**（画布并列落节点），由用户挑选或模型用 image2vl 辅助评审关键帧后推荐；候选数为澄清阶段可选项（默认 2，成本敏感用户可选 1） |
| **理由** | 生成是概率事件，同 prompt 多次抽取得产物可能差一个档次；网上好视频的本质是"幸存者"。当前管线只有生成没有挑选，这是"稳定出好效果"最朴素有效的手段 |
| **改动范围** | 仅 SKILL.md（工具已支持连续多次生成、并列落画布） |
| **风险/代价** | **生成成本直接翻倍**——必须作为澄清阶段选项让用户知情选择，不能默认强加 |

### 改动 6：原生音频接入（推动后端，外部依赖）

| | 内容 |
| --- | --- |
| **现状** | `generateAudio` 为占坑参数（传了被忽略），所有视频无声；BGM 靠用户上传节点混入 |
| **建议** | 推动后端为 FL2VA/Ref2VA 接入 H3 原生音频轨；接入后把占坑参数转正，并让总纲的音效/配乐字段（`overall_soundscape` / `non_diegetic_music`）真正驱动产物 |
| **理由** | 音画一体（对白口型、环境音、配乐）是 H3 相对其他视频模型最大的差异化优势，"惊艳感"起码一半来自声音。工具层占坑已留好位置（host-tools 参数 + generate.ts 透传点），接入是后端工作 |
| **改动范围** | 后端为主；本插件只需在接入后放开占坑参数 + 更新总纲能力边界 |
| **风险/代价** | 外部依赖，排期不可控；建议作为独立事项与后端沟通，不阻塞本文其余改动 |

### 改动 7：CV-039 H3 规范去重（选型决策，与改动 2 合并实施）

| | 内容 |
| --- | --- |
| **现状** | 总纲里有一份**不完整**的 H3 规范复制品（无三字段声音规范细节），全量版在 `h3-prompt-writing`；两者已出现漂移（STATUS.md 核实三字段零匹配） |
| **建议** | **方案 A（推荐）**：总纲只保留"最小骨架 + 强制路由"——写视频 prompt 前必须加载 `h3-prompt-writing`（含读 references），删除复制品细节。方案 B：把总纲复制品补全到与上游等价（双份永久同步） |
| **理由** | A 消除双写漂移的根，且 `h3-prompt-writing` 本来就注册在册、加载成本一次约 8K 字符；B 的同步负担已被实践证明会漂移（CV-039 即证据）。改动 2 的六段式骨架与 A 同思路：总纲保下限，references 供上限 |
| **改动范围** | SKILL.md 提示词章节重构 |
| **风险/代价** | A 使每次视频生成前的上下文多一次 skill 加载；若 `h3-prompt-writing` 加载失败需有降级路径（保留总纲最小骨架恰好就是降级方案，两者不冲突） |

### 改动 8（远期）：单镜精品快速模式

| | 内容 |
| --- | --- |
| **现状** | 唯一入口是全流程管线（澄清五要素 → 分镜 → 逐镜 → 拼接），没有"只要一条 15s 惊艳单镜"的轻路径 |
| **建议** | 需求澄清第 ① 步增加产物形态选项：**单镜短片**（跳过分镜/逐镜/拼接，一镜直出 + 候选挑选）作为与多镜头叙事并列的入口 |
| **理由** | 网上 demo 形态即单镜；对社媒传播场景，现有管线是"杀鸡用牛刀"且效果反而差 |
| **改动范围** | SKILL.md（澄清五要素前置一个形态问题 + 单镜分支流程） |
| **风险/代价** | 澄清多问一题；与现有五要素流程的兼容需要设计（单镜模式下"节奏/镜头数"两要素作废） |

## 四、P1 验证方法（AB 对比）

同一项目、同一分镜表、同一主角出现 ≥3 镜的场景：

1. **旧路径**：按现流程生成一轮（定妆照 → 单图关键帧 → FL2VA）
2. **新路径**：P1 改动后生成一轮（定妆 + 场景参考 → 组合参考关键帧 → Ref2VA 六段式）
3. **对比维度**：① 角色跨镜一致性（脸/发型/服装漂移程度）② 场景连续性（地标/光位）③ 单镜内运镜与动作幅度 ④ 整片节奏（配合改动 4 后镜头数变化）
4. 辅助：关键帧可用 `image2vl` 做客观比对；视频目前只能人眼评

### 6.1 P1 前置最小烟雾测试

| | 内容 |

### 6.2 改动 1 回退方案（防 Ref2VA 不达预期）

| | 内容 |
| --- | --- |
| **现状** | 改动 1 风险段承认"未实测"，但未给"实测后不达预期"时的回退路径 |
| **建议** | P1 验证后**分两档决策**：① Ref2VA 跨镜一致性 ≥ FL2VA 单图路径 → 完整采纳 P1 ② Ref2VA 跨镜一致性 < FL2VA → 回退到"**仅保留改动 3（关键帧多参考）+ 视频保持 FL2VA 单图**" |

### 6.3 改动 5 抽卡三段式

| | 内容 |
| --- | --- |
| **现状** | "模型用 image2vl 辅助评审后推荐"——具体形态（自动 vs 候选+用户挑）未明 |
| **建议** | **三段式**：① 画布并列落 N 个候选节点 ② 用户主动挑 / 显式让模型用 image2vl 评 ③ 选定节点连线继承父级，未选节点降为视觉灰阶。N 由澄清阶段定 |
| **理由** | 自动推荐省心但模型判断未必符合叙事意图；纯用户挑对不熟项目有判断成本。三段式把"评估能力"与"决策权"解耦：模型出参考意见，人做最终决定。同时避免候选长期滞留画布（未选节点降为灰阶） |

### 6.4 改动 4 镜头节奏边界条件

| | 内容 |
| --- | --- |
| **现状** | 建议"30s ≤ 3-4 镜、每镜 8-12s"，但未区分内容形态 |
| **建议** | 加边界条件："**默认用于叙事 / 抒情 / 角色向**；快节奏卡点 / 转场型（音乐卡点、节拍驱动）请保持短镜硬切（每镜 2-4s），新规则不适用" |
| **理由** | 节奏与内容形态强耦合：叙事需长镜表演弧线，卡点需短镜累积冲击。"一刀切默认"会把卡点内容也强行变长，反而降低质量。澄清阶段识别形态，决定走哪条默认值 |

### 6.5 改动 7 降级骨架具象化

| | 内容 |
| --- | --- |
| **现状** | 方案 A 说"保留总纲最小骨架就是降级方案"，但**降级到具体什么**未明 |
| **建议** | 把"最小骨架"显式定义：**仅 3 字段（subject / action / camera）+ 提示词总长 ≤ 200 字 + 无 Subject 标签 + 无 `<Picture N>` 引用**，与 FL2VA 兼容。h3-prompt-writing 加载失败时按此骨架回退 |
| **理由** | 降级方案必须可执行——否则加载失败时模型不知退到哪。具象化既给降级路径明确锚点，也暴露"骨架"和"六段式"的能力差异，让决策者评估 A 方案代价值不值 |

### 6.6 改动 8 提至 P1 同期

| | 内容 |
| --- | --- |
| **现状** | 列为"远期"，但理由部分自述"随时可做" |
| **建议** | **从远期提到 P1 同批**（最简版）——只在澄清阶段加形态分支（"单镜短片" vs "多镜头叙事"），单镜分支跳过分镜 / 逐镜 / 拼接，一镜直出 + 抽卡 |

### 6.7 单条 30s 成片生成成本对比

| 路径 | 关键帧 | 视频 | 抽卡 | 总计 | 相对基线 |

| P1（5 镜 + 参考组合） | 5 | 5 | 0 | 10 | 1.0× |

### 6.8 Ref2VA 六段式 prompt 最小示例

> 给决策者一个长度量级参考，非可直接使用的成品。

**示例**：1 镜，男主在雨夜街道中段奔跑（近景→中景推镜），8s

```
<Subject 1>: A young man in his mid-20s, short black hair, navy windbreaker,
worn sneakers — based on <Picture 1>.
<Subject 2>: Rainy urban street at night, neon signs on wet asphalt — based
on <Picture 2>.

[summary] The man sprints through a rainy night street, dodging puddles,
glancing over his shoulder, urgent and hunted.

[retention_analysis] <Picture 1> locks identity (face/hair/coat).
<Subject 2> matches <Picture 2> environment. Camera dollies forward from
medium to close as he runs toward lens.

[detailed_description] He starts mid-frame, then accelerates left-to-right.
Head turns over his right shoulder at second 3, eyes wide, mouth slightly
open. Rain drops bounce off his shoulders. Camera closes distance from 2.5m
to 0.8m over 8s, ending in tight close-up of his face.

[overall_soundscape] Heavy rain on asphalt, distant car horns, his rapid
breathing and footfalls. No dialogue.

[non_diegetic_music] Tense pulsing synth at 95bpm, swells at second 4.
```

**长度**：约 280 字符（含标签），与 FL2VA 的 50-80 字符**约 3-4 倍**。需在 P1 验证中实测是否值得。
