# 四季片 · 验收基准提示词（A / A2 / B 三版）

> 用途：`code-driven-explainer` 的固定验收基准。同一条内容规格出两版提示词 ——
> **A 版（工程口径）** 测「纪律是否被执行」，**B 版（用户口径）** 测「纪律是否被内化」，
> **A2 版（工程口径 · 确定性内容表）** 在 A 版纪律之上把设计输入也确定化（结构/旁白/布局三表），
> 测「管线装配能力」——设计自由度归零后，剩余耗时与缺陷全部 attributable to 管线本身。
> 建立于 2026-11-07，依据真机转录的三轮失败点；A2 增补于 2026-11-08（会话 19 病灶：设计自由度 = 思考爆量的第一来源）。
> 三版内容规格同源：B0–B7 是共同底座，A2 用 L1–L3 内容表把 B0–B7 细化到「逐段绑定」。

## 怎么用

| 版本 | 什么时候用 | 判读方式 |
|---|---|---|
| A 版 | 改动取证链、探针闸、错误回执、数据契约之后的**回归验收** | 逐条打勾，任何一条 ❌ 即为回归 |
| B 版 | 改 skill 措辞、改提示注入、评估模型「自己会不会想到」时的**拟真验收** | 只看「该想到的有没有想到」，不要求逐条命中 |

两版都跑一次 ≈ 一条片的时间成本。**建议 B 版先跑**：B 版暴露的是「skill 没教到位」，A 版暴露的是「机制坏了」。

## A 版 · 工程口径（专业）

```
用 code-driven-explainer 做一条 45 秒、16:9、30fps、1920×1080（1350 帧，成片时长 45±0.5s）的
中文科普片《为什么地球公转产生四季》：中文配音 + 词级卡拉OK字幕（caption 轨，非 textCard）。

【A 取证纪律 —— 不满足即视为未验收】
A1 第一次 render_composition 就必须是 spotFrames（不是先出全片 draft）。一次取满 ≤8 帧，覆盖
   全部画面判据：第 0 帧、末帧、两个 wipe 窗口的「前/中/后」、仪表盘指针的两个极值、折线末点
   countUp 的中途与终值、引线标注的完整态。之后每轮改动仍然先探针后看图，不攒到最后一次看。
A2 每张帧一律 read_image(file_path=…) 看**成片像素**，对照判据逐条打勾并写明帧号。
   抽帧是 JPEG q0.85；若看图工具报格式不支持，换 read_image，不要为转格式单独重编码抽帧。
A3 inspect_image 的 grid/bbox 只用于定位疑点、取精确数值（坐标/颜色/透明度），**不得**作为
   「某元素存在或不存在」的结论依据。
A4 以下四样都**不能**证明画面效果，只能证明结构：manifest 字段、report.animationWindows、
   report.lint[]、image2vl 的 VL 文字转述。画面结论唯一的合法证据是 A2 的看图记录。
A5 探针不落画布、用户看不见。首次探针后必须在回复里点明「刚才那几次是探针，不是成片」。
A6 若 read_image 报未声明 image input ⇒ 交付里明写「未做画面自检」，不得拿亮度网格或 VL 转述顶替。
A7 不跑负例（负例是校验闸的测试手段，不是交付流程的一环）。确实要跑时必须写明预期拦截点，
   并贴拒收回执原文。
A8 渲染超时或被拒时，先读回执里的「工单：…」诊断行与 msPerFrame，再决定动作。判据只有三条：
   未取单 / 无首帧 ⇒ 执行器链路问题，交原文给用户并建议重启客户端；已出首帧且进度在涨 ⇒ 才算
   内容偏重，可考虑降档或缩短。不得用 uptime / load average 归因，也不得为消超时删减画面元素。
A9 不得重编码或重采样 TTS 源音频来凑响度（会让渲染时间翻倍且终端用户无法复现）。响度不合规
   记为未决项，不算通过。
A10 若回执写「音频=无声」而片中有旁白，按缺陷上报，不得接受（这是必须抓住的误报）。
A11 交付前必须复述未决项，三类都要覆盖：体检告警逐条状态（report.lint[] 折叠时给计数 +
   前 3 条原文 + lintPath 落盘路径）、未核源事实、模型自身能力边界。

【B 内容规格】
B0 旁白先按 4–5 字/秒 定稿（全文 180–225 字），字数定了再合成 TTS；段边界取 tts 真值，
   不按字数估。caption 每句首尾相接，句间不留空白帧。
B1 片中一个仪表盘（gauge）元素，指针随讲解在 −23.5°~+23.5° 之间摆动（太阳直射点纬度），
   指针终值必须停在旁白说出的那个度数上。
B2 中段一条「近 30 年全球均温距平」折线（1995–2024 逐年，30 个点），最后一个点的数值数位
   滚动出现（countUp），终值必须等于该点数值本身，不许取整到别的数。
   单一基准：GISTEMP v4，1951–1980 基准期；30 个点全部同源同口径，禁止混用 HadCRUT / NOAA
   补点。数值的来源 URL 与访问日期写进 chart 的 dataSource，基准文字（1951–1980）必须直接
   出现在数据卡标签上，不许只写在 manifest 里。
B3 对「黄赤交角 23.5°」用引线标注，线的末端必须落在示意图的地轴本身上（不是落在旁边空白处
   或地球边缘），标注文字与旁白用词一致（统一写 23.5°，不写 23.5 度）。
B4 「直射 / 斜射」两段对比用分区揭示：左侧面板进场 reveal.direction:"left"（可见区自左展开）；
   右侧面板退场 reveal.out.direction:"right"（内容朝右退去 ⇒ 隐藏侧在左）。exit 不支持 clip，
   不要拿 exit 做擦除。两段揭示窗口不得在同帧出现「屏上什么都没有」。
B5 片尾无裸画面：第 1349 帧必须有字幕或旁白覆盖（末帧要单独取出看图确认）。
B6 中文字体先用 global.fontFamily 声明；数据卡与字幕卡的 box 同时给足宽和高 —— 标题不能削顶、
   最后一行不能被削底（矮盒子按宽度铺满会被裁）。
B7 折线图的年份类目标签必须画在盒子内部可见（不是落在 box 下沿被 overflow 裁掉）。

【C 交付复述格式】
① 判据表（一条一行，禁止散文）：
   | # | 判据 | 状态 | 取证方式 | 帧号 / 路径 / 原文 |
   示例：| 1 | 仪表盘指针摆动且终值 = 旁白值 | ✅ | read_image 帧 210 | … |
② 未决项：体检告警（计数 + 前 3 条 + lintPath）／未核源事实（凡本次会话内未落盘、来自记忆的
   数值、年份、机构名）／能力边界（哪条判据没法自证、为什么）。
③ manifest 路径、spec 路径、成片 url、探针帧清单（帧号）。
```

## A2 版 · 工程口径（确定性内容表）

> **与 A 版的唯一区别**：结构/旁白/布局由内容表定死（选片台「挑选结果」的产品化替身），
> 模型职责收缩为「按表装配 + 数据现场核对 + 取证纪律执行」。
> 用途：批 0/1/2 管线修复的验收跑——设计自由度归零后，剩余耗时与缺陷全部归因管线。
> 数据口径仍留给模型现场拉取（L3 数据保真判据保留测试价值）。

```
用 code-driven-explainer 做一条 45 秒左右（±2s，以 TTS 真值为准）、16:9、30fps 的
中文科普片《为什么地球公转产生四季》：中文配音 + 词级卡拉OK字幕（caption 轨）。
本片为**确定性内容表翻版**：结构与文案已定稿如下，你的职责是「按表装配」，不是重新创作——
内容表与任何纪律冲突时，先按表执行，冲突本身记为未决项上报。

【内容表 · L1 结构骨架】8 段（段号 → 主题 → 视觉元素 → 目标时长）：
  V1 钩子：距离不是原因，答案在地轴 → gauge 出场（指针停在 -23.5）
  V2 黄赤交角：23.5° 与回归线 → 引线标注指向地轴，指针摆到 +23.5
  V3 直射：能量集中 → 左面板 wipe 进（reveal.direction:"left"）
  V4 斜射：能量摊开 → 右面板 wipe 进 + 擦出（reveal.out.direction:"right"）
  V5 四季循环 → 公转示意（shape 轨道环 + 指针往复）
  V6 数据证据：近 30 年全球均温距平 → 折线 30 点（逐年）+ 末位 countUp + 数据卡
  V7 呼应：指针摆动 = 直射点足迹 → gauge 复摆
  V8 结论 → 标题卡 + 字幕覆盖末帧（第 1349 帧单独取帧确认）

【内容表 · L2 旁白脚本】（定稿全文，逐句对应 V1–V8，语速 4–5 字/秒；**不要改写**）：
  V1 四季不是因为地球离太阳远近——方向错了，答案在地轴上。
  V2 地轴斜着二十三点五度，太阳直射点在南北回归线之间来回摆。
  V3 直射时，同样的阳光摊在更小的面积上，能量集中，就是夏天。
  V4 斜射时，同样的光摊在更大的面积上，能量分散，就成了冬天。
  V5 地轴方向不变，地球绕着太阳转，直射点一年往返一次，四季循环。
  V6 近三十年，全球均温一路抬升。数据不会说谎：升温没有停，气候把每年的差异都记在账上。
  V7 仪表盘的摆动，就是直射点的足迹，四季的钟摆。
  V8 四季不是距离的故事，是角度的故事。

【内容表 · L3 视觉蓝图】（1280×720；box 为百分比中心语义 x/y/w/h）：
  主图形区（地轴/地球/公转）{x:38,y:42,w:52,h:52}
  仪表盘区 {x:82,y:42,w:26,h:30}
  图表区（V6 主导，与主图形区互斥在场）{x:50,y:50,w:76,h:44}
  数据卡 {x:82,y:76,w:28,h:18}
  标题区 {x:50,y:10,w:70,h:12}
  色板：底 #06080B / 主蓝 #38bdf8 / 强调橙 #ffb454 / 文字 #e8eefc

【帧窗规则】captions[].frames 与 audioFrames 一律取 TTS 真值（ffprobe），
帧窗由 builder 自动推导——**禁止在推理里手排整片帧号**；段间衔接交给 builder 顺序窗口。

【数据纪律】V6 数值现场拉取 GISTEMP v4（J-D 列）逐年 30 点（1995/1996 起至最新可得年），
dataSource + baseline（1951–1980 基线距平）写进 chart 并**出现在数据卡标签上**；
labelEvery 抽稀标签；末位年值 = countUp 终值。

【A 版取证纪律 A1–A11 全部保留，逐条有效】
【C 交付复述格式与 A 版一致】
```

### A2 与 A 版的对照读法

| 维度 | A 版 | A2 版 |
|---|---|---|
| 设计自由度 | 旁白/结构/布局全部临场 | 内容表定死 |
| 主要测量 | 纪律执行 + 创作质量 | **管线装配能力 + 判据消费** |
| 预期耗时 | 45~50min 级 | **25~30min 级**（设计思考出推理） |
| 与批 2 修复的关系 | 闸与纪律被行使 | 闸 + builder 帧推导 + 契约行为语义全链路被行使 |

## B 版 · 用户口径（拟真）

> 刻意保留真实用户的说话方式：不点工具名、不给帧号、不说取证方式、不列预算。
> 唯一的「技术味」是最后一句「先给我看几帧」—— 真实用户确实会这么提。

```
帮我做一条 45 秒左右的中文科普短视频，讲「为什么地球公转会产生四季」，16:9，配中文旁白，
字幕要一句一句跟着念出来的那种（逐字高亮）。

画面我想看到这几样：
1. 一个仪表盘，指针跟着讲解在南北回归线之间来回摆，讲到最后要停在对应那个角度上；
2. 中间插一张「近 30 年全球气温变化」的折线图，最后一个数字要滚上去；
3. 「黄赤交角 23.5°」用一条引线指到示意图的地轴上；
4. 讲「直射」和「斜射」的时候做个左右切换的擦除效果，一边进来一边出去；
5. 结尾别留光秃秃的画面，字幕要盖到最后一帧。

数据要准一点，别把不同来源的数字混在一起。整体别做得像 PPT 一样干巴巴的。
做完先给我看几帧确认，再出成片。
```

## 两版差异：省略了什么，就测什么

| 维度 | A 版 | B 版 | B 版能测的能力 |
|---|---|---|---|
| 探针预算 | 一次 ≤8 帧 + 覆盖清单 | 只说「先给我看几帧」 | 是否按 3 次硬闸自己规划帧，第一次就采全 |
| 取证方式 | 看图是唯一合法证据、四样禁自证 | 完全没提 | 是否主动 `read_image`，还是拿 manifest 自证 |
| wipe 方向 | 写死 `direction:"left"` / `out.direction:"right"` | 「一边进来一边出去」 | 是否自己避开「进场/退场不是同一口径」的坑 |
| 数据基准 | GISTEMP v4 / 1951–1980 / 30 点 / dataSource | 「别混口径」 | 是否自己锁定单一基准并把它落到画面上 |
| 音色 | 未指定（走缺省 + 交付说明） | 未指定 | 是否只打断一次、合并进意图卡，而不是自行挑资产 |
| 体积约束 | box 宽高都要给足 | 没提 | 是否踩过裁切后才修，还是组装时就避开 |
| 交期与预算 | 探针 1 次 + 全片 ≤3 次 | 没提 | 会不会无限重渲 |
| 交付复述 | 强制表格 | 没提 | 是否仍主动复述未决项（skill 是否内化） |

## 跑完怎么看（B 版观察点）

1. **第一次 render 是不是探针** —— 全片 draft 打头就是没内化（真机实测 20 次渲染里 10 次是无必要全片）。
2. **有没有自己提「基准」** —— 画面上出现 1951–1980 才算，只写在 manifest 里不算。
3. **reveal 有没有翻车** —— 出现「整屏空白」或「整层被遮」就是踩了方向坑。
4. **结尾最后一帧** —— 取第 1349 帧看图，裸画面即失败。
5. **回执音频行** —— 写「无声」而片中有旁白，直接记缺陷。
6. **音色** —— 有没有为了音色反复追问（应只打断一次）。

## 维护

- 内容规格（B0–B7）是三版的共同底座：**改一处必须三版同步改**（A2 的 L1–L3 是 B0–B7 的细化，细化变了也要回写 B0–B7 口径），否则横向对比失效。
- 纪律条目（A1–A11）只进 A 版。若某条在 B 版连续两轮都「没被想到」，说明它该写进 skill 而不是留在提示词里。
- 新增判据时优先加在 A 版，跑两轮确认稳定后再决定是否降级进 skill。
