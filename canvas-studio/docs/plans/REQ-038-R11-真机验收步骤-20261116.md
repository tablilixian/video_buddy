## 4. 第 2 轮 · T17 —— 改一段只重渲一段（本批最关键）

再说：**「读 spec 重新 scaffold，交付档渲一版」**。

只看回执那一行：

| 回执 | 判定 |
|---|---|
| `3 段（2 复用 / 1 重渲，边界来源 段表）` | ✅ 隔离成立 |
| `3 段（1 复用 / 2 重渲，边界来源 段表）` | ❌ s1 被 s2 带脏 |
| `3 段（0 复用 / 3 重渲，边界来源 段表）` | ⚠️ 先排除正常情形（见下） |
| `边界来源 spec` / `transition 末端` | ❌ 段表没生效 |

`0 / 3` 的三种**正常**情形：① 第一次带段表的渲染（段窗 200/400→190/390，旧 hash 全变）；② 这次 scaffold 顺带改了 `meta` 全局项；③ 上一轮手删了 `deliver/segments/` 但缓存还在（反过来只会复制，不会重渲）。

正确顺序：**先渲一次接受 0/3 → 再只改 s2 渲一次看是否 2/1**。
