## 1. 合成音轨策略矩阵（定稿）

判据只有一个：**本次合成纳入的片段数**（`resolvedClips.length`）。
1 个片段 = 一镜整出（同一次生成的画面连续，环境声前后一致）；≥2 个 = 多镜拼接（各镜环境声互不连续，硬拼会"跳"）。

| 片段数 | BGM | 原生音轨 | 成片音轨构成 | 输出时长锚点 |
|---|---|---|---|---|
| **1** | 无 | **保留** | 环境声（原样） | 片段真值 |
| **1** | 有 | **保留** | 环境声 ×1.0 **+** BGM 叠混 | 片段真值（BGM 必须 ≥ 它） |
| **≥2** | 无 | **全丢** | ⚠️ **无声**（见 §5 待确认 ①） | concat 真值 |
| **≥2** | 有 | **全丢** | 纯 BGM（含 1s 淡入淡出） | concat 真值（BGM 必须 ≥ 它） |

三条实现要点：

1. **丢音轨在转码阶段做**（`buildTranscodeArgs` 传 `-an`），不是事后 mute——这样 concat 产物天然无音轨，下游 `hasConcatAudio=false` 自动走「BGM 单轨」分支，链路自洽。
2. **淡出锚点 = 成片真值**，不是 BGM 时长（现状缺陷 CV-138：BGM 20s 配 6s 成片 → 淡出点算在 19s，落在片外）。
3. **输出时长用 `-t <成片真值>`**，不再用 `-shortest`（现状缺陷 CV-138：短 BGM 会静默截掉画面，6s+2s → 输出 2.000s，`exit=0` 无任何报错）。

## 2. 改动清单（按实现顺序）

### 第 1 步 · CV-140 生成路径接入真实时长探测（P0，其余步骤的数据基础）

| 文件 | `src/generate.ts`（落盘点 `:1302` 写盘、`:1306` 得 url 之后）、`src/contracts/canvas.ts` |
| 现状 | 节点 `duration` 存的是**请求值**（`:1352` `clampDuration(params.duration, …)`）；生成路径**从不** ffprobe |
| 改法 | 产物已落本地（`join(directory, filename)`）→ 复用 `runFfmpeg` + `parseFfmpegDuration` 探真值；节点 `duration` 存**真值**，新增 `declaredDuration` 存请求值 |

## 3. 完整流程示例

### 例：15 秒三镜口红广告（横屏 16:9）

**先记住两个数**：请求 5s → 实拍 **5.167s**（124 帧 @24fps，帧量化）。三镜合计 **15.500s**。
**这个 15.500s 是整条链的关键数**——BGM 必须比它长，淡出锚点也用它。

| 步 | 谁做 | 动作 | 画布/状态变化 | 本步的新能力 |
|---|---|---|---|---|
| 1 | 你 | 「做一条 15 秒三镜口红广告，横屏」 | 建项目，`mode=keyframe_review` | — |
| 2 | agent | 澄清 3 问（题材/风格/有无口播）→ 挂风格 skill | 风格 skill 就位 | — |
| 3 | agent | `write_screenplay` | 剧本节点 | — |
| 4 | **你** | 批准剧本 | `mode=drafting` | — |
| 5 | agent | `submit_storyboard_for_approval`：镜1 中景拿起口红 5s / 镜2 特写旋出膏体 5s / 镜3 全景微笑合盖 5s | 3 张分镜卡 | — |
| 6 | **你** | 批准分镜 | 进入出图 | — |
| 7 | agent | `character_sheet` → 「小雅」四视图拼图锚点 | 资产卡节点 | — |
| 8 | agent | `image_generate` ×3（每镜关键帧，带锚点参考） | 3 张关键帧，真分辨率 1920×1080 | — |
| 9 | agent | `video_generate` ×3（`duration=5, aspectRatio=16:9, filenames=[锚点]`） | 3 个片段节点，**各带 H3 原生音轨** | **CV-140**：节点显示 `5.17s`（真值），请求值另存 `declaredDuration=5` |
| 10 | agent | `list_shots` → 拿到 3 个片段 id **与真实时长** | — | **CV-140**：此时就能算出成片 15.500s |
| 11 | agent | `music_generate` → 请求 BGM **16s**（> 15.500s，留余量） | 音频节点 `16.02s` | **CV-140**：音乐节点也是真值 |
| 12 | agent | `compose_video(clipIds=[3 个片段], bgmNodeId=音乐节点)` | 成片节点落盘 | 见下方逐步 |
| 13 | **你** | 桌面验收：听 + 看角标 | 成片 `15.50s · 纯 BGM` | **CV-143** |

**第 12 步内部发生了什么**（这是整个功能的收口）：

```
① 片段数 = 3 > 1  →  多镜  →  keepNativeAudio = false
② 转码 3 段：buildTranscodeArgs(..., hasAudio && keepNativeAudio = false)
              →  每段加 -an  →  3 条环境声全部丢弃
③ concat →  15.500s，无音轨
④ 探测：concat 真值 15.500s（CV-138 补的那一行）
   BGM 真值 16.024s
⑤ 守卫：16.024 + 0.05 < 15.500 ？ 否 → 通过
⑥ 淡出锚点 = min(16.024, 15.500) = 15.500 → fade out 14.500 → 15.500
⑦ 输出：-map 0:v -map [bgm] -t 15.500  →  成片 15.500s，音轨 = 纯 BGM
⑧ 落 video-composite 节点（duration=15.500 真值），血缘指向 3 个源片段
```

**结果**：成片 15.500s；听不到任何环境声；BGM 从 t=0 起、头 1s 淡入、末 1s（14.5→15.5）淡出；视频轨与音频轨等长。

---

### 3.2 报错路径（BGM 生成短了）

若第 11 步按「15s」请求 BGM → 真实 **15.024s**：

```
⑤ 守卫：15.024 + 0.05 < 15.500 ？ 是 → 抛错
```

报错原文：

> **BGM 比成片短 0.476 秒（成片 15.500s，BGM 15.024s）。请把 BGM 时长提高到 ≥15.500s（建议 16s）后重新合成。**

- **不落半成品**：不生成成片节点，画布保持原样（不会出现"看着像成片、其实被截了"的假产物）；
- 工具结果 `isError`，agent 会读到这条中文提示并知道该重新生成多长的 BGM；
- 重生成 BGM（16s）再合成 → 走通。

> 为什么不做"自动拉伸/循环铺满"：拉伸会变调，循环会在非节拍点接缝。两条都是"听得出错"的降级，**报错让人做对**比悄悄出错好。

### 3.3 单镜对比（一镜整出）

同一支广告改成**一镜到底 10 秒**（一次 `video_generate` 出整条）：

| 步 | 差异 |
|---|---|
| 9 | 只生成 1 个片段（`duration=10`）→ 真值 10.000s（240 帧），自带连续的环境声 |
| 11 | BGM 请求 11s（> 10.000s） |
| 12 | `compose_video(clipIds=[那一个], bgmNodeId=…)` ← **旧版这里会被拒**（`至少需要 2 个视频片段`），CV-141 后放行 |
| 12 内部 | ① 片段数 = 1 → `keepNativeAudio = true`；② 转码**保留** aac 音轨；③ 单条 concat（实测可行：6.023s，aac 保留 ✓）；④ `hasConcatAudio=true` → **叠混**分支：`amix=inputs=2:duration=first:normalize=0`，环境声 ×1.0 + BGM ×0.35；⑤ 守卫同前；⑥ 淡出锚点 = 10.000；⑦ `-t 10.000` |
| 13 | 听起来：环境声**在**，BGM 铺在下面，两者都不被压暗（`normalize=0` 修掉了"各减半"） |

**单镜 + 无 BGM**：直接落盘原片段（含环境声），时长不变——即"一镜整出"的最简形态。

### 4.1 自动化（我这边跑，全绿才算完成）

| 合成真实回环 | 用本地素材跑 3 组：多镜+BGM / 单镜+BGM / BGM 短于成片 | 时长/音轨/报错三项与 §1 矩阵一致 |

第 4 项是**行为实证**，不只断言参数串：ffprobe 量成片时长、`volumedetect` 量末 1s 是否有淡出、确认多镜成片**测不到环境声**。

### 4.2 桌面验收（需要你手动点）

1. **多镜**：合成一版 3 镜成片 → 听：**没有环境声**、BGM 有头尾淡化；看：成片角标 `15.50s · 纯 BGM`。
2. **单镜**：合成一版 1 镜成片 → 听：环境声**在**，BGM 铺底，音量都不发闷。
3. **报错**：故意用一个比成片短的 BGM 合成 → 看到中文报错、画布上**没有**残次成片。

## 5. 待确认（两条，开工前拍板即可，不阻塞前 3 步）

① **多镜 + 不给 BGM = 全片无声**——这是策略的直接推论（环境声丢了、又没有替代音轨）。三种处理：
   - (a) **允许 + 结果里明确警告**「本次多镜合成未提供 BGM，成片将无声」（我倾向这条，不硬拦）
   - (b) 直接报错「多分镜合成必须提供 BGM」
   - (c) 多镜无 BGM 时保留环境声（等于给规则开例外，不推荐）

② **单镜混音里 BGM 音量取值** `0.35` 是估值。可先按 0.35 落地，验收时用 `volumedetect` 比对两版（0.35 / 0.5）再定；也可以直接给个你要的听感偏好。
