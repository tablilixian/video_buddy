### 2.1 主进程启动编排

| 文件 | 功能 |
| --- | --- |
| `src/main.ts` | 启动总装配：单实例锁 → 日志/崩溃取证 → shell 环境回收 → profile 选择与组合 → boot() 挂载 Host → 渲染层健康门 → 失败路由到恢复窗口。 |
| `src/bin.ts` | npm 启动器：解析 `--export-diagnostics/--help/--version`，否则 spawn Electron。 |
| `src/desktop-cli.ts` | `ELECTRON_RUN_AS_NODE` 私有引导，把 Electron 可执行变成打包 dsh CLI。 |
| `src/electron-runtime.ts` | `DesktopRuntime` 的 Electron 实现：窗口代际管理、托盘、更新下载/安装器执行、诊断导出、重启协调。 |
| `src/startup-generation.ts` / `shutdown.ts` / `startup-failure-routing.ts` | 代际资源所有权；5 秒有界升级式关停；失败走 stderr 还是恢复窗口的二值路由。 |
| `src/shell-environment.ts` | 打包 Unix 启动时用登录 shell 捕获白名单环境变量（nonce 标记、超时、进程组清理）。 |
| `src/desktop-runtime-environment.ts` | 生成 pnpm/dsh 命令 shim 目录并安装进程内 PATH（可逆 dispose）。 |
| `src/desktop-installation-id.ts` | userData 内持久化伪匿名 UUID v4（更新检查头用）。 |
| `src/crash-evidence.ts` / `lifecycle-events.ts` / `desktop-logger.ts` | 活跃 run 标记（不干净退出检测）、启动阶段 JSONL 证据、stderr+文件双写日志器。 |

### 2.2 Profile 生命周期

| 文件 | 功能 |
| --- | --- |
| `src/profile.ts` | 核心组合器：读 profile manifest、reconcile pnpm workspace、物化 launcher 私有 layer 并校验组合无漂移。 |
| `src/profile-manager.ts` | profile 发现/创建（staging+原子 rename）/删除/选择状态（0600/0700，symlink 拒绝）；全局名字闸门。 |
| `src/profile-service.ts` | Cordis `desktopProfiles` 服务：串行化 select（persist→restart 顺序，committed 目标不可被并发覆盖）。 |
| `src/profiles.ts` | 托盘上的 profile 切换菜单。 |
| `src/profile-materializer.ts` | 恢复/迁移后用打包 pnpm 重建依赖（frozen lockfile），带超时、输出上限、进程组终止。 |
| `src/profile-checkpoint.ts` | 三槽健康快照（7 文件 sha256+mode 校验），restore 写 skip-marker 防健康启动覆盖恢复点。 |
| `src/startup-recovery-controller.ts` / `startup-recovery-window.ts` / `recovery-plugin-uninstall.ts` | 预 Host 恢复面板两阶段操作（preview→execute，一次性 previewId、TTL、generation 校验）与插件卸载封装。 |
| `src/desktop-plugins.ts` | bundle 禁用/启用状态机（文件锁 + 严格 state v1 校验），recovery 与 Host 共用。 |
| `src/desktop-market.ts` | 机器级 Market provider 选择（disabled/community-market/dsh-market，fail-safe 读）。 |
| `src/session-projcache-recovery.ts` | >128MB 的 session_projcache.json 隔离改名。 |

### 2.3 更新体系

| 文件 | 功能 |
| --- | --- |
| `src/update-checker.ts` | 固定端点严格 SemVer 版本检查（`redirect:'error'`、4KB 上限）。 |

| `src/update-lifecycle.ts` | 代际内轮询/手动检查/确认下载状态机（托盘标签联动、AbortController）。 |
| `src/updates.ts` | Cordis 行：注册轮询策略 + `/desktop/updates/check` 路由。 |

### 2.4 终端与子进程

| 文件 | 功能 |

### 2.5 网络与 webserver

| `src/desktop-actions.ts` | 窄面 `desktopActions`（openTerminal/requestRestart）供可信 Host 插件。 |

## 三、dsh-community-market（插件市场壳）

| 文件/目录 | 功能 |
| --- | --- |
| `src/index.ts` | **完整 Cordos 插件入口**（name/inject/apply/Config）：装配路由与设置，可选注入 desktopActions/desktopPlugins/desktopProfiles+desktopPnpm 装出安装服务；编译期白名单 `registry.npmjs.org` 为合成代理主机名。 |
| `src/host/routes.ts` | 市场 HTTP 面：目录浏览、来源管理、安装预览/执行、重启授权。全部 mutation 走 loopback BlockList + `mutationAllowed` 同源校验，响应带 `cross-origin-resource-policy: same-origin`。 |
| `src/catalog/service.ts` / `source-store.ts` | 目录服务与多来源快照存储。 |
| `src/adapters/dsh-marketplace.ts` / `dsh-1024store.ts` / `dshfind.ts` / `standard-http.ts` | 目录来源适配器（把第三方页面折叠成标准 CatalogSnapshot）。 |
| `src/install/service.ts` | 安装域核心：候选表 + 5min 意图令牌（32 字节随机、TTL、单飞互斥、profile 钉定）；安装 = `pnpm add <pkg>@<exact>`，前置 npm registry 身份校验（name 匹配 + 稳定精确版本 + DSH bundle 声明 + 产品包黑名单）；profile package.json 临时文件+rename 原子改。 |
| `src/install/github.ts` | GitHub 来源校验器：owner/repo/commit(40hex) 白名单、raw.githubusercontent.com 钉源取 package.json、拒绝重定向改路径、subdirectory 契约校验（无 dot/parent 段）。 |
| `src/install/manual.ts` | 无可验证安装目标时的手动安装指引生成。 |
| `src/network/restricted-http.ts` | 受限 HTTP 客户端：HTTPS-only + 443 强制、DNS 解析钉地址（防重绑定）、IPv4/IPv6 全网段 BlockList、≤3 跳重定向且按跳复验 allowedOrigin、JSON content-type 校验、2MB 体量上限、连接/首字节/总超时三段；其上叠 URL 级 TTL 缓存与并发合页。 |
| `src/media/*` | 目录图片代理：受限图抓取、尺寸归一、引用计数。 |
| `src/contracts/*` | 生成的 catalog schema（ajv）+ 身份归一化 + 校验层。 |
| `src/client/*` | MarketLauncher/MarketOverlay/MarketSettingsTab 客户端 UI 与本地状态。 |

## 四、dsh-web-search-hybrid / dsh-web-search-tinyfish（搜索工具插件）

| 文件 | 功能 |
| --- | --- |
| `hybrid/src/index.ts` | 插件入口：注册 id=`hybrid` 的 search + fetch 两个 Provider 到 `ctx.web`。 |
| `hybrid/src/provider.ts` | 双通道调度：有 TinyFish key 委派 TinyFish，无 key（或有键失败非取消）回退免键引擎链（Bing zh-CN → DDG lite → DDG html）；免键抓取为上游 web-fetch-http 紧凑移植（http(s)、同源重定向 ≤4 跳、30s 超时、5MB 截断、charset 解码）——**无 SSRF/私网防护（CR-52）**。 |
| `tinyfish/src/index.ts` / `provider.ts` | TinyFish 免费档搜索/抓取 Provider：单 `X-API-Key`，401/429/Retry-After 错误分类；key 每次调用时解析（改设置即生效）。 |

## 七、deepseek-harness（上游，不在审查范围）

固定 Git 子模块（pnpm workspace 自治）。桌面行为只允许通过 `desktop-*` 插件面与 profile 组合扩展，兼容模式必须跑上游默认客户端。本仓对上游的全部本地适配以 `patches/` 与 `dsh-plugin-desktop` 承载，未发现越界直改。
