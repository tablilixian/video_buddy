# 分册：画面内排印（minimalist-product-ad-generator）

> 何时读：写终版文案、画终版文案锚点照、在节拍表里写文字列、写视频提示词里的文字行为时。

## 1. 文案规则

- 画面内广告文案必须是英文。用户给中文就本地化成简洁英文。
- 可见文案 3-5 个英文词，含空格最好不超过 32 个英文字符；不要写成孤立的 1-2 词功能标签。
- 文案要有苹果产品片的感觉：感官、收益驱动、材质驱动，或轻价值主张；避免促销口号与电商功能标签式措辞。
- 字体参考 SF Pro Display / SF Pro Text，提示词里优先写 `SF Pro Display Semibold`。
- 一个镜头最多两种文字颜色。
- 白科技风里前半段文字必须黑或深灰，禁止白底白字；暗轮廓光风里前半段可用白。
- **后半段永远是具体产品色。**
- 文字必须保持单行：不换行、不堆叠、不拆成多行。
- 任何一个时刻画面里只允许一行英文文案：不出现两行文字、双行标题、标题+副标题组合或多个文字块并存。两段式排印必须在同一行内延续或替换，绝不拆成上下两行。
- 文字不要放在字幕位（下方）。优先用垂直居中的视觉区，作为构图的左对齐或右对齐部分；字号略大，要像产品片的视觉元素而不是解释性字幕。

## 2. 文字必须作为画面运动出现，不是字幕兜底

- 文案锚点照里的文字只是字体、位置、单行版式、两段式配色的**参考**，不意味着整片只能用这一行。
- 节拍分镜表可以在不同镜头里定义多行短英文文案，每行 3-5 词、单行、可读，并遵守两段式配色规则；不要用孤立 1-2 词功能标签。
- 视频生成必须把分镜里的文案放进画面里。
- 文案不必每个镜头都出现。若视频模型容易把文字做错，主动降低出现频率：10s 片通常只保留片中一次 + 终版一次文案，不要每个镜头都上字。终版镜头必须包含一条稳定的单行文案。
- 默认让视频模型直接生成画内排印及其时序，**不要**悄悄降级成后期字幕、也不要留空位等后期叠加。仅当用户明确要求，或画内排印失败且用户接受兜底时，才使用后期兜底。

## 3. 已认可的片中段样式

干净留白 + 产品动作或产品特写主导画面 + 画面不拥挤 + 只有一行单行英文文案。文字可以贴着产品边缘、产品表面或特写高光区，让人觉得文字融进产品图而不是浮在上面像字幕。不要为了加文案破坏留白或再加第二个文字块。

## 4. 两段式文字动效

- 默认两段式文字动效必须可见：前半先淡入或轻微滑入，后半稍后淡入或轻微滑入。
- 后半出现时，前半在同一行内轻微让位。
- 让位幅度要克制，约 10-15px 或文字宽度的 8-12%。动效平滑克制；避免弹跳、霓虹、花哨 UI 效果。
- **不要**为了避免两行文字而把排印做成完全静止。正确解法是同行两段式入场、轻微让位、淡入或轻滑入；错误解法是上下拆行、双行标题，或干脆去掉文字动效。

## 5. 终版文案锚点照的排印

- 必须包含已确定的文案，**禁止用占位文案**。
- 文字保持单行。
- 字体 SF Pro Display Semibold。
- 文字颜色必须明确拆成两段：文案前半用黑或白，后半用具体产品主色。主色是紫色时，写"前半黑/白、后半紫色"，不要只写"产品色 + 黑或白"。
- 这张锚点照里可以有且只有这一行参考文案，不出现其他文字；但后续视频里的文案由节拍分镜表控制，可以有多行短英文文案。
