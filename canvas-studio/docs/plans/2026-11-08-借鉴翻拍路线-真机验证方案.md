## 0. 要验证的那句话

先把目的写成一句**可证伪**的话：

> 自由发挥时，模型一次会话里要同时决定四件事 —— **结构骨架 / 画面风格 / 叙事手法 / 什么算做对了**。四项全开放，且判据是模型自己现编的，所以只能靠成片后的反复 `read_image` 与重渲去收敛 ⇒ **品质方差大、耗时长**。
> 借鉴+翻拍把其中三项（风格、手法、判据）**外部锚定成常量**，模型只剩「把新内容映射进已验证骨架」一项 ⇒ 首次命中率上升、返工下降、方差收窄。

**证伪条件（写在前面，防止自我说服）**：若带锚包的一组在「通过率均值 / 通过率极差 / 到首版成片耗时 / 返工次数」四项上**没有一致方向的改善**，这条路线就算不成立，不投入产品化。四项只要有两项反向，也不算通过。

**现成的自由发挥基线**（`docs/plans/四季片失败会话复盘-20261107.md`，会话 `5b6dcfc6`）：

| 项 | 实测 |
|---|---|
| 会话时长 | **48.6 分钟**（11:14:52 → 12:03:27） |
| 步数 / 工具调用 | 120 步 / 135 次 |
| `render_composition` | **10 次**（探针 3 / 超时 2 / 全片 4 / 被拒 1） |
| `read_image` | **18 次** |
| 探针额度 | 3 次里 **2 次花在环境诊断**，留给内容验证只剩 1 次 |
| 结果 | 用户标「失败了」，D-01~D-09 九条缺陷 |

> ⚠️ 这行数据**含 RenderHost 全程不可用**（R-03，10 次渲染全回退画布页，每次 140–170s）。它是「放开思路跑」的真实代价，但**不能当纯净基线**直接比耗时 —— 见 §3.0 环境自检。

## 1. 先把「手法库」这个词还准

### 1.1 三层东西，上一稿我混着叫了

| 层 | 回答什么 | 形态 | 本蓝本的例子 |
|---|---|---|---|
| **类型表** | 这片**结构由什么决定** | 分类口径，不是模板 | 输入是「一组知识点」⇒ 概念递进，切点跟概念不跟句子 |
| **风格圣经** | 整片**长什么样、什么算做对** | 色值 / 字体角色 / 运动转场规则 / 负面清单 / 实现依赖 | `#1e1137` 满屏单色、无卡片容器、N1–N7 |
| **手法库** | 遇到**某个具体叙事难题，用哪一招解** | 卡片，每条写「做什么 / 适合 / **不适合** / 出自哪片」 | 尺度阶梯、朴素方案逐级失败、数值脊柱 |

上一稿结尾说「当手法库借，别当模板照搬」，并列了四条 —— 其中「数值脊柱」其实是**结构层**，其余才是手法层。**这个含混是我造成的，你的追问是对的。**

### 1.2 它是不是「交给大模型、告诉它用什么方式拍视频」？

**不是，至少不直接是。** 精确说法有三条：

1. **手法库不产出视频，也不决定整体拍法。** 整体拍法由类型表 + 风格圣经给。手法库管的是**局部招式**：「现在要讲跨量级对比」→ 有一张现成卡说「用尺度阶梯，别写成文字罗列」，并且**同时说「题目里没有可量化对象时别用」**。
2. **它交给模型的方式是「上下文文本」，不是程序、不是工具、不是 API。** 模型读它，然后在编排 manifest 时遵守它。没有任何一行代码会去查这个库。
3. **给法有三种，效果不同**：
   - **当菜单**（最有用）：从全表里**只挑 3 张**给模型，让它组合 —— 把 49 条全塞进上下文等于没给，还挤占注意力。
   - **当约束**：负面清单，「这几条不许用」「做不到就换 §6 的画法」，防翻车靠这个。
   - **当判尺**：交片时逐条 0/1 自评，**判据不再由模型现编**。

> 作者原话「手法库的价值在『不适合』那一栏」，说的就是第 2、3 种给法。只有「做法」一栏的手法库会被无差别套用。
>
> 顺带一个对账：项目里 `motion-patterns.md` / `shot-cards.md` **已经是手法库雏形**，但它们写的是「**我们支持什么效果**」（能力清单），缺的正是「**这支片在什么处境用了这招、什么时候别用**」那一栏。所以这不是要新建一套库，是**换一种写法**。

### 1.3 真正要交给大模型的是「锚包」，手法库只是其中一节

**锚包** = 风格圣经 + 3 张手法卡 + 负面清单 + 实现依赖（做不到→换什么画法）+ 代表帧拼版。

实物已备好：[`../demos/2026-11-08-蓝本锚包-究竟什么是光.md`](../demos/2026-11-08-蓝本锚包-究竟什么是光.md)（≤1 屏文本 + 3 张图）。

> **这份东西是纯 Markdown + 图片**，直接粘进真机会话第一句就能用。**不进代码库也行、不用 push 到运行时 checkout、不用发版、不改 skill 文件**。实验全程零工程改动 —— 这一点本身就是「耗时能不能降下来」的第一道检验。

## 3. 实验设计（两阶段，每阶段可单独停）

### 3.0 前置 · 5 分钟环境自检（**不做就别开跑**）

R-03 的教训：上次 10 次渲染全回退画布页，48.6 分钟里一大截是在跟执行器搏斗，探针额度还被诊断吃掉 2 次。**若这次再发生，测到的耗时差是环境差，不是路线差。**

跑一条 3 秒空片，确认：① RenderHost 是否接管（`__csRenderHost` 有值）；② 单帧渲染是否在预期时间内返回；③ 是否发生回退。
**三条任一不满足，先修环境再开跑**；实验结果表里必须记「本次是否回退」。

### 3.1 阶段 A · 走得通（**1 跑**）

| 项 | 内容 |
|---|---|
| 唯一动作 | 新会话第一句 = 锚包全文 + 一句题目；**其余什么都不改、不追加指令、不中途纠偏** |
| 题目 | 建议《光的波长》45s（与蓝本同构，映射阻力最小，专测「路线能不能通」） |
| 可直接用的起点 | [`../demos/2026-11-08-参考片拆解-究竟什么是光-Kurzgesagt.md`](../demos/2026-11-08-参考片拆解-究竟什么是光-Kurzgesagt.md) §5 的 45s manifest 骨架，字段已核过源码，**零改动可渲** |
| 判据 | ① 出片了没有；② N1–N7 通过率；③ 人眼一句「像不像 Kurzgesagt」 |
| **停止条件** | 出不了片，或 N1–N7 通过 < 4/7 → **先修锚包，再跑 1 次；仍不过就停，不进阶段 B** |

> 阶段 A 的真实作用不只是「走得通」，也是**校准锚包**：如果锚包本身写得含糊，阶段 B 测的是锚包质量而不是路线价值。

### 3.2 阶段 B · 更稳、更好、更快（**3 v 3**）

**必须 ≥3 次重复。** 你来的原因就是「品质不稳定」—— 跑一次只能测「好不好」，**测不出「稳不稳」**。

| 组 | 第一句 | 次数 |
|---|---|---|
| **G0 自由发挥** | 只有题目 + 规格，不给锚包、**不给任何风格描述** | 3 |
| **G1 借鉴+翻拍** | 题目 + 规格 + 锚包全文 + 3 张图 | 3 |

**顺序交替**（`G0 → G1 → G1 → G0 → G1 → G0`），每次**开全新会话**，避免上一跑的经验泄漏到下一跑。

题目二选一（见 §6 待拍板）：
- **推荐：四季片同题**（《为什么地球公转产生四季》45s）。理由：这正是「放开思路跑不稳」的原始现场，A/B 两版验收基准与 D-01~D-09 缺陷清单现成可当判尺，且是**跨题材迁移**，比同构题更能证明「借鉴」有泛化价值。
- 备选：《光的波长》同题重跑，映射最干净，但容易被质疑「只是抄得像」。

### 3.3 唯一变量与固定项

- **唯一变量**：第一句里有没有锚包。
- **固定**：题目、45s / 16:9 / 30fps、中文 TTS、同一模型、同一渲染器与画质档、同一超时设置、同一操作者、同一判尺、同一验收流程。
- **不固定但必须记录**：是否发生渲染回退、是否触发重试。

### 3.4 指标（每一项直接对上你的痛点）

| 你的痛点 | 指标 | 怎么采 |
|---|---|---|
| **品质不稳定** | 同组 3 次 N1–N7 通过率的**极差**；缺陷数极差 | 判分表逐条 0/1 |
| **品质不够好** | 通过率**均值**；人眼盲评（6 支打乱顺序、隐藏组别，按「像不像一支正经片子」1–5 分） | 盲评表 |
| **耗时特别长** | **到首版成片**的墙钟；总会话时长 | 会话起止时间 |
| **返工多** | `render_composition` 次数、`read_image` 次数、返工轮数、工具调用总数 | 会话转录 |

> 「到首版成片」比「总时长」更关键：自由发挥的耗时主要花在**反复看图再改**，锚包理论上压缩的正是这一段。

**额外两组判尺**（四季片题目时）：
- 「做对没」= 四季片 A 版既有判据（功能性）；
- 「像不像 / 散不散」= 锚包 N1–N7（风格性）。
两者分开记，**别用风格判据掩盖功能缺陷**（上一稿已踩过的归因陷阱）。

### 3.6 四个会让结论作废的坑（提前挡掉）

1. **执行器污染** → §3.0 自检 + 记录回退；发生回退的跑次单独标注，不与正常跑次混算耗时。
2. **学习效应** → 交替顺序 + 每次全新会话；G0 与 G1 用**同一份题目文本**，别给 G1 多写一句提示。
3. **锚包质量成了混杂变量** → 阶段 A 先校准，且阶段 B 全程**用同一份锚包，不中途改**。
4. **样本量** → 3 v 3 只够看**趋势**，不等于统计显著。够不够据此拍板由你定；要看硬结论就加到 5 v 5，但成本翻倍。

## 4. 临时豁免（**是提示词里的一句话，不是代码改动**）

在第一句末尾附一段，仅本次实验生效：

```
本次为路线验证实验，临时豁免以下既有纪律（不要修改任何 skill / 代码 / 配置）：
- 允许无逐句字幕条（文字只当画面标签与满屏重音用）；
- 允许纯色慢段落，体检若报「静态图文 / 裸画面」请忽略该告警；
- 不设 M1 20 分钟硬线，按真实节奏完成；
- spotFrames 取帧不限额度，需拿足像素证据；
- 任何「做不到」的效果，按锚包 §6 直接换画法，不要改渲染器、不要申请加字段。
```

> **关键**：豁免写在提示词里就够了。**不改 skill 文件、不关 lint、不动渲染器**。这样实验结束不会留下一堆需要回滚的工程改动 —— 结论若为否，成本只是一天会话。

## 5. 明确不做

1. 不写代码、不改 `Shape.tsx` / manifest 契约 / skill 文件、不发版、不 push 运行时 checkout。
2. 不建 GUI 选片台、不建手法库索引、不改 teardown-store、不接意图卡、不接 Q-C4。
3. 不重新拆更多外部参考片 —— **本轮只用这一支**，一支就够验路线。
4. 不把文章的类型表 / 12 类型搬进来替换六体裁。
5. 不在实验期间讨论产品化；产品化的前提是 §0 的证伪条件没被触发。
