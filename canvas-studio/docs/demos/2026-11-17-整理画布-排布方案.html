整理画布 · 点击后的排布 canvas-studio 方案原型

只讲「整理画布」这一个按钮的效果：节点怎么分列、连线往哪走、孤立节点落在哪。 数据取自真实项目「生成一段苹果手机广告」——24 个节点、32 条血缘边，节点尺寸按比例归一化，位置规则与真实一致。

三条规则

① 列 = 推进段，X 单向递增 输入 → 剧本·定稿 → 分镜 → 每镜产物 → 后期 → 成片，六段固定 X。主链边只连相邻列，所以箭头在结构上不可能右→左。
② 行 = 镜号，一镜一带 分镜卡与它的产物同 Y，外面套一个虚线框。横向读完一行 = 看完一镜；纵向扫下来 = 全片进度。
③ 孤立节点单独一条带 画布最底「待归档」，不进任何生产列（否则会被读成某个阶段）。三类原因分列，每条给处置动作。
