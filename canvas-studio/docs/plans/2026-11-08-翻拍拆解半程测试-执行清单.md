## 1. 执行步骤（提示词，放手跑）

```
用复刻流程拆解一支参考片（只拆解，不制作）：
1. 下载 https://www.bilibili.com/video/BV1Pt41167vp/ 的 p=15《究竟什么是光》
   （4 分 39 秒）到本项目，media_probe 校验产物（时长 279s±3s、分辨率、可解码）。
2. 对成片做结构取证：抽帧采样（覆盖全部段落切点，≤12 张）+ 逐段 video2vl 理解内容。
   画面结论以抽帧像素与切点检测为准，video2vl 文字转述只作辅助（A3 同款口径）。
3. 生成拆解表：段落切点（自适应切点检测）、每段时长与占比、讲解手法
   （类比/比喻/递进提问逐段标注）、旁白-画面对位关系。
4. teardown-verify 回核：切点实测 vs 拆解表边界，误差逐条列出。
5. 结构映射表：拆解表 → 我们表现域的对应元素建议（gauge/chart/textCard/shape/...），
   每段标注「借什么层」（结构骨架 / 节奏 / 手法），画风差异显式声明（角色动画不在表现域）。
6. 交付拆解报告：拆解表 + 回核结果 + 映射表 + 未决项。
```
