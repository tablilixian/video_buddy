# 短剧体裁编排（drama-format-director）

**定位**：L2 编排壳。上游是 `canvas-studio-creation` 总纲——需求澄清、审批语义、工具契约一律归总纲；下游一条主链路 + 题材叠加层：

- `drama-episode-executor`（通用短剧单集执行手册：episodic 流程纪律 + 集结构 / 节拍 / 角色预算）
- 题材特化导演**叠加**其上（如 `bible-story-director`——命中题材时二者同读，不互替）

本 skill 只做**定向与调度**——系列建档与集间定位是本壳的核心输出；单集怎么拍见 executor 手册。

## 1. 定向三问（对齐 Direction 阶段）

1. **题材与基调**：古装 / 现代 / 悬疑 / 温情？命中题材特化导演则显式声明叠加（本壳只路由，不复述题材纪律）。
2. **单集规格与集数规划**：单集时长（1.5–3 分钟）+ 预计集数（决定系列建档与每集信息量预算）。
3. **追看定位**：悬念强度（每集收尾断多狠）、角色阵容规模（常驻 ≤4）——一句话说出「观众为什么追下一集」。

问完即在回复中复述定向结论（题材 / 规格 / 追看定位）再开工。

## 2. 链路路由表

| 需求特征 | 链路 | 判据 |
|---|---|---|
| 连续剧式短剧（≥2 集追看） | `drama-episode-executor` + `series_manage` 建档 | 有集间连贯诉求；每集按手册流程走（brief → 创作 → 登记） |
| 单集独立小品（无集间连贯） | 总纲标准视频链（不建系列） | 「就拍一条」——不硬套 episodic 纪律 |
| 题材命中特化导演 | 上行链路 + 题材导演叠加 | 题材导演存在（如 bible-story-director）时二者同读 |

**降级路径**：单集试拍（观众没追看诉求）→ 退单集独立小品；系列规模 >9 集先只建前 3 集的档（recap 会改变后续走向，提前建满全是猜测）。

## 3. 系列建档与集间定位（本壳核心输出）

- **开工即建档**：`series_manage action=create` 建系列；每集开工 `episode_brief`、收尾 `upsert_episode` 登记 recap（流程细则唯一权威 = drama-episode-executor §0，本壳不复述）。
- **集间连贯判据**：角色 `lib:` 句柄跨集引用（禁文字重描述长相）；上集悬念下一集开头回收。
- **悬念收尾约束**：每集最后 10% 落在动作 / 信息断点上——这是「连续追看定位」的硬判据，验收时逐集核对。

## 4. executor 指派与交付要求

选定链路后**显式声明**走 `drama-episode-executor`（+ 题材导演），再加载对应 skill 开工。

- **验收清单**（4 条，逐集核对）：
  1. 前 3 秒钩子成立；上集悬念一句台词内回收
  2. 收尾悬念成立（断点在动作 / 信息上）
  3. 角色跨集一致（`lib:` 句柄可查，画面与定妆照对得上）
  4. 连续两集连看不迷路（前情 recap 已注入；recap 与成片内容对得上）

## 5. 不做清单

- **不复述单集执行细则**：集结构 / 节拍密度 / 角色预算唯一权威 = `drama-episode-executor`，本壳只给一句话指针。
- **不复述题材纪律**：题材特化唯一权威 = 对应导演 skill；本壳只判「命中与否」。
- **不替代总纲的审批语义**：覆盖层「确认落地」等门禁原样归 `canvas-studio-creation`，本壳不设门也不放行。
