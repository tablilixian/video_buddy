3. **用户拍板四项**：① 自动取代只认「输入指纹相同」（保守：无参考图/分镜卡锚点时拒绝判重）；② 补 `list_shots` 工具 + 视频工具 `replaces` 参数双通道；③ 失效节点**灰显 + 虚线框 + 角标，原位保留**（不折叠不隐藏）；④ 重新合成后旧成片**自动失效但保留在画布上**供对比。
4. **实现**：新增 `src/shot-versions.ts` 纯函数层（`shotStatusOf`/`isActiveShot`/`shotFingerprintOf`/`planSupersede`/`applySupersede`/`latestActiveOf`/`toggleRetire`）；节点加 `shotVersion`/`supersededBy`/`supersedes`/`retired`；`defaultComposeClips` 只收有效片段；`compose_video` 返回「纳入 N 段、跳过 M 段」+ 成片节点 id；成片进版本链；UI 灰显 + 版本角标 + 右键作废/恢复（恢复旧版时接管者自动作废）。

## 六、教训备忘（避免重蹈）

- Bash 命令一律加 `cd <绝对路径> &&` 前缀（cwd 会被重置到仓库根）。
- macOS BSD grep 交替语法用 `grep -E`，不支持 `\|`。
- 修改画布节点用节点标题/URL 字段，**不要用 `mv` 改磁盘文件名**（会导致节点 404）。
