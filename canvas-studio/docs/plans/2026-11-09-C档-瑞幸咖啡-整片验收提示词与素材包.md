```
用品牌宣传体裁做一条 20 秒、16:9 的 luckin coffee（瑞幸咖啡）品牌短片，中文配音与中文画面文案。

【定向三问 · 已给全，不要反问】
素材现实：附件 4 张官方素材（字标 logo / 蓝杯与咖啡豆 / 门店鹿标 / 咖啡师制作），
均取自官方站 web.luckincdn.com，溯源记为「用户提供 · 官方来源」，身份资产齐备。
投放场景：官网 + 社媒信息流。时长画幅语言：20s / 16:9 / 中文。
开工前先显式声明本片走 brand-promo-video-generator（素材足的完整链），并复述这三项，然后再动手。

【品牌事实表 · 唯一权威】
品牌名 luckin coffee（瑞幸咖啡）；鹿头图形 + 小写英文字标；主色深蓝 #212370 与白，辅助咖啡棕；
可见资产＝附件中的蓝杯、咖啡豆、门店、咖啡师制作。
除此之外的一切数据、销量、门店数、产品名、口号、CTA 均视为概念文案，不得当作官方事实；
未核源事实写进「未决项」复述，不进成片。
附件上的英文文案与奖项徽章只作视觉参考，不得照抄进成片，也不得当可引用数据（除非标注 dataSource=官网横幅）。

【身份资产红线】
logo / 字标 / 包装 / 门店 / 人物只用附件原件，绝不重画、近似绘制、拉伸或裁切重建，终版 logo 完整可读。
AI 生成素材一律不得含品牌标识、包装、门店或人物，并标注为概念化氛围素材，不冒充官方产品证据。

【三轨结合 · 显式授权】允许并要求生成「非身份类」素材，三轨必须同场：
① image_generate 出 1–2 张 16:9 氛围锚点图（手冲水流 / 咖啡液 / 蒸汽光影），
   画面禁任何文字与标识，prompt ≤500 字符、只写正向约束，一次一个串行调用；
② video_generate（首尾帧）或 video_composite 出 1 段 5 秒 H3 英雄镜头，
   只给需要真实运镜的段落，禁止为「消静态提示」逐镜生成；单次 ≤15s、后端单任务串行；
③ 排印、色彩状态、转场、CTA 走代码编排：scaffold_manifest → 内容表 → manifest-builder.mjs
   → render_composition，禁止手写 gen-*.mjs 绕过 official builder。
AI 素材经 video / image 轨进 manifest：id = 画布节点 id、src 同源、时长取 list_shots 真值，
禁外链、禁 @ref、禁产物名直接作下游入参；合成后严禁再调 video_generate / video_composite。
目标：AI 素材占 6–10 秒，其余为代码轨；成片不得是「图文卡片型（全片无视频片段）」。
付费生成若被审批闸拦下，立即明确告知需要放行，不要静默退化为纯代码轨。

【叙事与节拍】
前 3 秒钩子 → 2–5 个语义挂钩的色彩状态（瑞幸蓝 / 白 / 咖啡棕）→ 产品与制作佐证段
→ 结尾 3 秒明确 CTA；20s 共 6–8 个主节拍；转场由真实素材 / 几何驱动，不做假 HUD / 玻璃卡；片尾无裸画面。

【交付前】逐条对照 B1 编排壳路由 / B2 定向三问复述 / B3 真实性底线 / B4 叙事骨架与数据出处
/ B5 节拍与运动 / B6 时长画幅语言与终版 logo，说明结果；
并说明三轨各自实际用了哪些工具、AI 素材实际占多少秒、是否调用过手写生成器。

〈通用硬要求〉
要求：
① 首轮渲染就用 spotFrames 探针取代表帧，逐张 read_image 看成片像素后，对照判据表逐条打勾；
   inspect_image 的 grid/bbox 只用于定位疑点与精确数值，不得当「元素是否存在」的结论；
② 交付前复述未决项：体检告警逐条状态（lint[] 折叠时给计数 + 前 N 条 + 落盘路径）、
   未核源事实、模型自身能力边界；
③ 画面类结论禁拿 manifest 字段自证；图表数值必须单一基准、可溯源，pending 事实不得进成片；
④ 负例不跑（它是验收阶段可选的测试手段，不是交付流程的一环）。
```

> 与 v1 的三个关键差异：① 删掉 `〈粘贴通用硬要求〉` 占位符，四条原文直接贴全；② 明确「虚构品牌」→ 真实品牌 + 4 附件，消除「没有授权素材」自相矛盾；③ 把「不重绘」与「不生成」切开并给 AI 素材**秒数预算**（6–10s），堵住 v1 过度保守退成纯代码轨的那条路。

## 6. 已知风险（别当失败误判）

1. **权利**：网上取的官方素材严格说不是 B3 的「用户授权件」，仅内部能力测试；成片不得对外发布，素材不进仓库。
2. **明星肖像**：对照广告片含代言人镜头，人工看即可；不得作为生成素材、不得进附件、不得进成片。
3. **国际站素材**：附件为英文/新加坡门店，若模型写出「中国区门店数 / 生椰拿铁」等，属编造，按 B4 记红。
4. **AI 素材与实拍调色衔接**：项目里没有独立校验判据，只有分散口径；本场只记录，不据此判 B5 红。
5. **H3 串行耗时**：后端单任务串行、单次 ≤15s，20s 片可能明显变慢；不要与 v1 的 40.1min 直接比。
6. **对照片是 82s 创意片**，不是 15–30s 硬广；对照时只比「色彩状态 / 开场钩子 / 品牌露出 / 节拍密度」，不比总时长与叙事结构。
