## 三、★ 两条技术路线（决策核心，实测数据）

| 维度 | **路线 A：SSR**（`@remotion/renderer`） | **路线 B：CSR**（`@remotion/web-renderer`） |
|---|---|---|
| 状态 | ✅ S1–S4 **全绿** | ✅ S7–S8 **实测可用**（三项补验全过） |
| 渲染位置 | Node + **独立 headless-shell 进程** | **Electron 渲染进程**（自带 Chromium） |
| 浏览器 | 需 headless-shell → **+210MB**（zip 104MB；主二进制 187MB **不可裁**） | **+0** |
| 平台二进制 | `@remotion/compositor-*` **+42MB**（x64 25M + arm64 17M，通用包两份） | **+0**（依赖链**不含** `@remotion/renderer`） |
| webpack / 预构建 bundle | 需要 | **不需要**（"No bundling step"） |
| **性能实测** | ~**90 ms/帧** @1280×720 | **13 ms/帧** @1280×720（**快约 7 倍**）；30s 片 ≈**12s** |
| CSS 能力 | 完整（真截图） | **受限子集**：**`z-index` 不支持**（靠 DOM 顺序）、`object-position`/`writing-mode`/blend/inset 阴影不支持 |
| 编码 | ffmpeg + x264（**bitrate 可控**） | **OpenH264 软件编码**（bitrate 类参数可能不生效） |
| 字体 | 自托管 `@font-face` 可行 | ✅ **已验证 `loaded:true`** |
| 媒体组件 | 任意（推荐 `@remotion/media`） | **仅 `@remotion/media` 的 `<Video>/<Audio>`** |
| 输出 | 直接落盘 | blob/流 ⇒ **经 IPC 回写**；默认 `outputTarget` 是 `web-fs`（**需用户手势，不可用于后台渲染**） |
| 取消 | `makeCancelSignal()` 的 `CancelSignal` | **标准 `AbortSignal`** |
| 包体合计 | **≈ +250MB**（或三选一：zip 104MB / 首启下载 0MB） | **≈ +0** |

**建议：切 CSR（路线 B）** —— 收益叠加：省 250MB + 去掉 webpack/预构建/浏览器预置/字体预置 + **快 7 倍**。
**代价**：吸收 CSS 子集（**组件一律靠 DOM 顺序控层叠，不用 `z-index`**）+ 渲染占用渲染进程 + 需改造 §6/§7.3/§8/§12。

## 六、环境与纪律（血泪教训，别重复踩）

### 环境事实
- 开发机是 **Intel Mac**（`uname -m` = x86_64）⇒ 拿到 `compositor-darwin-**x64**`；**shared-memory capture 不启用**（需 Apple Silicon）；**M 系性能基线本机取不到**。
- **Electron 43.4.0 = Chromium 150.0.7871.224**（Node 24.18.1）；Remotion **4.0.535**；headless-shell 期望版本 **157.0.8080.0**。
- `ELECTRON_RUN_AS_NODE=1` **在本会话环境里会泄漏** ⇒ 起 Electron/读版本必须 `env -u ELECTRON_RUN_AS_NODE`（否则 `--version` 会打成 Node 版本）。

### agent 会话沙箱（工程可用，非产品问题）
- 跑 Remotion 脚本须 **`NODE_OPTIONS= node …`**（沙箱注入的 `node-language-shim.cjs` 会把「对已存在目录 mkdir」误判越权 → `bundle()` 报 `CODEBUDDY_BROKER_DENY`）。
- **`bundle({ outDir })` 必须显式给**（不给会自建 `/var/folders` 临时目录，撞同一道护栏）。
- 手动 spawn Chromium/Electron 须加 **`--no-sandbox`**（否则 `sandbox initialization failed` → GPU 进程死）；Electron 外壳另有 `CSR_NO_SANDBOX=1` 兜底开关。
- **`ps` 在沙箱内不可用** ⇒ 残留进程检查只能在用户终端做（脚本已做成"不可用则如实跳过"，勿改成断言）。
- macOS **没有 GNU `timeout`**（也无 `gtimeout`）⇒ 用脚本内超时（如 `S7_TIMEOUT_MS`/`S8_TIMEOUT_MS`）。
- **Electron 把目录当 app 启动必须有 `<dir>/package.json`（含 `main`）** —— 否则 `Unable to find Electron app … Cannot find module`。

### 工程纪律
- **no-git-commit until acceptance**：改完先自检，等用户验收后才提交；**说「提交并推送」才 push**（本批 `55f9fb8213` **未推送**）。

- git 拉取用 **fetch-then-ff-only**，不盲 pull。
- **用第三方新 API 前先读它的 `.d.ts` 签名** —— 这条纪律已两次救场（`canRenderMediaOnWeb` 的必填 `width/height`；`renderStillOnWeb` 用 `.blob({format})` 而非 `getBlob()`）。
- **别拿首次运行的性能数字当基线**：S7 的 72 ms/帧是**冷启**（含 WASM/编码器初始化），暖机后是 **13 ms/帧**。

## 八、关键 API 速记（避免再读源码）

**路线 A（SSR）**
- 三步链：`bundle({entryPoint, outDir})` → `selectComposition({serveUrl, id, inputProps})` → `renderMedia({composition /*对象*/, serveUrl, codec:'h264', inputProps, outputLocation, concurrency:1})`
- **`codec` 必填**；**`ffmpegExecutable`/`ffprobeExecutable` 在 v4 已移除且"静默忽略"**（传不存在的路径也照样出片 ⇒ 只能靠 code review 拦）
- 取消：`const {cancelSignal, cancel} = makeCancelSignal()`；中断抛 `renderMedia() got cancelled`，**不留残片**
- `staticFile()` 解析根 = **`<bundle>/public/`**（⇒ 注入落点 `<renderDir>/public/cs-assets/`；`publicDir` 只在 `bundle()` 时生效）
- **`<Composition calculateMetadata>`** 是动态时长/分辨率的唯一机制（漏写 = 成片时长静默不对）

**路线 B（CSR）**
- `renderMediaOnWeb({composition:{component,id,durationInFrames,fps,width,height,calculateMetadata}, inputProps, container, videoCodec})` → **`getBlob()`**
- `renderStillOnWeb({composition, frame})` → **`.blob({format:'png'|'jpeg'|'webp'})`**（不是 `getBlob()`）
- `getEncodableVideoCodecs(container, options?)` / `getEncodableAudioCodecs(container, options?)` —— **container 是位置参数**
- `canRenderMediaOnWeb({container?, videoCodec?, audioCodec?, width, height, …})` —— **不收 composition，width/height 必填**
- 取值域：`container` = `mp4/webm/mkv/mov/wav/mp3/aac/ogg/flac`；`videoCodec` = `h264/h265/vp8/vp9/av1`；`audioCodec` = `aac/opus/mp3/vorbis/pcm-s16/flac`
- 取消用**标准 `AbortSignal`**（与 SSR 的 `CancelSignal` 不同）
- 探针页面日志元素**必须挂 `documentElement`**（挂 `body` 会被 Remotion 的 bundle 清掉 ⇒ 白屏）

**canvas-studio 侧（两条路线都要）**
- 复用：`appendComposedVideoNode`（`compose.ts:628`）/ `ComposeResult`（`:63`）/ `urlToAssetPath`（`:118`）/ `buildAmixArgs`（`:281`）/ `probeMediaInfo`（`ffmpeg-run.ts:278`）/ `assertApprovalAllowed`（`host-tools.ts:718`）
