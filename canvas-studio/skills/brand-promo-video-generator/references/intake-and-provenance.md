# 分册：素材清单与溯源（brand-promo-video-generator）

> 何时读：清点用户素材、构建品牌事实表、写溯源清单、判断权利风险时。

## 1. 需要用户提供的元素

- Logo 文件或官方 logo 来源页。
- 字体文件、字体名、排印指引，或能清楚展示品牌排印的官网页面。
- 品牌色、色彩系统、风格指南，或能清楚展示官方颜色的页面。
- 产品图、界面截图、包装、渲染、素材或其他品牌影像。
- 产品信息：官方产品名、功能清单、发布重点、卖点、CTA、免责声明与目标受众。
- 公司/产品官网或官方素材包。

同时还要确认：目标时长（通常 15-30 秒；想要快节奏发布片推荐 15 秒）；画幅比例（16:9、9:16、1:1、4:3、3:4 或跟随参考图）；传播重点、分发渠道、旁白语言、画面内文案语言与可见文案需求。

身份承载资产无法认证时停下索要授权原件，不要生成貌似合理的替代品。

## 2. 品牌事实表提取项

1. 用户提供的原始导出件
2. 官方公司网站、静态包、新闻室、品牌门户、媒体包、新闻资料或官方仓库
3. 公司自有的媒体库
4. 授权图库或授权合作方素材包

提取：

- 确切的 logo 变体、安全空间与使用约束。
- 官方字体或可见的排印行为。
- 主色、辅色与动态品牌色。
- 品牌调性、原则、视觉母题与交互语言。
- 当前产品名、功能、场景、数据、口号、CTA 与免责声明。
- 官方摄影、渲染、界面截图、素材与媒体包内容。

不使用 logo 聚合站、搜索缩略图、粉丝复刻、Pinterest 转存或 AI 生成替代品作为身份承载来源。程序化图形只允许作为非具象运动层：遮罩、渐变、色场、网格、辉光、粒子、拖尾、排印、已验证数据的图表与转场几何。

## 3. 溯源清单字段

把每个身份承载资产记进一份可交付的紧凑清单（文本节点或表格）：

- 稳定资产 ID 与角色。
- 本地路径或画布节点引用（可用时）。
- 确切来源 URL 或用户提供来源备注。
- 来源类型（官网、媒体包、用户原始件、授权图库等）。
- 用于比对的验证目标。
- 权利或发布备注。
- 真实性状态：已验证 / 用户提供 / 已授权 / 已阻断。

清单本身不授予发布权。授权不清时把成片标注为非官方概念，并告知用户商业发布需要许可。

## 4. 风险信号

首次询问不要反复追问独立的权利/许可问题，除非出现具体风险信号：可见的第三方水印、明显抓取的电商图、用户表述自相矛盾、法律/医疗/金融合规声明，或用户要求商业发布。记录来源为"用户提供"，在来源摘要里给出权利提示，而不是卡住流程。
