# 科普 · 要点三卡（`science/three-cards`）

一句结论开场 → 三张要点卡 → 一句话落版。带四角括线与底部进度条（1C 装饰构件）。

| 项 | 值 |
|---|---|
| 画布 | 1920×1080 · 16:9 |
| 时长 | 1080 帧 @60fps = 18.0s（固定） |
| 卡片位 | 3（`itemCapacity`） |
| 素材 | 不需要 |
| 构件 | `cornerBrackets` + `progressBar`（40 刻度） |
| 音效 | 3 × `thud`（卡入场）+ 1 × `swoosh`（落版），全部**锚定到轨**而不是绝对帧 |

## 结构（时间轴）

| 轨 | 区间（帧） | 内容 |
|---|---|---|
| `hook` | 0–150 | 主标题（`title` variant，`maskReveal`） |
| `hook-lead` | 30–150 | 开场结论（`subtitle` variant，`fadeUp`） |
| `card1..3` | 150–430 / 430–710 / 710–990 | 每卡 `bullets` 两行：关键词 + 一句解释 |
| `ending` | 990–1080 | 落版一句话 |

## 槽位

见 `slots.json`（模型侧只能看到它）。**改文案不要改结构** —— 改了轨道数就不再是「换内容不动结构」。
