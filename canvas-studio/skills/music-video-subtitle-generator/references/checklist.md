# 分册：自检与交付（music-video-subtitle-generator）

## 1. 交付前静默自检

- [ ] 目标时长超过 15s 时，是否自动用了多镜拆解？
- [ ] 是否锁定了一条全局主音频，切点是否对齐节拍？
- [ ] 切点是否避开了唱词中断，口型与呼吸是否自然连续？
- [ ] 相邻镜头之间是否有清晰的拼接逻辑（尾/首帧续接、同方向运动、匹配切或节拍硬切）？
- [ ] 剪辑风格是否严格硬切，没有淡入淡出或柔转场？
- [ ] 角色/场景/排印三类卡是否职责隔离、没有串味？
- [ ] 排印是否是空间图层，且从不遮挡眼睛或主要面部表情？
- [ ] 全局画质、颗粒、色彩与光线是否一致？

## 2. 画布交付

完整 MV 提示词脚本锁定后，写入一个名为 `Complete MV Prompt` 或 `完整MV Prompt` 的画布文本节点。节点必须包含完整的多镜提示词脚本与拼接说明。后续修改更新同一个节点。

## 3. 多镜生成与拼接要点

1. **提示词锁定与画布写入**：确认完整的多镜提示词脚本（带时间戳、歌词映射、转场逻辑）已写入画布。
2. **逐镜生成**：按镜头表生成每个 2-5 秒镜头。续接镜头用上一镜的尾帧抽帧作为下一镜的 I2V 首帧。
3. **多轨剪辑与拼接**：导入全局主音频，按时间戳对齐所有镜头视频，在节拍网格上裁剪与变速，并用同方向运动或闪切遮罩检查接缝。
4. **收尾**：施加统一的 Movie LUT 与 35mm 胶片颗粒叠加，降低 AI 塑料感并锁定视觉一致性。
5. **交付**：输出无缝的完整 MV 视频文件。
