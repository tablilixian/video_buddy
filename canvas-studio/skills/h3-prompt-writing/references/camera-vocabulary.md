# 运镜词表

**只能用这 20 个运动类型。** 表外的说法（dolly zoom、crane、handheld、whip pan、
orbit、gimbal move…）一律不用，换成表内最接近的词。

| 运动类型 | 含义 |
|---|---|
| `Zoom In` / `Zoom Out` | 机身不动，焦距变化 |
| `Push In` / `Pull Out` | 摄影机整体前移 / 后移 |
| `Pan Left` / `Pan Right` | 机位不动，镜头水平转动 |
| `Truck Left` / `Truck Right` | 摄影机水平平移 |
| `Tilt Up` / `Tilt Down` | 机位不动，镜头垂直转动 |
| `Pedestal Up` / `Pedestal Down` | 摄影机整体升高 / 降低 |
| `Arc Shot` | 围绕主体弧线运动 |
| `Tracking Shot` | 跟随运动中的主体 |
| `Static Shot` | 机位与镜头都不动 |
| `Shake Slightly` / `Shake Strongly` | 轻微 / 强烈晃动 |
| `POV` | 主体视角 |
| `Roll Clockwise` / `Roll Counterclockwise` | 沿镜头轴顺 / 逆时针滚转 |

**Zoom 与 Push 的区别**：Zoom 是焦距变化（透视关系不变），Push 是机身移动（透视关系改变）。
"镜头推近"想表达空间进入感时用 `Push In`。

---

## 幅度与速度

| 维度 | 可用表达 |
|---|---|
| 幅度 | `with small amplitude` / `with large amplitude` |
| 速度 | `at slow speed` / `at fast speed` |

**中等幅度和正常速度省略不写。** 只在有意义时才加。

---

## 写法：运动类型 + 幅度 + 速度 + 指向对象

写成镜头内的**自然英文动作句**，不要在句尾堆标签。

✅ 正确：

```
The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.
The camera pans right with large amplitude at fast speed, revealing the open doorway.
The camera holds a static shot as the runner exits the frame.
```

❌ 错误：

```
A close-up of her hands. (Push In, small amplitude, slow speed)
Camera: push in slowly.
The camera does a dolly zoom on her face.
```

## 用量：官方用得很省

四组官方 IR 输出里的运镜词命中情况：

| 样本 | 时长 | 命中 |
|---|---|---|
| T2VA 太空 10s | 10s | Push In, Shake Strongly |
| I2VA 拉面 8s | 8s | Static Shot |
| Ref2VA 小羊 5s | 5s | Push In |
| T2VA 太空 5s | 5s | Push In, Shake Strongly |

**每份只有 1–2 处运镜。不要给每个镜头都配一个运镜。**
没有明确运动需求的镜头，要么写 `Static Shot`，要么根本不提镜头运动，
把字数花在画面内容上。

镜头只需要改变距离或轻微角度时，**用运镜，不要切镜头**。
