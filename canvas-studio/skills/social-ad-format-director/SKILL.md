# 社媒广告体裁编排（social-ad-format-director）

**定位**：L2 编排壳。上游是 `canvas-studio-creation` 总纲——需求澄清、审批语义、工具契约一律归总纲；下游三条链路：

- `code-driven-explainer`（图文卡点快剪：Remotion 卡片 + `analyze_beats` / `snap_cuts_to_beats` 卡点切换，零实拍素材）
- `viral-remake`（对标爆款复刻：拆解 → 草稿对照 → 换装裂变）
- 总纲标准视频链（H3 逐镜实拍感：有产品/人物素材、要实拍质感）

本 skill 只做**定向与路由**，选定链路后加载对应 executor 执行——手法与字段细则见其 SKILL.md 与 references/。

## 1. 定向三问（对齐 Direction 阶段）

开工前对齐三件事（`ask_user_choice`；放手跑模式改为自列假设；项目已有时长/画幅预设则沿用预设）。**可与 §2 的路由选择合并成一次提问**：

1. **平台与场景**：抖音 / B 站 / 小红书 / 视频号？投放位（信息流 / 主页 / 直播切片）？决定时长（15s / 30s / 60s）、画幅与钩子语态。
2. **前 3 秒钩子**：抓什么——冲突 / 悬念 / 利益点 / 反常识？（一句话说出来；说不出 = 还没想清楚，不开工）
3. **时长画幅与多版本**：单画幅还是 16:9 / 9:16 / 1:1 多画幅分发（阶段 2.1 起三档全支持；多版本 = 主版本定内容、变体改画幅重渲）？

问完即在回复中复述定向结论（平台 / 钩子 / 时长画幅）再开工。

## 2. 链路路由表

| 需求特征 | 链路 | 判据 |
|---|---|---|
| 图文快剪 / 卖点卡片 / 数据展示（零实拍素材） | `code-driven-explainer`（卡点链路：BGM 节拍 → 切点吸附） | 素材是图片 + 文案；节奏要卡点 |
| 用户给了对标爆款片 | `viral-remake`（拆解表 → 草稿 → 五项对照） | 「照这个感觉来」= 有参考片 |
| 产品 / 人物实拍感 | 总纲标准视频链（H3 逐镜）+ 本壳钩子纪律 | 有实拍素材或要写实质感 |

**降级路径**：实拍素材不齐 → 退图文卡点快剪；对标片风格元素不可复刻（见 viral-remake 边界）→ 拆解表取节奏与结构、素材重做。

## 3. 前 3 秒钩子纪律（本壳核心判据）

- 前 3 秒（90 帧 @30fps）内必须出现**钩子事件**：冲突台词 / 悬念画面 / 利益点字幕卡 / 反常识对比之一，**不是**空镜、logo 卡或标题卡干等。
- 钩子必须与卖点同源：钩子提出的问题，全片要给出答案；单条广告只讲**一件事**。
- 有 BGM 的快剪：切点走 `snap_cuts_to_beats` 吸附拍点（工具用法见 `toolchain.md`，本壳不复述）。

## 4. executor 指派与交付要求

选定链路后**显式声明**走哪条链路，再加载对应 skill 开工。

- **验收清单**（4 条，交付前逐条核对）：
  1. 前 3 秒有钩子事件（对照 §3 四形态之一，非空镜/logo 卡）
  2. 卡点切换落拍点（有 BGM 时；误差听感无违和）
  3. 多版本任务画幅齐全（16:9 / 9:16 / 1:1 按定向），内容一致、文字不溢出不裁切
  4. 单一信息点：一条广告只讲一件事，CTA 收尾明确

## 5. 不做清单

- **不复述节拍工具用法**：`analyze_beats` / `snap_cuts_to_beats` 参数与判据唯一权威 = `toolchain.md`，本壳只给一句话指针。
- **不复述复刻手法**：拆解表 / 转场近似 / 换装裂变唯一权威 = `viral-remake` 及其分册，本壳只做路由。
- **不替代总纲的审批语义**：覆盖层「确认落地」等门禁原样归 `canvas-studio-creation`，本壳不设门也不放行。
