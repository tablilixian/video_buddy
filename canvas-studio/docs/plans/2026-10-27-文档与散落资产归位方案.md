| 5 | `api-playground/` → `tools/` | 1 处 | `api-playground/README.md` 内相对命令 + `acceptance-test-cases.md:350` |

**每批独立 commit，全部用 `git mv`**（保留历史；二进制同样适用）。

**收尾断言**：
1. `git status` 无删除记录（只有 rename）；
2. 全库断链复查 = 4（与基线一致）；
3. `corepack yarn check` 全绿；
4. 仓库根 `git ls-files | grep -v /` 只剩工程与法律文件。

**回滚**：每批一个 commit，`git revert` 即可；媒体文件用 `git mv` 所以历史不受影响。
