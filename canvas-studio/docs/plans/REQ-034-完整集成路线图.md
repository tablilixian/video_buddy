## 三、完整集成四档（逐条）

### A 档 · 表达层补全（让 agent 能声明更多画面）

#### A1 · B2 语义 primitive（核心，价值最高）
- **目标**：把「公转 / 沿路径生长」变成 manifest 一等字段，agent 一行声明即表达关系类动画，而非像 CV-336/337 那样靠 `motion-helpers.mjs` 逐帧手算像素坐标内联成上百关键帧。
- **契约范围（2026-10-17 复核后收窄）**：只加 `orbit{center,radius,startAngle,period}` + `draw{path,growth}`。**`pulse` 不进契约** —— CV-336 修好多段关键帧后，`scale` 来回已是正常写法，再给一个一等字段会产生两条等价路径，skill 无从选择。`pulse` 落到 skill 范式（`references/motion-patterns.md` 给现成写法）。
- **⚠️ 隐含前置（2026-10-17 晚复核发现）**：`draw` 的载体 `shape:'path'` **在现有组件里不存在**（`Shape.tsx` 只有 circle/line/gradient/rect 四种 div 形状，零 SVG）。A1 必须连带补 `shape:'path'`（`useVideoConfig` 取宽高 + `pathLength` 做生长），细节见 [`REQ-034-二期开发文档-20261017.md`](./REQ-034-二期开发文档-20261017.md) §3.2。
- **落点**：`src/remotion/manifest.ts` 新增两字段 + 白名单；`src/remotion/timing.ts` 加纯函数 `orbitStateAt()` / `drawStateAt()`（**零 Remotion 依赖**，可 Host 算、可单测）；`src/remotion/components/*` 接线；`draw` 路径数学用 `@remotion/paths` 的 `evolvePath` / `getPointAtLength`（4.0.535 已实测导出）。
- **✅ 合成顺序（已定，2026-10-17 D-02）**：现有 `resolveAnimatedStyle`（`animated-style.ts:86-91`）里 `animate` 给出 x/y/scale/rotation/opacity，`fadeFrames` 与 `extraScale` 是**乘法**合并。已拍定规则：**① 位置来源三选一互斥（`orbit` 求 (x,y) ｜ `transform`/`animate` 声明值 ｜ 缺省 50/50）→ ② 非位置维度 `transform` 打底、`animate` 覆盖其声明过的维度 → ③ `scale`/`opacity` 类按乘法叠加**。
- **契约互斥**：轨道同时声明原语与 `animate` 的同一维度（如 `orbit` 与 `x`）时，`validateManifest` 应**报错而非静默择一**，错误信息指明冲突轨道；否则 agent 会写出「声明了但不生效」的 manifest。
- **依赖**：`@remotion/paths`（传递可解析，来自 devDep 链 —— **必须提升为直接依赖**，见 §七.1）。
- **验收**：构造含 `orbit` 的 manifest → 真渲染两帧像素有差；`remotion-timing.test.mjs` 扩 `orbitStateAt` / `drawStateAt` 纯函数断言 + **合成顺序断言**（原语与关键帧并存时结果唯一且可预期）。
- **优先级 P1** · 来源：原 B2（范围收窄见上）。

#### A2 · 效果栈（`glow`/`stroke`/`shadow`/`blur`/渐变遮罩）
- **目标**：组件可声明视觉效果，提升成片质感。
- **落点**：`src/remotion/manifest.ts` 加视觉效果枚举；`components/*` 接线（用 `@remotion/animation-utils` 或手写 CSS filter/`boxShadow`）。
- **⚠️ 字段名冲突（2026-10-17 晚复核发现）**：`effect` 已被 `TransitionTrack` 占用（`manifest.ts:187`，值域 `fade|slide|zoom|dissolve`）。本项字段名改用 **`fx`**，不重命名既有 `effect`（会破坏存量 manifest）。详见二期开发文档 D-11。
- **依赖**：无（**已定不装** `@remotion/animation-utils`，手写 CSS filter 约 40 行；少一个依赖少一处锁版风险）。
- **验收**：含 `fx` 的 manifest 渲染出对应视觉；单测校验枚举非法值报错；5 种效果各出一张静帧人看。
- **优先级 P2** · 来源：原 `createEffect` 评估项。

#### A3 · 形状库补全（arrow/triangle/star/polygon/…）
- **目标**：现 `Shape.tsx` 手绘 **circle / line / gradient / rect 共 4 种**；扩到常用几何（arrow / triangle / star / polygon 等）。
- **落点（✅ 已定方案②，2026-10-17 D-03）**：补装 `@remotion/shapes` 用于**新增**形状（arrow / triangle / star / polygon）；**老 4 种（circle / line / gradient / rect）保持手写不动** —— 换 div→svg 会让老 manifest 像素变，违反铁律⑤。`manifest.ts` 形状白名单从「组件层 case」上提为 `SHAPES` 集合并加校验（现无枚举，属隐患）。
- **依赖**：需 `@remotion/shapes`（**真缺失**，exact `4.0.535`）。
- **验收**：新形状渲染正确（真渲两帧验证）；`manifest.test.mjs` 扩白名单。
- **优先级 P2** · 来源：原 B4.2。

#### A4 · 转场库补全（wipe/clock/flip/…）
- **目标**：现转场 **fade / slide / zoom / dissolve 共 4 种**，由 `timing.ts:transitionOverride`（纯函数）算出 `opacity / translateXPercent / scale` 覆盖，再由通用壳 `TransitionShell`（`components/Transition.tsx:11`，**不是独立文件**）套用（路线 B 不用 z-index，层叠靠 DOM 顺序）。扩到 wipe / clock / flip 等。
- **落点（✅ 已定方案①，2026-10-17 D-03）**：扩展 `timing.ts:transitionOverride` 纯函数 —— 新增 `TransitionEffect` 枚举值（`wipeLeft`/`wipeRight`/`clock`/`flipX`）+ 算更多变换原语（`clipPath` 做 wipe、`rotateY` 做 flip）。**不装 `@remotion/transitions`**：它是 `TransitionSeries` 的 overlap 时间轴模型，与现有「单时间轴 + 相邻轨重叠窗口 + 纯函数 override」是两套架构，引入等于重写时间轴。
- **依赖**：无新依赖。
- **验收**：新转场渲染无闪帧（起/中/末三帧人看）；单测校验 `transitionOverride` 新分支边界值（t=0/0.5/1）。
- **优先级 P2** · 来源：原 B4.1。

## 四、KTV 专项（本周期暂缓 · 候补 B3）

**是什么**：字幕随配音逐词高亮（已读词变色/放大，未读暗色），即卡拉OK/抖音式高亮。技术本质是**词级时间戳**：渲染时按 `useCurrentFrame` 对比当前帧时间决定点亮哪个词。`@remotion/captions`（4.0.535 传递可解析，见 §〇 第三类）提供 `Caption` 组件 + `getCaptionsFromWhisperJson` / `getCaptionsFromSrt` 等解析器，把词级时间戳转成逐词高亮结构。

**瓶颈不在渲染，在「对齐数据源」**：当前 TTS 链路（Drama 后端）**不返回词级时间戳**，所以渲染侧就绪但无输入。获取途径：
1. **OpenAI Whisper API**（需 `OPENAI_API_KEY`）：音频发过去，开 `timestamp_granularities=["word"]` 拿 `whisper.json`（`words[].start/end`）。最直接。
2. **自托管 Whisper**（faster-whisper / whisper.cpp）：本机/内网跑，避外网 key，需部署 ASR 服务。
3. **其他 ASR**（Azure Speech、GLM 等）：只要返回词级时间戳，均可喂 `@remotion/captions`（支持 SRT/WebVTT/Whisper JSON）。

**性质**：独立于 TTS 的对齐步骤（TTS 出音频 → ASR 拿词时间戳 → 拼进 manifest 字幕轨）。**本周期状态**：用户 2026-10-17 确认暂无 ASR 源 ⇒ B3 **暂缓**，不占批次、保留为未来候选；§五批次表已移除 B3。待将来有 ASR 源（OpenAI key / 内网 ASR / 其他支持词级时间戳的 ASR）时，按 §四重新激活。

## 六、验证方式（沿用 REQ-034 四层验收法）

| 验收对象 | 手段 | 可信度 |
|---|---|---|
| 插值 / 采样纯函数（`orbitStateAt` / `drawStateAt` / 波形采样） | **`yarn test:smoke`**（禁裸 `node --test`，理由见 §七.5） | ✅ 强 |

| **旧 manifest 不回归**（新增） | 用既有样片 manifest 重渲，逐帧与基线一致 | ✅ 强（需 GUI） |
