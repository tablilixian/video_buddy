# 爆款复刻流程

适用：用户给一条参考视频，说「复刻」「拆解这条视频」「做个同款，产品换成 X」「照
这条批量出几版」。本质是把参考片的**结构**（节奏 / 镜头类型 / 转场 / 字幕形态 /
信息卡编排）映射成 `CompositionManifest`，素材与文案按用户要求替换——
**复刻结构，不复刻素材本身**。

编排定位：本文只做「拆解 → 映射 → 对照 → 批量」这一段；审批节奏与工具用法跟
`canvas-studio-creation` 总纲走，manifest 字段级契约的事实源是
`code-driven-explainer/references/manifest-contract.md`，本文不重复它们的参数细节。

## 0. 前置自检（三个都答上来再动手）

1. **参考片从哪来**：本地文件 → `upload_image` 落画布后抽帧看；是链接 → 让用户给
   文件或口述内容（不承诺能直接抓取远端视频，抓不到就按描述拆）。
2. **复刻深度**：默认 = **结构复刻**（节奏/镜头/转场对齐，画面用自己的素材重做）；
   逐镜像素级还原做不到（见 §6）。用户说「像它那样」就是结构复刻，别承诺更多。
3. **替换什么**：产品/品牌/文案哪些换、哪些保留？没有清单就 placeholder 先行 +
   逐项登记素材需求（generated / user / library 标来源），不要停下来等。

## 1. 拆解：产「爆款拆解表」

逐镜过参考片，产出**六列表**（模板与规则见 `references/remake-mapping.md` §1）：
**镜序 / 起–止秒 / 内容类型 / 元素与动效 / 转场入 / 字幕与文案落点**，外加一列素材需求。

- 用 `inspect_image` 读抽帧画面结构：0.5–1s 一帧起步，切镜密集再加密；转场类型看
  相邻两帧的变化形态。
- **同参考片已有拆解成果先读再拆**：会话/画布里已有本片的拆解便签或拆解表 → 核对
  后复用，禁止整表重拆——重拆不但烧时间，还会拆出与上一轮不一致的归段（甜品会话
  v2 实测教训：v1 拆对了的段落 v2 拆错）。
- **「元素与动效」列是本表的灵魂**（甜品复刻会话实测教训：只拆版式不拆运动，复刻
  会退化成静态卡轮播）：逐元素回答「**什么在动 / 怎么动（方向·幅度）/ 什么曲线
  （弹跳？渐入？）/ 和谁联动**（如：底部菜单切换 → 商品与标题背景同步换）」。
  版式只回答"长什么样"，动效才回答"为什么像原片"。
- 时长精确到 0.1s；总时长直接决定 `durationInFrames`（fps 固定 30，秒数 ×30）。
- 内容类型只归六类（§2 映射表左列：实拍段 / 静帧图 / 口播字幕 / 文案卡 / 数据卡 /
  节奏装饰），拿不准按画面主体归。
- **拆解表一次定稿**，落便签或文本节点给用户过目一眼；没有异议直接进映射，
  不要边拆边渲。

## 2. 映射：拆解表 → 轨道

全表在 `references/remake-mapping.md` §2–§3。速记：

- **铁律：画面上每个会动的元素 = 一条独立轨**（禁止把整帧画面烤成一张静态图再
  fade 轮播——那是 PPT，不是复刻；甜品会话 v1-v7 就栽在这）。背景色块 / 大标题 /
  产品 / 装饰球星 / 底栏，各自成轨，各配 `animate`（+ `easing`）或 `orbit`。
- 实拍段/产品演示 → `video` 轨；静帧/产品图 → `image` 轨（`fit: cover/contain/
  kenburns`，kenburns 推近是白嫖节奏感的第一手段）；一张精灵图切多格 → 每格一条
  轨加 `sourceRect` 百分比子区域；**产品/主体要融进场景（透明底）→ 四步工序缺一
  不可**：生图提示词固定「纯白背景」→ `image_matting` → `inspect_image` 核
  colorType=6 → alpha PNG 直引进 image 轨（平台已按 hasAlpha 免深底垫底，详见分册
  §2；伪透明拼贴会留棋盘格残边，实拍照抠不干净就回炉重绘）。
- 口播/歌词逐字 → `caption` 轨（词级卡拉OK，`src` 挂该句旁白，`tts_voiceover`
  逐句出）；句级字幕条/标题 → `textCard`（`anim` 四种入场动效）；**镂空描边大字**
  （品牌站常态）→ `fx: 'outline'`。
- 真数据表/对比 → `chart` 轨（`bars`/`dual`）；讲「每镜多长」这类结构数据直接
  `source: 'timeline'` 零手填。
- 节奏装饰（几何/光效/线条）→ `shape` 轨（9 种形状 × orbit/draw/fx）。
- **缓动速查**：弹跳/跃入 → `backOut`；柔性滑动 → `spring`；快出缓停 →
  `easeOutCubic`/`easeOutQuart`；淡入 → `easeIn`。**缺省 linear 没有生命感**，
  每条 animate 都要显式选档（全表在映射分册 §3.5）。**产品跳升/弹入直接套分册
  §3.6 的实测 preset**（曲线+幅度+时长现成，别现场重推参数）。
- 转场 11 式全表在映射分册 §3；参考片的转场名对不上就选**视觉最接近**的一式，
  别硬凑名字。
- 引擎能力与字段疑问查 `code-driven-explainer/references/manifest-contract.md`
  的 16 条实现细节——**不要读组件源码**（那是文档债复发，烧 token 还慢）。

## 3. 组装与渲染

- manifest 组装纪律、字段契约、尾部完整性自查全按
  `code-driven-explainer/references/manifest-contract.md`；长片必须走 `manifestPath`。
- **先 draft 档（480p）出对照版**，对照过了再 standard/high 出正片——复刻片要改
  几轮是常态，别在高清档上烧时间。
- **改一处先 spot-check 再整片**：`render_composition` 带 `spotFrames:[帧号…]`
  （≤8 个）只渲关键帧静帧、秒级回图，核对版式/文字/产品呈现后再整片渲——别把整片
  渲染当「看一眼」的工具（甜品会话 46 次整片渲，大多只为确认几个画面）。
- **素材生成后组装前过一遍 `qc_shot`**：逐张核对是否满足拆解表素材需求列（主体/
  背景/风格）；不合格当场重生成，别让废片进 manifest 再靠整片渲染返工。
- 工单队列并发 1：一次只渲一条；修正 = 改 manifest 重渲，不抽卡。
- 渲染窗口一扇窗只渲一单（连渲稳定性由宿主保证），批量时逐条排队即可。

## 4. 对照验收（原片 vs 复刻片）

并排五项，逐项 PASS 才算复刻完成：

| 项 | 判据 |
|---|---|
| 节奏 | 逐镜时长与拆解表偏差 ≤0.2s |
| 转场 | 形态与拆解表所选效果一致 |
| 字幕 | 出现时机与形态（词级/句级）一致 |
| 信息卡 | 数据与出现时机一致 |
| 整体观感 | 风格不跑偏（色调/密度/动效强度） |

偏差项按拆解表镜序定位到对应轨道改字段，不要整体重做。

有声片加第六项**响度对齐**：渲染报告 `report.loudnessLufs` 与参考片实测值差
≤2dB（参考片响度 ebur128 测一次，记进拆解表；复刻会话实测原片 −11.4 / 复刻
−15.3，差 4dB 没人发现就是缺了这一项）。

## 5. 批量换装（爆款裂变）

- 把「会变的」抽成变量表：产品图 URL / 品牌名 / 文案字段 / 价格数字（模板见映射
  分册 §5）。
- 循环 = 复制 manifest 骨架 → 按列替换变量 → 逐条 `render_composition`。一条爆款
  出 N 版、多条爆款换产品，都是这个做法。
- ⚠️ 文案替换不是盲替：caption 的词数变化会影响能量谷推导与折行，textCard 长文案
  会触发排版自适配——替换后看渲染体检提示再出下一版。
- 素材没齐的版本先 placeholder 出片占位并登记素材需求，不让整批等一张图。

## 6. 边界（如实告知用户）

- **任意代码级动效不复刻**（自由粒子 / 物理模拟 / 网页特效）：引擎是受控 manifest
  字段集，不是自由网页。CSS 级自由度看 html-in-canvas 档的落地进度。
- **渲染器已知边界**：conic 渐变遮罩、mix-blend-mode、真 3D 透视会被忽略或退化
  （能力基准归因 A2/A9）；映射分册 §3 给了最近似替代，差异要向用户说明。
- **素材质量不评**：placeholder 只验结构；实拍感取决于生图/生视频模型，与复刻
  流程无关。
- **版权默认换掉**：参考片里的真人脸 / 品牌素材直接复用有风险，默认替换或让用户
  提供授权素材。
