## 一、需求背景（已拍板的决策，勿重新讨论）

- 需求来源：把 `~/Desktop/job/reelsbuddy-auth/docs/electron-login-migration.md` 的 Electron 登录方案接入本项目；UI 参考 Miora 风格截图（左登录渠道 / 右循环视频）。

- **session 架构**：client（renderer）是唯一 session 持有者（supabase-js PKCE + autoRefreshToken）；Host 只被动收推送、内存缓存不落盘、**刻意不自己刷新**（避免 Supabase refresh token 轮换双持互踢）。`visibilitychange` 唤醒补推一次。
- **后台三条大原则**（后台未完全拍板，先按此设计）：① 后台自己验签 Supabase JWT；② **提交时校验一次**，轮询/取消不再校验（长任务 40min 中途不踢死）；③ 未登录尽量客户端拦截，漏网由后台校验兜底，agent 自行处理错误。
