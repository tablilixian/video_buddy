# 视觉资产三类模式

为 AI 视频创作设计标准化的视觉资产提示词。输入为剧本、故事梗概、世界观设定或分镜文本；输出为可直接投喂图像生成模型的角色定妆照、场景空镜、道具资产设定图。

---

## 核心原则：三类模式互不混用

| 模式 | 用途 | 画面要求 |
|------|------|----------|
| **Mode A: 角色定妆** | 角色身份锁定 | 禁止动作，全身照，正面视角 |
| **Mode B: 场景空镜** | 环境氛围设定 | 绝对不能有人，全景广角 |
| **Mode C: 道具资产** | 武器/载具/机械设定 | 正交视图，中性背景 |

**硬规则**：
- 角色 prompt 中不得出现环境全景
- 场景 prompt 中不得出现任何人物
- 道具/载具 prompt 中不得出现无关人物或场景
- 同一 IP 内的多资产必须显式声明共享配色与设计语言

---

## Mode A: 角色定妆 (Character Design Sheet)

### 必备要素

- **姿态**：Full body shot（全身照）、Standing pose（自然站立）、Front view（正视图）
- **表情**：Neutral expression（中性表情）
- **背景**：纯色或极其简单的环境氛围，确保轮廓清晰
- **必备词汇**：`Character sheet`, `Full body shot`, `Standing`, `Front view`, `Neutral expression`

### 中文提示词模板

```
[影调风格]，[角色名]，[年龄/身份]，[详细外貌特征]，[服装细节]，全身照，自然站立，正面视角，无动作，纯白色背景，电影级灯光，[特定布光]
```

### 英文提示词模板

```
[Style/Tone], [Character Name], [Age/Role], [Physical Details], [Outfit], full body shot, standing pose, front view, looking at viewer, character sheet, cinematic lighting, [Lighting Setup], [Camera/Lens], 8k --ar 9:16
```

### 半身特写变体

当需要面部/气质细节参考时，输出 half-body portrait：

```
half-body portrait, looking at camera, [面部细节描述]
```

遵循"一个强项，两个辅助"的五官主次逻辑，皮肤按写实纹理描述（毛孔、细纹、素颜感）。

---

## Mode B: 场景空镜 (Environment Concept Art)

### 必备要素

- **画面**：绝对不能有人（Nobody / No people）
- **视角**：Panoramic view（全景/广角），展示环境全貌
- **必备词汇**：`No people`, `Empty scene`, `Wide angle`, `Cinematic lighting`, `High detail`

### 中文提示词模板

```
[影调风格]，[地点名]，[环境细节与陈设]，[光影/气候]，空无一人，全景图，无人物，电影色调，[特定镜头参数]
```

### 英文提示词模板

```
[Style/Tone Keywords], [Location Name], [Architectural/Nature Details], [Lighting & Atmosphere], no people, nobody, empty scene, panoramic view, wide angle shot, cinematic color grading, [Lens/Atmosphere], highly detailed --ar 16:9
```

---

## Mode C: 道具/载具/机械资产 (Prop & Vehicle Asset Sheet)

### 适用范围

武器、法器、贴纸道具、载具、机器人、机械单位等非人物资产。

### 视角固定规则

| 资产类型 | 视角 | 画幅 |
|----------|------|------|
| 道具 | `front orthographic view`（正交视图） | `--ar 1:1` |
| 载具 | `pure side view`（纯侧视） | `--ar 16:9` |
| 人形机械 | `Robot asset sheet, Full body, Standing, Front view` | `--ar 9:16` |

成对道具可"一正一侧或正面+轻微3/4角度"并列陈列。

### 必备要素

- **可信度锚定**：用现实参照物锚定尺寸与机械逻辑
- **机械体关键词**：批量制造、可靠性、模块化、维护接口
- **必备词汇**：`isolated asset`（或 `asset sheet`）、`neutral gray background`、对应视角词、`high detail`

### 中文提示词模板

```
[风格定调句]，[资产类型与身份锚点]，[整体形态与结构分解]，[配色系统与共享设计语言声明]，[材质与旧化痕迹]，[负面约束：比例排除/风格排除/文字排除]，[Asset type] + [View]，isolated asset，neutral gray background，[Lighting]，high detail，8K --ar [1:1 或 16:9 或 9:16]
```

---

## 七段式骨架（适用所有模式）

每条 prompt 按以下七段组织：

1. **风格定调句**：全资产共享同一句关键词
2. **主体声明**：类型 + 身份 + 世界观锚点
3. **结构分解**：整体→局部逐项描述
   - 角色：气质→骨相→五官→身材→服装→佩挂
   - 道具/载具：形态→结构→材质→细节
4. **配色系统**：显式列出主色序列，跨资产声明继承
5. **旧化痕迹**：写实资产必写沙尘、划痕、掉漆、维修补丁等
6. **负面约束**：用中文正面否定句写进 prompt 正文
7. **英文固定后缀块**：资产类型词 + 视角 + 背景 + 灯光 + 画质词 + `--ar`

---

## 负面约束写法

用中文正面否定句写进 prompt 正文，不用参数后缀实现排除：

```
不是 Tron 风格，无发光霓虹，不网红脸、不幼态，不参考任何真实人物，禁止任何文字
```

三类排除：
- **风格排除**：不是赛博朋克、不是霓虹风格
- **比例排除**：不幼态、不 Q 版
- **内容排除**：不参考真实人物、禁止文字

---

## 旧化与使用痕迹

写实资产必须包含旧化描述：

| 资产类型 | 旧化词汇 |
|----------|----------|
| 服装 | 沙尘覆盖、划痕、磨损、补丁、褪色 |
| 武器 | 刀刃卷曲、握把缠绕磨损、金属氧化 |
| 载具 | 掉漆、锈蚀、维修痕迹、弹孔、刮擦 |
| 机械 | 油污、螺丝松动、面板划痕、散热口积灰 |

强度控制："大量但克制"——有明显使用感但不影响整体识别。

---

## 配色系统声明

同一 IP 内的所有资产必须显式声明共享配色：

```
【配色系统】
- 主色：深灰色（#2A2A2A）——装甲、服装主色
- 辅色：暗红色（#8B0000）——警示条纹、眼睛
- 点缀：银色（#C0C0C0）——金属部件、武器刃部
```

## 与分镜流程的整合

### 第一步：剧本影调分析

处理任何剧本前，先定义视觉基调：

1. **叙事类型分析**：识别剧本所属流派（硬核科幻、东方玄幻、黑色电影、末世废土等）
2. **影调设定**：匹配光影方案（伦勃朗光、丁达尔效应、高反差、低饱和莫兰迪等）
3. **色彩科学**：设定主色调与对比色对冲方案（青/橙对比、单色调、冷暖分割等）

### 第二步：提取清单

列出剧本中涉及的核心角色清单与场景清单。每个条目附一句身份/功能定位说明。

### 第三步：逐个生成提示词

按三类模式逐个输出，每条 prompt 独立完整、可直接复制使用。

---

## 与 H3 IR 的转换

视觉资产提示词用于 `image_generate` 生成定妆照/空镜/道具图，再将生成的图片作为参考图传入视频生成。

**流程**：
```
剧本 → 视觉资产提示词 → image_generate → 参考图 → video_generate (Ref2VA)
```

**资产卡锁定**：
生成的图片会成为"资产卡"，其 lockedPrompt 会逐字复用到后续的视频提示词中，确保身份一致性。
