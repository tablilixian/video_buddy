# 通用短剧执行手册（drama-episode-executor）

> **上游体裁壳（必读）**：本 skill 是 `drama-format-director` 的**下游 executor**。
> 用户点名本 skill 时**仍须先加载该壳**完成定向三问（题材基调 / 单集规格 / 追看定位）——
> 点名只决定「用哪条链」，不替代定向。

**定位**：知识型 executor 手册——`drama-format-director` 壳与题材特化导演（`bible-story-director` 等）之下、总纲流程之上的**单集执行细则**。上游 `canvas-studio-creation` 负责流程与审批；本手册只回答「一集怎么写、怎么拍、怎么收」。

## 0. 开工上下文（episodic 流程纪律，每集必走）

1. **开工先取前情**：`episode_brief(seriesId, episodeNo)` → 前情 recap + 库内角色 `lib:` 句柄。没有系列先 `series_manage action=create` 建系列、登记集号。
2. **recap 进澄清**：把前情提要原样写进本集澄清上下文——观众忘了剧情是短剧第一死因。
3. **角色一致性走句柄**：角色长相 / 服装 / 场景一律用 `@ref[lib:…]`（或先物化），**禁止凭文字记忆重描述**。
4. **收尾登记**：本集成片后 `series_manage action=upsert_episode` 写本集 recap（≤2000 字：谁做了什么 / 悬念留了什么 / 新增人物物件）——这是下一集的开工上下文。

## 1. 集结构（单集 1.5–3 分钟短视频剧）

| 时段 | 内容 | 判据 |
| --- | --- | --- |
| 0–3s | 冷开场钩子 | 冲突动作 / 悬念画面 / 反常台词三选一；**非** logo、空镜、标题卡 |
| 3–15s | 承接 | 上集悬念**一句台词内**回收 + 本集目标立起 |
| 中段 | 2–3 拍 | 每拍一个信息或转折；拍与拍之间有因果，不是并列素材堆 |
| 最后 10% | 悬念收尾 | 断点 = 动作中断 / 反转台词 / 新信息揭示；**不是**「且听下回分解」式旁白 |

## 2. 节拍与钩子密度

- 90s 集 ≈ **6–9 个主节拍**；每 15–25s 一个微钩（台词反转 / 动作升级 / 镜头信息差）。
- 前 3 秒必须出现「往下看的理由」；对白每镜 ≤2 句（口播预算 4–5 字/秒，超了拆镜）。
- **递进纪律**：每集推进一个主目标一步；原地打转的集宁可砍掉重写（观众用集数衡量进度）。

## 3. 角色预算与一致性

- 常驻角色 **≤4**（每个都有名字 + `lib:` 定妆句柄）；每集新面孔 ≤1（观众记忆预算）。
- 定妆照四视图入库一次（`add_to_library` category:character），跨集**只引用不重生成**。
- 系列主场景入库（category:scene）：省预算且视觉连续。

## 4. 镜头与生成纪律（总纲流程内的短剧特化判据）

- 90s 集镜头预算 **12–20 镜**；钩子镜与悬念收尾镜**必须存在**（分镜表里点名）。
- 角色镜全带 `shotRefs` 定妆句柄（绑镜纪律，Host 会拒收缺省调用）。
- 对白片必配配音（总纲第 8 步判据原样生效）。

## 5. 单集验收判据

1. 前 3 秒钩子成立（非空镜 / logo / 标题卡）。
2. 上集悬念一句台词内回收（观众不需要重看上集）。
3. 收尾悬念成立（断点在动作 / 信息上，不在旁白上）。
4. 角色跨集一致（`lib:` 句柄可查，画面可与定妆照对上）。
5. 集内无原地打转（主目标有可见推进）。

## 6. 边界

- **不复述总纲流程与审批**：唯一权威 = `canvas-studio-creation`；本手册不设门不放行。
- **不复述 episodic 存储口径**：`series.json` 方案见 `docs/plans/短剧episodic方案-20261104.md`；工具用法看工具描述。
- **不做题材特化**：古装 / 圣经 / 悬疑等题材纪律见对应导演 skill（如 `bible-story-director`），本手册与题材导演**叠加使用**，不互替。

## 画面判据取证（六体裁统一，2026-11-05）

本地产物（抽帧 / 素材）的画面判据**首选 `read_image(file_path=…)` 看图本身**，禁拿 manifest 字段自证；精确数值用 `inspect_image`；`image2vl` / `video2vl` 是 VLM 文字转述，仅保底且**不可当事实**。全契约见 `canvas-studio-creation/references/toolchain.md` §7。
