# 句级字幕时序口径（MVP）

**现状约束**：后端 TTS（`tts_voiceover` / Drama `txt2speech`）响应**没有任何字级 / 句级时间戳**，仓库也无 forced-alignment / 转写对齐代码。因此**词级同步无数据源**，MVP 只做**句级**，按下面的纯口径派生，零新依赖。

## 派生流程

1. `tts_voiceover` 产出旁白后，取它结果里的**真值时长 T**（秒）——该字段是 ffprobe 实测，**不是**后端响应里的"生成耗时"（两者实测差约 2.8 倍，勿混用）。
2. 按**字数占比**把 T 分配给每句：`句i时长 = (字数i / 总字数) × T`。
3. 句间可加固定呼吸间隔（默认 **0.15s**，**从相邻句时长内扣**，不额外拉长总长）。
4. 折算帧：`startFrame = round(累计秒 × fps)`；**末句 `endFrame` 强对齐 `round(T × fps)`**，吸收舍入误差。
5. **无旁白**（纯 BGM / 无音频轨）时回退 **字数 × 0.25s（4 字/秒）**估算——沿用 `voiceover-writing` 现行惯例。
6. **兜底校验**：末句 `endFrame` 与旁白总帧偏差 > 0.5s 时会出现在结果 `warnings` 里（不阻断渲染），要转告用户。

## 屏上时长：相邻字幕卡必须首尾相接（硬口径）

字幕卡的 `durationInFrames` 是**屏上**时长，不是该句的语音时长 —— 每句要延伸到**下一句的
`startFrame`**（末句到 `meta.durationInFrames`）：

```
卡i.durationInFrames = 卡(i+1).startFrame - 卡i.startFrame     // 末句 = 总帧 - 卡i.startFrame
```

理由（2026-10-16 实测）：句间呼吸间隔 + 每张卡自带的 6 帧淡入淡出叠加后，接缝处前后两卡的
不透明度会**同时落到 0**（实测第 129 帧不透明度 0.00）⇒ 每句交界闪一次背景。两条一起才治本：

- **卡首尾相接**（不留空白帧）—— 按上面的口径算 `durationInFrames`；
- **字幕卡不做淡入淡出** —— `variant: "subtitle"` 由组件层硬切（渲染器已按此实现，你不用也无法在
  manifest 里调）；整片的首尾渐变请用 `transition` 轨，或把首/尾卡改成 `title` 形态。

呼吸间隔的听感照旧（那一句的语音照常在间隔前结束），只是字幕在间隔期间**保持显示**。

## 卡片形态与断句

- 一条字幕卡 = 一句（`variant: "subtitle"`）。长句按标点（，。！？；）再切，单卡中文建议 **≤ 18 字**，与展示时长匹配。
- 断句要顺着语义停顿，不要机械按字数等分；旁白稿里的逗号是天然切口。
- 数据 / 数字类信息优先用 `variant: "dataCard"` 的 `data` 键值对呈现，比塞进字幕条更清楚。

## 误差预期

总长精确（实测值），误差只在句边界（受语速不均影响，典型 ±0.3s/句），显著优于裸 4 字/秒估算。

## 词级字幕（二期，有前置条件）

需要后端 TTS 响应增加 word / sentence 时间戳，**或**引入 forced alignment（本地转写对齐）。在前置条件满足前，不要尝试用估算伪造成逐字高亮——观感会与音频明显脱节。

## 词级对齐（caption 轨，能力基准 #05 收口 · 2026-10-31）

`caption` 轨的逐字高亮时间戳两种来源，**显式声明永远优先**：

1. **`words` 显式声明**（帧）：外部对齐数据（ASR / 未来后端词级时间戳）直接填
   `[{text, from, to}]`，与文本的口播字符（非标点）按顺序一一对应。
2. **能量谷推导**（缺省）：浏览器解码 mp3 → 10ms RMS 包络 → 语音区起止（峰值 12% 门槛）
   → 字间谷（±50ms 窗局部极小，谷深 < 峰值 35%，间隔 ≥ 80ms）→ 谷为主边界，
   不足处按**间隙长度比例**内插。平坦停顿区（逗号）的边界取**停顿尾部**（下一字起音点），
   避免静音期提前高亮。

**精度与边界（如实）**：±1–3 帧 @30fps，前提是中文慢速 TTS（语速均匀、字间谷可辨）。
语速快、口语连读、多音字粘连时谷会糊掉，退化为近均匀切分 —— 那就别承诺逐字精度，
改用句级 textCard 字幕。后端将来提供词级时间戳时，填 `words` 即可，渲染层零改动。
