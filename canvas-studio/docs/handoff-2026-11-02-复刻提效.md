## 五、本会话沉淀的工程铁律（新会话必读）

1. **无 index git 提交法**（受管 shell 封 `.git` unlink/rename 时）：`hash-object -w` 产 blob → `ls-tree` 取旧树 → 替换条目 → `mktree` 逐层重建 → `commit-tree -p` → **python truncate 直写 loose ref**（不走 rename 所以放行）。
   ⚠️ **untracked 新文件必须显式 hash-object 后 upsert 进子树**——只从 ls-tree 取清单会静默漏挂（本会话踩过：批四首提漏 4 文件）。**提交后必须逐文件 `git cat-file -e <commit>:<path>` 核对**。
2. 新工具登记四件套缺一 smoke 即红：param-guard 分类表 + tool-presentation 三档表 + tool-registry 基线/名单 + toolchain.md & canvas-studio-tools.md 表格行。
3. 全 src 禁 `throw new Error` → `throwError('CS-USER-ERR')`；JSON 序列化写盘禁裸 writeFile → `writeFileAtomic`（AR-03）。
4. 测试 import `lib/**`（先 tsc emit）；测试文件需 `import '../lib/errors/catalog.js'` 副作用注册错误码；入口只准 `yarn test:smoke`。
5. 环境封锁分层波动：先 `touch` 探针定通路；`$$` 不跨 Bash 调用、cwd 每次重置需 `cd &&` 串。
6. SKILL.md 闸 14KB（现 9178B），内容尽量写 references 分册。
