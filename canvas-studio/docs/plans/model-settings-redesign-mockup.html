我的 Provider

已配置的 provider 默认折叠为一行，点「编辑」展开完整配置；密钥只存凭据域，不落明文。此区域本次从断线状态修复，与桌面设置双向同步。

底层对任何端点都要求非空密钥：无鉴权自部署端点请在 API Key 填任意占位符（如 -），或在该 provider 下加 headers: { authorization: unused }。 DramaServer 官方区块为只读展示：目录与凭据由登录态自动维护，无需手动填写。
