## 2. 生图执行层（`image_generate`）

**prompt 编译顺序**：主体/世界 → 核心奇观 → 纹样如何改变自然 → 巨物小人尺度 → 材质 → 主色 → 光线 → 构图 → STYLE LOCK 后缀。

- **纹样必须写成「自然按纹样秩序运动」，禁止写成贴图**：
  - ❌ `clouds with Han dynasty cloud patterns` / `山峰上有传统云纹装饰`
  - ✅ `vast clouds curling in the flowing rhythm of Han dynasty cloud motifs` / `云海沿汉代云气纹的轨迹盘旋舒展`
- **材质优先级**：流体 > 湿润矿物 > 金箔/古金 > 丝绸 > 普通自然材质。
- **色彩比例**：约 80% 低饱和基础色（墨黑/深青/象牙白）+ 15% 古金 + 5% 朱砂。
- **光线**：侧逆光 / 后逆光 + 低角度神性光源，金色轮廓光，深青黑阴影。避免影楼柔光。

**STYLE LOCK 后缀（每次逐字追加到 prompt 末尾）**：

> 真实电影人物与绘画化自然世界并存，大块形体优先，环境以浓重绘画色块塑造，空气具有厚度与黏度，云雾如厚重颜料缓慢流动，山石呈湿润矿物与黑曜石质感，局部边缘柔化、融化、拖曳，古典绘画式体积光与克制古金轮廓光，局部写实、整体绘画，东方神话超现实主义

**`negativePrompt` 基线**（按当前画面增删，不要无脑堆）：

> 二次元，卡通，游戏 CG，MMORPG，3D 渲染感，影楼古风写真，网红汉服，廉价金色，霓虹赛博，过饱和，纹样贴图感，满屏祥云，清晰树叶与高锐度岩石的风光摄影感，matte painting，塑料皮肤

## 3. 视频执行层（MiniMax H3）

按 `h3-prompt-writing` 选模式：无参考 T2VA、单参考 I2VA、首尾帧 FL2VA、多参考 Ref2VA。

**运动逻辑优先从「纹样运动」产生**（原文 §26），不要另设抽象运镜：

| 纹样 | 运动逻辑 |
| --- | --- |
| 云气纹 | 云层沿卷曲轨迹缓慢生长 |
| 海水江崖 | 浪潮层层推进，最终凝固成山 |
| 宝相花 | 云与光从中心向外逐瓣展开 |
| 缠枝纹 | 植物 / 河流 / 衣带沿连续曲线蔓延 |
| 朱雀 | 火云由普通云层逐渐形成翼状天地结构 |

视频描述一律用 **时间段 + 当前动作 + 环境变化 + 运镜 + 最终停点**，禁止抽象导演术语堆砌。

## 4. 与创作流程的衔接

- 本 skill 属**风格层**，在总纲「风格确定后」加载；**剧本阶段照常执行**（`write_screenplay`）。
- 原文 §25「系列视觉圣经」里的世界规则、色彩、材质、光线固定资产 → **写进剧本节点，不要另建「视觉圣经」节点**。
- 用户只给命题时：给 A / B / C 三方向（核心母题 + 核心纹样 + 显化等级 + 一句话奇观 + 画面核心描述），用 `ask_user_choice` 点选，再进入剧本 → 分镜。
- 各镜定妆照与关键帧沿用同一套纹样家族与 STYLE LOCK；跨镜头一致性由原文 §19 系列一致性机制保证。

## 5. 出图前自检（完整版见 references §20 / §V0.3 §8）

1. **东方性**：去掉人物服装后画面是否仍有东方秩序？
2. **纹样性**：纹样是否只贴在衣服/背景？是 → 升级到 L2–L5。
3. **奇观性**：能否一句话讲清这个超现实事件？
4. **克制**：中国元素是否过多？是 → 删。
5. **电影性**：像「一个场景正在发生」还是一张摆拍海报？
6. **STYLE LOCK**：大块形体、空气有厚度、半液态材质、边缘软化、古典体积光是否都在？

最高原则：**纹样不是被画在世界上，而是世界按照纹样生长。**
