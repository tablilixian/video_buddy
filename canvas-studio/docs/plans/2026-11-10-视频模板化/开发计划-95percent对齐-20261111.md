## §2 三条关键技术决策（先定架构，再写代码）

### D-A · 卡片墙必须引入「容器层」，但**不缩水到 12 张**

你说得对：**3D 能力在 #12/#13 已验证没问题，不再拿性能预算当缩水理由**。
但当前 `cardWall` 是「1 张卡 = 1 条独立 3D 轨」的**扁平架构**（`src/remotion/furniture.ts`），
62 张带内部图表/代码的卡 ⇒ 62 条背景轨 + ~186 条内部轨 = **248 个独立 WebGL 预合成层**。
按 #13 实测 60 层 = 243ms/帧 线性外推 ≈ **900ms/帧**（24s@60 ≈ 22 分钟/支），
且浏览器 WebGL 层数有实际上限 —— 这不是「慢一点」的问题，是**架构不成立**。

| 路线 | 做法 | 3D 层数 | 代价 |
|---|---|---|---|
| **A（主推）** | 新增 `type:'group'` 轨：`children[]` + 自身 `transform`；渲染器把子轨包进一个 div 再对容器做 `perspective() rotateY()` | **1** | 中：契约新增轨类型 + 校验 + 组件 + 字段表 + lint。#12 的 **G 格已证明这条路真出画**（容器 transform 包 20 张 Tile ✅） |
| **B（S1-A 实测后否决）** | 保持扁平，62 张各 1 条 3D 轨 | 62 | #15 实测 **146ms/帧**，且目视是**规则网格、没有统一灭点**，不像原片那面斜墙 ⇒ 视觉不合格，不再作为过渡 |
| C（否决） | 62 张 × 4 条全 3D 轨 | 248 | 高且不可行 |

**S1-A 决策反转（D-44）**：原计划「先走 B 验视觉、同时做 A 探针」已被 #14/#15 的
像素证据推翻 —— #14 A 格（容器统一灭点）才是原片卡片墙的样子，且更快
（**82ms/帧** vs #15 的 146ms/帧）。⇒ **直接做 A（group 轨），B 路线取消**。
两条路线上 62 张卡都真出画、H4 逐帧 md5 全等，所以 3D 能力确实不是约束。

### D-B · 人像做成「媒体端口」，不是写死图片

- 新增槽 `presenterSrc`（`type:'media'`），**支持 image 与 video 两种形态**：
  后缀 `.mp4/.webm` ⇒ `VideoClipTrack`，其余 ⇒ `ImageClipTrack`（两种轨都已存在，
  `src/remotion/manifest.ts:416/437`）。后期换视频**只改 src，不动模板结构**。
- 两种版式同时预置：**竖幅矩形**（段 3，带四角括线）+ **圆形 PIP**（段 10–12，右上角）。
  圆形裁切需给 media 轨加 `clip:'circle'`（`Shape.tsx:117` 已有 `borderRadius:50%` 原语，
  但 media 轨是否消费需先验证 —— 这是小契约扩展，不是新管线）。
- **缺省占位由程序生成**（深灰底 + 几何轮廓/首字母），不搬原片真人肖像与品牌资产
  （页面明写「演示人物与声音不作为用户素材打入模板包」，字体与品牌另有许可）。
  placeholder 保证 `src` 恒有值 ⇒ 编译期不需要「条件轨」逻辑，零额外复杂度。
- `meta.requiredAssets` 保持 `[]`（占位自带），用户上传素材时由 `slots` 覆盖端口值。

### D-C · 视觉语言基线，四处小契约扩展

| 缺口 | 落点 | 复杂度 |
|---|---|---|
| 银色金属渐变字 | `fx` 新增 `metal` 档，复用 `FxStyle.textFill`（`src/remotion/timing.ts:1006`）写 `linear-gradient` + `background-clip:text`；`TextCard` 消费 | 低 |
| 铺满的圆点阵网格背景 | 新增 `shape:'dotGrid'`，**必须走 SVG `<pattern>` + `<rect fill=url(#…)>`**；#16 首轮实证 CSS `radial-gradient` 平铺被 web-renderer 忽略（整格只剩一个糊点），SVG pattern 重跑后真出画且仅 13ms/帧 | 低 |
| 帧级时间码 `00:00:38:00` | `textCard` 新变体 `timecode`，按 `useCurrentFrame()` 纯帧函数格式化（禁 `Date.now`） | 低 |
| 音频波形 / 序号 / `PRESENTER` 标签 | 用现有 `shape` + `textCard` 组合成 `hud` 复合单元（`D-A` 的 group 可复用） | 低 |

动画能力**已经够用**：`VISUAL_DIMENSIONS = x/y/scale/rotation/opacity/rotateX/rotateY/z`
（`src/remotion/timing.ts:597`），推近、落下弹跳、光斑扫过、数字滚动全部可用，
上一版只是模板里没写 `animate`，不是渲染器缺能力。
