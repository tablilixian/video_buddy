# 分镜修改纪律与防堆卡方案（BUG-008 · CV-251）

## 1. 现状与根因

**症状**：用户打回分镜、要求修改某镜文案后重提，画布上的分镜卡没有变化（或模型只在对话里描述修改），有时还多出一张整表卡。

重提路径本身完好（CV-050, 2026-09-17）：`submit_storyboard_for_approval` → `parseStoryboardShots` 解析逐镜表格 → `mergeShotCards` 按镜号对齐 → 同号复用旧卡（id/位置不动、只换文案），新号新建避让。**真正缺口有两个**：

1. **模型不知道「改分镜 = 重提整表」**：工具 description 只说「把分镜表提交给用户审批」，没有任何修改场景的指引；skill 总纲第 65 行「二次修改 → 直接右键重试或 steer」更是把分镜也一并覆盖了（右键重试/steer 只对媒体节点有意义），模型于是把修改说在对话里或去改剧本节点——画布分镜卡自然纹丝不动。
2. **解析失败防堆卡缺失**：confirm 模式下 `shots.length === 0`（模型返回的不是逐镜 markdown 表格）时走「整表单节点」回退分支，`appendCanvasNode` 无条件追加——画布上已有分镜卡时，这就是「没变化还多一张卡」的直接来源。

## 2. 方案（用户拍板「先做 A」：描述纪律 + skill 纪律 + 防堆卡，不做单镜编辑工具）

### 2.1 工具描述补硬指引

`host-tools.ts` `submit_storyboard_for_approval` description 末尾追加：

> **修改既有分镜（用户打回改文案、增删镜头）也必须调用本工具重新提交完整分镜表**——画布会按镜号原地更新既有卡片、不产生重复卡；只在对话里描述修改、或去改写剧本节点文本，都不会更新画布上的分镜卡。

点名两条反模式（只改对话 / 改剧本节点），模型不再有「修改可以绕开重提」的想象空间。

### 2.2 skill 总纲同步

`skills/canvas-studio-creation/SKILL.md` 两处：

- **行 65「二次修改」条**：carve-out 分镜例外——「唯一例外：分镜内容要改 → 必须调 submit_storyboard_for_approval 重提完整分镜表」。
- **第 3 步「分镜规划 → 审批」**：补「打回后改分镜 = 重提完整分镜表（含『衔接』列仍要写全），画布按镜号原地更新既有卡；表格必须是每镜一行的 6 列格式，解析不出会直接报错、不落卡」。

（文件 17.5KB / 上限 20KB，余量充足。）

### 2.3 解析失败防堆卡（机制兜底）

`execute` 内、模式分支之前加一道共用闸门：

```ts
if (shots.length === 0 && existing.some((node) => node.toolName === STORYBOARD_NODE_TOOL)) {
  throwError('CS-USER-ERR', { message: `分镜表未解析出逐镜表格，且画布上已有分镜卡——不再追加整表节点。${STORYBOARD_PARSE_HINT}` })
}
```

- **判据**：`toolName === STORYBOARD_NODE_TOOL` 的任意既有节点（含旧整表回退节点——它存在时再堆一张整表同样是堆卡）。
- **抛错而非结回合**：错误发生在 `updateWorkflow` / `concludeTurn` 之前，回合不终止，模型收到带格式引导的报错可**同回合修正重试**——与 `resolveShotRefs` 的可操作报错同一哲学。
- **格式引导共用一份文案**：新常量 `STORYBOARD_PARSE_HINT`（6 列表格样例 + 「修改也是重提完整表」），防堆卡报错与两处降级提示（auto 未落卡 notice / confirm 整表回退 deferred）三方共用，口径不分叉。
- **无卡首提不回归**：画布上没有任何分镜节点时，解析失败仍走整表单节点回退（CV-026/027 既有设计，保留）。

## 4. 测试

- **防堆卡**：先正常提 2 镜 → 重提无表格文本 → 断言抛 `CS-USER-ERR`（message 含引导文案）、画布节点数不变、workflow 状态不变、`concludeTurn` 未被调。
- **回归**：空画布首提解析失败 → 仍走整表单节点回退，降级提示带格式引导。
- **描述断言**：工具 description 含「重新提交完整分镜表」「原地更新」「不会更新画布上的分镜卡」。
- 既有 8 个 CV-050 用例（mergeShotCards 语义 + 端到端重提）全部保持通过，证明重提合并路径无回归。

## 5. 真机验收步骤

1. 提交一个 3 镜分镜并批准，等逐镜卡落画布。
2. 打回，在对话里说「把第 2 镜的画面描述改成 XX」→ 模型应**重提完整分镜表**，画布上 3 张卡 id/位置不变、第 2 镜文案更新，**不新增卡**。
3. （边界）诱导模型返回非表格文本（如「分镜：一个镜头，少女看信」）重提 → 应收到格式报错引导，画布**不多出**整表卡；模型按引导修正后同回合重提成功。
