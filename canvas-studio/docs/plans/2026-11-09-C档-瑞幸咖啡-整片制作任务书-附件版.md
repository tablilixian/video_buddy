## 1. 成片规格与语言口径

- 20 秒（±1s）、16:9、1280×720，成片落到画布且可播放。
- 投放场景：官网 + 社媒信息流。
- **语言口径：英文**。同批附件是品牌国际站英文物料，旁白与画面内文案一律英文，与素材同源；
  对话用中文不改变视频语言。这是本任务明确指定的语言选择，不是默认推断。
- 附件上原有的英文文案与奖项徽章只作视觉参考，**不得照抄进成片**（见 §7）。
- 全片 8 个主节拍（见 §4）；结尾 3 秒给明确 CTA 与完整 logo，片尾不留裸画面。

## 2. 体裁与定向

- 本片是**品牌宣传短片，以实体产品为主角**。**不点名任何具体 skill / executor**：
  按产品流程完成体裁定向后开工，用哪条链由定向结果决定。
- **定向三问的答案已给全，可直接引用、无需再向用户提问**：
  ① **素材现实**：同批 4–5 张官方图（字标 logo / 蓝杯与咖啡豆 / 门店鹿标 / 咖啡师手冲），
  身份资产齐备，溯源记为「用户提供 · 官方来源」；
  ② **投放场景**：官网 + 社媒信息流；
  ③ **时长画幅语言**：20s / 16:9 / 英文。
- 开工前在回复里**复述一次定向结论**。给全答案只意味着不必再问用户，**不等于跳过体裁定向**。

## 3. 单一创意命题与产品主角

- **命题**：「From a bean to the blue cup」——只讲附件里看得见的四件事：
  **咖啡豆 → 咖啡师手冲 → 深蓝杯 → 门店**，让观众看清「这杯咖啡是怎么来的」。
- **产品主角**：附件 2 里的**深蓝杯 + 咖啡豆主视觉**。全片至少出现 3 次，
  其中一次完整可读（不裁掉杯身）、一次作为开场揭示、一次作为结尾结果。
- 每一拍都要回答「这一拍让观众多知道了产品的哪一件事」。**禁止**用抽象特效、氛围空镜、
  色块转场或概念文案替代产品镜头；不要把故事藏在动效后面。
- 不引入附件里看不见的产品、口味、功能、参数、价格、门店数、获奖或官方口号。

## 5. 文案调性与禁用词

- 英文短句、现在时、具体名词；每句 ≤8 词，可读停留 ≥1.2s；不押韵、不喊口号。
- 全片文案 ≤8 句；旁白与画面文案不要重复堆同一句。
- **禁用**：一切数字、销量、门店数、价格、中国区产品名、官方口号、获奖表述、最高级
  （best / No.1）、功能或疗效承诺，以及附件上照抄来的英文文案与奖项字样。
- 第 8 拍 CTA 属**概念文案**，交付卡里标为「未核源 · 概念文案」，不得当官方主张。

## 6. 声音与节奏

- 器乐 BGM 为主 + 英文短句旁白；不要为压时长把旁白挤在一起；字幕只在必要时出现，
  不逐字重复旁白。
- 2–3 个峰值：2.5s（主视觉揭示）、10s（门店）、18s（logo）；
  两处安静刹车：7.5s、16s。一拍一个主动作。
- 音频目标 −20 ~ −9 LUFS；交付前实测并写明实测值。

## 附录 A · 工程约束（不改变上面的创意要求）

### A1 三轨结合（必须同场，不得退化为纯代码轨）

1. **AI 生图**：`image_generate` 出 1 张 16:9 **咖啡粉 / 水流微距**锚点图（画面禁文字与标识）；
   prompt ≤500 字符、只写正向约束；一次一个串行调用。
2. **H3 视频**：`video_generate`（首尾帧）或 `video_composite` 出 1 段约 5 秒
   **咖啡液注入无字标杯口的微距推近**，只给第 4 拍，禁止为「消静态提示」逐镜生成；
   单次 ≤15s，后端单任务串行。**生成调用显式传 `resolution:"720p"`**（本片交付 1280×720，
   不要落默认 480p 再用 `video_rerender` 重出一次）。
3. **代码编排**：排印、色彩状态、转场、CTA 走
   `scaffold_manifest → 内容表 → manifest-builder.mjs → render_composition`；
   **禁止手写 `gen-*.mjs` 绕过 official builder**。

- **AI 素材的内容要求（优先于任何秒数指标）**：两段必须承担**产品特写或制作细节**（注入、
  液流、杯口），不得是纯氛围空镜；**两段不得同源重复** —— 不接受「一张静帧 + 以它为首帧的
  推近」当两段素材，一个拍粉/水、一个拍液/杯口。标为概念化制作特写，不冒充官方产品证据。
- **不设 AI 素材秒数硬指标**：AI 素材只服务第 4 拍，其余时长全部留给附件原件的
  产品镜头；成片不得是「图文卡片型（全片无视频片段）」。
- AI 素材经 video / image 轨进 manifest：`id` = 画布节点 id、`src` 同源、时长取 `list_shots` 真值；
  禁外链、禁 `@ref`、禁把产物名直接作下游入参；合成后严禁再调 `video_generate` / `video_composite`。
- 付费生成若被审批闸拦下，**立即明确告知需要放行**，不要静默退化为纯代码轨，也不要假装已生成。

### A2 通用硬要求（四条，逐条执行）

1. 首轮渲染就用 `spotFrames` 探针取代表帧，逐张 `read_image` 看成片像素后，对照判据表逐条打勾；
   `inspect_image` 的 grid/bbox 只用于定位疑点与精确数值，不得当「元素是否存在」的结论。
   探针额度：**交付前结构探针 ≤3 次**（`quality:"draft"` 草稿不算成片、不占批注额度，可边渲草稿边复探）；
   **交付档 standard / high 定稿后还有 1 次成片后批注探针**，优先用它覆盖片尾 CTA 段（446–609 帧）。
   额度用满即按纪律收口：把未复核段写成未决项，不要反复渲全片换额度。
2. 交付前复述未决项：体检告警逐条状态（`lint[]` 折叠时给计数 + 前 N 条 + 落盘路径）、
   未核源事实、模型自身能力边界。
3. 画面类结论禁拿 manifest 字段自证；图表数值必须单一基准、可溯源，`pending` 事实不得进成片。
4. 负例不跑（它是验收阶段可选的测试手段，不是交付流程的一环）。

### A3 交付前自检（逐条在交付卡里说明结果）

- 定向结论是否已复述，体裁定向是否在点名缺位的情况下正常完成。
- §4 的 8 拍是否都有「展示什么 + 为什么」；≥3 拍是产品特写 / 交互 / 使用场景 / 结果。
- 旁白是否 ≥2 句讲产品或制作，而非全片概念文案；语言是否全片英文、无附件文案照抄。
- AI 两段素材是否不同源、是否 ≥1 段含产品细节、是否只用在第 4 拍。
- logo / 字标 / 门店 / 人物是否全部来自附件原件、无重绘、无外部图混入，终版 logo 完整可读。
- 20s / 16:9 / 英文、峰值与刹车、色彩状态 2–5、无假 HUD、片尾无裸画面、产物落画布可播。
- 三轨各自实际用了哪些工具、AI 素材实际占多少秒、是否调用过手写生成器、实测响度。
