# 分册：预检与创意契约（music-video-subtitle-generator）

> 何时读：写最终视频提示词或生成视频之前必读。
> 画布落地与审批以 `canvas-studio-creation` 为准；本册只给 MV 的锁定项与契约字段。

## 1. 视频格式

固定选项：

| 用途 | 画幅 | 分辨率 |
| :--- | ---: | ---: |
| TikTok / Reels / Shorts 竖屏 | 9:16 | 1080×1920 |
| YouTube / Bilibili 横屏 | 16:9 | 1920×1080 |
| 信息流方图 | 1:1 | 1080×1080 |
| 密集竖屏广告测试 | 9:16 | 720×1280 |
| 电影宽银幕 MV | 21:9 | 2560×1080 |

选定的画幅必须在角色卡、场景卡、排印参考、镜头提示词、视频片段与成片合成中全程复用。

## 2. 目标时长与多镜结构

写提示词或生成视频之前先确认目标 MV 时长。**绝不要把模型默认值当用户意图。**

给一张紧凑的时长卡：

1. **10 秒测试**：一到两个镜头，验证角色、场景、排印与音频风格。
2. **15 秒钩子**：2-4 个短镜头，承载更完整的副歌/钩子/表演乐句。
3. **30 秒或更长的完整 MV（多镜拼接）**：许多模型有 15 秒单次生成上限，因此自动使用多镜拼接工作流——先生成或锁定一条连续歌曲/BGM，把 30 秒拆成 4-8 个 2-5 秒的动态镜头，再按节拍同步与首尾帧续接拼接。
4. **自定义时长**：用户给定时长；按所选模型的单段上限规划镜头数与拼接方式。

已上传音乐时，确认的时长就是音乐窗口长度。

## 3. 音乐窗口

上传或指定的音乐长于确认时长时，写提示词前先锁定一段：

1. 推荐窗口：由 assistant 找出最强的副歌/钩子/情绪转折并请用户确认。
2. 用户时间戳：由用户给出起止秒数；验证两端都在音频内。
3. 多版本：仅用于广告钩子测试或多个创意方向。

音乐短于目标时长时，除非用户明确要求拉伸或延长，否则使用完整音频。

## 4. 歌词锁定与"无歌词则先造词"的兜底

在写最终视频提示词或生成之前，先确定歌词归属：

1. 用户提供歌词 → 那是锁定歌词。除非明确要求，不得生成、添加、重写、扩写、翻译、改写或替换。
2. 用户想要没有歌词的成品音乐美学 MV → 生成与音乐风格、人声模式、时长、情绪与视觉预设匹配的简短原创歌词，然后锁定。
3. 锁定歌词是说唱/演唱表演与可见排印的**唯一文本来源**。
4. 把锁定歌词拆进每镜的 `Rap line:` / `Vocal line:` / `Soft vocal line:` / `Spoken line:`。
5. 每个 `Typography:` 字段都必须来自同一份锁定歌词。演唱表演期间，可见文字必须逐词匹配实际唱出的短语。
6. 终版排印 MV 里，表演者必须说唱或演唱锁定歌词，带可见口型、下颌运动、呼吸、面部重音、点头与手部重音，跟随乐句与节奏。

## 5. >15s 的默认多镜拼接

30 秒这类 >15s MV，全局多镜提示词脚本是权威来源：

1. **锁定完整主音频**：一条连续的歌曲/BGM，带完整人声与 groove，作为唯一音频基线。
2. **建镜头时间线**：把 30 秒拆成 4-8 个 2-5 秒的短镜头，精确映射到歌词时间戳与节拍（军鼓、808、drop）。
3. **首尾帧与场景连续性**：镜头 B 接同一场景时，用镜头 A 的尾帧当镜头 B 的首帧；硬切时保持同一角色卡、服装、光线提示词，并用同方向运镜或匹配切视觉元素衔接。
4. **生成与剪辑合成**：视频 agent 按镜头表逐镜生成；剪辑 agent 把所有片段对齐到全局主音频节拍网格，做裁剪、变速与拼接，得到自然的口型同步、节拍同步与转场。

细则见 `references/stitching.md`。
