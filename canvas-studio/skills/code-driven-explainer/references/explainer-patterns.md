# 科普结构、卡片形态与节奏

本分册给**内容组织**建议（不是硬约束）。目标：让 30–90 秒的解说短片「一看就懂、一屏一个点」。

## 结构：钩子 → 主体 → 收尾

| 段 | 时长占比 | 做什么 | 常用卡片 |
| --- | --- | --- | --- |
| 钩子 | 10–15% | 用一个反常识问题 / 一组对比数字抓住注意力 | `title` / `dataCard` |
| 主体 | 70–80% | 3±2 个要点，**一个要点一张卡或一段素材** | `subtitle` / `dataCard` / `bullets` |
| 收尾 | 10–15% | 一句话结论 + 行动 / 回味 | `title` / `subtitle` |

**一屏一个点**：不要在同一张卡里塞两个论点；观众注意力只够消化一个。

## 结构模板（按信息形态四选一，P4 · 2026-11-03）

「钩子 → 主体 → 收尾」是骨架；下面四个模板决定**主体段怎么长**。开工前按信息形态选一个，
段权重可以直接当编排预算用（explainer-format-director 的结构预算校验按此口径对齐）。

### T1 陈述型（缺省，即上面的骨架）

适用：单一概念、定义、「是什么」。主体 3±2 个要点线性展开，一屏一点。

### T2 对比型

适用：A vs B、误区 vs 正解、前后变化。核心纪律：**对比双方必须同构**（同样的卡型、同样的
布局位置，只换内容），差异才能被看见。

| 段 | 占比 | 做什么 | 常用能力 |
| --- | --- | --- | --- |
| 钩子 | 15% | 抛出「大家都以为 A」 | `title` |
| A 面 | 30% | 误解 / 旧方案（冷色调、弱动效） | `subtitle` + `shape` 冷色 |
| B 面 | 35% | 正解 / 新方案（暖色调、`reveal` 擦除登场强调「换视角」） | `reveal:{kind:'wipe'}` |
| 收尾 | 20% | 一句话裁决 | `dataCard`（两侧各一个关键数字） |

### T3 时间线型

适用：发展史、步骤流程、因果链。核心纪律：**时间轴要可见**（底部 `shape` 细线 + 节点圆点），
事件卡按时间顺序依次 `startAfter` 接力（`gapFrames: -6` 轻微叠化）。

| 段 | 占比 | 做什么 | 常用能力 |
| --- | --- | --- | --- |
| 钩子 | 15% | 「从 X 到 Y 只用了多久」 | `title` + 时间轴铺底 |
| 事件 2–4 个 | 60% | 每个事件一张卡，锚定在时间轴节点上 | `callout` 指向节点 + `startAfter` 接力 |
| 收尾 | 25% | 趋势外推或总结 | `chart` `variant:'line'`（逐年数据） |

### T4 原理拆解型

适用：「为什么」——机制、因果、内部结构。核心纪律：**先整体后局部**，拆到哪层标注到哪层。

| 段 | 占比 | 做什么 | 常用能力 |
| --- | --- | --- | --- |
| 钩子 | 15% | 反常识现象（「太阳表面 5500°C，日冕却上百万度」） | `title` / `dataCard` `countUp` |
| 整体 | 25% | 全景图 / 结构图铺底 | `image` / `shape` |
| 逐层拆解 2–3 步 | 45% | 每层一个 `callout` 指向部件 + 旁白解释 | `callout` + `reveal:{kind:'spotlight'}` 聚光当前层 |
| 收尾 | 15% | 机制一句话复述 | `subtitle` |

### 模板选用判据

- 内容能提炼成**两个对立面** → T2；能画成**一条轴** → T3；能拆成**结构层次** → T4；都不是 → T1。
- 模板可以嵌套（T4 的拆解步内部用 T2 对比），但**一段只套一个模板**。
- 段权重 ±5% 内浮动合法；偏离超过 ±10% 会在编排体检里得到结构风险提示。

## 卡片形态怎么选

- `subtitle`：配旁白逐句呈现的核心信息，本路径的主力。
- `dataCard`：出现具体数字 / 对比时用 `data` 键值对（`全球老龄化 16%`），比把数字塞进字幕条清楚得多。
- `bullets`：并列清单（3–5 条），配停顿逐条点出。
- `title`：开场主题或章节转场。

## 素材与卡片的配合

- 有实拍 / 生成视频素材时：**素材铺底、字幕卡叠上**（字幕卡 `startFrame` 落在对应素材区间内）。
- 纯图文解说（无视频素材）：用 `shape` 的 `gradient` 做背景、`image` 铺图、`textCard` 承载信息，`transition` 在段落间过渡。
- `image` 用 `fit: "kenburns"` 给小图加缓推，避免静态感。

## 用动画讲对比与过程

静态卡片只能"陈列"，动画才能"解释"。四种最常见的信息关系，都靠 `animate` 表达。

> **完整范式库（可复制的 manifest 片段 + 决策表 + 复用代码）已下沉到 `references/motion-patterns.md`**，
> 本处只给速查，组装时以该分册为准。

| 想讲清的事 | 动起来的方式（详见 motion-patterns.md） |
| --- | --- |
| **顺序 / 步骤** | 元素依次出场：各轨错开 `startFrame`，用同一套入场 `animate`（§2.5 序列揭示） |
| **大小 / 量级对比** | 同一时刻到位、各给不同 `to.scale`（起点可一致）（§2.7） |
| **趋势 / 累积** | `chart` `variant:'line'` 直接画折线（P2' 起一等公民，不再拿长条接力近似） |
| **周期 / 关系**（脉动、往复、环绕） | 呼吸两段首尾相接（§2.3）；绕中心转用 `orbitSegs` 多段线性近似（§2.1） |
| **读数 / 揭晓**（指针、仪表、KPI） | 指针 = `shape` + `pivot:{x:50,y:100}` + `animate.rotation` 甩弧（P1）；KPI = `dataCard` + `countUp:true` 数位滚动（P2'） |
| **指认 / 强调**（指着讲、聚光） | `callout` 一条轨（锚点+引线+标签，P3）；聚光强调 = `reveal:{kind:'spotlight'}`（P3） |

三条纪律：

- **动一次就够**：入场动画 0.5–0.8s（15–24 帧 @30fps）。全程都在动 = 没有重点。
- **别让观众等**：`animate.startFrame` 要落在这张卡真的在屏上的区间内 —— 卡切走了再动没人看得到。
- **只动该动的维度**：只写 `x` / `opacity` 的动画不会碰 `scale`，可以安全地与 `fit: "kenburns"` 叠加。
- **让运动被看懂**：任何移动体都要配静止参照（轨道环 / 网格 / 背景点）+ 拖尾残影，否则慢速位移读成「两个随机点」（motion-patterns.md §0）。

## 节奏与时长

- 单张卡**别短于 1.5s**（来不及读）也别长于 6s（开始走神）；中文按 ≤18 字配约 2.5–4s。
- 转场（`fade` / `slide`）时长 **0.5–1s** 足够；全片别全都是同一种转场（宿主会判「幻灯片风险」）。
- 宿主会给「图文卡片型成片」的风险提示（命中静态占比 / 运动密度 / 镜头数）：**这是合法形态**，
  别为此去改成逐镜生成视频。削弱静态感的正解是**让画面动起来**——差异化转场、`image` 用
  `fit: "kenburns"` 缓推、**给卡片 / 形状写 `animate`**（入场、缩放、往复）、把并列信息拆成逐张入场。

## 自检清单（交给用户前过一遍）

- [ ] 钩子在**前三秒**内出现？
- [ ] 主体 ≤ 5 个要点，每个要点一张卡 / 一段素材？
- [ ] 每句字幕都配了旁白，且句长与展示时长匹配？
- [ ] 数字类信息用了 `dataCard` 而非字幕条？
- [ ] **至少一处在动**（视频 / `kenburns` / `animate`），且动得有理由（不是为动而动）？
- [ ] 需要讲"对比 / 过程 / 关系"的地方用了 `animate`，而不是只放一张静态图？
- [ ] 收尾有一句明确结论？
