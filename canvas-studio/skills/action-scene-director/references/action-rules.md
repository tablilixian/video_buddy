# 动作打戏四条铁律详解

设计任何动作场景前，先按这四条搭骨架，再填血肉。缺一不可。

---

## 铁律一：时序拆段

**核心原则**：总时长（≤15 秒）拆成多个 2-3 秒的小阶段。每个阶段只负责**一组主要动作**，用时间戳显式标出。

**为什么重要**：
- AI 视频模型对长文本的理解能力有限，过长的提示词会导致动作混乱
- 2-3 秒是模型能稳定执行的"动作单元"
- 时间戳让模型明确知道"现在该做什么"

**正确示例**：
```
0:00-0:02 女主从掩体后方快速探身，手持粒子步枪瞄准前方
0:02-0:05 怪兽前冲，女主侧身闪避，同时开枪射击
0:05-0:08 子弹击中怪兽肩甲，火花四溅，怪兽被冲击力带偏
0:08-0:10 女主趁机拉开距离，重新装填弹药
```

**错误示例**：
```
女主从掩体后方探身，瞄准前方，怪兽前冲，女主闪避，开枪射击，子弹击中怪兽，火花四溅，怪兽被带偏，女主拉开距离，装填弹药...（10个动作塞在一个阶段）
```

## 铁律二：动作因果链

**核心原则**：相邻阶段的动作必须是物理因果关系。每个动作都要能回答"上一个动作给了它什么条件"。

**为什么重要**：
- 孤立动作 = 瞬移/穿模的根源
- 因果链让模型理解"为什么这个动作会发生"
- 物理合理性决定成片可信度

**因果链检查方法**：
```
阶段A：对手前冲
  ↓ （因为）对手前冲产生了动量
阶段B：女主借惯性转身
  ↓ （因为）女主转身产生了空档
阶段C：对手趁机抓向女主肩膀
```

**正确示例**：
```
0:00-0:02 怪兽嘶吼着前冲，地面震动
  ↓ （因为）怪兽前冲产生了巨大动量
0:02-0:04 女主侧身闪避，借怪兽冲势顺势转身
  ↓ （因为）女主转身产生了攻击角度
0:04-0:06 女主反手一刀，刀锋划过怪兽侧腹
  ↓ （因为）刀锋造成伤害
0:06-0:08 怪兽痛呼，身体前倾，露出背部破绽
```

**错误示例**：
```
0:00-0:02 怪兽前冲
0:02-0:04 女主突然出现在怪兽背后（瞬移，无因果）
0:04-0:06 女主攻击怪兽背部
```

## 铁律三：环境反馈

**核心原则**：每个阶段至少写一处环境反馈（尘土飞扬、金属撞击、沙石崩塌、地面裂纹、碎屑飞溅）。这不是装饰——它告诉模型力量来自哪里，打击感由此落地。

**为什么重要**：
- 环境反馈是"打击感"的视觉化表达
- 它告诉模型"这个动作产生了多大的力量"
- 没有环境反馈的动作会显得"轻飘飘"

**环境反馈词库**：

| 地面材质 | 反馈词汇 |
|----------|----------|
| 沙石 | 尘土飞扬、沙石崩塌、地面裂纹、沙尘暴起 |
| 金属 | 火花四溅、金属撞击声、甲板震颤、铆钉松动 |
| 废墟 | 碎屑飞溅、墙体崩塌、砖石散落、灰尘弥漫 |
| 水面 | 水花四溅、波纹扩散、水雾弥漫、涟漪震荡 |
| 冰面 | 冰屑飞溅、裂纹蔓延、冰面碎裂、寒气蒸腾 |

**正确示例**：
```
0:00-0:02 女主从掩体后方快速探身，手持粒子步枪瞄准前方
  环境反馈：掩体边缘碎石滚落
0:02-0:05 怪兽前冲，女主侧身闪避，同时开枪射击
  环境反馈：怪兽脚步踏碎地面，沙石飞溅
0:05-0:08 子弹击中怪兽肩甲，火花四溅，怪兽被冲击力带偏
  环境反馈：金属撞击声，甲板震颤
```

**错误示例**：
```
0:00-0:02 女主探身瞄准（无环境反馈）
0:02-0:05 怪兽前冲，女主闪避（无环境反馈）
```

## 铁律四：资产锁定

**核心原则**：提示词开头用独立段落声明人物的脸、发型、服装、武器、身体比例**全程不变**。双角色场景必须分别说明每张参考图对应谁。

**为什么重要**：
- AI 视频模型容易在生成过程中"忘记"角色外观
- 资产锁定是"身份一致性"的保障
- 参考图映射防止模型混淆多个角色

**资产锁定段模板**：
```
【资产锁定】
- 女主"岚"：25岁女性，黑色短发，左脸有疤痕，身穿改装战术装甲（深灰色，肩部有红色警示条纹），手持粒子步枪。参考图1 = 女主全身三视图
- 怪兽"伴猎兽"：四足生物，灰色鳞甲，背部有骨刺，红色眼睛。参考图2 = 怪兽全身三视图
```

**群战对手面孔规则**：
```
【对手面孔规则】
- 6只伴猎怪中，每只的头部形状、鳞片颜色、眼睛大小必须各不相同
- 禁止任何对手与女主有相似的面部特征
- 镜头要明确拍出各对手的差异（如特写不同怪兽的头部）
```

## 进阶技巧

### 动作轨迹拆解式描写

关键一击不写结果、写轨迹——四步链条让模型逐帧可执行：

```
空中下落 → 双手高举 → 竖向重劈 → 刀锋正中厚甲
```

### 微慢动作给具体时长

命中瞬间的慢速不写"轻微慢动作"，写具体时长：

```
约 0.2-0.3 秒微慢动作后立刻恢复正常速度
```

每段最多一次微慢动作。

### 动作结果允许失败

打击 ≠ 命中即胜。物理一致的挫败比全程碾压更有可信度：

```
刀砍不进硬甲被弹开，反作用力震飞主角，刀刃卷曲
```

### 结尾必须铺垫下一轮

余韵段不止定帧——给下一段留钩子：

```
车头重新朝向目标、意识到破不了甲、扯下工牌走向出口
```

## 与 H3 IR 的转换

动作打戏提示词转为 H3-Context-IR 时：

1. **时序段** → `integrated_multimodal_description` 中的 `[Shot N]` 时间戳
2. **资产锁定段** → `subject_definitions` 中的角色定义
3. **环境反馈** → 融入主描述的环境描写
4. **音效段** → `overall_soundscape` 中的环境音

**示例转换**：
```
动作打戏提示词：
0:00-0:02 女主探身瞄准，掩体碎石滚落
0:02-0:04 怪兽前冲，地面震动，沙石飞溅

H3 IR：
[Shot 1] At 00:00.000, the camera pushes in toward the female warrior...
[Shot 2] At 00:02.000, the camera cuts to the beast charging forward...
overall_soundscape: Rocks crumbling, ground trembling, debris scattering.
```
