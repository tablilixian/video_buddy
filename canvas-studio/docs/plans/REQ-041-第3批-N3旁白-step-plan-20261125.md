## 1. 目标与硬限制

目标：A9 —— 点开某屏能听到**该屏**的旁白，起点按段帧窗裁剪（第 2 屏不从 0 起）；hover 仍是静音画面。

硬限制：hover 不是用户手势，浏览器不允许带声自动播放（§9.6 ②）。点开是用户手势，可以带声。**这不是设计选择，不要试图绕过。**

## 2. 数据源（两处必须先认清）

1. **旁白在 `build/manifest.json` 的 `audio`**，不在段产物里（段 mp4 无音轨，R11-C3 刻意）。两种形态：`voiceOverUrl`（单句）与 `voiceOver[]`（多句，二者互斥，manifest.ts:2494）。`ManifestVoiceOver` 只有 `{src, startFrame?, volume?}`（manifest.ts:1033）—— **没有时长字段**。
   - ⇒ 每句旁白的时长必须等 `<audio loadedmetadata>` 后从 `audio.duration` 读真值。**不要用「下一句起点」倒推**：短句会比间隔短，倒推会把下一句的静音也算进来。
2. **`deliver/card.json` 没有旁白信息**（`DeliveryCard`，deliverable.ts:180）。所以扩展段清单路由，不新开路由：
   - `src/segment-media.ts` 额外读 `build/manifest.json`（缺失 / 坏 JSON 静默跳过，不给 UI 一张错误卡），回 `fps` + `voiceOver: [{src, startFrame?}]`（**原样透传，不在宿主算时长**）。
   - `src/contracts/segment-media.ts` 加字段；`src/client/api.ts` 与 `use-segment-media.ts` 沿用同一条清单，不改取数次数。
   - 清单仍以段是否存在为过滤前提：段没渲过的卡不挂播放器（第 1 批的诚实失败口径不变）。

**验收前置**：你给的那个验收项目 `audio` 是空的（无旁白）。A9 必须换一个带 `tts_narration` / `audio.voiceOver` 的项目验，不能拿空旁白项目假装通过。

## 3. 细看播放器

- 新组件 `src/client/SegmentDetailOverlay.tsx`。**入口走右键「查看详情」**（分镜卡点击手势已拍板不变：点击 = 选中 / 详情，不改点即播）。在「查看详情」里提供「带声音细看」态。
- 播放内核用原生 `<video muted loop playsInline>` + `<audio>`。不引 Remotion Player：段产物是 mp4，Player 要 bundle + manifest，是绕路；帧步进用 `video.currentTime ± 1/fps` 已够。复用 `RenderPreviewOverlay` 的打开 / 关闭信号与容器样式，**不动它的整片逻辑**。
- 一个段可能命中多句旁白：按段帧窗取交集，当前只挂命中的那一条 `<audio>`；切段换 `src`，不叠多条人声（manifest.ts:2386 已有「caption 自播 + voiceOver 双份人声」告警，细看播放器只按 `manifest.audio` 叠）。

## 4. 同步纯函数（可单测，零 React 依赖）

放共享层 `src/segment-audio-sync.ts`（与第 1 批 `segment-media-map.ts` 同一层，tsc 会 emit 到 `lib/`，测试 import 得到）：

- `audioWindowOf(segment, clip, audioDurationSec, fps)` → `{ offsetSec, playSec }`
  - `clipStart = clip.startFrame ?? 0`
  - `offsetSec = Math.max(0, (segment.startFrame - clipStart) / fps)`
  - `playSec = Math.min(audioDurationSec - offsetSec, segment.frames / fps)`
  - 旁白整句在段窗外 ⇒ 返回 `null`（该屏无声，video 照播）
- `videoToAudioTime(videoTimeSec, segment, offsetSec, fps)` / 反向：video 时间 → 音频真实时间 `offsetSec + (videoTimeSec - segment.startFrame / fps)`。
- `play` / `pause` / `seeked` / `timeupdate` 双向同步；`loop` 回到段首时 `audio.currentTime = offsetSec`。audio 未 loadedmetadata 时静默不播，不抛、不卡住 video。

## 5. 测试（行为断言）

1. 第 2 屏旁白起点 = `(seg2.startFrame - clip.startFrame)/fps`，**不是 0**（A9 的核心断言）。
2. 短句不越界：`playSec` 取 audio 真时长与段时长的较小值。
3. 多句旁白只命中落在该段帧窗的那一条；无交集返回 `null`。
4. fps 非法 / `startFrame` 缺省 → 回退 0，不 NaN。
5. 坏 manifest / 无 audio 的项目回空清单，播放器不出现，Console 无红。
6. 反向变异：把起点写死成 0，A9 测试必须红。

## 6. 风险与不做

- 音频 404 / 跨域：`<audio>` 静默降级为无声，video 照播；不弹错误卡。
- 不给卡加 `voiceOverUrl` / `audioUrl` 持久字段、不写 `canvas.json`（同第 1 批纪律）。
- 不做多卡同时出声；hover 永远静音单例（CV-082）。
