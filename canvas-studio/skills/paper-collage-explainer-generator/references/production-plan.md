# 分册：制作方案与静帧规格（paper-collage-explainer-generator）

> 何时读：拆解输入、写制作方案文档、写某段的静帧视觉规格时。

## 1. 拆解输入

对每一句台词、概念、故事或题材，提取：

- 核心含义：观众应该理解什么。
- 情绪：平静、紧迫、讽刺、惊讶、荒诞、明晰、沉思、神秘或俏皮。
- 动作动词：打开、连接、泄漏、归档、压缩、劈开、照亮、绑定、组装、揭示、坠落、追逐、变形、碰撞。
- 视觉隐喻：一个能表达该想法的具体形象，**不要**把台词写到画面上。
- 关键物件：三到六个大的、可读的纸组。
- 音频含义：该节拍是否适合纸滑入、pop、按压、轻敲、窸窣或 snap 音效。

故事题材拆成三到六个简洁节拍（除非用户指定数量）。相近节拍可以共用设计语言，但每个都要有独立的隐喻、物件组、色场与音效节奏。

## 2. 制作方案文档结构

制作方案文档包含以下部分：

### Brief

- 题材或原始台词。
- 已知的受众 / 使用场景。
- 画幅与时长假设。
- 色调与节奏。
- 视觉风格小结。
- 媒体策略陈述：默认保留或生成拼贴音效；除非用户明确要求，不加 BGM、口播/语音、字幕。
- 有用时的可选项提问：是否要口播、BGM 或字幕——保持它们是可选的。

### 视觉隐喻

每个计划段：

- 核心含义。
- 情绪。
- 一句话视觉命题。
- 三到六个关键物件。
- 建议背景色与点缀色。
- 预计组装顺序。
- 预计拼贴音效时刻（滑入、pop、按压、轻敲、窸窣或 snap）。

### 脚本 / 视觉节拍轨

用户明确要求口播时，写一份简洁口播稿。用户没有明确要求口播时，**不要**写口播稿，改写一份无声的视觉节拍轨，说明观众能从这组画面理解什么。

用户只需要给现有台词配 B-roll 时，把原句作为上下文保留，不要自己编口播。

### 分镜

每段包含：

- 段标题。
- 终帧描述。
- 运动想法。
- 大致时长。
- 拼贴音效想法。
- 风格延续与色彩和谐的备注。

## 3. 静帧视觉规格

每个已确认段写一份紧凑、可直接用于出图的视觉规格。包含：

- 台词含义或故事节拍。
- 视觉隐喻。
- 画幅。
- 背景色场。
- 点缀色。
- 关键物件组与各自作用。
- 构图、前景/中景/背景纵深与负空间。
- 与终帧的关系。
- 风格延续备注。
- 该张静帧专属的避免清单。

配色语义与色板约束见 SKILL.md 的「色彩语义」；不要把钴蓝当自动默认色。
