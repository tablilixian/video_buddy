使用方法

  • 点选项实时切换口径，左栏立即变形；顶部横幅显示当前组合
  • 「套用推荐」一键回 ①A ②A ③A ④B；选择自动保存，刷新不丢
  • 组头可折叠 / 双击重命名；段头「＋」新建分组；行 hover 出「⋯」
  • 技能 / 资产（及②C 时的灵感）会开示意浮层，Esc 或 ✕ 关闭
  • 折叠加「预览设计图原始态」＝设计图所示的扁平形态

已定口径（无需拍板）

  • Credits 纯展示占位（2026-10-07 已拍）；升级套餐置灰「即将上线」
  • 「＋创作」= 跳首页创作台（D4：新建入口唯一）
  • 技能 / 资产 = 接现有浮层的纯增量入口
  • 段头「刷新」按钮摘除（错误卡仍有重试）
  • ①A 下不单独渲染「未分组」小节头（「项目」头即其标题）
  • hover / 选中 / 空态等未定义处沿用现有交互惯例
