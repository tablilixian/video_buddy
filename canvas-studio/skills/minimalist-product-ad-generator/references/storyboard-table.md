# 分册：节拍分镜表（minimalist-product-ad-generator）

> 何时读：锚点照定下之后、出任何视频片段之前，必须先产出并逐字读回这张表。
> 这张表是视频模型的执行表，不是美术稿；分镜格式的通用纪律以 `canvas-studio-creation/references/shot-format.md` 为准，本册只给本风格的列与节拍细则。

## 1. 表格组织方式

按「用户选择陈述 → 节拍内容 → 原则」组织。

### 用户选择陈述

写清已确认的风格、画幅、时长、叙事骨架、主变体、产品主色、变体策略与文案。例：

> White-tech style, 16:9, 10 seconds, Color Family spine, purple as the main variant, other colors as supporting layers, copy: Color Meets Sound.

### 节拍内容表

推荐列：

| Time range | Shot | Shot purpose | Visual lead | Visual / camera move | Variant state | Copy | Text color | Text effect | Transition / continuity | Rhythm intent |
|---|---|---|---|---|---|---|---|---|---|---|

## 2. 表格规则

- 5s 建议 3-4 个节拍；10s 建议 5-7 个；15s 建议 6-9 个。
- 时间范围用秒，不要要求帧号。
- 一拍一个主动作；次要层稍晚出现。
- 明确写出主变体何时独现、辅助变体何时入场、全系列何时收尾。
- 文案拆分只用自然语言写"前半/后半"。**禁止**写箭头、斜杠、加号或分隔符——模型可能把它们当成画内文案渲染出来。
- 文字颜色必须用具体产品色名，并按风格拆开写：白科技风写"前半黑或深灰、后半具体产品色"；只有暗轮廓光风前半才可白。例：白科技风 + 紫色主色 → "前半黑或深灰，后半紫色"。不要写"产品色 + 黑或白"。
- 文字容易出错时先砍文字节拍：10s 片通常只用一次片中文案 + 一次终版文案，其余节拍标"无文字"。不要每个镜头都上字。
- 终版节拍必须是稳定的满幅产品收尾 + 完整单行文案。绝不以四宫格、分屏、分镜板、锚点拼版、产品小窗或画框网格收尾。文字仍属垂直居中的构图区（左对齐或右对齐），不是下方字幕位。只有用户提供了才加 Logo。

节奏意图词汇表：setup、establish、prepare、impact、brake、settle。

## 3. 九条原则

1. 核心文字保持单行。
2. 任何一个时刻只有一行单行英文文案；禁止两行文字、上下拆行、标题+副标题组合、多个文字块并存。
3. 恰好两种文字颜色：黑或白 + 已确定的具体产品色。
4. 文字必须出现在视频里；不能只依赖后期兜底。
5. 镜头连续性 = 元素连续性 + 运动连续性 + 形态连续性。
6. 顺滑度 = 缓动 + 无尴尬时机 + 无缝进出场。
7. 整体节奏跟随用户选定的时长。
8. 文字动效必须可见：前半先轻微淡入/滑入，后半稍后淡入/滑入；后半出现时前半在同一行内轻微让位。不要把文字做成完全静止，也不要拆成上下两行。
9. 风格已确认时，表格必须严格遵循该风格。
