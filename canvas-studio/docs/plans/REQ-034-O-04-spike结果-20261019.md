## 二、数据明细

环境：Electron `43.4.0` / Chrome `150.0.7871.224` / Node `24.18.1`，macOS 本机。
样本：`480×270 · 30fps · 30 帧`，轨道 = 满画布渐变 `shape` + 一条真实 `<video>`（ffmpeg testsrc2 2s）+ 一张带动画的标题卡；抽帧位置 `0 / 15 / 29`。

### Q2（rAF，同一 10 秒窗口）

| 窗口 | 帧数 | ticks/s |
|---|---|---|
| 可见窗口（默认节流，最小化） | 34 | 3 |
| 隐藏窗口（`backgroundThrottling:false`） | **590** | **59** |

这就是真机「切走页面就静默挂死」的机制复现：**节流开 ⇒ 3/s（等于停摆）；关上 ⇒ 满帧**。

### Q3（渲染）

| 窗口 | ok | msPerFrame | mp4 字节 | 抽帧 |
|---|---|---|---|---|
| 可见 | ✅ | 225.7 | 44,611 | 3 |
| 隐藏 | ✅ | **352.2** | 44,619 | 3 |

### Q4（逐像素）

```
frame 0  : 52d1696f…5739f  （可见#1 = 可见#2 = 隐藏）
frame 15 : a8cc1281…5fee7  （可见#1 = 可见#2 = 隐藏）
frame 29 : 540dfcb6…db96f  （可见#1 = 可见#2 = 隐藏）
mp4 字节哈希：可见 ≠ 隐藏（44611 vs 44619 字节）
```

三次渲染的**抽帧 PNG 逐字节相同**（PNG 由 `OffscreenCanvas.convertToBlob` 产出，同一份 RGBA ⇒ 同一串字节 ⇒ 哈希相等即像素相等），而 **mp4 文件哈希不同**。

## 三、对方案的三条直接影响

1. **Q4 PASS ⇒ O-05/O-06 按原计划做**：不必把预览面板也搬进 RenderHost。用户页继续承担预览快渲（`render-preview.ts`），RenderHost 只接成片工单。
2. **隐藏窗口慢 1.56×（352 vs 226 ms/帧）⇒ 别把「后台渲得更快」写进文案**。这轮 30 帧样本的耗时噪声较大（首帧编码器初始化占比高），但它足以说明「隐藏窗口不保证更快」，进度条与超时口径按**实测速度**算，不按乐观值算。
3. **mp4 字节不可作为确定性断言**：方案 §6 的 **A7「同 manifest 渲两次哈希一致」在当前实现下不成立**（编码器容器时间戳/码流不保证逐字节复现）。确定性校验必须落在**抽帧像素**（或解码后帧比对）上，不能拿文件哈希当闸。

## 四、未覆盖 / 残留风险（S1 前必须补）

| # | 风险 | 说明 |
|---|---|---|
| **R1** | Q1 只验到「独立 Electron main」这一层 | dsh 装了 `installProfilePackageResolver`（自定义模块解析）。真正的判据是 **canvas-studio 的 Host 模块（`lib/index.js`，由 Cordis 载入）里能不能取到 `electron`**。补法：加一个 env 门控探针，在真实 app 里打一行 `app.getVersion()`；三级退化（`createRequire` → `process.mainModule.require` → `ctx.desktopRuntime`）仍按方案保留 |
| **R2** | 样本过小 | 480×270 / 30 帧 / 3 个抽帧点 / 无音频 / 无转场。真实成片 1280×720、600 帧、含 BGM 与转场 ⇒ S1 验收要再用一条真 manifest 复跑 Q3/Q4（≥8 抽帧点） |
| **R3** | GPU 路径未锁定 | 本轮没固定 `hardwareAcceleration`；若用户机器编码器走软编，两窗口一致性结论仍成立（都是软编），但**速度基线会变** |
| **R4** | 隐藏窗口的 `show:false` vs `offscreen:true` 未对比 | 本轮只验 `show:false` 路径（正是方案要用的那个）。`offscreen` 作为退化路径未测 |
| **R5** | 沙箱噪声 | 本机受管 shell 里 Electron 报 `SandboxOriginDatabase ... Access denied`，属环境（`~/Library/Application Support/Electron` 的删除被拦），不影响四问结论 |
