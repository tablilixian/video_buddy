# REQ-036 爆款复刻 —— 需求转化计划（2026-10-31）

> **需求来源**：用户提供的微信文章（OiiOii「全能复刻」，2026-10-31）。核心主张：Agent 拆解爆款视频 → **Code2Video**（写一个会自己动的网页 → 浏览器逐帧截图拼成视频，界面/文案/动效部分）+ **视频模型**（食物/产品/人物等实拍画面）混合管线；局部改稿零成本重渲；一条爆款批量换产品换文案。
> **用户问题**：「如果想要复刻里面的内容，咱们目前的项目的能力，能否复刻出来」→ 2026-10-31 能力对照结论：**核心管线同构（manifest→CSR 逐帧渲染 = Code2Video 的工程化形态），8 项具备 / 2 项缺口**；用户拍板把缺口转成开发计划（本档）。
> **登记**：tracking.md §二 REQ-036；渲染层转化线的既有能力全部走 CV-385~390（治理补账，见 STATUS §4.1）。

## 二、子项拆解

### R-1 爆款复刻编排 skill（skill 层，估 1–2 天）

- **目标**：给一条参考视频（文件/链接），产出复刻 manifest → 渲成片 → 换素材换文案批量出片。它是把现有渲染能力变成「复刻生产力」的临门一脚。
- **内容五件**：
  1. **拆解清单**：镜头节奏表（每镜时长 / 内容类型 / 转场 / 字幕形态），可借助既有 inspect_image / 抽帧真值；
  2. **映射表**：节奏 ↔ 轨道与 `durationInFrames`；转场 ↔ TransitionEffect 全表（11 式 + clock-poly）；字幕 ↔ caption（词级）/ textCard（句级）；信息卡 ↔ chart / shape；实拍段 ↔ video/image 轨（素材占位先行，§07 素材清单 + CV-369 就绪门禁复用）；
  3. **素材替换清单**：placeholder 优先，逐项标注来源（generated/user/library）；
  4. **批量参数化**：同一 manifest 骨架 × 多套「素材/文案」变量，会话内循环出片（D-R3）；
  5. **验收对照**：原片 vs 复刻片并排 5 项（节奏 / 转场 / 字幕 / 信息卡 / 整体观感）。
- **落点形态**（D-R1，预拍板建议：**独立 skill**，如 `viral-remake`，触发词「复刻/拆解这条视频」；理由：与 `code-driven-explainer` 触发场景不同，混入会稀释两边触发）。
- **约束**：skill 层（skills/** + 文档）不触 src/**，可在当前桌面验收窗口内开工。

### R-2 image 轨 sprite 子区域裁切（渲染层，估 0.5–1 天）

- **字段设计**（D-R2，预拍板建议）：ImageTrack 新增 `sourceRect: { x, y, w, h }`，**百分比 0–100、与 box 同口径**；缺省 = 整图（老 manifest 零影响）。
- **实现约束**（CSR 写法护栏，bench 已证）：不用 `background-position`（`backgroundImage: url()` 不等待加载）；用容器 overflow hidden + 内层 `<Img>` 偏移缩放实现（纯 DOM，渲染器白名单内）。
- **校验**：数值域 0–100、`x+w ≤ 100` / `y+h ≤ 100` 越界拒收；`manifest-contract.md` 同步；L2 模板全链（schema → 组件 → 单测 → skill → 棘轮显式登记）。
- **约束**：触 src/** → **必须等当前桌面验收窗口结束再开工**（用户正在验收，验收窗不改产品代码）。

### R-3 素材供给（无开发）

- 食物/产品实拍感素材 = 现有生图/生视频工具链（后端模型）；精灵图可先由 Agent 预裁切（inspect_image 定位 + 上传裁切产物），R-2 落地后省掉这一步。

## 三、依赖与顺序

- R-1 ∥ R-2 无相互依赖，可并行。
- R-1 可即开工（验收窗口内）；R-2 等验收窗口结束。
- **质量上限前置**：若目标样片的风格重度依赖 conic mask / mix-blend-mode / perspective（bench 归因 A2/A9 渲染器边界），需先落 C2 html-in-canvas 档（P1 既有队列项）再复刻该片；否则直接做。

## 四、验收出口

- **R-1**：真机全流程一次跑通——参考视频 → 拆解清单 → manifest → `render_composition` 出片 → 换一套素材/文案再出一版；对照 5 项逐项 PASS。
- **R-2**：一张精灵图 3 个子区域 3 条轨同片渲染正确；越界 sourceRect 拒收；单测 + 反向变异；棘轮登记。
- **整体**：一条 15s 爆款复刻样片（placeholder 素材）出片。

## 五、决策点（预拍板建议，不阻塞开工）

| # | 问题 | 建议 | 理由 |
|---|---|---|---|
| D-R1 | 复刻 skill 独立 vs 并入 code-driven-explainer | 独立 | 触发场景不同（用户给参考视频），混入稀释触发 |
