# 风格库（预设出口的纯知识扩展层；30 条风格行）

> **定位**：`style-presets.md` 的 11 条预设只覆盖「有专属流水线」的组合；本册是**没有流水线的纯知识风格行**——每行只给一份可直接复用的 5 项 Look tokens + 风格段写法，**不配 skill、不配 GIF、不进预设网格**。
> **加载规则**：选中本册任何风格行都**不加载任何风格 skill**（= `style-presets.md` 加载规则表第 3 行「否」）——没有流水线可加载，硬加载只会把错误流程套上去。
> **接线**：预设出口见 `references/style-presets.md`；澄清 ②-3 见 `references/clarification.md`；5 项 tokens 规格、样张与落卡规则见 `references/look.md`（**执行前必读**）。
> **收录 30 条纯知识风格行（8 类）**——头部计数与表内行数由 `tests/style-library.test.mjs` 对账，增删行必须同步改这里。

## 1. 什么时候用（两条通路）

1. **命中即用（②-1 反推比对）**：用户原话能对上本册某行（「来点黑色电影的感觉」）→ 直接取该行 tokens **逐字**用作 ②-1 的 5 项 tokens，Look 来源标「风格库」，不再让用户重新描述；②-2 样张与 `look_card` 落卡照常走。
2. **出口分批浏览（②-3，11 条预设没命中时才摆）**：按类分批用 `ask_user_choice` 点选——每轮 ≤4 个选项、一次只问一轮，**不要把 30 行一次倒给用户**；选中后回到第 1 条同一条路径。

**三层风格体系的分工（别摆错层）**：

| 层 | 数量 | 载体 | 何时用 |
| --- | --- | --- | --- |
| 成片预设（style-presets.md） | 11 | 预设行 ↔ 风格 skill 1:1，带 GIF 网格 | 有专属流水线的品类 |
| 视觉风格（src/visual-styles.ts） | 12 | 图像生成的风格前缀，画布「风格」弹层 | **单张图**的画法（定妆 / 样张），不决定成片 |
| 风格库（本册） | 30 | 纯知识 Look 行 | 长尾风格：只需要可复用的视觉约束，不需要流水线 |

三张表**名字互不相撞**（门禁：本册守卫 `tests/style-library.test.mjs` + 图像层 `tests/visual-styles.test.mjs` D1-2）。

## 2. 选中之后（与 CV-151 资产路径完全同路）

把该行「Look tokens」整理成 **5 行**（`色彩：…` / `光线：…` / `材质：…` / `镜头语汇：…` / `节奏：…` 各一行）→ ②-2 出 1 张基调样张 → 用户认了调 `look_card` 落卡（`name` 用「Look · <风格名>」）→ 之后逐镜注入与 ②-1 完全同路，tokens 在 prompt 里逐字节复用。

- **不加载任何风格 skill**（本册没有 skill 可加载）；**不进 `STYLE_DEMO_MAP` 预设网格**（没有 GIF，点选走普通文字选项）。
- tokens 里**不写风格名**（`look.md` §8 硬约束 2），不写画幅与时长（那是澄清第 ③ 步）。
- 风格约束写进每镜 prompt 的**风格开关段**：整体声明放最前、只声明一次、中途不切换（写法见 `h3-prompt-writing`）。

## 4. 扩容流程（新增一条风格行）

1. **取名**：与本册已有行、11 条成片预设、12 条视觉风格**零重名**（防撞由 `tests/style-library.test.mjs` 守，撞了直接红）。
2. **归类**：挂进 §3 的 8 类之一（新类才动类标题与计数说明）。
3. **写 4 列**：风格（≤8 字短标签）/ 适用 / Look tokens（5 项字段齐全、顺序固定、正向表述，不写风格名、画幅与时长）/ 风格段与镜头要点（风格开关段前置一句 + 转场或运镜注意）。
4. **改头部计数**（第 4 行的「30 条」）——漏改即被对账测试抓红。
5. **跑验证链**：`corepack yarn typecheck && corepack yarn build && corepack yarn verify:loader && corepack yarn test:smoke`，提交信息带 CV 号。

**什么时候该升级成真正的 skill（而不是继续加行）**：某风格开始需要**自己的流程**（分镜骨架、专属门禁、逐镜约束）时，按 `docs/skill-expansion-spec.md` §3/§5 走完整扩 skill 流程（建目录 + `platform.yaml` + 预设表加行 + GIF 按需）。**行是知识，skill 是流水线，别互相越界**——本册永不承载流程。
