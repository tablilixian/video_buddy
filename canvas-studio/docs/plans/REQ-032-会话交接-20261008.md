## 九、方案已定案的核心设计（实施时直接照做，勿再讨论）

1. **描述区 token-lite**：结构化词条 chips（可 ×）+ 自由文本 textarea 混排——**不用** contenteditable、**不用** image/video 的纯文本插入反解（`低沉` 跨维重名：音色质感×音高，反解有歧义）。显示与 `instruct_prompt` 同一 `composeSpeechInstruct`（所见即所投）。
2. **卡状态写通**：`{fn, sel, free, body, lyrics, lyricsOn, ref}` 七元组每次变更即时写 `generationPrompt`（区别 image/video 草稿-发送二段；理由：结构化状态须跨开关存活）。参数键形：tts `{txt_prompt, instruct_prompt, refaudio?, voice_sel?, voice_free?, fn}`、music `{caption_prompt, lyrics_prompt?, duration, fn}`（`fn` 区分 voice/design 子形态，host 忽略）。
