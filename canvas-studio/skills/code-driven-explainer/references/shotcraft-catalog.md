## camera（10 张） — 相机与运镜

### sc-basic-3d-scene(空间卡片巡游)
- **一句话**:卡片带姿态散布 3D 空间,相机逐站飞行对齐,末步拉远总览
- **能量**:中(转场有空间惊喜,停留段安静读卡) · **时长**:约 6s(180f,四站三段飞行各约 1s)
- **典型参数**:站点姿态: 每站至少一个新变换维度; OVERVIEW 缩放: s=3.1(相机拉远 1/3.1); perspective: 1000px(与最大 |z| 约 2:1)
- **调节手感**:rz 画框旋转站是记忆点,一支片用一次
- **已知坑**:逆变换旋转顺序(Z→Y→X 反序)乱不得,多轴复合站会歪;rz90° 站卡内文字跟着躺倒,文案要短
- **我们能不能做**:暂缓(真 3D 场景树:多卡各持 x/y/z/rx/ry/rz 姿态 + 相机取逆飞行,缺 per-card 独立 z 纵深与真透视遮挡)。伪 3D 近似:RQ-24 预合成整页散布图后用 image.camera 多段 keys 逐站飞行(x/y/zoom/rotX/rotY/rotZ/persp),离焦卡靠预烘焙压暗/虚化——"世界跟着转正"的多卡语义打折
- **走哪条轨道**:暂缓;近似路线 = image.camera keys 逐站插值 + 预合成散布图 + 聚焦/离焦预烘焙;真场景树待 three 轨道

### sc-crash-zoom-punch(急推点名)
- **一句话**:全景一拍急推砸到目标特写,落位回弹或撞停震屏二选一
- **能量**:高(瞬时冲击,非持续) · **时长**:动作 6–11f + 前 hold ≥30f / 后 hold ≥45f
- **典型参数**:急推时长: 6f(4–8f); 目标 zoom: 2.4–2.8; 震屏包络: 14px·e^(−t/1.8),6f 收干
- **调节手感**:急推 >10f 读作普通推近,冲击感消失
- **已知坑**:终点必须高清纹理(低倍截图糊字,先栅格化);一支片急推 ≤2 次,回弹与震屏两款别混用
- **我们能不能做**:能(2D 轻量):急推/回弹 = image.camera keys 段内 ease-in + 过冲回收 key;撞停震屏 = 逐帧 x/y keys 拟指数衰减(6f 每帧一键);急推段运动模糊无对应层,省略或预生成
- **走哪条轨道**:image.camera keys(zoom 1→2.6 + x/y 收敛 ease-in;回弹款加 3–6% 过冲段;震屏款逐帧 x/y 抖动 keys),终点用 RQ-24 高清截图

### sc-cursor-flyover(光标巡览)
- **一句话**:整页俯瞰淡入,相机依次飞四角特写,光标同步指点并落点击涟漪
- **能量**:中(匀速巡航,涟漪打拍) · **时长**:约 6s(俯瞰 1.2s + 四步各 0.7s 过渡加停留)
- **典型参数**:特写倍率: s=1.72(俯瞰 0.8); 步进节奏: 过渡 0.12/停留 0.08; 点击涟漪: 0.055,scale 0.3→1.9
- **调节手感**:停留短于 0.05 变"扫过",没有"参观"感
- **已知坑**:光标落点与 tx/ty 按真实截图重标,换宽高比整表重标;停留段可加 ≤1px 呼吸位移防"卡住"
- **我们能不能做**:能(2D 轻量):相机查表步进 = image.camera 五站 keys(x/y/zoom,inOutCubic);光标 = 预生成箭头素材轨,animate 与相机同表 waypoints + scale(1/s) 补偿;涟漪 = shape:'path' 描边圆环或预生成环 PNG;开场 blur 淡入用淡入近似
- **走哪条轨道**:image.camera keys(俯瞰 0.8→四角 1.72,过渡/停留交替)+ 光标 image 轨 animate 同步 + shape:'path' 涟漪 + audio.sfx click 四连

### sc-depth-layer-moves(分层深度运镜)
- **一句话**:三层视差横移出纵深;伪 dolly-zoom 主体钉死、背景膨胀压来
- **能量**:视差=中 / dolly=中高 · **时长**:视差 4–5s 持续;dolly 3–4s 单向
- **典型参数**:视差层系数: 0.35/0.7/1.4; dolly 膨胀行程: scale 1→2.0–2.5; 背景 opacity: ≤0.6 防读作故障
- **调节手感**:层间梯度 ≥2 倍才可辨;层数 ≤4 防过载
- **已知坑**:主阅读层/主体必须高清无 blur;视差×3D 斜拍组合未验证;dolly 一支片 ≤1 次
- **我们能不能做**:近似(能做):多层 = 整页按层切片(RQ-24)+ 各 image 轨 animate 同一位移乘不同系数;层间 blur/降饱和/透明度锚无逐轨滤镜 → 预烘焙进各层素材;dolly 款主体独立 image 轨钉屏,背景轨 animate scale 1→2.25,主体落影用预生成影
- **走哪条轨道**:分层 image 轨 ×3 animate(x 各乘 0.35/0.7/1.4,blur/降饱和预烘焙);dolly:主体轨静态 + 背景轨 animate scale,shape:'vignette' 收氛围

### sc-graze-face-tour(贴面游走)
- **一句话**:大倾角贴面掠过 UI,文字悬空带同形软影,随镜头行进先后贴落
- **能量**:中高(运镜推进+连续落位) · **时长**:单段 4–5s,可多段接力
- **典型参数**:悬浮高度: 120–180px; 贴落错峰: 按行进方向 0.2→0.85; 段间接力: 交叉淡化 ≥8f
- **调节手感**:错峰=起点错开、下落并行;串行等待被裁
- **已知坑**:空中元素提亮 ~1.3x 防被压黑带吞;巡礼镜必须错峰并行、整体登场镜才全体齐落,选错语法两边都被裁
- **我们能不能做**:近似(能做):贴面机位 = image.camera keys(rotX/rotY 大倾角 + x/y/zoom 推进 + persp),远处渐虚靠预烘焙或省略;文字贴落 = textCard fadeUp(offsetY 大值 + wordDelayFrames 错峰);同形软影随高度收敛做不了 → fx:'shadow' 恒定影或预生成,写明近似
- **走哪条轨道**:image.camera keys(倾角 + 推进)+ textCard fadeUp/wordDelayFrames 错峰贴落 + fx:'shadow';接力段 transition fade ≥8f

### sc-overhead-camera-moves(俯拍揭示两式)
- **一句话**:A 整页平躺抬头揭示;B 桌面卡阵俯拍横滑,猛扎入选中页抬正
- **能量**:A 中 / B 中高 · **时长**:A 约 4.8s / B 约 4.7s
- **典型参数**:A rotateX: -80° 平躺→0 抬正(约 43f); B rotateX: 62° 俯拍; drop 段: 角度/缩放/位移三通道同跑
- **调节手感**:rotateX/scale/translateY 共用 out-cubic,末端轻过冲
- **已知坑**:原卡未设「已知坑」节;约束在选型表内——A 末端轻过冲、B drop 三通道同跑
- **我们能不能做**:能(2D 轻量):A = image.camera keys(rotX -80→0 + translateY/zoom 同段插值,out-cubic + 轻过冲 key);B = 预合成卡阵图后 rotX 62° + x 横滑,drop 段 rotX/zoom/x 同一 key 段内天然同拍——"三通道同跑"是 keys 原生优势
- **走哪条轨道**:image.camera keys(A:rotX/zoom/translateY 单段 out-cubic;B:rotX 62 + x pan → rotX 0 + zoom 收拢一气呵成)+ B 需 RQ-24 多页合成卡阵图

### sc-space-camera-moves(空间大动作运镜)
- **一句话**:构件沿 Z 错峰炸开再合体震屏;俯角俯冲气垫减速落 hero 特写
- **能量**:高 · **时长**:A 5s(炸开-悬停-合体);C 3–5s 单向俯冲
- **典型参数**:A 炸开: translateZ 60–320px 错峰 3f,ease-out-back(1.7); C 行程: rotX 72°→0 + scale 0.42→1.35; C 速度: 主俯冲 82% in-cubic + 气垫 18% out-poly(5)
- **调节手感**:一条 p=一次机动;分开驱动读作三个动画打架
- **已知坑**:构件须切块截图,整页一张图炸不开;C 终点特写先高清栅格化;无 Easing.quint,写 poly(5)
- **我们能不能做**:近似(能做):C 原生——image.camera keys(rotX/zoom/x/y 同段插值,82/18 双段 easing),运动模糊缺 → 省略或预生成,落地软影用 shape:'gradient' 径向;A 伪 3D——group 静态 rotateX/rotateY/persp 倾角基座 + 构件切片各 image 轨 animate 径向位移×scale 拟 translateZ,深度锚(投影/亮度)预烘焙,z 遮挡靠轨序
- **走哪条轨道**:C:image.camera keys 双段(82% in-cubic / 18% out-poly(5))+ shape:'gradient' 软影;A:group 倾角容器 + 构件 image 轨 animate(back 炸开、逆序合体 + 折线震屏)+ 预烘焙深度锚

### sc-steep-tilt-glide(侧立滑移)
- **一句话**:页面侧立 60° 强透视成斜墙,镜头钉死,页面自沿横面滑移掠过
- **能量**:中高(透视炫技,节奏匀) · **时长**:4s(120f)单镜,页面越宽越长
- **典型参数**:倾斜角: rotateY -60°(实战 55–65°); 滑移曲线: 尾段斜率不归零的 bezier; 页面宽度: ≥3 屏内容
- **调节手感**:命门:镜头全常数、页面自移
- **已知坑**:角度守 55–65°,出区间等于换手法;滑移中途停死会被裁;与贴面游走卡同段二选一
- **我们能不能做**:能(2D 轻量):image.camera keys(rotY -60/rotZ -2/persp 1100 全程恒定,x 段内滑移)——对平面截图,相机平移与页面自移像素等价,语义按"物动镜不动"标注;速度重影 = 同素材滞后双轨低透明度或预生成;揭亮 = colorShift;悬空贴落 = textCard fadeUp 错峰近似
- **走哪条轨道**:image.camera keys(rotY/rotZ/persp 恒 + x 多 key 拟尾段不归零 bezier)+ 滞后重影轨 + textCard fadeUp 贴落 + colorShift 揭亮;超宽页面用真实长截图

### sc-tension-camera-moves(情绪运镜四式)
- **一句话**:四式情绪镜:冻结环绕、斜角滚正、慢推蓄力、后拉孤立收束
- **能量**:A 高/B 中/C 低压升/D 低收 · **时长**:单式 4–5s;全片 ≤2 式各 1 次
- **典型参数**:A 环绕: rotateY 0→55°→0,顶点悬停约 10f; B 滚正: -10° 过冲 +1.2° 后 14f 收回; D 后拉: zoom 2.2→0.62 / 110f out-cubic
- **调节手感**:双时钟命门:冻结期内容肉眼完全静止,相机却在动
- **已知坑**:C 前段极缓是设计,验收看完整播放;同镜别叠 speed-ramp 类时间操纵;D 与 outro 一收一放二选一
- **我们能不能做**:能(2D 轻量):A = image.camera rotY 双段 + zoom keys,冻结用预生成图表中态帧;B = rotZ keys(-10 + 正弦微漂多 key + 单次过冲);C = zoom in-quad keys + shape:'vignette' 渐深 + 顶点零过渡硬切;D = zoom out-cubic + 兄弟卡分轨 animate opacity 按距离错峰熄灭(亮度衰减预烘焙暗版)+ 主卡光晕 shape:'gradient' 径向近似
- **走哪条轨道**:image.camera keys(四式各自 rotY/rotZ/zoom 行程)+ vignette 轨(C)+ 黑 rect 轨沉黑(D)+ 卡片分轨 opacity 熄灭(D);A 冻结帧预生成

### sc-terminal-3d(终端空间流)
- **一句话**:三终端窗散布空间,相机逐窗飞访,到站敲命令、输出逐行滑出
- **能量**:中(飞行给动感,打字给节奏) · **时长**:约 6s(三站各约 1.6s 停留 + 0.85s 飞行)
- **典型参数**:拉远鼓包: sin(π)×210px; 飞行/停留比: 0.14/0.20; 聚焦衰减: /420px,blur 峰值 2.2px
- **调节手感**:窗姿态角度差是散布感来源,全朝正前退化成平面轮播
- **已知坑**:窗姿态与相机变换须严格互逆,只改 pose 数据;打字都排在到站后;末窗留 ≥0.04 尾量防切黑
- **我们能不能做**:近似(能做):三窗 = 三 image 轨(素材带静态 rotateY 姿态),相机飞行改写为各轨 animate 逆动(世界动、镜不动,平面下像素等价),拉远鼓包 = 多段 animate scale;距离聚焦只做 opacity/brightness,动态 blur 缺 → 预烘焙虚化版或省略;打字机 = textCard typewriter(等间隔近似,逐字符非等间隔时序没有),输出行 = 分行 textCard fadeUp 错峰
- **走哪条轨道**:三 image 轨 animate 逆动(x/y/scale 多段,含 sin 鼓包)+ textCard typewriter + 行级 textCard fadeUp;离焦 blur 预烘焙;命令保持"命令短、输出 3–4 行"

### sc-avatar-grid-radial-build-colorize(网格分环生长染色)
- **一句话**:8×7 小卡网格由中心分环生长铺满,约 15% 卡片随后陆续染红标异常,标题图例居中
- **能量**:中(生长有节奏,染色段是安静的"发现"时刻) · **时长**:约 5.6s(铺满 ~1.2s · 染色段陆续浮现)
- **典型参数**:异常比例: 15%; 生长速度: 每环 4 帧 + 3 帧抖动; 染色窗口: 每张 0.036 散布 0.30–0.60
- **调节手感**:同环 3 帧随机抖动不可省,砍掉后波前整齐得像机器
- **已知坑**:染色三通道(底/描边/点)须同一曲线驱动,分开会"点红了底还白";中央留空保留占位,删格会让环心偏移生长波变形
- **我们能不能做**:近似(38 格同构卡可拼;分环 stagger 与随机染色靠逐格延迟表手工排程)
- **走哪条轨道**:assetGrid(或 shape:'rect'×38 网格)+ 逐格 animate(opacity+scale 入场延迟表);染色=逐格叠加红色 rect 或色变 animate;标题 textCard + 图例 chipRow

### sc-before-after-slider-scrub(前后对比拉杆)
- **一句话**:处理前后两版画面叠放,分割杆先猛甩过冲再慢扫回看,杆过处新版显影揭出
- **能量**:中(快甩是打击点,慢扫是阅读期) · **时长**:4–5s
- **典型参数**:速度比: 快甩 12f / 慢扫 48f(约 5:1); 快甩行程: 8%→76% 过冲回 70%; 慢扫终点: 40%
- **调节手感**:速度比 <3:1 节奏对比不可感
- **已知坑**:两版必须同布局同机位,否则读作两个页面;慢扫终点停 40% 别归零,留一段 after 定格
- **我们能不能做**:能(原生)
- **走哪条轨道**:before/after 双 image 叠放,after 层用 reveal 分区揭示跟随杆位;分割杆 shape:'rect'+animate 三段(快甩/回弹/慢扫);BEFORE/AFTER 角标 textCard;whoosh/tick 音 audio.sfx

### sc-chart-live-moves(活体图表三式)
- **一句话**:活体图表三式:示波流线实时写入、点阵迁徙聚成大数字、新值冲破图表逼轴重标
- **能量**:中高(数据即剧情) · **时长**:各 4–6s
- **典型参数**:A 流速: 8px/f; B 点数/点径: 320/9px; C 冲出幅度: 卡顶外 220px
- **调节手感**:真语境是入库前提:真标题/轴标/单位/读数,灰阶版测不出表达力
- **已知坑**:三式是独立手法,同片各 ≤1 次且错开段落;A 尖峰与 C 重标只能发生一次,重复即廉价
- **我们能不能做**:近似(A 预绘长波形平移+尖峰段多段变幅可拼;C 双状态 chart+刻度交叉换可拼;B 320 点远超 shape 手拼 ≤20 元素上限 → 缩点示意或暂缓)
- **走哪条轨道**:A: shape:'path' 长波形+animate translateX 平移+尖峰段多段 animate;B: ≤20 颗 shape:'circle'+animate 三幕迁徙(spring 错峰)+textCard 标签/数字;C: chart(线)两段状态+textCard 刻度交叉换+animate 冲出框

### sc-counter-confetti(计数彩纸)
- **一句话**:大数字冲刺计数带过冲,到位前 5 帧彩纸两侧炸入,冲击环扩散收尾
- **能量**:高(计数蓄力+爆点释放,情绪峰值镜头) · **时长**:约 4.6s(计数 0.3–2.6s · 纸屑 2.4s 起)
- **典型参数**:计数曲线: easeOutQuart 0.06–0.56; 抢拍量: 提前 0.04; 纸屑数量: 52 片
- **调节手感**:抢拍提前 0–0.02 读作同拍,>0.08 纸屑像别人的庆祝
