## 2. GT 复现步骤（ffmpeg 7.1.1 可用版）

官方 `render.mjs` 用到 `scale=in_primaries=...:in_transfer=...`，**这是 ffmpeg 8.x 才有的选项**，本机 7.1.1 会在第 0 帧 EPIPE 崩溃。处置：另写 `render-local.mjs`，**只替换编码端滤镜串**（模板 `core/` 与 `render.mjs` 一字未改，`integrity.json` 329 个文件 SHA-256 逐个校验零不匹配）。

```sh
cd /tmp/motion_probe_2026/x
python3 -m venv .venv && .venv/bin/pip install numpy scipy soundfile pyloudnorm jsonschema
npm ci                                  # playwright-core
.venv/bin/python adapter.py plan    --input ../run/user.json --out ../run/plan.json
.venv/bin/python adapter.py prepare --input ../run/user.json --out ../run/instance
.venv/bin/python adapter.py preview --instance ../run/instance --out ../run/preview_t2.png --time 2
node /tmp/motion_probe_2026/render-local.mjs --root run/instance --out-dir run/frames_out
ffmpeg -y -framerate 60 -i <frames>/%05d.jpg \
  -vf "scale=in_range=full:out_color_matrix=bt709:out_range=full,format=yuv444p,colorspace=ispace=bt709:irange=pc:iprimaries=bt709:itrc=srgb:space=bt709:range=tv:primaries=bt709:trc=bt709:format=yuv420p,sidedata=mode=delete" \
  -c:v libx264 -preset veryfast -crf 18 -pix_fmt yuv420p \
  -color_primaries bt709 -color_trc bt709 -colorspace bt709 -color_range tv -movflags +faststart ../run/silent.mp4
.venv/bin/python mix.py --instance ../run/instance --silent-video ../run/silent.mp4
```

**7.1.1 vs 8.x 的滤镜差异（记住这条，别再踩）**：7.1.1 的 `scale` 滤镜只支持 `in_range` / `out_range` / `in_color_matrix` / `out_color_matrix`，**不支持** `in_primaries` / `in_transfer` / `out_primaries` / `out_transfer`。

## 7. 复刻这套东西时踩过的坑（别再踩第二遍）

1. **ffmpeg 8.x 专属滤镜**：官方 `render.mjs` 在 7.1.1 上第 0 帧 EPIPE → 用 `render-local.mjs` 只换编码端滤镜串，模板源码零改动。
2. **`uv` 缺失**：`adapter.py` 用 PEP 723 声明依赖 → 用 venv + pip 手动装。
3. **`box.x/y` 是中心不是左上角**：写成 0,0 只占左上四分之一（这条在 `render_composition` 的工具描述里也写着）。
4. **`animate.x/y` 是 0–100 百分比位置**：`translate((x−50)%, (y−50)%)`；与 `box` 互斥（`shape` 轨豁免）。
5. **数组 vs 字符串双语义**：`textCard.text` 是数组 = 作者显式分行（校验数组长度 + 每行 `maxCharsPerLine`）；是字符串 = 整块（校验总字数 + `\n` 行数）。**两者必须分开判**。
6. **容量按 variant 声明，不按字段逐个声明**（我们的内容角色由 `textCard.variant` 决定）。
7. **「有意两行标题」不是 bug**：真实项目里 `hook-title` = `["四季","是因为离太阳远近吗？"]`、`s6-title` = `["不是距离","而是倾斜"]` 都是作者有意的两行。
8. **`validateManifest` 报 ok ≠ 没溢出**：实测本方案自己的 manifest 初稿（B1 正文盒 900×105px）真实 `fitTextPolicy` 验算 = 24.2px / 2 行 / maxLines=1 ⇒ `overflow=true`，而 `validateManifest` 同时报 **0 error 0 warning** —— **零层拦截**。`check-fit.mjs` 是这个缺口的最小复现脚本。
