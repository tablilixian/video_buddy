# 风格前缀出图差异探针（V1）

- 固定用户提示词：`一位少女站在长安城楼上，远处是连绵的山脊与晨雾`
- 重复次数：1
- 端点：POST http://117.50.108.73:8082/api/v1/generate/txt2image（1280×736）
- 成功 2 / 失败 0

> **机器只负责产出可比对的图，不判定优劣。** 风格差异是否肉眼可辨、
> 哪条前缀真的生效，交给人工看图判断。

## 用例与产物

| # | 风格 | 前缀字数 | 耗时 | 产物 |
| --- | --- | --- | --- | --- |
| 20 | 图生图 无风格基线 | 0 | 25.8s | `20-i2i-baseline` |
| 21 | 图生图 + 电影感（59 字） | 59 | 23.4s | `21-i2i-cinematic` |

## 各用例最终提示词（与生产 composeImagePrompt 同构）

### 图生图 无风格基线

```
保持参考图中人物的发型、服装与体型完全一致，把她放到夜晚的城楼上，背景是远处的山脊与云雾
```

### 图生图 + 电影感（59 字）

```
电影质感，低饱和青橙色调，暗部厚重保留细节；高对比侧逆主光配柔和补光，背景自然虚化；细腻胶片颗粒与轻微暗角，克制而高级，保持参考图中人物的发型、服装与体型完全一致，把她放到夜晚的城楼上，背景是远处的山脊与云雾
```
