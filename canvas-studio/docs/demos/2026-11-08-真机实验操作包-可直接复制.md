## 2. 第一句 A · G1（跑次 1 / 3 / 5，整块一次粘贴）

```text
做一支 45 秒、16:9、30fps 的中文科普短片，题目《光的波长》。
内容讲清楚三件事：光是电磁波；波长决定我们看到的颜色；不同波长之间相差多少个量级。
中文配音 + 背景音乐。完成后交付成片。

【制作锚包 · 开工前已定，照此执行】

任务性质：翻拍，不是照抄。内容全部换成上面的题目，骨架、色板、构图规则、负面清单照下面执行。相似度档位 = 借骨架做差异（不逐镜复刻，也不只挑一两个装饰性手法）。

硬约束（逐条可判，违反即返工）：
N1 不要 PPT 卡片感：全片 textCard 轨 ≤ 2 条；无圆角面板、无边框容器。
N2 不要多色叠加：每帧主色覆盖 ≥ 75% 画幅；色板外主色 = 0。
N3 不要渐变 / 阴影 / 光晕：shape:'gradient' = 0；fx:shadow/glow = 0。
N4 不要硬切黑帧：段间首尾帧主色覆盖率 ≥ 60%。
N5 不要逐句字幕条：caption 轨 = 0；文字只当画面标签或满屏重音用。
N6 不要空概念段：每段至少 1 个几何主体 + 1 个标签。
N7 不要首帧 / 末帧裸：第 0 帧与末帧主体均可见。

色板（只能从这里取）：#1e1137 深紫主底（全片占 21.9%）／#fdfdfd 白／#eb2942 红／#33d1cd 青／#6e48f2 紫／#fae518 亮黄／#4100b2 深蓝紫／#dd0f78 洋红／#ececec 片尾浅灰。每段一个满屏底色 + 1–2 个主体色，不叠第三种大面积色。

参考片的色彩状态（照这个节奏排你的段落，内容换成波长）：
0–18s 深紫：六边形同心框 + 星空 + 黄四角星
20–48s 白：蜂巢六边形群、正弦波箭头条、彩虹扇形
50–68s 红：γ 射线尺度标注、氢原子圆
70–78s 青：低频波、小行星尺寸对照
80–100s 深紫→紫：蜂巢网格、电场/磁场三条波、一句自我推翻的纠误
110–143s 亮黄：手托球体、白条带、六边形收缩成一点
145–162s 浅粉：原子核 + 同心圆波纹
165–198s 深蓝紫：electric / magnetic field 波
200–203s 洋红：满屏粗斜体大字，全片唯一重音，只留 3–5s
205–279s 深紫→亮黄→浅灰：光点条带、星空收束、片尾卡

结构骨架：
1. 一个概念一屏，每段 15–30s；画面段落边界取概念边界，不取旁白句子边界。
2. 首尾回环：开场与收尾用同一几何母题（六边形／星空），尺度或颜色不同。
3. 全片约 10 个满屏色彩状态，靠整屏换色 + 主体连续变形推进；原片 279 秒里只有 2 个硬切，不靠剪辑。
4. 文字只有两种角色：小型全大写标签 / 一次满屏重音句。
5. 主体是纯代码几何（六边形 / 圆 / 正弦波 / 同心圆 / 箭头条），居中，占 40–80% 画幅。扁平矢量、无实拍、无摄影机、无景深。

手法卡（本片只准用这 3 张，每条含「不适合」）：
· 尺度阶梯：把同一个量在不同量级下画成可比的形状（原片用同一条正弦波对比 γ 射线 10 picometer ↔ 氢原子 ↔ 小行星 ↔ 无线电波）。用在题目存在跨量级可量化对象时。不适合：无量化对象的纯叙事件，不要为用而硬造数字。
· 朴素方案逐级失败：先给最常见的简化示意（光 = 一条正弦波），再明确推翻它（这图是骗人的），然后逐级补上真正的层次。用在科普题存在普遍误解时作开场。不适合：纯陈述型资讯，不要在没有误解可纠的题上假装纠误。
· 数值脊柱：选一个量（波长）贯穿全片，每一屏都在量它的不同侧面，结尾收束到它。不适合：多主题拼盘，不要把三个不相干的数轮流叫脊柱。

实现依赖：做不到就按下面换画法，开工前定，别做到一半才发现。
· 形状连续 morph：animate 不插值 d，做不到 ⇒ 整屏换色 + reveal:{kind:'wipe'} + 同构几何缩放接续（同一个六边形在不同段缩放/旋转/换色，让观众读出「同一个东西变了」）。
· 实心任意 SVG 路径：path 渲染写死 fill="none" 只能描边 ⇒ 用描边 path + draw 生长，实心块用 circle / polygon 组合替代，本次不改代码。
· 满屏白字蓝描边粗斜体：textCard 无描边空心字 ⇒ 实心白字 + 洋红底 + 极大字号 + 斜体，靠对比做重音（不加 fx:shadow，会破 N3）。
· 数百点星空 / 蜂巢群 / 角色表演：成本超标、无角色库 ⇒ 6–12 个 circle 稀疏点 + 缩放呼吸；角色用「六边形 + 两个小圆」符号替代，或干脆不出现。
```
