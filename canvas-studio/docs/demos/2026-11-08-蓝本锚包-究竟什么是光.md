## 4. 结构骨架

1. **一个概念一屏**，每段 15–30s，**画面段落边界取概念边界，不取旁白句子边界**。
2. **首尾回环**：开场与收尾用同一几何母题（六边形／星空），尺度或颜色不同。
3. 全片 **约 10 个满屏色彩状态**，靠**整屏换色 + 主体连续变形**推进；`scene>0.3` 硬切全片仅 2 个，不靠剪辑。
4. 文字只有两种角色：小型全大写标签 / 一次满屏重音句。
5. 主体是**纯代码几何**（六边形 / 圆 / 正弦波 / 同心圆 / 箭头条），居中，占 40–80% 画幅。扁平矢量、无实拍、无摄影机、无景深。

## 5. 手法卡（本片只准用这 3 张）

> 这就是「手法库」的最小实物：每条写 **做什么 / 什么时候用 / 不适合什么时候用**。三栏缺一不可，尤其第三栏。

| 手法 | 做什么 | 什么时候用 | **不适合** |
|---|---|---|---|
| **尺度阶梯** | 同一个量在不同量级下画成可比的形状（原片：γ 射线 10 picometer ↔ 氢原子 ↔ 小行星 ↔ 无线电波，全用同一条正弦波的波长对比） | 题目里存在跨量级、可量化的对象 | 无量化对象的纯叙事件；不要为了用而硬造数字 |
| **朴素方案逐级失败** | 先给出最常见的简化示意，再明确打上「这图是骗人的」推翻它，然后逐级补上真正的层次 | 科普题存在普遍误解时，作开场结构 | 纯陈述型资讯、品牌片；不要在没有误解可纠的题上假装纠误 |
| **数值脊柱** | 选一个量贯穿全片，每一屏都在量它的不同侧面，结尾收束到它 | 全片围绕同一个核心量 | 多主题拼盘；不要把三个不相干的数轮流叫「脊柱」 |

## 6. 实现依赖：开工前就定「做不到换成什么画法」

| 想要 | 现状 | **本次改用什么** |
|---|---|---|
| 形状连续 morph | `animate` 不插值 `d`，结构性做不到 | **整屏换色 + `reveal:{kind:'wipe'}` + 同构几何缩放接续**；同一个六边形在不同段缩放/旋转/换色，让观众读出「同一个东西变了」 |
| 实心任意 SVG 路径 | `path` 渲染写死 `fill="none"`，只能描边 | 描边 `path` + `draw` 生长；实心块用 `circle` / `polygon` 组合替代，**本次不改代码** |
| 满屏白字蓝描边粗斜体 | `textCard` 无描边空心字 | 实心白字 + 洋红底 + 极大字号 + 斜体，靠对比做重音（不加 `fx:shadow`，会破 N3） |
| 数百点星空 / 蜂巢群、角色表演 | 成本超标 / 无角色库 | 6–12 个 `circle` 稀疏点 + 缩放呼吸；角色用「六边形 + 两个小圆」符号替代，或干脆不出现 |
