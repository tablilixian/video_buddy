# 验收与交付纪律

> 这份分册管「**怎么验、怎么交**」——判据怎么取证、什么时候出片、交付前必须做什么。
> 契约坑（字段怎么写对）见 `references/pitfalls.md`；结构与卡片形态见 `references/explainer-patterns.md`。
> 证据来自科普 0.1 中文版 + 英文重制版两轮真机会话的验收（2026-11-04）。

## §1 首轮渲染就用 `spotFrames` 探针（P9）

**为什么**：实测单次探针 **1.5s**，全片 draft **24–29s**——**快 17 倍**。
事故里 20 次渲染有 10 次是无必要的全片 draft，前 6 次渲染**全是**全片 draft，
第 7 次才首次用上探针。

**怎么做**：

- **首轮渲染就用 `spotFrames`**，一次性覆盖**每条判据的代表性帧**
  （字幕卡取首帧 + 末帧、转场取窗口首尾、reveal 取揭示前后、图表取出现帧）。
- **全片 draft 只用于交付前定稿**——用户要看的是成片，不是探针。
- 探针**不落画布节点**（工具语义）：用户在画布上**看不见**探针产物，必须主动交代；
  实测一轮会话静默「探针 → 看图 → 改坐标」循环了约 50 分钟才被用户叫停。
- **静默自检 ≤2 轮**就必须出完整草稿落画布；每轮修改后重渲草稿，别攒到「自认为好了」才出片。

## §2 画面类判据**必须看图本身**（P8）

**为什么**：事故里 render #7 采的帧**正好在 callout 窗口内**，也确实调了看图工具，
但看的是 **32×18 的亮度字符网格**，结论写成「地球区域出现了代表地轴的亮条…以及**引线起点**」——
**把别的东西误认成引线**。结论看着有据，其实证据不支持。

**怎么算合格**：

- **成片像素**是画面类判据的**唯一**依据。看图本身，或可复算的像素统计。
- `inspect_image` 的 **grid / bbox 模式只用于「定位疑点」**——它能告诉你「这一带有个亮条」，
  **不能**作为「引线 / 文字 / 图形**存在与否**」的结论依据。
- **禁止以 manifest 字段自证画面效果**：manifest 里写了 `reveal` / `animate`，
  不等于画面上就有那个效果。事故 A4 正是凭 manifest 字段自证，漏检了整层不可见。

**取证方式必须在记录里标注**，每条判据归到一类：

| 取证方式 | 用于 |
|---|---|
| 成片像素 | 元素存在 / 位置 / 遮挡 / 排版溢出 |
| 音频实测（ffprobe） | 响度 / 静音段 / 音轨构成 |
| 工具调用实录 | 流程是否发生（探针是否发出、负例是否发出） |
| manifest 静态解析 | **只**用于结构性事实（字段、轨道重叠、时长） |
| 数据溯源比对 | 图表值 = 声明值 / 素材出处 |

## §3 负例必发闸门（P5）

**规则**：**正例成片交付后，必须在同一会话发出负例提示词，并验证它被拦。**

- **未执行不得结案**。录里查不到负例消息的，该判据如实记「未执行」，
  **本体裁不予结案**（六体裁批量验收材料 §〇.5 的硬闸门）。
- 事故：0.1 批 A8 负例**从未发出**，直到续跑批人工补上，**+245.7min**；
  负例因漏发无法判定，**卡住整批收口**。
- 负例的**预期拦截点**要写清楚（例：anchor 指向不存在的词窗口 ⇒ fail-fast 拒收，
  提示先补字幕词再锚，不得静默接受悬空锚点）。
- 发出后要**留下拦截证据**（错误文案 / 拒收位置），不是「发出去了」就算。

## §4 自验边界：机器判据归 agent，审美归用户

**机器判据**（有资格也有义务自检）：文字出画 / 轨道重叠（几何计算）/ 数据保真（图表值 = 声明值）/
响度（ffprobe 实测）/ 时长真值（`list_shots`）。
正面例：用响度实测推翻渲染报告的「纯 BGM」误报。

**美学判断**（没资格替用户做）：「好不好看」「风格喜不喜欢」。
看图工具可以查**错误**，不能替用户验收**审美**。

## §5 上下文预算（会话耗时的第一杠杆）

compaction 次数是健康度指标（实测一条片 3 次，每次后都要重读文档、重推状态）。

- references **按需取用**：只读当前链路要用的段落与分册，不要全部通读；
- bash 大输出写文件只回摘要（tail / 统计行），整段输出不进上下文；
- compaction 后只补读缺的部分，信任画布便签与 manifest 现状，**不重新考古**。
