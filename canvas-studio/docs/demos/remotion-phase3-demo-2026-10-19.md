## 二、故事正文

**《凌晨四点》** · 36 秒 · 1920×1080 · 30fps · 1080 帧 · 写实电影感

一句话：**天亮前的两个小时，城市在做最安静的事。**

| 幕 | 时长 | 画面 | 文字 | 观感要求 |
| --- | --- | --- | --- | --- |
| **S1 片头** | 90f / 3s | 近黑底 + 一条细横线 | 主标「凌晨四点」· 副标「城市还在睡」 | 主标**弹入**（有重量、轻微过冲）；副标接力；细线横向拉开 |
| **S2 空街** | 210f / 7s | 图 A：空荡的十字路口，湿沥青反光，冷蓝 | 无字幕（留白） | 画面**极缓推进**；一层**冷蓝色罩**从青蓝渐变到微暖，像天色在变 |
| **S3 便利店** | 210f / 7s | 图 B：街角便利店，暖白灯光溢出玻璃门 | 「灯，是留给还没回家的人」 | 店招处**叠一层发光**；字幕出现时音乐**自动压低** |
| **S4 首班公交** | 210f / 7s | 图 C：首班公交驶过空站台，车前灯拉出光带 | 「第一班车，载着第二班人生」 | 画面**横向缓移**；与 S3 之间用**带缓动的叠化**，不要硬切 |
| **S5 数据卡** | 120f / 4s | 纯排版（深色背景 + 竖排细线） | 「04:00 — 06:00」+ 两行小字 | 数字**逐字出现**，两行小字**错峰**跟进 |
| **S6 尾声** | 240f / 8s | 回到图 A，压暗 | 「天亮之前，谁都可以慢一点」 | 全片元素**统一退场**（下沉 + 淡出），不要一个个突然消失 |

**音频**：一段氛围/BGM（≈36s）；底部一细条**音频律动**贴着画面底边；全片首尾淡入淡出。

## 三、直接粘给客户端的提示词

> 复制下面整段，粘进客户端新建项目的输入框。

```
做一条 36 秒的 Remotion 代码驱动短片《凌晨四点》，1920×1080 / 30fps，写实电影感。
不要做分镜、不要关键帧、不要视频生成，直接出 Remotion 成片。

【素材】
1. 生成 3 张静图，统一风格（电影感、35mm、冷调、无人物正面、4:3 以上横构图）：
   A 空荡的城市十字路口，湿沥青反光，凌晨冷蓝
   B 街角便利店，暖白灯光从玻璃门溢出
   C 首班公交驶过空站台，车前灯拉出光带
2. 生成一段约 36 秒的氛围 BGM。如果音频生成失败，跳过音频轨继续出片，并在最后说明。

【分幕】6 幕，严格按下面时间轴与内容：
S1 3s 近黑底+细横线；主标「凌晨四点」，副标「城市还在睡」
S2 7s 图 A；无字幕
S3 7s 图 B；字幕「灯，是留给还没回家的人」
S4 7s 图 C；字幕「第一班车，载着第二班人生」
S5 4s 纯排版；大字「04:00 — 06:00」+ 两行小字说明
S6 8s 图 A 压暗；字幕「天亮之前，谁都可以慢一点」

【技术硬要求 —— 逐条都要用上】
- 6 幕的时间轴用 startAfter 顺序衔接，不要手算 startFrame
- 每幕结束都要有退场动画，不要硬消失；全片片尾统一退场
- 全片统一调色：轻微对比+饱和提升、偏暖、暗角 0.35、颗粒 0.15
- 缓动不要只用默认档：主标要有回弹感，线条与位移用带收束感的档位
- S2 要有一层色罩，颜色从冷到暖渐变，用图层混合压在画面上
- S3 店招处叠一层发光（混合模式）
- S3→S4 的转场要带缓动、时长 8~20 帧
- 字幕出现时 BGM 自动压低
- 底部音频律动用线条形态、平滑一些
- S5 数字逐字出现，两行小字错峰

【出片顺序】
1. 先用草稿质量档出一版，我看节奏
2. 再出一版标准档
3. 最后把渲染报告里的渲染耗时、单帧耗时、命中了几条编排体检、抽帧图片都给我
```

## 四、验收清单（人眼打勾）

### A. 观感（这条片子「好不好看」）

- [ ] **S1 主标**落位有轻微回弹，不是匀速推上去
- [ ] **没有硬切**：任两幕交界处都看不到「啪」一下的突跳
- [ ] **没有任何元素突然消失**（都是淡出/下沉退场）
- [ ] **全片有统一影调**：暗角在四角能看出来、暗部有细颗粒、整体偏暖
- [ ] **S2 天色在变**：蓝调渐渐往暖走，不是从头蓝到尾
- [ ] **S3 店招发光**：灯周围有溢出感，不是一块死白
- [ ] **S5 数字逐字出**，两行小字晚半拍跟上
- [ ] 全片不出现字压边、元素出画、转场叠影

### B. 引擎能力是否真的生效（三期重点）

- [ ] 渲染日志里有「顺序衔接已解析」那行，且 6 幕起点首尾相接无缝隙
- [ ] 编排体检（lint）条数 ≤ 3，且没有 ML-02（片尾前结束却没退场）
- [ ] 渲染报告里 `quality` 与所选的档一致
- [ ] 抽帧 ≥ 4 张（有转场时更多），能覆盖每一幕
- [ ] **对照**：把 `meta.look` 整段删掉再渲一版 —— 两版肉眼应有明确差别；文件大小也应不同

### C. 速度（三期 W5 的口径）

- [ ] `draft` 档出片明显更快（目标 ≥ 2.5×，看报告里的 `msPerFrame` 与 `totalMs`）
- [ ] 第二次渲同一 manifest（预热后）比第一次快，`warm` 字段为真

## 五、跑不通时的降级阶梯

| 现象 | 先降到哪一级 |
| --- | --- |
| 图像生成失败 / 风格不统一 | 去掉 3 张图，S2~S4 改用深色渐变块 + 大字排版，其余能力照测 |
| BGM 生成失败 | 跳过音频轨（`audioViz` 与闪避一并跳过），其余照测；**不要**为凑音频塞一条无关音乐 |
| 编排体检刷满 12 条 | 先只修 ML-02 / ML-09（出画与硬消失），其余留到下一轮 |
| 渲染超时 / 报错 | 先把时长砍到 18 秒（S1+S3+S6）确认链路，再逐幕加回 |
