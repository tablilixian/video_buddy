### 2.4 D-04 · D1 队列参数

- 宿主侧显式 **FIFO** 队列，渲染并发 **= 1**（客户端本来只能串行，多开只互抢 CPU/内存）；
- 队列上限 **4**，超出直接拒收（`CS-USER-ERR`，文案「渲染队列已满，请等当前任务完成」）；
- 超时改为按片长自适应：`timeoutMs = clamp(2 × 声明时长 + 120s, 10min, 30min)`，替换固定 10min（`render-job.ts:28`）；单测注入值断言同步改。

现状依据：`pendingRenderJobFor(projectId)` 只返回第一张工单（`render-job.ts:99`），客户端 `client/index.ts:1371` 会 abort 上一个 ⇒ 现在是「隐式排队 + 无顺序 + 无进度 + 无上限」。

## 三、批次 1a · A1 语义原语（`orbit` + `draw`）

> **已定取 2 个号**（2026-10-17）：① 契约 + 纯函数 + 校验；② 组件接线 + 真渲取证 + skill 同步。开工时取号。

### 3.1 目标与边界

- **做**：`orbit`（公转关系）与 `draw`（路径生长）进 manifest 契约；补最小 `shape:'path'`（`draw` 的载体）。
- **不做**：`pulse`（退回 skill 范式，见路线图 A1 收窄）；不做通用路径变形（morph）；不做可视化编辑。
- **为什么值**：现在「行星绕太阳」要模型内联上百个关键帧（`motion-helpers.mjs` 手算像素），既贵又易错；原语化后一行声明。

### 3.2 契约草案（可直接抄进 `manifest.ts`）

```ts
/** A1：公转（帧级，纯函数求值）。坐标系与 VisualState 同域：0–100 百分比。 */
export interface OrbitMotion {
  /** 圆心（百分比坐标）。 */
  center: { x: number; y: number }
  /** 半径（与 x/y 同单位，> 0）。 */
  radius: number
  /** 起始角度（度）。0° = 正右（+x），角度增大 = 顺时针（屏幕 y 向下）。缺省 0。 */
  startAngle?: number
  /** 转一圈所需帧数（> 0）。缺省 = 本轨 `durationInFrames`。 */
  periodInFrames?: number
  /** 方向；缺省 'cw'。 */
  direction?: 'cw' | 'ccw'
}

/** A1：路径生长（仅 `shape:'path'` 轨可用）。 */
export interface DrawMotion {
  /** 生长到多少比例（0–1），缺省 1 = 全画出。 */
  to?: number
  /** 轨内相对起始帧（缺省 0）。 */
  startFrame?: number
  /** 生长耗时（帧，缺省 = 整轨）。 */
  durationInFrames?: number
  /** 缓动，沿用 `AnimateEasing` 白名单。 */
  easing?: AnimateEasing
}
```

`BaseTrack` 增一个可选字段（**只加不改**）：

```ts
  /** A1：公转。与 `transform` / `animate` 的位置维度**互斥**（见 validateManifest）。 */
  orbit?: OrbitMotion
```

`ShapeTrack` 增 `shape: 'path'` 分支与三个字段：

```ts
  /** 'path' 时必填：SVG path 的 d，坐标空间 = 0–100 双轴百分比。 */
  d?: string
  /** 'path' 时描边宽度（相对画布宽度的百分比，缺省 0.5）。 */
  strokeWidth?: number
  /** 'path' 时生长控制；缺省 = 全画出。 */
  draw?: DrawMotion
```

### 3.4 校验规则（`validateManifest` 新增）

| 规则 | 报错文案要点 |
|---|---|
| `orbit.radius` 必须是 (0, 100] 的有限数 | 指明轨道 id + 实际值 |
| `orbit.center.x/y` 必须 0–100 | 同上 |
| `periodInFrames` 若给必须 > 0；缺省取轨道时长，轨道时长 ≤ 0 时直接报错（防除零） | 指明需要显式给 |
| `startAngle` 必须有限（允许任意度，内部取模） | — |
| `direction` 只允许 `cw` / `ccw` | — |
| **互斥**：轨道有 `orbit` 且（`transform.x/y` 或任一 `animate` 含 x/y）⇒ 报错 | 「位置已由 orbit 决定，请移除 transform/animate 的 x/y」 |

> ⚠️ **极易漏的一步**：`KNOWN_BASE_TRACK_KEYS`（`manifest.ts:285`）与 `KNOWN_TRACK_KEYS.shape`（`:290`）是「契约外字段告警」的唯一事实源。新增 `orbit` / `d` / `strokeWidth` / `draw` 若不同步这两张表，**每条用到新字段的 manifest 都会带一条『契约外字段』告警**——模型会以为自己写错了。验收时必须断言「合法新 manifest 的 warnings 为空」。

> ⚠️ **命名冲突（路线图漏了）**：`effect` 这个字段名**已被 `TransitionTrack` 占用**（`manifest.ts:187`，值域 `fade|slide|zoom|dissolve`）。A2 若照路线图写 `effect` 会与转场轨语义撞车，`KNOWN_TRACK_KEYS` 也没法区分。**已定改用 `fx`**（见 D-11）。

- 接线：效果**统一在 `resolveAnimatedStyle` 里折算成样式串**（`AnimatedStyle` 增 `cssFilter?: string` / `textShadow?: string` / `maskImage?: string`），组件只负责贴。理由与「唯一接线点」同源：写进组件就会出现「某个组件忘了读」。
- 依赖：可选 `@remotion/animation-utils`；**已定不装**，手写 CSS 足够（5 种效果 ~40 行），少一个依赖少一处锁版风险。
- 同步：`KNOWN_BASE_TRACK_KEYS` 加 `fx` + `ANIMATED_FX` 白名单 + 校验。
- 验收：5 种效果各渲一张静帧比对（人看）+ 单测「非法值报错、`fx` 不再触发契约外字段告警」。

### 5.2 A3 形状库

- 补装 `@remotion/shapes`（exact 4.0.535）；新增 kind：`arrow` / `triangle` / `star` / `polygon`。
- **老 4 种保持手写**（D-03），`shape:'path'` 已在 1a 落。
- `manifest.ts`：`SHAPES` 白名单**已存在**（`:230`，`rect|circle|line|gradient`），校验也在（`:554`）。A3 要同步改三处：`ShapeTrack['shape']` 联合类型（`:178`）、`SHAPES` 集合（`:230`）、`Shape.tsx` 分支（`:25-39`）。
- 验收：4 种新形状各出静帧；非法 kind 校验报错（现有机制，补一条新形状的负例）；**老 4 种像素不变**（同一条 manifest 改前/改后各渲一次比像素）。

### 5.3 A4 转场库

- 落点：`timing.ts` `transitionOverride` 扩 `TransitionEffect` 枚举：`wipeLeft` / `wipeRight` / `clock` / `flipX`；同时扩 `EFFECTS`（`manifest.ts:231`）与 `TransitionTrack['effect']` 联合（`:187`）。
- `TransitionShell`（`Transition.tsx:11`）增 `clipPath` / `rotateY` 两种原语；`TrackTransitionOverride` 字段扩展。
- **不装 `@remotion/transitions`**（D-03）。
- 验收：每种转场渲 3 帧（起/中/末）无闪帧（人看）+ 单测 `transitionOverride` 新分支的边界值（t=0/0.5/1）+ **老 4 种转场像素不变**。
- 风险：`clipPath` 在 CSR 编码里是合成层操作，注意**不要用 CSS `transition`**（铁律②），全部按帧求值。
