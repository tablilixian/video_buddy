**⚠️ 复制后必须处理的 5 点（直接 `cp` 会白屏或找不到二进制）**：
1. **`@remotion/bundler` 要装进产品仓**：现在只在 spike 的独立 npm 树里。`canvas-studio/package.json` 加 devDependency `@remotion/bundler@4.0.535`，然后 `corepack yarn install`（会改根 `yarn.lock`，**与代码同批提交**）。`enableScripts:false` 对它是安全的（纯 JS，无 postinstall）。
2. **React 单实例**：Remotion 的 bundler 会**自己注入 `resolve.alias`**（`react` / `react/jsx-runtime` / `react-dom/client` / `remotion` → **bundler 自己的 node_modules**）。spike 里 bundler 与产品不同树，导致 `react 19 + react-dom 18` 混用 → 渲染进程抛 `Cannot read properties of undefined (reading 'ReactCurrentBatchConfig')` **白屏**。**入库后 bundler 就在 `canvas-studio/node_modules`，注入的 alias 自动指向产品树（react 18.3.1）⇒ 该附加 alias 可去掉**；但**必须实跑复核**（`S10_BUNDLE_ONLY=1` 先过打包，再用 sourcemap 的 `sources` 确认 `node_modules/react` 只有一份）。
3. **`extensionAlias` 必须保留**：产品源码用 `../manifest.js` 这类 ESM specifier 指 `.ts/.tsx`，webpack 需 `resolve.extensionAlias = { '.js': ['.ts','.tsx','.js'] }` 才能映射。
4. **路径基准要改**：`ROOT/REPO/compositorDir` 现值基于 spike 目录。
   - `compositor-darwin-<arch>` 改为从 **`canvas-studio/node_modules/@remotion/`** 找（产品装了 remotion 就有；ffmpeg/ffprobe 也在这，需 `DYLD_LIBRARY_PATH=<该目录>`）。
   - `electron` 仍用 `createRequire(join(REPO,'dsh-plugin-desktop','package.json'))('electron')`：从 `canvas-studio/scripts/remotion-verify/` 上溯三级 = 仓根 ✅ **不用改**。
   - 入口 import 的 `../../../src/remotion/components/Root` 深度同样不变 ✅。
5. **`assets/` 别入库**：临时素材（4 个二进制）让 `make-assets.mjs` 现造；在 `scripts/remotion-verify/` 下加 `.gitignore` 兜 `assets/` 与 `out/`。

## 五、本轮新踩的坑（血泪，别重复踩）

1. **白屏第一嫌疑永远是"React 不是单实例"**：症状 = 窗口白 + 页面无任何日志；根因见 §四.3-2。**排查靠 Electron 外壳转发 `console-message`**（`app-s10/main.js`），否则页面报错完全看不见。
2. **bundle 入口必须调用 `registerRoot`**，否则整页 JS 不执行（白屏无日志）。不想注册得传 `ignoreRegisterRootWarning: true` —— 但**那样页面根本不会跑**，只有纯 Node 侧 `renderMedia` 场景才适用。
3. 页面日志元素**必须挂 `documentElement`**（挂 `body` 会被 Remotion 的 bundle 清掉）。
4. **必须显式 `outputTarget: 'arraybuffer'`**：默认解析结果是 `web-fs`（`canRenderMediaOnWeb` 回显 `resolvedOutputTarget:'web-fs'`），需用户手势、后台渲染不可用。
5. 静态服务器**不支持 Range(206)** 时，mediabunny 会退化为顺序流式读取并打印警告（**产品侧真实资产路由应支持 206**，否则大 clip 读取低效/可能抛错）。
6. `licenseKey: 'free-license'` 可消掉 Remotion 的许可告警（NFR-1 已确认两人公司 Free 覆盖）。

## 八、环境与纪律（延续 + 本轮补充）

### 环境事实
- 开发机 **Intel Mac**（x86_64）⇒ `compositor-darwin-**x64**`；**无 GUI 的 agent 会话跑不了 CSR**（S10/S7/S8 必须在用户终端跑）。
- **Electron 43.4.0 = Chromium 150.0.7871.224**；Remotion **4.0.535**；CSR 编码器实测 `["h264","h265","vp8","vp9","av1"]` × `["aac","opus","mp3","pcm-s16","flac"]`。
- **产品仓没有系统 ffmpeg，也没有 ffmpeg-static 二进制**（`.yarnrc.yml` 的 `enableScripts:false` 跳过 postinstall）——但 **Remotion 的 `@remotion/compositor-darwin-*` 自带一份 minimal ffmpeg/ffprobe**（有 libx264/aac/mp4 muxer/image2/lavfi 的 sine，**没有** testsrc2/gradients 等视频源滤镜），够造测试素材；调用需 `DYLD_LIBRARY_PATH=<compositor 目录>`。

### agent 会话沙箱
- 跑 Remotion 脚本须 **`NODE_OPTIONS= node …`**；`bundle({ outDir })` 必须显式给；手动 spawn Chromium/Electron 加 `--no-sandbox`（Electron 外壳有 `CSR_NO_SANDBOX=1` 兜底）。
- `ps` 沙箱内不可用；macOS 无 GNU `timeout`（用脚本内 `*_TIMEOUT_MS`）。
- **Electron 把目录当 app 启动必须有 `<dir>/package.json`（含 `main`）**（本会话踩过：只放 `main.js` → 静默起不来）。

### 工程纪律
- **no-git-commit until acceptance**：改完先自检，等用户验收；**说「提交并推送」才 push**。
- 提交前：`git fetch origin dev` 核对 + `git diff --cached` 密钥扫描（sk-/api_key/secret/Bearer/ghp_/AKIA）。
- **用第三方新 API 前先读它的 `.d.ts`**（本会话第三次救场：`renderMediaOnWeb` 要 `inputProps`、`audioCodec`、`licenseKey`）。
- 沙箱内 build 首步 `clean.mjs` 会撞批量删除阈值 ⇒ 逐步骤 `node node_modules/.bin/tsdown && tsc -p tsconfig.json && tsc -p tsconfig.client.json --emitDeclarationOnly`。
- 局部校验用 `node node_modules/.bin/tsc -p tsconfig.json --noEmit`（`npx tsc` 会报 "not the tsc command"）。
- 新测试严禁塞进 `baseline-red.json`。

## 十、关键 API 速记（CSR / 路线 B，更新版）

- `renderMediaOnWeb({ composition, inputProps, container:'mp4', videoCodec:'h264', audioCodec:'aac', outputTarget:'arraybuffer', licenseKey:'free-license', onProgress, signal })` → **`getBlob()`**
  - `composition` = `{ component, id, durationInFrames, fps, width, height, defaultProps, calculateMetadata }`；**`inputProps` 与 `defaultProps` 都要给**。
  - 取消 = **标准 `AbortSignal`**（不是 `makeCancelSignal`）。
- `renderStillOnWeb({ composition, inputProps, frame, licenseKey })` → **`.blob({ format:'png'|'jpeg'|'webp' })`**（**不是** `getBlob()`）。
- `getEncodableVideoCodecs(container)` / `getEncodableAudioCodecs(container)`：**container 是位置参数**。
- `canRenderMediaOnWeb({ container, videoCodec, width, height })`：**不收 composition，width/height 必填**；回显 `resolvedVideoCodec/resolvedAudioCodec/resolvedOutputTarget`。
- **`bundle()` 入口必须 `registerRoot`**；`resolve.extensionAlias` 是解析产品 `.js` specifier 的关键（§四.3-3）。
- `@remotion/media` 的 `<Video>`/`<Audio>` 是 CSR 唯一可用媒体组件；`objectFit` 走 **prop** 不走 `style`；`<Video>` **自带音轨**。
- canvas-studio 侧复用点（route B 都要）：`appendComposedVideoNode`(`compose.ts:628`) / `ComposeResult`(`:63`) / `urlToAssetPath`(`:118`) / `saveLocalAssetBytes`(`generate.ts:1110`) / `pollGenerationQueue`(`client/index.ts:1265`) / `registerStudioRoutes`(`routes.ts:542`) / `upload-media` + `readRawBody`(`routes.ts:2189`/`:455`)。
