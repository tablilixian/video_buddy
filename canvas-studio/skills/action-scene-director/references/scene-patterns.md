# 题材场景配方

本文件给出动作场景在**不同题材**下的"场景配方"——即在四条铁律（时序拆段 / 动作因果链 / 环境反馈 / 资产锁定）之上，按题材微调的节奏、地面材质、环境反馈词库、运镜与常见失败模式。

SKILL.md 第一步的"题材类型"决定选用哪一套配方。同一段戏只选一种题材配方主导，不混用。

---

## 题材一：近身对打

**适用**：武侠 / 格斗 / 室内近战 / 一对一贴身交锋。
**节奏微调**：蓄力 ~25% / 爆发 ~55% / 余韵 ~20%——爆发段占比最高，因为近身戏全靠连续因果动作链撑起打击密度。

**地面材质与反馈词库**：

| 地面材质 | 反馈词汇 |
|----------|----------|
| 木地板 | 木屑飞溅、地板震颤、鞋底摩擦痕、断木横飞 |
| 石板 / 青砖 | 石屑迸裂、裂纹蔓延、碎砖滚落 |
| 金属台面 | 火花四溅、甲板震颤、铆钉松动、刮擦白痕 |

**运镜**：爆发段贴身手持跟拍（轻微震动强化打击感），蓄力段低角度仰拍对峙，余韵段缓推或定帧。
**因果链重点**：每个格挡 / 闪避都要能回答"上一个动作给了什么条件"——对手挥拳→女主侧身借力旋踢，而非凭空换位。
**常见失败模式**：十几个动作塞进一个阶段（模型混乱）、孤立位移（瞬移穿模）、打击无环境反馈（轻飘飘）。

## 题材二：载具追逐

**适用**：车追车 / 摩托追逐 / 飞船缠斗 / 任何带机动载具的高速戏。
**节奏微调**：蓄力 ~20% / 爆发 ~60% / 余韵 ~20%——以"追逐—逼近—险险错身"为循环，爆发段最密。

**核心约束**：
- 载具是"角色"的延伸——资产锁定段必须声明载具外观（车型 / 涂装 / 损伤状态）全程不变，与人物锁定并列。
- 速度感靠**环境参照物后掠**实现：路牌、护栏、电线杆快速倒退，而非单纯写"很快"。
- 因果链体现在"博弈"：前车急刹→后车侧滑避让→借惯性切入内线。

**环境反馈词库**：

| 环境 | 反馈词汇 |
|------|----------|
| 城市道路 | 轮胎摩擦白烟、护栏火花、玻璃碎渣、落叶被气流卷起 |
| 荒野土路 | 尘土尾迹、碎石迸射、车辙深陷、植被被碾倒 |
| 空中 / 太空 | 尾焰拉长、云层撕裂、碎片飘散、能量护盾涟漪 |

**运镜**：长焦跟拍保持速度压缩感；错身瞬间切广角展现场景尺度；碰撞用短促手持抖动。
**常见失败模式**：载具外观逐帧漂移（未锁定）、速度感缺失（只写"高速"无参照物）、追逃双方距离忽远忽近（因果断裂）。

## 题材三：群战

**适用**：多对多混战 / 小队遭遇战 / 围攻。
**节奏微调**：蓄力 ~30% / 爆发 ~50% / 余韵 ~20%——蓄力段用于建立"敌我数量与阵型"，避免一上来就乱。

**核心约束**：
- **群体敌人分层写**（SKILL.md 进阶规则 6）：交代数量与行为顺序（"6 只伴猎怪纷纷转身嘶吼，其中 2 只率先扑出"），镜头明确拍出该顺序。
- **对手面孔规则**：多对手头部形状 / 鳞片颜色 / 眼睛大小必须各不相同，禁止与主角相似（见 action-rules.md 铁律四）。
- 焦点切换：每段只聚焦 1-2 个交战单元，其余用"背景群像"虚化处理，避免全景塞满动作导致模型失焦。

**环境反馈词库**：复用铁律三的地面材质表，叠加"群体规模感"词汇——尘土被多脚踩踏成雾、碎屑成片飞溅、金属撞击声叠成轰鸣。

**运镜**：先广角建立战场阵型，再切中景跟拍主角单元，关键时刻特写单个对手差异。
**常见失败模式**：敌我数量忽多忽少（未锁定群像规模）、对手长相一致（面孔规则失效）、全景动作过载（模型失焦）。

## 题材四：巨型生物对决

**适用**：人类 / 机甲 vs 巨兽 / 哥斯拉式对峙 / 巨物压迫戏。
**节奏微调**：蓄力 ~35% / 爆发 ~45% / 余韵 ~20%——蓄力段最长，因为"巨物压迫感"靠建立尺度差而非动作密度。

**核心约束**：
- **尺度差是第一优先级**：用参照物锚定巨兽体量（"巨兽一步跨过整条街道""女主仅及其脚踝"），环境反馈以"大规模破坏"为主。
- 人类动作在巨兽节奏里是"插针式"——人类快速闪避、巨兽缓慢碾压，两套时序并行（人类 2-3 秒单元 vs 巨兽一次动作跨多单元）。
- 资产锁定：巨兽的鳞甲 / 骨刺 / 眼睛颜色必须全程一致，且每次只拍其局部（爪、眼、躯干）避免整身形变。

**环境反馈词库**：

| 破坏对象 | 反馈词汇 |
|----------|----------|
| 建筑 | 墙体崩塌、砖石暴雨、玻璃幕墙碎裂、尘柱冲天 |
| 地面 | 地裂纵深蔓延、沥青翻卷、坑洞炸开 |
| 植被 | 巨树拦腰折断、树冠成片倒伏、根系拔地而起 |

**运镜**：人类视角低角度仰拍巨兽制造压迫；巨兽动作切极远航拍展现场景尺度；命中瞬间短促微慢动作（≤0.3 秒）。
**常见失败模式**：巨兽体量与参照物矛盾（忽大忽小）、人类与巨兽时序不同步（穿模）、整身巨兽形变（未锁定局部拍摄）。

## 跨题材共性提醒

1. 四类配方都建立在四条铁律之上，不违反铁律去套配方。
2. 三拍式（蓄力 / 爆发 / 余韵）是总框架，本文件的"节奏微调"只改占比，不改结构。
3. 资产三类模式（角色定妆 / 场景空镜 / 道具资产）见 `asset-patterns.md`，配方中涉及的载具、巨兽、群像都需先锁定资产再开拍。
4. 音效层：默认"不要音乐，只保留音效"，四类题材的环境反馈词汇可直接映射为对应音效（碎石 / 金属撞击 / 引擎 / 建筑崩塌）。

## 与 H3 IR 的转换

题材配方里的"节奏占比 / 环境反馈词汇 / 尺度差"在转 H3-Context-IR 时对应：

- 节奏占比 → `integrated_multimodal_description` 的 `[Shot N]` 时间戳跨度分配
- 环境反馈词汇 → 主描述的环境描写 + `overall_soundscape` 的环境音
- 尺度差锚点 → `subject_definitions` 中角色与巨兽的 size 关系声明
