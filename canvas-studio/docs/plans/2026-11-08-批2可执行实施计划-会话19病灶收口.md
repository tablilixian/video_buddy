## 1. 第 1 批 · 逐项实施拆解（拍板即可开工；全部插件侧，T3 验证）

### 1.1 turn 异常死亡 → 桌面通知薄版（P1 ①）

- **现状**：turn/end reason ∈ {max-tokens, auth, error} 时无任何用户可见信号——会话 19 三次死亡分别发生在 23:16 / 次日 09:07 / 09:34，用户全靠手动发现。
- **改动**：dsh-plugin-desktop 桌面层监听 turn/end（接线先例 = `src/index.ts:439` 的 `session/event`），reason.kind ∈ {max-tokens, auth} ⇒ 系统通知「创作回合已中断（原因），点击继续」；点击 = 复用既有「继续」入口发一条续跑消息。
- **锚点**：先查桌面通知链路（Electron `Notification` 或应用内 toast 的既有形态，P2-B「AUTH 通知」同链路可合并设计）——**这是本项第一步，未查清前不动码**。
- **验收**：单测模拟 turn/end 事件 ⇒ 通知触发断言；反向变异（移除监听 ⇒ 红）。真机：人为触发（临时调小 maxTokens 或等待自然触发）⇒ 通知出现且可一键继续。
- **刻意不做**：自动续跑（无人工确认的自动续跑可能把错误方向跑满一晚——先薄版拿数据）。

### 1.2 scaffold 前置闸 + builder 生成标记（P2）

- **闸（拒收）**：`render_composition` execute 入口（`host-tools.ts:3651/:3704`）前置检查 per-project 状态（按 `projectId` 的 Map，仿 `render-host-fallback.ts` 形态）：`write_storyboard 已落地 && scaffold_manifest 从未调用` ⇒ `CS-USER-ERR` 拒收，文案：「先 `scaffold_manifest` 出骨架（M1：落地后 20 分钟内首片），再把内容表填进 `build/manifest-spec.json` 跑 builder，不要手写 manifest」。状态在 scaffold 首调后清除。
- **标记（观察期 warning）**：`manifest-builder.mjs` 写 `build/manifest.json` 时加 `meta.generatedBy: 'manifest-builder'`；render_composition 对缺标记的 manifest 发 warning（观察期，不拒收——存量手写项目会告警一次，登记后决定是否升硬闸）。
- **文案**：`write_storyboard` 回执（`host-tools.ts:3940` execute）尾行补：「下一步立即 `scaffold_manifest`；禁止手写 `build/manifest.json`（会绕过字段校验与 builder 契约）」。
- **验收**：正向 = builder 流全绿零告警（现有 `tests/manifest-builder.test.mjs` 扩一条 generatedBy 断言）；反向 = ①未 scaffold 直接 render ⇒ 拒收文案断言；②手写 manifest 缺标记 ⇒ warning 断言。全量 smoke + 反向变异。

### 1.3 契约生成物「行为语义」扩容 + SKILL 指针强化（P3）

- **证据**：会话 19 模型读过 generated.md（以及 builder.md）后仍读源码 60 次——它要的是**行为语义**（这套机制怎么表现），而生成物只回答「哪些值合法/默认是多少」。
- **改动**：`gen-component-contract.mjs` 的静态 header 段后追加「行为语义速查」手写段（随文件一起过 --check 门禁，不会漂）：
  - reveal 进场/退场两口径（`direction` = 可见区自该侧展开；退场擦除用 `reveal.out`，exit 不支持 clip）；
  - gauge = values 恰 1 项 + `gaugeMax`，指针/进度环用法；
  - countUp = 数值前 45 帧缓出滚动（`count-up.ts` 同语言），标签纪律见 ML-14；
  - subtitle-fit 折行与 `fontSize` 缺省公式（= canvasHeight×0.11，720p 即 79px——四季片踩坑点）；
  - `draw` 虚线坑 → 指向 pitfalls §9（不传 draw 的规避）；
  - `audioFrames` 填法 → 指向 manifest-builder.md 字段表。
- **SKILL.md:101 指针强化**：「生成物没覆盖到的，先在回复里**点名缺口**（引用生成物条目名），再读源码，并把缺口写进交付未决项」——缺口声明既是行为约束也是生成器迭代输入。
- **验收**：`--check` 一致 + 体积闸（generated.md 预计 5.5KB → ~8KB，远低于相关闸）；真机判据 = 读 `src/remotion/**` bash ≤12 次（会话 19 为 60）。
